# Legacy Materials

本目录保存从旧版 AIGC 中隔离出来的历史项目资料和旧工具链。

这些内容只用于人工追溯或后续能力演化分析，不属于当前通用 AIGC 默认读取路径。

## 默认规则

- 默认不得读取本目录。
- 不得把本目录内容当作当前通用框架规则执行。
- 需要从旧资料提取可复用能力时，必须进入 `AIGC/workflows/capability-evolution/WORKFLOW.md`。
- 提取时只读取入口、索引和与本轮目标直接相关的最小文件集合。
- 旧项目事实不得迁回 `AIGC/wiki` 或通用工作流。
