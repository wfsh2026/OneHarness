## S-04.5 架构预分析

本工具不创建 Unity System/Component，而是**生成创建它们的代码文件**。工具本身是纯 bash 脚本，不涉及 C# 编译或 Unity 运行时。

## S-06 脚本执行流程

```
ability-gen.sh 接收命令行参数
    │
    ▼
[验证阶段] 检查参数完整性 + 目标路径可写 + 文件不重复
    │ 失败 → 报错退出（exit 1）
    ▼
[ID 分配] 解析现有 Config 文件获取最大 ConfigId / FuncId
    │ ConfigId = max_existing + 1
    │ FuncId = max_existing + 1
    ▼
[创建阶段] heredoc 生成 6 个新文件
    │ AbilityM_{Name}.cs
    │ AbilityM_{Name}_Select.cs
    │ S{AB|AE}_{Name}System.cs
    │ C{AB|AE}_{Name}System.cs（条件）
    │ Rpc_{Name}.cs
    │ AbilityM_{Name}.csv
    ▼
[注册阶段] sed 修改 5-6 个现有文件
    │ Config: const + string + 2 switch
    │ ServerManager: switch case
    │ ClientManager: switch case（条件）
    │ Proto: FuncID + switch case
    ▼
[输出摘要] 列出所有创建/修改的文件路径
    │
    ▼ exit 0
```

## S-08 边界条件

### 依赖外部接口
- Mac 系统的 `sed`（BSD 版本），需 `sed -i ''` 语法
- `grep` 用于幂等检查和 ID 解析
- `awk` 用于数字提取

### 禁止做的事
- 禁止覆盖已存在的文件（防止破坏手写代码）
- 禁止在脚本中硬编码绝对路径（必须相对于项目根目录）
- 禁止跳过注册步骤（原子性要求）

### AB vs AE 差异表

| 差异点 | AB | AE |
|--------|----|----|
| ConfigId 起始值 | 10000 | 20000 |
| Config 文件 | `AbilityConfig_AutoGenerated.cs` | `AbilityEffectConfig_AutoGenerated.cs` |
| ModID | 14 | 15 |
| Proto 文件 | `14_Proto_AbilityAB_Auto.cs` | `15_Proto_AbilityAE_Auto.cs` |
| Switch 前缀 | `SwitchAB` / `SwitchAB` | `SwitchAE` / `SwitchAE` |
| currentState | AB | AE |
| RPC 接口 | `IAbilityABCreateRpc` | `IAbilityAECreateRpc` |
| InData | `AbilityIn_{Name}` (有 `In_StartPoint:Vector3`) | 无 InData |
| RPC 特有字段 | `startPoint:Vector3` | `gpoId:int` |
| Server System 特有 | `useInData = (AbilityIn_{Name})InData` | 无 InData 行 |

## S-09 验收标准

- [ ] **编译层**：ability-gen.sh 生成的所有 .cs 文件可被 Unity 编译通过（无语法错误）
- [ ] **结构层**：生成的 `AbilityM_{Name}_Select.cs` 与现有 `AbilityM_Bomb_Select.cs` 结构完全一致
- [ ] **注册层**：所有注册文件的 switch case 和 const 定义格式与现有条目一致
- [ ] **幂等层**：重复运行相同参数，脚本提示已存在并跳过，不产生重复注册
- [ ] **AB/AE 分支**：AB 和 AE 两种类型均能正确生成对应差异代码

## 附录：命令行参数规格

```bash
ability-gen.sh \
  --name <AbilityTypeName>       # 必填，如 Fireball
  --type <AB|AE>                 # 必填，技能类型
  --fields <field_list>          # 必填，M_ 字段定义，如 "M_Power:int,M_LifeTime:float"
  --csv-fields <field_list>      # 必填，CSV 导出字段列表
  --primary-keys <key_list>      # 可选，主键字段列表
  --sync-client <true|false>     # 必填，是否同步客户端（IsSyncCreateCAB）
  --in-fields <field_list>       # 可选，AbilityIn 字段（仅 AB），如 "In_StartPoint:Vector3"
  --project-root <path>          # 可选，项目根路径，默认当前目录
```
