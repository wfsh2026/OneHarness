## 一、测试前准备

### Editor 环境
- 打开 BR 模式场景
- 确认 `SOCarSkill.txt` 中 MotoSheep skill1 CD = **10s**（测试值，正式改回 30s）
- 确认 `AbilityM_RainbowLeap.csv` 已配好数值（RampLength=30, SprintLength=50, RampAngle=30, Duration=5）
- 打开 Console 窗口，过滤 `[SABC]` 和 `[CAB_RainbowLeap]` 标签观察日志

### 真机环境
- Build APK 并安装
- 确认可进入 BR 模式、找到 MotoSheep 并上车
- 准备 Logcat 过滤 `Unity` tag 观察日志

### 通用操作说明
- **释放技能**：驾驶 MotoSheep 时按 E 键 / 点击技能 GUI 按钮
- **观察控制台**：注意 `[SABC]` 打头的射线检测日志和 `[CAB_RainbowLeap]` 打头的客户端日志
