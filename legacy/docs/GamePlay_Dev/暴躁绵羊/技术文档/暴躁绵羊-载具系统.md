## S-03：功能需求

玩家在 BR 模式中发现 MotoSheep 载具后，可以上车驾驶，体验高耐久（HP 1230）、高操控性（转向角 44°）的重型街机摩托车，支持双人骑乘、氮气加速、主动跳跃。

---

## S-04：功能定位

本文档负责 MotoSheep 载具的注册、配置、物理参数、预制结构、输入控制与 UI 图标。职责边界：不涉及彩虹飞跃 Ability 的实现（由 Ability 子文档覆盖），不修改 MotorCarController 核心物理逻辑。

## S-04.5：架构预分析

**N/A（无新建 System/Component）**

MotoSheep 复用 PonyVehicle 的 `MotorCarController` + `Car` + `CarShift` + `CarNet` 整套架构，不新建 System 或 Component。新增内容限于：
- 配置数据（SOCarData + MotorCarSetting）
- 输入注册（VehicleStateButtonControl switch case）
- 预制体（拷贝 PonyVehicle 改名）
- 技能触发控制器（MotoSheepSkillController，纯客户端 MonoBehaviour，非 System/Component 体系）

## S-06：ASCII 交互链路图

### 6.1 上车流程

```
玩家靠近 MotoSheep → 显示交互提示
    │
    ├── [PC] 按 F 键 / [Mobile] 点击交互按钮
    │       ↓
    │   ClientSend: CMD_InteractVehicle { vehicleId, seatIndex=0 }
    │       ↓
    │   Server: StartGame.AddCarForData() 验证 → 挂载玩家到座位
    │       ↓
    │   ServerSend: RPC_VehicleState { playerId, vehicleId, seatIndex }
    │       ↓
    │   Client: 切换输入设备为载具 → VehicleStateButtonControl 注册按钮
    │       ↓
    │   UI 显示: 加速按钮(Dash) + 下车按钮(GetOut) + 换座按钮(Seat) + 技能按钮(Skill)
```

### 6.2 驾驶操控流程

```
玩家输入 WASD / 摇杆
    │
    ├── MotorCarController.ApplyInput(steer, throttle, brake)
    │       ↓
    │   WheelCollider 物理模拟 → Rigidbody 运动
    │       ↓
    │   CarNet: 位置/旋转网络同步 (CarNetServer → CarNetClient)
    │       ↓
    │   视觉车轮旋转 + 转向表现更新
    │
    ├── 按 Shift / 点击 Dash 按钮
    │       ↓
    │   CarShift.StartShift() → CarShiftLogic 提升极速到 shiftSpeed(119)
    │       ↓
    │   OilConsumption 扣除加速油耗
    │
    ├── 按 Space / 点击跳跃按钮
    │       ↓
    │   MotorCarController.Jump(jumpPower=50, jumpDis=1.5)
    │       ↓
    │   FlyDownForce(50) + RevseCarForce(35) 滞空控制
```

### 6.3 技能触发流程

```
玩家按 E / 点击 GUI 技能按钮
    │
    ├── MotoSheepSkillController.OnSkillInput()
    │       ↓
    │   CD 检查（30秒）→ 不就绪则返回
    │       ↓
    │   发送技能请求:
    │   MsgRegister.Dispatcher(new SM_Ability.PlayAbility {
    │       Sign = "AB_RainbowLeap",
    │       InData = { In_StartPoint, In_Forward }
    │   })
    │       ↓
    │   → 交由 Ability 子文档链路处理（见 暴躁绵羊-彩虹飞跃Ability.md S-06）
```

## S-07.5：配置文件速查

> 所有配置文件路径及其在 MotoSheep 开发中的作用。修改后需要注意是否需要重建 Bundle。

| # | 配置文件 | 作用 | 关键字段 | 修改后需重建 Bundle？ |
|---|---------|------|---------|-------------------|
| 1 | `Assets/ToBundle/Config/Txt/SOCarData.txt` | 载具基础数据，控制 HP / 油量 / 座位数 / 爆炸伤害等数值 | `CarSign` `HP` `Oil` `CarRoleNum` `BoomDamage` `BoomRadius` `skill1` | ✅ 是（Txt Bundle） |
| 2 | `Assets/ToBundle/Config/Txt/CarItemAsset.txt` | 皮肤资源路径注册表，定义每个皮肤 ID 对应的 Bundle 路径和资源名称 | `id` `path` `name` | ✅ 是（Txt Bundle） |
| 3 | `Assets/ToBundle/Config/Txt/SOCarSkinData.txt` | 皮肤数据配置，关联皮肤与损毁皮肤（Spoiled）、移动特效、Low/Mid 版本 | `id` `CarSpoiledSign` `CarSign` `moveEff` `stopEff` `shiftEff` `isLow` `isMid` | ✅ 是（Txt Bundle） |
| 4 | `Assets/ToBundle/ScriptableObject/Vehicle/MotoSheep_MotorCarSetting.asset` | MotorCarController 物理参数，控制速度 / 转向 / 跳跃等手感 | `maxSpeed`(77) `shiftSpeed`(119) `SteerAngle`(44) `jumpPower` `jumpDis` | ❌ 否（SO 直接引用） |
| 5 | `Assets/ToBundle/ScriptableObject/LevelData/Vehicle.asset` | BR 模式投放配置，控制载具在哪些地图生成、生成数量 | `VehicleType` `SpawnCount` `SpawnWeight` | ✅ 是（LevelData Bundle） |
| 6 | `Assets/ToBundle/Config/Txt/SOCarSkill.txt` | 载具技能按钮配置，控制技能 CD / 持续时间 / UI 按钮图片位置 | `CarSign` `SkillCD`(当前10，正式30) `SkillTime`(5) `ShowImg` `Posx` `Posy` | ✅ 是（Txt Bundle） |
| 7 | `Assets/ToBundle/ScriptableObject/SOCreateObjData/RainbowIslandCreateData.asset` | BR 彩虹岛地图载具生成概率配置 | `carSign` `Ratio`(20) | ❌ 否（SO 直接引用） |
| 8 | `Assets/ToBundle/ScriptableObject/SOCreateObjData/RainbowIsland_MaltCliffCreateData.asset` | 麦芽悬崖地图载具生成概率配置 | `carSign` `Ratio`(20) | ❌ 否（SO 直接引用） |

### 字段详解

#### SOCarData.txt — 载具基础数据
```
Id        CarSign    HP    Oil    CarRoleNum    BoomDamage    BoomRadius    ...  skill1
MotoSheep MotoSheep  1230  5000   2             300           6             ...  AB_RainbowLeap
```
- `HP`：载具最大血量（1230）
- `Oil`：油箱容量（5000，油耗由 CarShift 控制）
- `CarRoleNum`：最大乘坐人数（2 = 驾驶 + 副驾）
- `BoomDamage` / `BoomRadius`：爆炸伤害(300) / 半径(6m)
- `skill1`：技能1的 Sign（AB_RainbowLeap），VehicleStateButtonControl 注册时读取

#### CarItemAsset.txt — 皮肤资源路径注册表
```
id              path                        name
MotoSheep       MotoSheep/MotoSheep         MotoSheep
MotoSheep_Low   MotoSheep/MotoSheep         MotoSheep_Low
MotoSheep_Spoiled MotoSheep/MotoSheep       MotoSheep_Spoiled
```
- `id`：皮肤唯一标识，与 SOCarSkinData.txt 中的 `id` 对应
- `path`：Bundle 内的相对路径（根路径为 `Assets/ToBundle/Skin/Cars/`）
- `name`：Bundle 内的资源名称（对应预制体名，不含 `.prefab`）
- **作用**：运行时根据皮肤 ID 动态加载对应的预制体 Bundle

#### SOCarSkinData.txt — 皮肤数据配置
```
id         CarSpoiledSign     CarSign    moveEff                  shiftEff             isLow        expressionSign
MotoSheep  MotoSheep_Spoiled  MotoSheep  PonyVehicle_Effect_loop  PonyVehicle_Effect_UI MotoSheep_Low
```
- `id`：皮肤 ID（与 CarItemAsset.txt 的 id 对应）
- `CarSpoiledSign`：损毁形态皮肤 ID（`MotoSheep_Spoiled`）
- `CarSign`：所属载具 Sign（`MotoSheep`）
- `moveEff`：行驶特效名称（当前用 `PonyVehicle_Effect_loop` 占位）
- `shiftEff`：氮气加速特效 UI（当前用 `PonyVehicle_Effect_UI` 占位）
- `isLow`：该皮肤对应的低配版本皮肤 ID（`MotoSheep_Low`）

#### MotoSheep_MotorCarSetting.asset — 物理参数
> 挂载在皮肤预制体根节点的 `MotorCarController` 组件上，通过 Inspector 字段 `motorCarSetting` 引用。

- `maxSpeed`：普通行驶极速（77 km/h）
- `shiftSpeed`：氮气加速极速（119 km/h）
- `SteerAngle`：最大转向角度（44°）
- `jumpPower` / `jumpDis`：跳跃力度 / 距离

#### SOCarSkill.txt — 技能按钮配置
```
Id               CarSign    SkillCD  SkillTime  ShowImg         Posx   Posy   Scale
AB_RainbowLeap   MotoSheep  10       5          MotoSheep_Skill -445   420    0.7
```
- `SkillCD`：技能冷却秒数（**测试用 10s，正式应改为 30s**）
- `SkillTime`：技能执行时间（5s，与 AbilityM CSV 的 M_Duration 对应）
- `ShowImg`：War 图集中的 Sprite 名称（需美术补充 `MotoSheep_Skill`）

#### Vehicle.asset — 投放配置
> 路径：`Assets/ToBundle/ScriptableObject/LevelData/Vehicle.asset`，SOCarDataConfig 在运行时读取该 SO 控制地图中的载具生成。

#### SOCreateObjData — 地图载具生成概率
> 路径：`Assets/ToBundle/ScriptableObject/SOCreateObjData/`，每个地图模式对应一个 `.asset` 文件。

```
vehicleCreateRatio:
  - carSign: MotoSheep
    Ratio: 20
```
- `carSign`：载具 Sign（`MotoSheep`，与 `ItemData.MotoSheep` 一致）
- `Ratio`：生成权重（20），所有载具 Ratio 之和不必为 100，系统按相对比例随机
- **已配置的地图**：
  - `RainbowIslandCreateData.asset`（彩虹岛主地图）✅ Ratio=20
  - `RainbowIsland_MaltCliffCreateData.asset`（麦芽悬崖）✅ Ratio=20
- **未配置的地图**（原 `vehicleCreateRatio: []`，不刷载具）：
  - `RainbowIsland_RookieCampCreateData.asset`（新手营）
  - `RainbowIsland_SportsPartyCreateData.asset`（运动派对）
- **注意**：新增地图模式时，需手动在对应 `.asset` 中添加 MotoSheep 条目

## S-08：边界条件

### 8.1 依赖的外部接口

| 接口 | 提供方 | 用途 |
|------|-------|------|
| `MotorCarController` | 3rd/RCC | 物理驱动，提供 ApplyInput/Jump 接口 |
| `CarShift / CarShiftLogic` | Car 模块 | 氮气加速逻辑 |
| `CarNet / CarNetClient / CarNetServer` | Car 模块 | 网络同步；`CarNetServer._estimatedSpeedXZKmh` 提供 XZ-only 速度给彩虹飞跃 |
| `StartGame.AddCarForData()` | StartGame | 载具实例化入口 |
| `SM_Ability.PlayAbility` | AbilitySystem | 技能触发消息（由 MotoSheepSkillController 发送） |
| `CameraController.SetCameraRatio` | Camera 模块 | FOV 过渡控制 |

### 8.2 禁止做的事

- **禁止修改 MotorCarController.cs**（核心物理控制器，任何改动影响所有载具）
- **禁止修改 CarShift/CarShiftLogic 核心逻辑**（仅可通过配置调参）
- **禁止在 Car.cs 中直接实现 Ability 逻辑**（Ability 归属 AbilitySystem，Car 仅负责触发入口）
- **禁止修改 ItemData.cs 中 MotoSheep 常量**（已存在，直接复用）

### 8.3 边界定义文档引用

- 载具体系归属：MotorCarController 技术栈（非 GPO 载具框架），参见 `载具参考范例.md` 中"核心类结构"章节区分
- 策划案：`aigc/docs/Gameplay_Designer/载具设计策划案：暴躁绵羊（修订版）.md`
