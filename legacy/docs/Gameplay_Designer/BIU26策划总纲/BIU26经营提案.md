# BIU26 经营提案
> **文档版本**：v1.0
> **起草日期**：2026/03/25
> **最后确认**：2026/03/25（主策划逐项确认）
> **文档性质**：论证"为什么这个产品值得做"，而非"这个产品做什么"

---

## 一、产品理念（一句话定位）

> **让曾经喜欢射击、但被操作门槛劝退的玩家，重新找回射击游戏的战术博弈乐趣。**

### 品类定位
多人竞技射击 × 自动化割草发育 × 吃鸡式战术收尾

### 核心体验关键词
```
低门槛射击爽感 · 发育碾压快感 · 战术博弈留存感 · 社交皮肤身份认同
```

### 差异化一句话
> 弹壳解决了"打不中"的问题，BIU26 进一步解决了"赢不了"的问题——用发育优势替代操作优势，让战术判断成为胜负的决定因素。

---

## 二、目标用户画像

### 核心用户：「被劝退的射击老玩家」

| 维度 | 描述 |
|------|------|
| **年龄层** | 25～40岁 |
| **行为特征** | 曾经重度玩过射击游戏（CF/PUBG/荒野行动等），随着工作和年龄增长减少或放弃游戏 |
| **核心痛点** | 反应速度下降、操作跟不上年轻人，被虐→挫败→流失 |
| **真实需求** | 不是"零门槛的游戏"，是"门槛合适、但仍有博弈深度的射击体验" |
| **娱乐习惯** | 碎片时间游玩，对单局时长敏感，5-8分钟内要有完整的情绪弧线 |
| **触达渠道** | 微信社交关系链（老玩家群体有强社交属性） |

### 具体用户原型
> 李明，32岁，中层管理，曾经是《CF》重度玩家。现在偶尔开局，但进房间就被吊打，"打开游戏的挫败感比不玩游戏还难受"。他不是不想玩射击，他是"玩不赢了所以放弃了"。如果有一款射击游戏他能稳定赢，他会把老朋友拉进来一起玩。

## 三、为什么这个体验对目标用户成立

### 3.1 痛点→解决方案映射

| 目标用户痛点 | 现有产品的处理 | BIU26 的解法 |
|------------|------------|------------|
| 操作反应跟不上 | PUBG/CF：无解，被虐 | 六把悬浮武器自动索敌，射击无需瞄准 |
| 打不到人，没有正反馈 | 弹壳：解决了，但只有PVE | PVE割草阶段提供密集击杀正反馈 |
| PVE没有博弈感，易腻 | 弹壳/土豆：无PVP | 缩圈机制强制接解，长TTK PVP保留战术空间 |
| 赢了没有社交价值 | 大多数小游戏：无皮肤经济 | 赏金→枪皮肤，胜利可见、可展示 |

### 3.2 为什么"长TTK PVP"是关键设计

短TTK射击（如CS）：胜负由"谁先打中"决定 → 拼操作和反应
长TTK射击（如BIU26）：胜负由"走位、时机、资源管理"决定 → 拼战术判断

对目标用户而言，战术判断的退化速度远慢于反应速度退化。这意味着他们在BIU26中有真实的竞争力，而不只是"被照顾的失败者"。

## 四、核心体验与核心循环

### 4.1 核心体验（情绪定义）

> 玩家感受到：**"我越来越强，强到足以碾压所有人"**——先碾压小怪，再碾压玩家。

这是一条**持续上升的碾压感弧线**，两段高峰：
1. 发育期高峰：六把武器齐全，满屏子弹横扫怪物
2. PVP期高峰：凭战术判断击败其他玩家，赢得赏金

### 4.2 核心循环（单局内）

```
[入局]
玩家进入地图，初始持有少量武器
        ↓
[发育期 — PVE割草]
击杀小怪 → 获得武器/强化 → 六把悬浮武器逐步解锁
高频击杀反馈，快速积累碾压感
        ↓
[过渡期 — 缩圈信号]
地图安全区开始收缩，玩家自然向中心聚集
发育完成的玩家开始与其他玩家产生接触
        ↓
[PVP期 — 战术博弈]
长TTK对抗：走位、掩体、时机判断决定胜负
发育差距形成初始优势，但战术判断仍有翻盘空间
        ↓
[结算 — 赏金发放]
存活/积分最高玩家获得赏金
赏金积累可购买具备社交价值的枪皮肤
        ↓
[循环驱动]
皮肤展示 → 社交传播 → 新用户引入 → 下一局
```

### 4.3 兴趣曲线（单局）

```
爽感
 ↑
高│              ★PVP高峰（击杀玩家）
  │         ★★          ★★
  │    ★★★    ★★    ★★      ★（赏金结算）
  │ ★（入局）
低│
  └────────────────────────────→ 时间
    0      3min    6min    10min
    入局   发育中   PVP开始  结算
```

> 注：兴趣曲线时间轴基于单局5-8分钟目标，实际横轴刻度在原型验证后校准。

设计原则：
- **发育期不能平稳**：每解锁一把武器必须有明显的火力质变感知
- **PVP期必须有战术信号**：缩圈、地形、对手位置信息必须清晰
- **结算必须是高峰**：赏金发放界面需要有仪式感

## 五、商业成立性

### 5.1 盈利路径

| 收入来源 | 机制 | 用户心理驱动 |
|---------|------|------------|
| 枪皮肤直购 | 赏金积累购买，或直接付费 | 社交展示价值，"我的皮肤证明我赢过" |
| 赛季通行证 | 赛季专属皮肤和赏金加成 | FOMO感 + 持续游玩动力 |
| 好友邀请机制 | 组队额外赏金加成 | 老玩家拉老朋友回来 |

### 5.2 留存驱动

| 留存层级 | 驱动机制 |
|---------|---------|
| 短期（Day1） | 发育爽感 + 第一次击杀玩家的高峰 |
| 中期（Week1） | 皮肤解锁进度 + 排行榜位置 |
| 长期（Month+） | 社交关系链（老朋友一起玩）+ 赛季内容更新 |

## 六、核心设计假设与验证计划

以下假设需要原型验证，验证通过后才能进入全面开发：

| # | 假设 | 验证方法 | 验收标准 |
|---|------|---------|---------|
| 1 | 长TTK PVP能让低操作玩家感受到战术博弈感而非"硬磨血量" | 邀请5名目标用户原型游玩，观察PVP阶段反应 | 玩家主动使用掩体/走位，而非站着互射 |
| 2 | 六把武器解锁过程中，每把武器的加入有明显的火力质变感知 | 内部测试，逐把武器单独验证 | 测试者能描述出"多了一把之后明显不一样" |
| 3 | 目标用户（25-35岁射击老玩家）愿意在发育期投入时间，不会因为"打不过年轻人"而流失 | A/B测试：有/无缩圈保护期的两个版本 | 有保护期版本的Day1留存率提升>10% |

## 七、已确认核心参数

| 参数 | 确认值 | 设计备注 |
|------|-------|---------|
| 单局时长 | 5-8分钟 | 发育期约2-3分钟，PVP期约3-5分钟 |
| 单局玩家数 | 8-12人 | 地图中型规模，PVP遭遇密度适中 |
| 武器获取机制 | 击杀小怪概率掉落 | 必须设计保底机制，阈值待数值验证 |
| PVP TTK目标 | 3-5秒 | 支撑走位博弈，不拖慢局内节奏 |
| 赏金货币属性 | 待定 | 虚拟积分兑换 or 真实付费体系，商业化方案确认后补充 |

## 八、开放问题（下阶段需要进入核心体验设计后解答）

- **发育保底阈值**：击杀多少只小怪保底掉落一把武器？（影响2-3分钟内的发育节奏）
- **初始武器数量**：玩家入局时持有几把武器？（影响第一分钟的体验密度）
- **发育差距上限**：发育最多的玩家 vs 最少的玩家，PVP期的属性差距应该控制在多少倍以内？（影响翻盘可能性）
- **缩圈节奏**：第一次缩圈在几分钟时开始？缩圈速度如何与8-12人在5-8分钟内完成接解对齐？
