## 一、地图设计目标

```
三个需要同时满足的条件：

① 发育期（前2-3分钟）：
   8-12名玩家分散在地图各处，各自独立割草，互不干扰

② PVP期（3分钟后缩圈）：
   缩圈把玩家自然聚拢，接触密度逐渐提升直到决出胜者

③ 全程：
   地图大小让玩家在任何时间都不会感到"找不到怪/找不到人"的空旷感
```

## 二、地图尺寸推算

### 2.1 推算依据

| 参数 | 数值 | 来源 |
|------|------|------|
| 玩家数量 | 8-12人 | 经营提案 |
| 发育期时长 | 2-3分钟 | 核心体验设计 |
| 刷怪外径 | 12m（以玩家为圆心）| 小怪设计 |
| 玩家移速（参考）| 约5-6m/s | 游戏全局框架 |
| 缩圈第1圈后面积 | 原图约60% | 核心体验设计 |

### 2.2 尺寸推算过程

**发育期玩家分散要求：**
- 8-12名玩家需要各自独立割草，相互不干扰
- 每人的割草活动范围约为刷怪外径×2 ≈ 直径24m的圆形区域
- 为保证8-12人不重叠：需要约8×(24m×24m) ≈ 4600㎡的有效空间
- 加上地图边缘缓冲和地形变化：**地图总面积约120m×120m = 14400㎡**

**缩圈压缩验证：**
- 第1圈后60%：约93m×93m，8-12人开始接触
- 第2圈后30%：约66m×66m，激烈PVP区域
- 第3圈：约30m×30m，最终决战

**玩家移速验证：**
- 从地图边缘到中心：约60m，以5m/s移速需12秒进圈
- 圈外伤害每秒扣1%HP，12秒内不进圈损失12%HP——有压力但不致命，合理

### 2.3 最终地图尺寸提案

```
地图总尺寸：120m × 120m（正方形）
有效战斗区域（去除边缘装饰）：约100m × 100m

初始安全圈半径：约60m（覆盖全图）
第1圈收缩后半径：约37m（约60%面积）
第2圈收缩后半径：约26m（约30%面积）
第3圈最终半径：约13m（最终决战区）
```

> ⚠️ **以上尺寸为推算提案，需在原型中通过实际游玩验证移动感受是否舒适。**

## 三、区域划分（多区域+中心富集）

### 3.1 区域结构总览

```
         ┌──────────────────────────┐
         │  [外围区] × 4个象限        │
         │  开阔地形为主              │
         │  普通怪密度高              │
         │  白质武器掉落区            │
         │     ┌────────────┐        │
         │     │  [过渡区]   │        │
         │     │  混合地形   │        │
         │     │  普通+精英  │        │
         │     │  ┌──────┐  │        │
         │     │  │[中心] │  │        │
         │     │  │富集区 │  │        │
         │     │  │精英+  │  │        │
         │     │  │头目   │  │        │
         │     │  └──────┘  │        │
         │     └────────────┘        │
         └──────────────────────────┘
```

### 3.2 三个区域定义

#### 外围区（4个象限，各占地图约20%面积）

| 设计项 | 内容 |
|--------|------|
| **地形** | 开阔草地/沙地，少量单独树木或石块作为轻掩体 |
| **怪物密度** | 中等（保证发育期割草节奏）|
| **怪物构成** | 普通怪为主（偶尔精英怪）|
| **掉落品质** | 白质为主 |
| **缩圈作用** | 第1圈收缩时此区域进圈，玩家开始向中间移动 |
| **视觉特征** | 明亮开阔，卡通草地风格，视野开阔 |

#### 过渡区（环绕中心的圆环区域，约占地图30%）

| 设计项 | 内容 |
|--------|------|
| **地形** | 混合地形：小型建筑/箱子/树丛，掩体密度中等 |
| **怪物密度** | 较高（进化后精英怪集中区域）|
| **怪物构成** | 普通+精英怪混合 |
| **掉落品质** | 白质/蓝质混合 |
| **缩圈作用** | 第2圈收缩时此区域进圈，PVP接触高峰 |
| **视觉特征** | 中等明亮，少量建筑物增加层次感 |

#### 中心富集区（地图正中，约占10%面积，约30m×30m）

| 设计项 | 内容 |
|--------|------|
| **地形** | 有明显地标建筑（圆形或标志性形状），少量掩体 |
| **怪物密度** | 高（精英+头目怪主要区域）|
| **怪物构成** | 精英怪+头目怪 |
| **掉落品质** | 蓝质/金质为主 |
| **缩圈作用** | 最终圈范围，最后决战区 |
| **视觉特征** | 地标明显（从外围可见），引导玩家知道"中心在哪里" |
| **设计意图** | 主动去中心有高回报（好装备），但危险也高（强怪+其他玩家）|

## 四、掩体设计原则

### 4.1 卡通风格掩体类型

| 掩体类型 | 高度 | 适用区域 | 战术用途 |
|---------|------|---------|---------|
| 大圆石/卡通石块 | 低掩体（玩家蹲下可遮蔽）| 外围区 | 轻度掩护，不影响割草流动性 |
| 卡通箱子/货物堆 | 中掩体（站立遮半身）| 过渡区 | PVP期的主要战术掩体 |
| 小型建筑（房屋/亭子）| 高掩体（完全遮蔽）| 过渡区/中心 | 高价值掩体，争夺节点 |
| 树木/灌木 | 视觉掩蔽（无碰撞遮蔽）| 外围区 | 提供视觉隐蔽，不阻挡子弹 |

### 4.2 掩体密度原则

```
外围区：掩体稀疏（每100㎡约1-2个小石块）
        → 开阔割草，不阻挡小怪和玩家移动

过渡区：掩体适中（每100㎡约3-5个中型掩体）
        → 支撑PVP期的走位和交火

中心富集区：掩体少（地标建筑1-2个，周围开阔）
        → 决战区必须开阔，避免"藏角落"苟活
```

**设计依据（原则一：真实竞争）**：
中心富集区刻意减少掩体，是为了防止"蹲角落苟到最后"的消极策略在最重要的决战区有效。

## 五、地标与导航设计

### 5.1 玩家如何感知"中心在哪里"

中心富集区需要有明显的视觉地标，玩家站在地图任意位置都能看见：

| 地标设计 | 视觉要求 |
|---------|---------|
| 中心建筑 | 高度约8-10m，色彩鲜艳，与周围地形有强烈对比 |
| 缩圈光墙 | 安全区边缘有明显的蓝色光墙（参考吃鸡类游戏），玩家无需看地图 |
| 小地图 | 右上角显示玩家位置+安全圈范围+缩圈倒计时 |

### 5.2 缩圈中心点设计

```
安全圈中心点：固定在地图正中心（不随机）

设计意图：
  玩家每局都知道"往地图中心跑"，无需每局重新学习
  固定中心让地图地标建筑可以服务于导航功能
  与随机圆心相比，固定圆心降低新手理解成本
```

## 六、地图与系统的联动设计要求

| 系统 | 地图需要配合的设计 |
|------|----------------|
| 极坐标刷怪 | 地图需要足够开阔，确保刷怪外径12m范围内有有效地面（不能是悬崖/水体）|
| 缩圈机制 | 地图边缘必须有明显的"不可进入区域"视觉（悬崖/海洋/光墙）|
| 武器替换 | 掉落武器需要在地面可见（亮色光效标识），玩家能快速发现并决策 |
| 金币系统 | 金币掉落也需要有视觉标识，与武器掉落外观需明显区分 |
