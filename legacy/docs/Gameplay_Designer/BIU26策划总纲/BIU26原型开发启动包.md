> **让曾经喜欢射击、被操作门槛劝退的玩家，在低操作门槛下重新感受到射击游戏的割草爽感和战术博弈乐趣。**

## 三、原型验证目标

原型的目标是验证**两个核心假设**，而不是实现完整游戏：

### 假设1：发育期的割草感是否密集且令人成瘾

> 玩家在2-3分钟内击杀50-80只小怪，逐步解锁6把悬浮武器的过程，是否感受到持续上升的碾压感？

**验收标准**：测试者能自发描述"越来越强"的感受，而不是"找不到怪"或"武器没感觉"。

### 假设2：长TTK PVP是否能让低操作玩家感受到战术博弈

> PVP期TTK 3-5秒，玩家是否主动使用掩体/走位，而非站着互射？

**验收标准**：至少一半测试者在PVP中产生走位/撤退行为。

## 五、原型开发优先级

### Phase 1：核心发育循环验证（最高优先）

**目标：验证假设1（发育期割草感）**

需要实现：
- [ ] 手持武器1把 + 辅助瞄准自动开火
- [ ] 悬浮武器系统（挂点、自动索敌、自动开火）
- [ ] 小怪极坐标刷怪（刷怪内径4m/外径12m）
- [ ] 击杀小怪→概率/保底掉落悬浮武器
- [ ] 悬浮武器逐步解锁（0→6把，每解锁一把有视觉变化）

**灰盒占位方案（无美术资源时）：**
- 小怪：不同颜色的Capsule（普通灰色 / 精英蓝色 / 头目金色）
- 悬浮武器：不同颜色的Cube围绕玩家漂浮（火=橙，冰=青，电=紫）
- 掉落武器：地面上的发光Cube
- 金币：地面上的黄色小球

**Phase 1 体验节点（完成后让主策划测试）：**
> 能否在2-3分钟内从1把武器成长到6把，并感受到明显的火力变化？

---

### Phase 2：缩圈与PVP接解（中优先）

**目标：验证假设2（长TTK战术博弈感）**

需要实现：
- [ ] 缩圈机制（安全区显示 + 圈外掉HP）
- [ ] 玩家对玩家的伤害（TTK目标3-5秒，通过数值调整实现）
- [ ] 多人测试环境（至少4-6人）

**Phase 2 体验节点：**
> 玩家在PVP期是否主动使用掩体走位，而非站着互射？

---

### Phase 3：元素系统与克制（低优先，验证核心后再做）

- [ ] 三种元素的视觉差异（子弹拖尾颜色）
- [ ] 元素状态效果（燃烧DOT / 冰冻减速 / 电弧弹射）
- [ ] 三种元素反应（蒸发爆裂 / 感电燃烧 / 超导连锁）
- [ ] 小怪元素属性与克制奇迳效果

---

### Phase 4：金币经济与结算（验证前两个后）

- [ ] 金币三来源（击杀小怪/进圈/击杀玩家）
- [ ] 死亡50%转移规则
- [ ] 结算界面金币展示

## 六、设计四原则（程序员开发决策时的对齐基准）

当遇到实现上的取舍时，以这四条原则判断方向：

1. **真实竞争**：不做保护新手的特殊机制，竞争是真实的
2. **爽感密度**：任何超过30秒无事发生的时间段都是漏洞
3. **机制驱动行为**：每个机制都应该引导玩家自发做设计想要的事
4. **保留操控感**：手持武器必须让玩家感觉"是我在打枪"
