## 一、单局内兴趣曲线（v0.1 预设版）

### 1.1 曲线图

> 情绪强度1-5分制，5分为最高情绪峰值

```
情绪强度
 ↑
5│                              ★★ 最终对决
 │                         ★★★
4│              ★ 首次击杀玩家  ★  PVP混战
 │           ★★             ★
3│      ★★★ 全阵容达成     ★
 │    ★ ★                ★
2│  ★    ★ 武器逐步解锁  ★ 缩圈接解
 │★（入局）              ★（缩圈预警，短暂紧张）
1│
 └────────────────────────────────────→ 时间
   0:00  0:30  1:00  1:30  2:00  2:30  3:00  4:00  5:30  7:30
   入局        发育中       全阵  缩圈   PVP开始  激烈  结算
```

### 1.2 各节点情绪机制对应

| 时间 | 情绪节点 | 预设强度 | 驱动机制 | 设计要求 |
|------|---------|---------|---------|---------|
| 0:00 | 入局 | 2分 | 第一把手持武器的射击手感 | 辅助瞄准必须立刻有响应感 |
| 0:20 | 第一把悬浮武器 | 2.5分 | 悬浮武器出现的视觉冲击 | 解锁动画需有仪式感（光效+音效）|
| 1:15 | 三把悬浮里程碑 | 3.5分 | 进入"多武器状态"，视觉质变 | 此时满屏感必须明显不同于开局 |
| 2:40 | 全阵容达成 | 4.5分 | 六把武器全部到位，碾压感高峰 | 第6把解锁时需有专属"集齐"反馈 |
| 2:30 | 缩圈预警 | 2分（紧张）| 安全区边界出现 | 缩圈警告UI醒目但不引发焦虑 |
| 4:00 | 首次击杀玩家 | 4分 | 第一次PVP接触并击杀 | TTK 3-5秒给足战术时间，击杀需大声反馈 |
| 5:30 | PVP混战激烈期 | 4.5分 | 多人乱战，高风险高收益 | 金币转移机制在此时发挥最大张力 |
| 7:00 | 最终对决 | 5分 | 最后2-3人决出胜负 | 全局最高情绪峰值，绝不能让人感到平淡 |
| 7:30 | 赏金结算 | 4分（幸福感）| 赏金数字滚动，明细展示 | 即使输了也要有正向情绪，明细展示成就感 |

### 1.3 三条强制设计要求

1. **低谷不能超过30秒**：任何情绪降至1分以下的时间段超过30秒，说明该阶段有"空洞"需填补
2. **全阵容达成必须是发育期最高点**：玩家到2:40仍未感受到质变 → 发育设计失败
3. **结算必须是正向情绪**：即使输了，赏金明细（"我割草赚了X金币"）也要给到成就感

## 二、产品全周期兴趣曲线（v0.1 预设版）

### 2.1 曲线图

```
兴趣
 ↑
高│  ★★（新手期高峰：第一次全阵容+击杀玩家）
  │★        ★★（社交高峰：拉朋友进来一起玩）
  │              ★★（皮肤高峰：第一件皮肤到手）
  │                   ★★（赛季高峰：新内容解锁）
  │                         ↘（自然衰减）
低│                            ★（召回钩子）
  └──────────────────────────────────────→ 时间
    Day1   Week1   Month1   Month3   Month6
```

### 2.2 各衰减点与应对机制

| 衰减时机 | 衰减原因 | 应对钩子 | 设计优先级 |
|---------|---------|---------|---------|
| Day1→Day3 | 新鲜感消退 | 第一件皮肤获取路径（让玩家看到"3局后可以解锁X"）| 极高 |
| Week1→Week2 | 对局内容重复感 | 拉好友组队的引导（好友一起玩是最强留存锚）| 极高 |
| Month1→Month2 | 皮肤收集进度缓慢 | 赛季通行证/限时皮肤（FOMO感驱动）| 高 |
| Month3+ | 核心玩法熟悉后无新鲜感 | 新元素/新地图/新武器类型（内容更新）| 中 |

### 2.3 新手第一局的四个关键情绪节点（Day1留存核心）

```
必须在第一局内完成：
  ① 前30秒：第一次击杀小怪，有击杀反馈（"打中了"）
  ② 前1分钟：第一把悬浮武器解锁（"哦！可以这样！"）
  ③ 前3分钟：第一次全阵容达成（体验到游戏最佳状态）
  ④ 首局结束：赏金结算看到明细（"原来可以积累皮肤"）

任意一个节点缺失或体验不流畅 → Day1留存率显著下降。
```

## 三、兴趣曲线验收方法

兴趣曲线不是靠文档验证的，靠**观察真实玩家行为**：

| 可观察的玩家行为 | 说明什么 |
|--------------|---------|
| 全阵容达成时有明显身体反应（前倾、发声）| 发育期情绪高峰成立 |
| 死亡后立刻说"再来一局" | 单局情绪弧线完整 |
| 游戏后主动描述"某次击杀玩家的经历" | PVP期产生了难忘时刻 |
| 第一局后询问"皮肤怎么得" | 留存钩子已被感知 |
| 发育期中途放下手机/走神 | 某个时间段情绪跌至空洞，需定位并填补 |

### v0.1（2026/03/25）— 初版预设，测试前

基于设计逻辑推导，尚未经过真实玩家测试。所有情绪强度数值和时间节点均为预设值。

**待验证的核心假设：**
- 武器每20-30秒解锁一把，是否产生"持续上升"的发育感
- 全阵容达成（2:40）是否真的是情绪峰值，还是被后续事件稀释
- PVP期首次击杀（约4:00）能否稳定产生4分以上的情绪反应
