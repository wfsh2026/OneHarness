2. 模式概述
2.1 一句话介绍
在TPP视角下，玩家手持与背部悬浮多把武器进行自动索敌射击，通过局内Roguelike三选一构筑极具视觉冲击力的元素流派，对抗源源不断的怪物潮的极限生存割草PVE模式。
2.2 目标用户与核心体验
●	目标用户：喜欢爽快割草、追求高频正反馈、热衷于Roguelike局内构筑（BD）与策略组合的PVE/休闲玩家。
●	核心体验关键词：满屏特效、策略构筑（BD）、爽快割草。
2.3 战斗体验画像
（可量化的体验预期）
●	TTK（击杀耗时）：
○	前期/小怪：极短（0.5s~1s），强调如割草般的碾压感。
○	后期/精英怪：中等（3s~8s），需要依赖玩家构筑的元素连携（如感电易伤、爆燃结算）进行击杀。
●	血线压力：随回合数呈阶梯式上升。前期血线波动在 80%~100%，后期高压回合（精英怪潮）血线可能在 20%~60% 剧烈波动，考验玩家的走位与免伤/吸血词条构筑。
●	操作密度：中等偏低。由于悬浮武器支持自动索敌开火，玩家的核心操作集中在【走位聚怪】、【规避高危伤害】以及【思考三选一词条搭配】。
●	容错边界：较高。允许玩家局内多次倒地（变为小肠肠），不仅有队友救援机制，还有基于死亡次数的自动复活以及回合结束强制复活机制。
3. 核心战斗机制 (3C与战斗逻辑)
3.1 悬浮武器系统 (Hover Weapons)
本模式在经典射击基础上，新增背部悬浮武器模块。
●	挂载与数量限制：最大支持 4把 悬浮武器（读取全局配置）。获得新武器时，自动装备至当前编号最小的空闲相对挂点。
●	延迟跟随算法：
○	悬浮武器群共用一个中心坐标（CenterPos）。
○	移动逻辑：玩家移动后，CenterPos 延迟 0.1秒 （可配）以玩家基础移速开始跟随。
○	追赶机制：若 CenterPos 与 玩家距离  米（可配），则移速乘以 移速倍率 直至进入范围内。
●	索敌与射击机制：
○	属性重构：所有枪械新增【元素枚举】、【元素伤害】、【悬浮命中率】字段。
○	悬浮武器无后坐力与散布计算，直接依据配置的 悬浮命中率（如85%）判定是否命中。
○	跟随移动时也能独立索敌开火。

4. 元素特性系统 (核心BD设计)
4.1 通用词条
●	无限叠加类：所有元素伤害+%、武器暴击伤害+%、角色最大生命值+%。
●	有限叠加类（需配表上限）：武器射速+%、暴击率+%、换弹速度+%、角色移速+%、免伤+%。
4.2 火元素流派 (Fire)
围绕**【灼烧】持续伤害与连锁爆炸**展开。
●	【灼烧】Debuff：独立计算层数，持续掉血。达到最大层数后，新附加的灼烧会重置最早那一层的时间戳。
●	事件派生链：
1.	火球：射击命中X次   概率发射火球造成AOE+灼烧。
2.	陨石（前置:火球）：火球爆炸   概率触发延迟陨石坠落（AOE+灼烧）。(若有“额外生成”词条，新陨石继承上一个陨石的目标点)。
3.	燃烧区（前置:陨石）：陨石坠地   生成持续圆形火圈。单次伤害 = 基础值 + 枪械火焰伤害 * 转换率。
4.	爆燃（前置:灼烧）：灼烧目标受火伤   概率清空目标所有灼烧层数   瞬间全额结算剩余伤害。
4.3 电元素流派 (Electric)
围绕**【感电】全局易伤与高频群攻**展开。
●	【感电】Debuff：目标受到的所有来源伤害额外增加 X%。
●	事件派生链：
1.	电弧：命中   概率在就近敌人间弹射。若目标带【感电】，该次弹射伤害获得额外增幅。
2.	落雷：暴击/概率触发   目标头顶延迟劈下落雷。
3.	地面电流（前置:落雷）：落雷触地   沿极轴向外扩散多道电流。单个目标不会被同一次生成的电流重复伤害。
4.	静电场（前置:感电）：感电目标受电伤   对周围爆发闪电AOE并传染感电。
5. 局内环境与刷怪逻辑
彻底摒弃固定点位，采用围绕玩家的动态极坐标域生成机制，确保战斗连贯性。
5.1 空间极坐标规则
●	以玩家当前位置为圆心  。
●	生成区域：仅在 圆环内径（4m）至 圆环外径（12m）之间生成。
●	角度分布权重（以玩家面朝方向为极轴  ）：

○	普通刷怪区：  及   （两侧）
○	少量刷怪区：  （后方）
5.2 时间轴与怪物组解析
●	触发条件：回合数 == 设定回合 且 回合已进行时间 == 刷新时间点。
●	若一时间点配置了多个 怪物组ID，系统随机抽取一组执行。
●	离散生成逻辑：若怪物组配置生成 N 只怪，且 刷新时间区间 = 2秒。这 N 只怪不会在同一帧出现，而是随机分配在 [触发时刻, 触发时刻 + 2秒] 内逐个通过协程在上述极坐标区生成。
6. 系统关联与经济
6.1 局外带入与带出
●	带入限制：严禁带入局外数值道具。仅允许带入枪械的皮肤与饰品外观（悬浮武器需同步显示）。
●	产出结算：
○	本局通关回合数（结算界面展示）。
○	死亡/胜利结算时，根据回合数和表现发放局外经验或特定活动代币（按活动期配置）。
6.2 匹配机制与入口
●	入口：街机模式新增“多武器PVE（测试）”入口。大厅展示玩家【最多通关回合数】（无记录显示 - ）。
●	匹配池规则：支持 单人 / 双人 / 四人 匹配。
●	动态难度补差：不强行补机器人。局内刷怪系统（极坐标怪物组数量）与 Boss难度数值，将直接根据当前实际对局玩家人数动态索引不同的难度配置表。
6.3 生死循环与胜负
●	死亡状态：HP归零变为【小肠肠】。允许移动、跳跃、吃经验、选词条。禁止攻击。
●	复活条件：
1.	存活队友靠近交互施救（同经典）。
2.	满足配置的自动复活时间（按本局死亡次数递增，如第1次0.3x分钟，第2次0.6x分钟）。(若队友施救中达到自动复活时间，直接打断并复活)
3.	当前回合倒计时结束，进入下回合时全员复活。
●	胜负条件：
○	失败：全员同时变为小肠肠，且 通关回合数   目标配置值。
○	胜利：生存并通关回合数   目标配置值。
7. 信息与博弈
7.1 视觉信息 (Visual & UI)
●	UI/提示：
○	排行榜入口跳转（支持后台热更开关控制，关闭时点按弹窗提示）。
○	三选一界面：展示词条图标、流派标识、刷新按钮（附带剩余次数显示）。
●	角色3C动画：
○	悬浮武器同步Idle浮动：HTR@idle_HoverWeapon。
○	悬浮武器射击动作预留：HTR@shoot_HoverWeapon_UMP9/M416/等。
●	特效反馈 (VFX)：
○	受击与状态：怪物身上的【点燃状态特效】(复用现有)、【感电状态特效】。
○	火系爆发：火焰子弹、火球/陨石飞行与坠地爆炸、陨石坑燃烧、【爆燃】瞬间升腾特效。
○	电系爆发：闪电子弹、电弧链条与命中闪光、落雷与坠地爆炸、落雷产生的【地面扩散电流网】。
7.2 听觉信息 (Audio)
FPS/TPS中声音提供极强的爽感反馈：
●	火系音效：发射火球、火球连环爆炸、陨石划破空气的坠落声、沉闷的陨石坠地爆炸声。
●	电系音效：电弧弹射的清脆“噼啪”声、震耳的落雷劈击声、地面电流扩散的“滋滋”声。
●	战斗环境音：悬浮武器的密集射击声需做合理的空间衰减，避免多武器开火时产生爆音。
8. 局外系统关联
8.1 枪械与排行榜系统
●	枪械系统关联：挂载的武器类型直接继承局外配置的美术表现（枪械模型、皮肤）。
●	排行榜：提供【PVE通关排行榜】（按通关回合数倒序排列），支持筛选：地区 / 好友 / 全服。仅保留历史榜单。
8.2 数据埋点 (Telemetry)
为验证“割草体验”和“难度设计”是否符合预期，游戏服需埋入以下数据点位：
1.	大盘数据：PVE模式日活参与人数、参与人次。
2.	通关率漏斗：难度ID / 参与人数 / 通关人数 / 通关率 / 人均通关前重玩该关卡次数。
3.	难度体验诊断：
○	血线压力验证：回合死亡率（难度ID / 回合数 / 平均倒地次数）。
○	数值养成验证：回合养成率（难度ID / 回合数 / 平均等级）。
4.	流派平衡性监控：
○	武器选取率（难度ID / 武器ID / 武器品质 / 玩家选取率）。
○	BD堆叠度（选取该武器的玩家平均装备该武器的数量）。
○	有效DPS（平均每把武器/流派造成的实际伤害占比）。
