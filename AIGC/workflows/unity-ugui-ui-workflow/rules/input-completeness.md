# Unity UGUI UI 输入完整度规则

执行前必须检查：

- 最终效果图。
- 背景图、按钮素材、图标素材、装饰素材和 Logo。
- 设计分辨率和目标屏幕比例。
- Unity 版本、Canvas Scaler 设置和 TextMeshPro 要求。
- 是否需要 Tween 库，以及已确认的 Tween 库名称。
- 是否需要自动生成 Prefab。
- 资源导入路径和输出路径。
- 交互说明、动态数据来源和界面跳转关系。

## 分级规则

| 等级 | 判定 | 允许输出 | 阻塞内容 |
| --- | --- | --- | --- |
| L1 | 只有最终效果图 | 策划分析、拆解建议、层级建议、切图清单、第一版估算布局 | 完整代码、最终 Prefab、完整资源绑定 |
| L2 | 效果图和拆分素材 | L1 内容、切图记录、拼接还原文档、导入设置、资源依赖、施工方案 | 交互、动态数据、字体或状态未确认时不得写死 |
| L3 | 效果图、素材、项目设置和交互说明齐全 | 完整施工方案、集中配置、Editor 创建脚本、Controller、绑定表和运行检查 | 截图校准前不得宣称最终还原 |

## 待确认规则

- 缺失项必须写入待确认项，不能编造。
- 可以估算的布局、字号、颜色或坐标必须标注“第一版估算值，需要 Unity 截图后校准”。
- 需要用户决定的技术路线、素材来源、字体、交互结果或业务跳转，不能由工作流默默选择。
- 如果输入不足以进入代码生成，只输出分析和交接包，不生成完整 Unity 脚本。

## 成功标准

1. 当前输入等级明确。
2. 输出范围与输入等级一致。
3. 待确认项说明了影响和下一步处理方式。
4. 没有把估算值写成最终事实。
