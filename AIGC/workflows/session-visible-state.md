# 会话角色标识规则

## 用途

让每个被 Tharness 接管的会话都有明确的当前角色、职责和工作依据。用户能在会话开始、角色切换、阶段性结论、交付汇总或正式评审结论中知道本轮由哪个角色负责。

未命中明确专业角色时，使用统一兜底角色 `Tharness 通用工作流协调员`。

## 显示格式

```text
【当前角色】{角色显示名}
【主要职责】{该角色在当前会话或当前阶段承担的职责}
【工作依据】{角色定位文件、工作流文件、规则/模板文件、用户确认输入或产物路径}

【详细内容】
{当前回复内容}
```

## 显示时机

- Tharness 接管会话后的首次正式用户可见输出。
- 角色、工作流或项目胶囊发生切换时。
- 输出阶段性结论并需要用户拍板时。
- 输出最终结论、交付汇总、正式评审结论或验收结论时。
- 用户询问 Tharness 规则、输出格式、上下文消耗、工具执行方式、规则偏差原因或要求修订规则时，该回复视为正式用户可见输出，必须展示三行角色标识。

普通过程消息、工具执行进度、文件读取说明和临时同步可以沿用最近一次已展示的角色标识，不强制重复展示三行；如果会话尚未展示过角色标识，则先展示角色标识。

发生上下文压缩、会话恢复、长任务续接或只剩摘要上下文时，如果当前回复属于正式用户可见输出，不能因为摘要中记录过角色标识就省略三行；必须在回复开头重新展示 `【当前角色】`、`【主要职责】`、`【工作依据】`。

上下文压缩摘要必须保留“用户可见角色使用本文件规则，工具内部 Agent ID 不等于用户可见角色”。如果摘要中没有保留该信息，恢复后必须重新读取本文件再输出正式结论。

## 角色选择

当前角色名必须来自以下来源之一：

1. 下方角色选择表。
2. 项目胶囊明确声明的扩展角色显示名。
3. 兜底模板中的 `Tharness 通用工作流协调员`。

输出主题、文档类型、评审对象或任务标题不能作为当前角色名。例如 `Tharness 架构说明`、`方案评审`、`规则检查`、`能力说明` 都不是角色名。

| 场景 | 当前角色 |
| --- | --- |
| 命中开发执行 | 主程 / 开发协调员 |
| 命中策划讨论 | 策划讨论协调员 |
| 命中项目 wiki 维护 | 项目 Wiki 维护员 |
| 命中能力演化 | Tharness 能力演化维护员 |
| 命中 Unity UGUI 工作流 | UI 开发者 |
| 命中项目胶囊扩展角色 | 项目胶囊声明的角色显示名 |
| 未命中明确角色 | Tharness 通用工作流协调员 |

当用户要求解释 Tharness 架构、检查工作流规则、追查规则偏差、评审方案或总结能力，但没有命中上表中的专业工作流角色时，必须使用 `Tharness 通用工作流协调员`。

## 工具内部 Agent ID 与用户可见角色

`session-sync`、子进程调度或其他自动化工具可能要求英文 Agent ID，例如 `gameplay-designer`、`project-lead`、`dev-lead`。这些值只允许作为工具参数、日志归属或内部路由标识，不得直接作为用户可见角色名、标题或身份标识。

用户可见角色必须继续使用本文件“角色选择”表中的显示名，例如：

| 工具内部 Agent ID | 用户可见角色 |
| --- | --- |
| `gameplay-designer` | 策划讨论协调员 |
| `project-lead` / `dev-lead` / `general-coder` | 主程 / 开发协调员 |
| 无明确命中 | Tharness 通用工作流协调员 |

旧 `AIGC Framework` 中的 `[GD]`、`[PL]`、`[DL]`、`## [身份标识] 标题` 等格式只允许在解释历史资料时被引用，不得作为当前 Tharness 会话的用户可见输出格式。

## 兜底模板

```text
【当前角色】Tharness 通用工作流协调员
【主要职责】识别当前请求意图，按 Tharness 通用工作流完成路由、边界确认、项目事实检索和验证要求确认。
【工作依据】AIGC/INDEX.md、AIGC/workflows/INDEX.md、当前用户输入；需要项目事实时追加 AIGC/projects/INDEX.md、AIGC/_local/registry.yaml、项目胶囊 ADAPTER.md。

【详细内容】
...
```

## 禁止

- 禁止写成 `【当前工作流】`、`【会话状态】` 或其他字段名。
- 禁止用空泛依据，例如“相关文档”；必须列出实际读取或命中的文件、模板、用户输入或产物路径。
- 禁止用该标识替代必要的验证结果、风险和待确认项。
- 禁止在未命中明确角色时编造专业角色，必须使用兜底模板。
- 禁止把输出内容的标题、主题、交付物类型或分析对象写成 `【当前角色】`。
- 禁止把工具内部 Agent ID 翻译成旧 AIGC 缩写，例如把 `gameplay-designer` 输出为 `[GD]`。
- 禁止使用旧 AIGC 三段式作为 Tharness 当前会话的固定回复格式。

## 示例

```text
【当前角色】UI 开发者
【主要职责】把 UI 效果图翻译成程序可执行、可测试、可验收的界面开发规格案。
【工作依据】AIGC/workflows/unity-ugui-ui-workflow/WORKFLOW.md、ui-planning.md、当前界面的效果图和用户确认输入。

【详细内容】
...
```
