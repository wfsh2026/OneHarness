## 技术方案

- **语言**：Bash shell script
- **创建方式**：heredoc（`cat <<'EOF' > file`）— 避免变量转义问题
- **修改方式**：sed — 在标记点前插入代码行
- **环境**：Mac (BSD sed)，需兼容 Linux (GNU sed)
- **幂等性**：所有修改前 `grep -q` 检查是否已存在
- **原子性**：先验证所有前置条件（路径可写/无冲突），再批量执行

## 关键 ADR

| # | 决策点 | 选定方案 | 原因 |
|---|--------|---------|------|
| ADR-1 | 脚本格式 | bash sh 脚本 | 用户 Mac 环境，sh 最轻量 |
| ADR-2 | 工具路径 | aigc/harness/tools/codegen/ | 与项目 AIGC 工具体系一致 |
| ADR-3 | 注册原子性 | 全部在工具内完成 | 核心动机：AI 遗漏注册是最大痛点 |
| ADR-4 | Component 生成 | component-gen.sh 独立工具 | 修订原"不做"决策：固化基类选择+生命周期注释，减少 AI 遗漏 |
| ADR-5 | GUI/SO 功能 | 不做 | 工具仅供 AI Agent 命令行使用 |
| ADR-6 | 场景工具架构 | Bash + C# Editor 双步骤 | 场景 Prefab 操作必须 Unity API |
| ADR-7 | 完整场景工具 | scene-gen.sh 全链路 | scene-server-gen.sh 保留供单独重生成 |
| ADR-8 | SceneData 分离 | partial class + static ctor | 不污染手写代码 |
| ADR-9 | 服务端场景策略 | 强制，不可跳过 | 移除 skip 选项，避免 AI 选择跳过 |
| ADR-10 | session-sync | 子命令式工具 | 声明与执行合一 |
| ADR-11 | Component 工具 | component-gen.sh 5类型支持 | 固化 base class 决策 + 生命周期引导 |
| ADR-12 | Mode 工具 | mode-gen.sh 全套注册 | 解决 ModeData 4处分散注册遗漏 |
