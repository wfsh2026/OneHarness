## S-03：功能需求

驾驶 MotoSheep 时，玩家按 E 键/GUI 按钮释放"彩虹飞跃"技能，在载具前方生成一条两段式彩虹之路（30° 坡道 + 平坦冲刺道）。任意载具驶上彩虹路后获得 +30% 极速/加速、0 油耗增益；5 秒后彩虹路渐变消散。

---

## S-04：功能定位

本文档负责 AB_RainbowLeap（主动技能：彩虹路生成）的 Ability 实现，以及 RainbowRoad_Entity（彩虹路 Mesh 实体 MonoBehaviour，含 Trigger 增益逻辑）。

> **⚠️ ADR #12 架构决策**：原设计中的 AE_RainbowRoadBuff 已移除。原因：AE 系统目标类型为 `ServerGPO`，而 MotorCarController 载具不是 GPO 实体，无法作为 AE 目标。增益效果改由 `RainbowRoad_Entity.OnTriggerEnter/Exit` 直接修改 `MotorCarController` 的 `maxSpeed`/`shiftSpeed`/油耗属性实现。

职责边界：不涉及载具物理/注册/输入（由载具系统子文档覆盖），仅通过 SM_Ability.PlayAbility 消息接收技能触发。

## S-04.5：架构预分析

### 需要哪些 System？

| System / 组件 | 端 | 继承 | 核心职责（一句话） |
|--------|----|------|-----------------|
| SAB_RainbowLeapSystem | Server | S_Ability_Base | 接收技能请求，计算锚点，障碍检测，广播生成消息，施加 CD |
| CAB_RainbowLeapSystem | Client | C_Ability_Base | 收到 RPC 后客户端实例化 RainbowRoad_Entity Mesh |
| RainbowRoad_Entity | Client | MonoBehaviour | 彩虹路实体生命周期 + **Trigger 直接增益**（maxSpeed/shiftSpeed/油耗修改 + FOV 过渡 + 特效） |

> ~~SAE_RainbowRoadBuffSystem / CAE_RainbowRoadBuffSystem~~ — 已移除（ADR #12：载具非 GPO 实体，AE 系统无法生效）

### 每个 System 挂哪些 Component？

**SAB_RainbowLeapSystem**
- `ServerAbilitySync`（PGC 默认，base.AddComponents 自动挂载）— 网络同步
- 无额外 Component（逻辑直接在 System 的 OnStart/OnUpdate 中处理）

**CAB_RainbowLeapSystem**
- `ClientAbilitySync`（PGC 默认）— 接收 RPC 数据
- 无额外 Component（实例化 RainbowRoad_Entity prefab）

**RainbowRoad_Entity**（MonoBehaviour，非 Ability System）
- 管理 Trigger 增益：`OnTriggerEnter` 检测 MotorCarController → 缓存原始值 → 修改 maxSpeed/shiftSpeed/油耗
- 管理 Trigger 移除：`OnTriggerExit` → 恢复原始值
- 管理 FOV 过渡：进入时 +10° / 离开时恢复（通过 CameraController.SetCameraRatio）
- 管理特效：彩虹拖尾 / 加速气流线 的播放与停止
- 管理生命周期：5 秒后 Opacity 渐变 → Destroy

### 每个 Component 的核心职责

| Component | 新建/复用 | 核心做什么 | 关键字段/依赖 |
|-----------|---------|-----------|-------------|
| `ServerAbilitySync` | PGC 默认 | RPC 广播 ability 数据给客户端 | — |
| `ClientAbilitySync` | PGC 默认 | 反序列化 RPC 数据 | — |
| `RainbowRoad_Entity` | 新建 | Trigger 增益 + 生命周期 + 特效 | 依赖 MotorCarController、CameraController |

### 依赖关系

- `MotoSheepSkillController`（载具子文档）→ 发送 → `SM_Ability.PlayAbility { Sign="AB_RainbowLeap" }`
- `ServerAbilityManager_SwitchAB` → 路由 → `SAB_RainbowLeapSystem`
- `SAB_RainbowLeapSystem` → 广播 → `Proto_Ability.TargetRpc_PlayAbility` → `ClientAbilityManager_SwitchAB` → `CAB_RainbowLeapSystem`
- `CAB_RainbowLeapSystem` → 实例化 → `RainbowRoad_Entity` prefab
- `RainbowRoad_Entity` → TriggerEnter → **直接修改** `MotorCarController.maxSpeed`/`shiftSpeed`/油耗（缓存原始值）
- `RainbowRoad_Entity` → TriggerExit → **直接恢复** `MotorCarController` 原始值
- `RainbowRoad_Entity` → FOV 过渡 → `CameraController.SetCameraRatio`

## S-06：ASCII 交互链路图

### 6.1 彩虹飞跃释放全链路

```
[客户端 · 驾驶员]
MotoSheepSkillController.OnSkillInput()
    │
    ├── CD 本地预检（30秒）→ 不就绪则返回（UI 提示冷却中）
    │
    └── MsgRegister.Dispatcher(new SM_Ability.PlayAbility {
            Sign = "AB_RainbowLeap",
            InData = { In_StartPoint = vehicle.position + forward*5, In_Forward = vehicle.forward }
        })
            │
            ▼
[服务端]
ServerAbilityManager.OnPlayAbility()
    │
    ├── MData = AbilityM_RainbowLeap.Select(Sign)
    ├── SwitchAB → case AB_RainbowLeap:
    │       ↓
    │   AddSystem<SAB_RainbowLeapSystem>(playAbilityData)
    │
    └── SAB_RainbowLeapSystem.OnAwake()
            │
            ├── 获取 InData: startPoint, forward, currentSpeed(XZ-only)
            ├── 水平化: hForward = ProjectOnPlane(forward, up) — 无论上坡/下坡始终水平
            ├── 速度自适应: spawnDist = M_SpawnDistance(3m) × 倍率(低速1×/中速2×/高速3×)
            ├── 锚点计算: spawnPos = startPoint + hForward * spawnDist
            ├── SABC障碍物检测组件
            │       → 当前状态: 地面检测/宽度检测/障碍物截断 均已屏蔽(TODO)
            │       → 固定 y-5f，使用配置最大半宽，全量生成两段
            ├── 生成实体（ServerAbilitySync 广播给所有客户端）
            ├── 施加 CD = M_CD(30秒)
            └── 设置自毁定时器 = M_Duration(5秒)
                    │
                    ▼
            Proto_Ability.TargetRpc_PlayAbility
            (广播: abilityId, sign, position, rotation, rampLength, sprintLength)
                    │
                    ▼
[客户端 · 所有玩家]
ClientAbilityManager.OnTargetRpc()
    │
    └── SwitchAB → case AB_RainbowLeap:
            ↓
        CAB_RainbowLeapSystem.OnStart()
            │
            ├── Instantiate(RainbowRoad_Entity.prefab, position, rotation)
            ├── RainbowRoadMeshBuilder.Build(rampLength, sprintLength, ...)
            │       → 生成两段式梯形 Mesh + MeshCollider
            └── RainbowRoad_Entity.StartLifecycle(duration=5s)
                    │
                    ├── 5秒后: StartCoroutine(FadeOut) → 材质 Opacity 渐变 → Destroy
                    │
                    └── Trigger Volume 激活（覆盖 Mesh 表面）
```

### 6.2 彩虹路增益 Buff 链路（Trigger 直接修改，ADR #12）

```
[客户端]
RainbowRoad_Entity.OnTriggerEnter(Collider other)
    │
    ├── 检测: other.GetComponentInParent<MotorCarController>()
    │       → 找不到 → 忽略
    │
    └── 找到 MotorCarController mcc →
        │
        ├── 缓存原始值:
        │   _origMaxSpeed = mcc.maxSpeed          // 例: 77
        │   _origShiftSpeed = mcc.shiftSpeed      // 例: 119
        │   _origOilConsumption = carShift.oilConsumption
        │
        ├── 应用增益:
        │   mcc.maxSpeed *= (1 + speedBoostPct)    // 77 → 100
        │   mcc.shiftSpeed *= (1 + speedBoostPct)  // 119 → 154
        │   carShift.oilConsumption = 0             // 0 油耗
        │
        ├── FOV 过渡:
        │   CameraController.SetCameraRatio(fovDelta=+10°, transitionTime=2s)
        │
        └── 播放特效:
            启动彩虹拖尾 ParticleSystem
            启动加速气流线 ParticleSystem

---

[客户端]
RainbowRoad_Entity.OnTriggerExit(Collider other)
    │
    ├── 检测: other.GetComponentInParent<MotorCarController>()
    │       → 找不到 → 忽略
    │
    └── 找到 → 与缓存匹配 →
        │
        ├── 恢复原始值:
        │   mcc.maxSpeed = _origMaxSpeed            // 恢复 77
        │   mcc.shiftSpeed = _origShiftSpeed        // 恢复 119
        │   carShift.oilConsumption = _origOilConsumption
        │
        ├── FOV 恢复:
        │   CameraController.SetCameraRatio(fovDelta=0, transitionTime=2s)
        │
        └── 停止特效:
            停止彩虹拖尾 ParticleSystem
            停止加速气流线 ParticleSystem
```

> **注意事项**：
> - 多辆车同时在彩虹路上时，需用 Dictionary<MotorCarController, OrigValues> 分别缓存
> - 彩虹路销毁时（5 秒生命周期结束），OnDestroy 中需遍历仍在路上的载具，恢复其原始值
> - 增益参数（speedBoostPct=0.3, fuelCostOverride=0, fovDelta=10°）从 RainbowRoad_Entity 可序列化字段读取

## S-10：已知问题与调试记录

### 10.1 SABC 射线截断行为分析

> 射线从 `spawnPoint（车前5m）` 向前射，检测范围 `totalLength = rampLen(30) + sprintLen(50) = 80m`，层级掩码 `~(1<<11)`（排除 Layer 11）。

| 情况 | 触发条件 | 结果 |
|------|---------|------|
| rampLen < 30 | spawnPoint 向前 **0~30m 有碰撞**（hitDist < rampLength） | `rampLen = hitDist`，`sprintLen = 0`（强制清零） |
| sprintLen < 50 | spawnPoint 向前 **30~80m 有碰撞**（hitDist ≥ rampLength） | `rampLen = 30`（保持），`sprintLen = hitDist - 30` |
| 两者均为原值 | 80m 内无碰撞 | `rampLen = 30`，`sprintLen = 50` |

**⚠️ 已知代码约束（重要）**：按当前 SABC 逻辑，`rampLen 被截断` 与 `sprintLen 保持50` **不能同时出现**。如果日志输出 `rampLen:3.43 sprintLen:50`，说明：

1. **日志来源非 OnDetectComplete**：可能记录了 CSV 原始值（30/50）而非 SABC 返回值
2. **旧 Build 缓存**：Code Changes 尚未被 Unity 重新编译生效
3. **Layer 11 不是 Terrain**：射线打到的是地形以外的物体（建筑/树木/其他载具）

**待确认事项**：
- Terrain 具体在哪个 Layer？（SABC 目前排除 Layer 11，若 Terrain 不在 Layer 11，坡面地形会截断射线）
- 日志 `rampLen:X sprintLen:Y` 是哪个文件哪一行输出的？（确认是 OnDetectComplete 回调值还是其他地方的 CSV 值）

### 10.2 实测观察日志（待定位）
