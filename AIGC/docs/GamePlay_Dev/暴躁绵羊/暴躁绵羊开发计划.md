## Codegen 指令清单

> 以下列出所有需执行的 codegen 工具命令。用户阶段 5 审图通过后，阶段 6 直接依序执行。

### 指令 1：生成 AB_RainbowLeap（彩虹飞跃主动技能）

```bash
bash aigc/harness/tools/codegen/ability-gen.sh \
  --name RainbowLeap \
  --type AB \
  --fields "M_CD:float,M_Duration:float,M_SpawnDistance:float,M_RampLength:float,M_RampAngle:float,M_SprintLength:float,M_RampNearWidth:float,M_RampFarWidth:float,M_SprintNearWidth:float,M_SprintFarWidth:float,M_EffectSign:string" \
  --csv-fields "M_CD,M_Duration,M_SpawnDistance,M_RampLength,M_RampAngle,M_SprintLength,M_RampNearWidth,M_RampFarWidth,M_SprintNearWidth,M_SprintFarWidth,M_EffectSign" \
  --primary-keys "M_Sign" \
  --sync-client true \
  --in-fields "In_StartPoint:Vector3,In_Forward:Vector3"
```

### ~~指令 2：生成 AE_RainbowRoadBuff~~ — 已移除（ADR #12）

> 增益逻辑改由 RainbowRoad_Entity.OnTriggerEnter/Exit 直接修改 MotorCarController 属性实现，无需 AE codegen。
> 原因：AE 系统目标类型为 ServerGPO，MotorCarController 载具不是 GPO 实体。

### 指令 3：手动操作（非 codegen）

以下操作需在 codegen 执行后手动完成，不通过工具生成：

1. **复制预制**：拷贝 PonyVehicle 预制体目录 → 重命名为 MotoSheep
2. **复制 MotorCarSetting**：`PonyVehicle_MotorCarSetting.asset` → `MotoSheep_MotorCarSetting.asset`，修改物理参数
3. **SOCarData.txt**：新增 MotoSheep 数据行
4. **Vehicle.asset**：新增 MotoSheep 投放条目
5. **VehicleStateButtonControl.cs**：switch 新增 MotoSheep case
6. **AutoPrefabCarrier**：新增 MotoSheep 目录 + 注册
7. **RainbowRoad_Entity.cs**：手写彩虹路 Mesh 生成 + Trigger MonoBehaviour
8. **MotoSheepSkillController.cs**：手写技能触发控制器（E 键/GUI 按钮）
