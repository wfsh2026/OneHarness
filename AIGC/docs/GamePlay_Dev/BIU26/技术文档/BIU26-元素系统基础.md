## 一、S-03 功能需求

**玩家体验**：在 BIU26 割草发育过程中，拾取悬浮武器后发现它带有火/冰/电元素标签——火武器击中目标后目标冒橙火持续掉血，冰武器积累冰冻值令敌人变蓝变慢，电武器命中时闪电弧向附近目标弹射。三种效果各自可感知，玩家开始主动思考武器阵容的搭配。

---

## 二、S-04 功能定位

本文档覆盖 BIU26 Phase 3 的**元素数据层 + 三种基础状态效果层**：
- 元素类型枚举定义（None/Fire/Ice/Electric）
- 武器拾取时随机分配元素，通过 RPC 同步客户端视觉拖尾
- 服务端 `ServerBIU26ElementManager`（Mode 级 ComponentBase）维护目标的 Burn/Freeze 状态
- 每次武器开火时，在服务端将对应元素效果施加到目标身上

**不包含**：元素反应（Fire+Ice/Fire+Electric/Ice+Electric 的组合爆发，见 Phase 3.5 文档）、同元素增强（Phase 3.5 实现）、怪物元素克制（后续迭代）。

    玩家进入3m范围
      │
      ▼
[SM_AI.Event_AddMasterAI] → 召唤 FloatingWeapon GPO
      │ OR_CallBack
      ▼

      ▼

      │ element != None
      ▼

      │
      ▼

      │
      ▼

## 七、代码骨架

```csharp
// ServerBIU26ElementManager.cs（Mode 级 ComponentBase）
// 职责：元素分配 + 触发 SAE（状态管理完全托管给 SAE，不持有 Burn/Freeze 状态字典）
using System.Collections.Generic;
using Sofunny.BiuBiuBiu2.CoreGamePlay;
using Sofunny.BiuBiuBiu2.Data;
using Sofunny.BiuBiuBiu2.Message;
using Sofunny.BiuBiuBiu2.ServerMessage;
using Sofunny.BiuBiuBiu2.Template;
using UnityEngine;

namespace Sofunny.BiuBiuBiu2.ServerGamePlay {
    public class ServerBIU26ElementManager : ComponentBase {
        // 武器元素映射 (weaponGpoId → element)
        private Dictionary<int, SE_BIU26.BIU26ElementType> _weaponElements = new();
        // 冰冻积累值 (targetGpoId → 当前积累)，满 MaxFreezeValue 触发 SAE
        private Dictionary<int, float> _freezeAccum = new();
        private List<SE_Mode.PlayModeCharacterData> characters;

        protected override void OnAwake() {
            MsgRegister.Register<SE_BIU26.Event_FloatingWeaponAdded>(OnWeaponAdded);
            MsgRegister.Register<SE_BIU26.Event_WeaponFiredAtTarget>(OnWeaponFiredAtTarget);
            Register<SE_Mode.Event_GameState>(OnGameState);
        }

        protected override void OnClear() {
            MsgRegister.Unregister<SE_BIU26.Event_FloatingWeaponAdded>(OnWeaponAdded);
            MsgRegister.Unregister<SE_BIU26.Event_WeaponFiredAtTarget>(OnWeaponFiredAtTarget);
            Unregister<SE_Mode.Event_GameState>(OnGameState);
            _weaponElements.Clear();
            _freezeAccum.Clear();
            characters = null;
        }

        private void OnGameState(ISystemMsg body, SE_Mode.Event_GameState e) {
            if (e.GameState != ModeData.GameStateEnum.RoundStart) return;
            Dispatcher(new SE_Mode.Event_GetCharacterList { CallBack = list => characters = list });
        }

        private void OnWeaponAdded(SE_BIU26.Event_FloatingWeaponAdded e) {
            if (e.WeaponGPO == null || e.WeaponGPO.IsClear()) return;
            var element = (SE_BIU26.BIU26ElementType)UnityEngine.Random.Range(0, 4);
            _weaponElements[e.WeaponGPO.GetGpoID()] = element;
            if (element == SE_BIU26.BIU26ElementType.None) return;
            Rpc(new Proto_Mode.Rpc_BIU26WeaponElementSet {
                weaponGpoId = e.WeaponGPO.GetGpoID(),
                element     = (byte)element,
            });
        }

        private void OnWeaponFiredAtTarget(SE_BIU26.Event_WeaponFiredAtTarget e) {
            if (!_weaponElements.TryGetValue(e.WeaponGPO.GetGpoID(), out var element)) return;
            if (element == SE_BIU26.BIU26ElementType.None) return;
            if (e.TargetGPO == null || e.TargetGPO.IsClear()) return;
            if (e.TargetGPO.HasTag(GamePlayTagData.TagEnum.Dead)) return;

            var tid = e.TargetGPO.GetGpoID();
            switch (element) {
                case SE_BIU26.BIU26ElementType.Fire:
                    // 触发/刷新 Burn SAE（SAE 内部管理 stacks 上限、DOT、Tag 生命周期）
                    MsgRegister.Dispatcher(new SM_Ability.PlayAbilityEffect {
                        FireGPO   = e.WeaponGPO,
                        TargetGPO = e.TargetGPO,
                        MData     = AbilityM_BIU26Burn.CreateForSign("BIU26Burn"),
                        InData    = new AbilityIn_BIU26Burn { In_Power = BurnDamagePerStack },
                    });
                    break;
                case SE_BIU26.BIU26ElementType.Ice:
                    // 本地积累冻结值；满阈值且目标未冻结时触发 Freeze SAE
                    _freezeAccum[tid] = (_freezeAccum.TryGetValue(tid, out var fv) ? fv : 0f) + FreezePerHit;
                    if (_freezeAccum[tid] >= MaxFreezeValue
                        && !e.TargetGPO.HasTag(GamePlayTagData.TagEnum.BIU26Frozen)) {
                        _freezeAccum[tid] = 0f;
                        MsgRegister.Dispatcher(new SM_Ability.PlayAbilityEffect {
                            FireGPO   = e.WeaponGPO,
                            TargetGPO = e.TargetGPO,
                            MData     = AbilityM_BIU26Freeze.CreateForSign("BIU26Freeze"),
                        });
                    }
                    break;
                case SE_BIU26.BIU26ElementType.Electric:
                    ApplyArcBounce(e.WeaponGPO, e.TargetGPO);
                    break;
            }

            Rpc(new Proto_Mode.Rpc_BIU26ElementStatusApplied {
                targetGpoId = tid,
                element     = (byte)element,
            });
        }

        private void ApplyArcBounce(IGPO weaponGPO, IGPO primaryTarget) {
            if (characters == null) return;
            var center      = primaryTarget.GetPoint();
            int bounceCount = 0;
            foreach (var character in characters) {
                if (bounceCount >= ArcMaxTargets) break;
                var gpo = character.CharacterGPO;
                if (gpo == null || gpo.IsClear()) continue;
                if (gpo.GetGpoID() == primaryTarget.GetGpoID()) continue;
                if (gpo.HasTag(GamePlayTagData.TagEnum.Dead)) continue;
                if (Vector3.Distance(gpo.GetPoint(), center) > ArcRadius) continue;

                var capturedGpo = gpo;
                weaponGPO.Dispatcher(new SE_GPO.Event_GetAtk { CallBack = atk => {
                    int arcDmg = Mathf.Max(1, Mathf.RoundToInt(atk * ArcDamagePercent));
                    capturedGpo.Dispatcher(new SE_GPO.Event_DownHP { DownHp = arcDmg, AttackGPO = weaponGPO });
                }});
                bounceCount++;
            }
        }

        private const float FreezePerHit    = 25f;
        private const float MaxFreezeValue  = 100f;
        private const float BurnDamagePerStack = 5f;
        private const float ArcRadius       = 3f;
        private const int   ArcMaxTargets   = 3;
        private const float ArcDamagePercent = 0.4f;
    }
}
```

### Ability 工程师子任务规格（供 Ability 工程师参考）

```
【Burn SAE 规格】
Sign：          "BIU26Burn"
MData 字段：    M_DeltaTime=1f（每秒 DOT），M_LifeTime=6f，M_MaxStacks=10
InData 字段：   In_Power=5（每层 5 HP/s，由 ElementManager 传入）
行为：
  OnStart  → AddTag(BIU26Burning)
  每帧     → ServerAbilityDownHpByTime 每秒触发 SE_Ability.HitGPO（伤害 = stacks × In_Power）

Sign：          "BIU26Freeze"
MData 字段：    M_LifeTime=3f，M_SlowRate=0.4f
行为：
  OnStart  → AddTag(BIU26Frozen)
             target.Dispatcher(SE_AbilityEffect.Event_AddEffect{
               Effect=GpoMoveSpeedRate, Value=-M_SlowRate, CallBack=保存 handle})
  OnClear  → handle.Remove()
             RemoveTag(BIU26Frozen)
             _freezeAccum[targetId] = 0f（通知 Manager 重置积累）
```

## 八、S-08 边界条件

### 依赖的外部接口

| 依赖 | 说明 |
|------|------|
| `SE_BIU26.Event_FloatingWeaponAdded` | Phase 2.5 已实现，武器召唤成功时全局广播 |
| `SE_Mode.Event_GetCharacterList` | Phase 2 已实现，用于获取所有玩家 GPO 列表（电弧弹射遍历用）|
| `SM_Ability.PlayAbilityEffect` | 框架原生，触发 SAE。Fire 命中 → Burn SAE；冰冻积累满 → Freeze SAE |
| `SE_AbilityEffect.Event_AddEffect` | 由 SAE_BIU26FreezeSystem 内部使用，框架自动网络同步减速（Manager 不直接调用）|
| `SE_GPO.Event_DownHP` | 由 SAE_BIU26BurnSystem 内部使用，每秒 DOT（Manager 不直接调用）|
| `GamePlayTagData.TagEnum.BIU26Burning` / `BIU26Frozen` | **需追加到枚举**（Ability 工程师负责），Manager 通过 `HasTag` 读取 |
| `Proto_Mode.GetProtoDoc()` switch | 每新增一个 Rpc/Cmd struct，**必须**在 switch 追加对应 case，否则反序列化时无法识别 |

### 禁止事项

- **禁止** `ServerBIU26ElementManager` 在内部维护 Burn/Freeze 状态字典——状态生命周期完全托管给 SAE
- **禁止** 修改 `GPOM_BIU26FloatingWeapon` 结构体来存储元素类型（GPOM 是静态配表，元素是运行时随机分配）
- **禁止** `ClientBIU26FloatingWeaponView` 通过 `Shared Material` 修改颜色——必须使用 `MaterialPropertyBlock`（Rule 18）
- **禁止** 在 `ServerBIU26WeaponPickupZone` 内做元素分配——元素逻辑全部集中在 `ServerBIU26ElementManager`
- **禁止** Electric 电弧弹射到 Minion GPO（AISystem GPO）——只对 `GPOType.Role` 的玩家施加，需过滤 `gpo.GetGPOType() != GPOData.GPOType.Role`
