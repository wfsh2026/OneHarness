## S-06：完整交互链路图

```
═══════════════ 服务端触发端（DL 模式系统调用） ═══════════════

[ServerBIU26FloatingWeaponAttack.FireAtTarget(targetGPO)]
    │
    ├─ 从 FloatingWeaponManager 取当前武器 Power 值（白/蓝/金×倍率）
    │
    └─ MsgRegister.Dispatcher(new SM_Ability.PlayAbility {
           FireGPO  = playerGPO,         // 玩家 GPO（发射方）
           MData    = trackingMissleData, // AbilityM_TrackingMissle 的 MData
           InData   = new AbilityIn_TrackingMissle {   // 【AB工程师确认字段名】
               In_StartPoint = floatingWeaponWorldPos, // 悬浮武器的 WorldPosition
               In_TargetGPO  = targetGPO,              // 锁定目标
               In_Power      = weaponPower              // 本把武器的伤害值
           }
       })

═══════════════ Ability 框架处理（现有框架，不修改） ═══════════════

SM_Ability.PlayAbility
    └─ ServerAbilityManager.OnPlayAbilityCallBack
         ├─ MData.Select()  →  读取 CSV "BIU26_FloatingWeapon_Bullet" 行
         └─ HandleAbilityABType()
              └─ ServerAbilityManager_SwitchAB
                   └─ case AB_BIU26FloatingWeaponBullet:
                        └─ AddSystem<SAB_TrackingMissleSystem>
                             ├─ 初始化飞行轨迹（从 StartPoint 追踪 TargetGPO）
                             ├─ 每帧更新位置（M_TrackSpeed / M_LockSpeed）
                             ├─ 命中判定 → MoveDistance 超出 OR 碰到 TargetGPO
                             │       ├─ 触发 HP 扣除（In_Power 值）
                             │       └─ 播放命中 Ability（如有配表）
                             └─ ServerAbilitySync → TargetRpc_PlayAbility(protoDoc)
                                  └─ ClientAbilityManager
                                       └─ CAB_TrackingMissleSystem（灰盒黄球飞行）

═══════════════ 最终结果 ═══════════════

targetGPO.HP -= weaponPower
→ 如果 HP ≤ 0 → 触发死亡流程 → SE_BIU26.Event_MinionKilled
```
