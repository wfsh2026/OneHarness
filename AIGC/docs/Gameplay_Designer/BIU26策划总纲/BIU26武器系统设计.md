## 一、武器三维系统概述

玩家看到一把悬浮武器，同时读到三层信息：

```
┌──────────────────────────────────────────────────┐
│  维度1：枪械类型（模型形状）                         │
│  → 决定战斗用途：打群体/单体，近程/远程，续航/爆发    │
│                                                  │
│  维度2：元素（子弹拖尾颜色）                         │
│  → 决定击杀机制：触发什么反应，克制什么怪物            │
│                                                  │
│  维度3：品质（模型大小）                             │
│  → 决定数值强度：小=白质，中=蓝质，大=金质           │
└──────────────────────────────────────────────────┘

玩家无需看任何文字说明，看一眼武器即可理解它的定位。
```

## 二、枪械类型设计（6种）

### 2.1 六种枪型定义

| 枪型 | 克制对象 | 核心机制 | 操作密度 | 适用场景 |
|------|---------|---------|---------|---------|
| **手枪** | 无特定克制 | 基础稳定输出，低弹速连射 | 最低 | 全能保底，适合发育期早期 |
| **冲锋枪** | 克制单体快速接近的敌人 | 极高射速，单体DPS极强，范围小 | 低 | 应对快速冲近的敌人 |
| **霰弹枪** | 克制群体接近的敌人 | 扇形散射，近距离群体覆盖 | 低 | 应对蜂拥而来的小怪群 |
| **步枪** | 无特定克制，全能型 | 射速、射程、伤害最平衡 | 低 | 任何情境均有效 |
| **机枪** | 克制高血量大型单位 | 持续高弹幕，弹药无限但过热冷却 | 低 | 打精英怪和Boss阶段 |
| **狙击枪** | 克制远程/高优先级目标 | 超高单发伤害，穿透，射速极慢 | 低 | 瞬间爆发击杀关键目标 |

> **注：** 所有枪型均为悬浮武器，玩家无需瞄准操作，自动索敌开火。枪型差异体现在AI行为逻辑（优先选择哪类目标、攻击频率、攻击方式）和视觉弹道形态上。

### 2.2 六种枪型的视觉弹道形态

| 枪型 | 弹道形态 | 视觉特征 |
|------|---------|---------|
| 手枪 | 单点小圆弹，中速 | 小而密集的弹点 |
| 冲锋枪 | 单点极小弹，极高频 | 高密度弹幕流，几乎连成线 |
| 霰弹枪 | 扇形散射短程 | 近距离爆开的散弹 |
| 步枪 | 单点中弹，中速 | 标准弹道，最直观 |
| 机枪 | 单点大弹，持续喷射 | 厚重感的弹幕流 |
| 狙击枪 | 单点极大弹，极慢 | 细长光束，穿透感强 |

## 三、元素系统（火/冰/电）

### 3.1 元素视觉识别

> 元素通过**子弹拖尾颜色**表达，无需文字标注玩家即可识别。

| 元素 | 拖尾颜色 | 命中粒子颜色 | 状态持续时的视觉 |
|------|---------|-----------|--------------|
| **火** | 橙红 | 橙色火焰粒子 | 目标持续燃烧（橙色火焰覆盖身体） |
| **冰** | 青白 | 冰晶碎片飞溅 | 目标覆盖冰霜，移动拖慢（身体半透明冰蓝色）|
| **电** | 蓝紫 | 蓝色闪电弧 | 电弧在目标身上/目标之间持续跳跃 |

### 3.2 单元素击杀机制

| 元素 | 基础效果 | 叠层设计 | 最大层数 | 击杀特效 |
|------|---------|---------|---------|---------|
| **火** | 持续灼烧DOT（每秒X伤害） | 每次命中+1层，层数越多DOT越强 | 10层 | 目标燃烧至熔化，橙色爆炸散开 |
| **冰** | 减速（-40%移速）→ 积累冻结 | 命中积累冻结值，满值冻结 | 无层数，冻结值机制 | 目标碎裂成冰块四散 |
| **电** | 链式弹射（最近目标，约3m） | 每次命中传导至1-3个相邻目标 | 无层数，每次触发独立 | 目标电弧爆散，蓝色闪光 |

### 3.3 同元素叠加效果

> 若发育出的悬浮武器中有2把以上相同元素，该元素效果增强：

| 同元素数量 | 增强效果 |
|---------|---------|
| 2把同元素 | 该元素状态叠层速度+50%，状态持续时间+30% |
| 3把同元素 | 额外效果解锁（见下方） |

**3把同元素解锁的额外效果：**

| 元素 | 3把同元素额外效果 |
|------|----------------|
| 火×3 | 燃烧目标死亡时爆炸，范围点燃周围目标（火焰传播） |
| 冰×3 | 冻结目标碎裂时，碎片对周围目标造成冰冻值积累 |
| 电×3 | 链式弹射距离从3m扩展到6m，可弹射目标数量从3个到5个 |

## 四、元素反应（火×冰×电，3种组合）

### 4.1 三种元素反应总览

| 组合 | 反应名称 | 触发条件 |
|------|---------|---------|
| 火 + 冰 | **蒸发爆裂** | 已燃烧目标被冰击中（或反之） |
| 火 + 电 | **感电燃烧** | 已燃烧目标被电击中（或反之） |
| 冰 + 电 | **超导连锁** | 已冻结/减速目标被电击中（或反之） |

### 4.2 三种反应详细设计

---

#### 反应① 火 + 冰 → **蒸发爆裂**

```
触发：目标已有燃烧状态时被冰攻击命中（或反之）
效果：
  · 清空目标身上所有燃烧层数
  · 将燃烧层数转化为一次性爆发伤害（层数×N）
  · 爆炸产生蒸汽冲击波（范围2.5m），对周围目标造成降低版爆发伤害
  · 冲击波波及目标同时获得冰冻值积累
视觉：橙白色蒸汽爆炸，圆形冲击波向外扩散
音效：蒸汽喷射+爆炸声
体验关键词：积攒火层，一把冰枪触发整片爆炸
```

**策略价值：**
- 积累火层作为"储能"，时机到了用冰触发清算
- 对密集小怪群极有效（爆炸AOE波及周围）

---

#### 反应② 火 + 电 → **感电燃烧**

```
触发：目标已有燃烧状态时被电攻击命中（或反之）
效果：
  · 目标进入【感电燃烧】复合状态：
    - 燃烧DOT伤害提升80%（电流加热）
    - 电弧弹射效果不消失，继续传导至相邻目标
    - 相邻被弹射目标同样获得强化燃烧状态
  · 复合状态持续4秒
视觉：目标身上橙紫色电弧缠绕燃烧粒子，弹射时带走火焰
音效：燃烧声+电弧声混合
体验关键词：火焰顺着闪电跑到其他怪身上
```

**策略价值：**
- 单目标先点燃，再用电弧把"强化燃烧"扩散出去
- 群体清场效率极高

---

#### 反应③ 冰 + 电 → **超导连锁**

```
触发：目标已减速（冰状态）时被电攻击命中（或反之）
效果：
  · 冰雪导电，电弧弹射范围从3m扩展到8m
  · 弹射目标数量从3个扩展至7个（一次覆盖整片怪群）
  · 所有被弹射目标同时受到减速（-60%移速，3秒）
  · 减速目标受到所有伤害+20%（超导易伤）
视觉：蓝白色超大范围闪电网覆盖怪群，大量目标同时被电弧连接
音效：大范围电弧轰鸣
体验关键词：一个闪电覆盖整片地图的怪
```

**策略价值：**
- 冰先减速聚拢，电弧触发全场范围超导
- 视觉冲击力最强，满屏感最高峰

## 五、品质阶梯设计

### 5.1 三级品质定义

| 品质 | 模型大小 | 数值强度 | 获取方式 |
|------|---------|---------|---------|
| **白质**（基础）| 标准尺寸（1x） | 基础数值 | 发育期早期掉落 |
| **蓝质**（强化）| 中等放大（1.4x） | 数值×1.5 | 发育期中期掉落 |
| **金质**（精英）| 明显放大（2x） | 数值×2.5 | 发育期后期/精英怪掉落 |

### 5.2 品质的视觉设计规范

- 模型整体等比放大，保持原有形状，**不改变外形设计**
- 品质提升时，武器底座/枪管有对应品质颜色的光晕：
  - 白质：无光晕
  - 蓝质：蓝色微光光晕
  - 金质：金色跳动光晕 + 解锁时专属音效

### 5.3 品质对视觉满屏感的影响

金质武器体积更大，视觉上更显眼，在背后悬挂时更有"强大阵容"的视觉感知。
- 6把白质武器：满屏感基准值
- 混合蓝质/金质：满屏感显著提升
- 6把金质武器：视觉冲击力最高（游戏理想的发育终态视觉）

## 六、武器获取与替换机制

### 6.1 全局掉落规则

```
小怪击杀后：必定掉落金币 + 概率掉落武器

武器掉落品质随缩圈线性提升：
  发育期     → 白质为主
  第1圈收缩  → 蓝质开始出现
  第2圈收缩  → 蓝质/金质混合
  第3圈（终）→ 金质为主
```

### 6.2 武器替换规则

玩家拾取地面武器时，可以选择：
- **替换**：将已装备的某把悬浮武器替换为新武器（枪型/元素/品质可能全都变化）
- **忽略**：不拾取，继续使用当前武器

**替换的策略价值：**
- 用更高品质的同枪型武器替换（纯数值提升）
- 用不同元素的武器替换（调整元素组合，触发新反应）
- 用不同枪型替换（补充战斗场景覆盖）

### 6.3 发育完成后的持续成长

发育完成（6把悬浮武器全部解锁）后，刷怪仍有意义：

> 玩家始终面临决策："继续打怪升级武器品质，还是去猎玩家拿金币？"

这个决策在缩圈压力下不断变化，是发育期结束后维持游戏张力的核心机制。

## 七、武器组合的策略决策框架

### 6.1 玩家在发育期面临的三个决策维度

```
决策维度1：枪型组合
  → 我需要更多近程压制（冲锋/霰弹），还是远程爆发（狙击）？
  → 当前有精英怪 → 优先拾取机枪

决策维度2：元素组合  
  → 凑同元素（叠层效果增强）？还是凑两种元素（触发反应）？
  → 当前怪物是火系 → 优先拾取冰元素武器（克制）

决策维度3：品质选择
  → 出现了一把白质狙击枪和一把蓝质手枪 → 选哪个？
  → 通常选品质更高的，除非枪型极不需要
```

### 6.2 克制系统（怪物元素属性，待小怪设计文档补充）

> 怪物元素属性和克制奇迳效果将在《BIU26小怪设计文档》中详细定义。
> 核心原则：被克制元素命中时，视觉上有明显的"弱点被击中"反馈（如冰系怪被火击中时冰甲熔化），且数值上有显著的额外伤害或特殊击杀效果。

## 八、武器系统全景速查

```
一把悬浮武器 = 枪型（形状）× 元素（颜色）× 品质（大小）

枪型（6种）：手枪 / 冲锋枪 / 霰弹枪 / 步枪 / 机枪 / 狙击枪
元素（3种）：火（橙红）/ 冰（青白）/ 电（蓝紫）
品质（3级）：白质1x / 蓝质1.4x / 金质2x

元素叠加：
  同元素×2 → 状态效率+50%
  同元素×3 → 额外效果解锁

元素反应（三种组合）：
  火+冰 → 蒸发爆裂（AOE爆发清场）
  火+电 → 感电燃烧（强化DOT+扩散传播）
  冰+电 → 超导连锁（超大范围闪电网）

决策层级（优先级从高到低）：
  1. 克制当前怪物元素
  2. 凑反应组合
  3. 叠同元素
  4. 选更高品质
```
