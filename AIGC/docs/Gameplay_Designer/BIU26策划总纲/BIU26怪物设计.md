## 一、设计原则

### 1.1 小怪的两个设计职责

```
职责1：提供发育期的击杀正反馈（割草感的来源）
职责2：制造对武器组合的策略压力（行为差异 → 枪型克制需求）
```

小怪不只是"被打死的背景"——它的行为模式和元素属性，是玩家在发育期做出"我需要哪把枪"决策的依据。

### 1.2 小怪设计的约束条件

- 单只小怪TTK（玩家持有1把手持武器时）：**0.3-0.8秒**
- 发育期2-3分钟内：玩家需击杀约**50-80只小怪**
- 割草感要求：小怪死亡动画必须短促爽快，不能有冗长倒地过程

## 二、行为类型设计（4种）

小怪行为类型与枪型克制形成对应关系，玩家通过观察敌人行为，自然产生"我需要某种枪型"的判断。

### 类型A：冲锋型（单体快速接近）

| 属性 | 设计 |
|------|------|
| **移动方式** | 快速直线冲向玩家，速度约8-10m/s |
| **攻击方式** | 近身单体爪击/撞击，伤害高但频率低 |
| **血量** | 低（快死快爽，不拖节奏） |
| **威胁模式** | 单个时威胁中等，但突然多个同时冲来时压力大 |
| **对应克制枪型** | **冲锋枪**（极高射速，快速击杀单体接近目标） |
| **外观视觉线索** | 体型细长，四肢修长，冲刺姿态明显 |

---

### 类型B：群涌型（集群慢速接近）

| 属性 | 设计 |
|------|------|
| **移动方式** | 慢速向玩家聚集，速度约2-3m/s，但成群出现（5-15只一组）|
| **攻击方式** | 近身范围啃咬，单只伤害极低，但堆叠伤害可观 |
| **血量** | 极低（能被一发打死，但量多） |
| **威胁模式** | 单只无威胁，成群包围时有被"淹没"的压迫感 |
| **对应克制枪型** | **霰弹枪**（扇形散射，一发覆盖多只群涌型小怪） |
| **外观视觉线索** | 体型矮小圆滚，成群移动时形成"蚁群"视觉 |

---

### 类型C：远程型（保持距离射击）

| 属性 | 设计 |
|------|------|
| **移动方式** | 主动保持与玩家约15-25m的距离，玩家靠近则后退 |
| **攻击方式** | 远程投射物攻击，弹速较慢但连续射击 |
| **血量** | 中等 |
| **威胁模式** | 单个持续造成远程干扰伤害，玩家如果不优先处理会持续掉血 |
| **对应克制枪型** | **狙击枪**（超远射程+高单发伤害，瞬间消灭远程型目标） |
| **外观视觉线索** | 体型中等，背部有明显发射器/触角，站立时有蓄力发光动作 |

---

### 类型D：坦克型（高血量慢速推进）

| 属性 | 设计 |
|------|------|
| **移动方式** | 极慢速稳定推进，速度约1-1.5m/s，无法被击退 |
| **攻击方式** | 近身大范围AOE冲击波，伤害高，前摇明显（玩家有时间走位）|
| **血量** | 极高（单只击杀耗时5-10秒，是其他类型的5-10倍）|
| **威胁模式** | 是"精英怪"的基础形态，出现时需要专注击杀，否则持续推进施压 |
| **对应克制枪型** | **机枪**（持续高弹幕输出，专门针对高血量目标） |
| **外观视觉线索** | 体型庞大，厚重装甲感，移动时地面震动粒子 |

## 三、元素属性与克制奇迳效果

每种元素小怪被克制元素命中时，触发**视觉和数值双层**的奇迳效果。玩家能立刻看见"我克制到它了"。

### 3.1 克制矩阵

| 怪物元素 | 外观颜色标识 | 被克制元素 | 奇迳效果 |
|---------|-----------|---------|---------|
| **火系怪** | 身体表面常燃，橙红发光 | 冰 | 冰攻击命中时**瞬间冻结**（无需积累冻结值），冻结状态下受到所有伤害×2，碎裂时爆炸范围+50% |
| **冰系怪** | 冰甲覆盖身体，青白色 | 火 | 火攻击命中时**熔化冰甲**（冰甲熔化动效），冰甲消失后受到所有伤害×2，且移速-30% |
| **电系怪** | 身体持续放电，蓝紫闪烁 | 电 | 同元素电攻击命中时**过载短路**（反而被击晕0.8秒），击晕状态下受暴击率+50%的额外暴击 |
| **无属性怪** | 无特殊颜色，标准外观 | 无克制 | 对所有元素伤害正常承受，是触发元素反应的最佳目标 |

> **电系怪被电克制**的设计意图：同元素反而触发过载，制造"同元素并非总是最优"的策略有趣性，避免玩家无脑堆同元素。

### 3.2 克制视觉可读性规范

玩家必须在**不看任何说明的情况下，通过观察小怪外观**判断其元素属性：

| 怪物元素 | 可感知的直觉信号 |
|---------|--------------|
| 火系 | "这怪在燃烧 → 应该怕冰" |
| 冰系 | "这怪穿着冰甲 → 应该怕火" |
| 电系 | "这怪在放电 → 电会让它过载" |
| 无属性 | "没有特别颜色 → 随便打，适合触发反应" |

## 四、行为类型 × 元素属性的组合

小怪的**行为类型**和**元素属性**是独立的两个维度，可以自由组合，形成丰富的敌人变体：

| 组合示例 | 威胁特征 | 应对策略 |
|---------|---------|---------|
| 冲锋型×火系 | 快速冲来，近身后附加燃烧 | 冰元素冲锋枪：冻结+近距离清除 |
| 群涌型×冰系 | 大量冰甲小怪包围 | 火元素霰弹枪：一发熔化一片冰甲 |
| 远程型×电系 | 远距离持续电击，难以靠近 | 电元素狙击枪：过载短路+远程清除 |
| 坦克型×无属性 | 高血量慢推，适合堆元素反应 | 机枪叠元素状态+触发反应清算 |

> 这4种行为类型 × 4种元素属性 = 理论16种变体，足以支撑游戏全程的敌人多样性，无需更多基础类型。

## 五、怪物三档阶梯设计

### 5.1 三档定义

| 档位 | 名称 | 掉落武器品质 | 主要出现阶段 |
|------|------|-----------|-----------|
| 第1档 | **普通怪** | 白质 | 全程出现，发育期为主 |
| 第2档 | **精英怪** | 蓝质 | 第1圈收缩后开始出现 |
| 第3档 | **头目怪** | 金质 | 第2圈收缩后开始出现 |

### 5.2 进化机制（核心设计）

> 怪物档位的提升，不是时间触发，而是**"未被消灭的普通怪随缩圈自然进化"**。

```
进化规则：
  第1圈开始收缩时：地图上残留的部分普通怪 → 进化为精英怪
  第2圈开始收缩时：地图上残留的部分精英怪 → 进化为头目怪

进化比例（提案）：
  约30-40%的残留普通怪进化为精英
  约30-40%的残留精英怪进化为头目
  （其余继续作为低档怪存在，保证基础击杀密度）
```

**设计意图：**

| 玩家行为 | 进化机制的反馈 |
|---------|-------------|
| 积极割草，快速清场 | 残留怪少，进化数量少，战场更干净 |
| 消极避战，专注躲圈 | 大量普通怪积累进化为精英/头目，难度反噬 |
| 主动清精英/头目 | 获得蓝质/金质武器，发育领先 |

> **关键洞察**：这个机制让"积极打怪"和"消极苟活"产生了**可见的难度差异**，玩家能感受到"我清场越勤，战场越可控"。符合原则一：真实竞争，行动有代价。

### 5.3 三档在视觉上的区分

| 档位 | 体型倍率 | 颜色变化 | 特殊视觉 |
|------|---------|---------|---------|
| 普通怪 | 1x（基准） | 标准元素色 | 无 |
| 精英怪 | 1.4x | 颜色更深饱和 | 身体轮廓光晕（蓝色） |
| 头目怪 | 1.8x | 颜色最深，接近暗色 | 金色能量轮廓，移动时有能量尾迹 |

### 5.4 三档数值成长

| 档位 | 血量倍率 | 攻击倍率 | 移动速度变化 |
|------|---------|---------|-----------|
| 普通怪 | 1x | 1x | 标准 |
| 精英怪 | 2.5x | 1.5x | -10%（更重，但伤害更高）|
| 头目怪 | 6x | 2.2x | -20%（但有特殊技能补偿）|

> ⚠️ **以上倍率为初版提案，需原型验证：头目怪在全阵容金质武器下的TTK是否保持在2-4秒（有压迫但不拖沓）。**

### 5.5 头目怪的特殊技能（简化版）

头目怪不只是"更厚血量的精英怪"，需要一个简单的特殊能力让玩家感知到档位差异：

| 行为类型的头目特殊技能 | 设计 |
|------------------|------|
| 冲锋型头目 | 冲刺时留下元素轨迹，轨迹对玩家持续造成伤害 |
| 群涌型头目 | 死亡时召唤2-3只普通怪（死亡繁殖）|
| 远程型头目 | 投射物变为追踪型，玩家需要走位规避 |
| 坦克型头目 | 血量低于50%时进入狂暴，攻击速度×2 |

## 六、发育期刷怪密度设计要求

### 6.1 数量需求推算

| 参数 | 数值 | 依据 |
|------|------|------|
| 发育期目标时长 | 2-3分钟 | 核心体验设计文档 |
| 需要击杀怪物数 | 50-80只 | 以保底N=10计算6次武器掉落 |
| 平均击杀速率需求 | 约25-40只/分钟 | 50÷2 到 80÷2 |

### 6.2 刷怪节奏设计

```
刷怪方式：以玩家为圆心的动态极坐标刷怪（参考现有GPOSpawner系统）

刷怪半径：内径4m（玩家周围不刷）/ 外径12m（超出范围不刷）
刷怪频率：每5-8秒刷新一批（每批2-5只，根据玩家当前武器数量动态调整）
方向权重：前方60°权重高（迎面挑战感）/ 侧方中等 / 后方低
```

### 6.3 动态刷怪密度（随武器数量调整）

> 武器越多，DPS越高，刷怪密度需对应提升以维持割草感：

| 玩家悬浮武器数量 | 刷怪密度调整 | 设计意图 |
|--------------|-----------|---------|
| 0-2把 | 基准密度 | 发育早期，密度适中，让玩家感受到成长 |
| 3-4把 | 密度×1.5 | 发育中期，火力提升，密度跟上 |
| 5-6把 | 密度×2.0 | 全阵容，满屏子弹需要配合满屏怪才有割草感 |
