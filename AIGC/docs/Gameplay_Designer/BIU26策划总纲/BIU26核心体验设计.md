> **文档版本**：v0.3

> **文档性质**：核心体验设计，聚焦"玩家在局内的每一分钟感受什么"，不涉及技术实现

## 零、设计原则与选择依据

> **本章记录主策划在核心设计决策背后的思考依据。**
> 后续所有细节设计必须对照本章原则自检，确保方向一致。

### 原则一：真实竞争，而非被照顾

目标用户是被操作门槛劝退的老玩家，不是零基础新手。他们需要的是"在公平规则下真实地赢"，而不是"被系统设计成赢家"。

**设计影响：**
- 选择全局PVP可直接射击，而非PVE-only或区域隔离
- 金币经济采用死亡50%转移，而非"全员都有奖励"的温和机制
- 不设置新手保护期或初始无敌时间

**判断标准：** 任何降低竞争真实性的设计，都需要有充分理由才能加入。

---

### 原则二：爽感密度优先于内容丰富度

目标用户娱乐时间碎片化，每一分钟都必须发生有意义的事。宁可减少内容量，也要保证单位时间内的刺激密度。

**设计影响：**
- 单局目标5-8分钟，而非15-20分钟
- 缩圈强制接解，消灭空窗期，而非自由探索
- 武器解锁节奏紧凑（约每20-30秒一把），不允许"发育空窗"

**判断标准：** 设计中任何超过30秒"什么都没发生"的时间段，都是需要填补的漏洞。

---

### 原则三：机制驱动行为，而非内容填充时间

金币三来源（割草/进圈/击杀玩家）的设计，不只是经济系统，是**行为诱导机制**：
- 强者携带更多金币 → 制造"猎富玩家"动机
- 死亡保留50% → 弱者有底线，不因一次失败全部清零
- 进圈是金币里程碑 → 缩圈本身成为玩家期待的节点

**设计影响：**
- 多条并行的正反馈路径（割草流/猎人流/生存流），不同风格玩家各有激励
- 经济机制的核心价值是"引导玩家自发地做设计想要他做的行为"

**判断标准：** 每个机制都应该能回答"这个机制让玩家自发地做什么？"如果回答不出来，这个机制可能是多余的。

---

### 原则四：保留操控感，不做"玩家只是在观看"的游戏

手持武器选择"半自动开火+辅助瞄准"，而非弹壳式的全自动。

**选择依据：** 目标用户的射击记忆来自CF/PUBG，他们对"我在主动打枪"有情感依赖。如果游戏完全自动化，他们会感觉"这不是射击游戏，这是放置游戏"，从而与预期产生落差。

**设计影响：**
- 手持武器必须有"我瞄准了目标"的操控反馈
- 辅助瞄准只是降低精准度要求，不能替代玩家的方向控制意图
- 悬浮武器全自动，提供碾压感，而手持武器提供参与感——两者分工明确

**判断标准：** 如果把手持武器去掉，游戏体验是否实质改变？如果答案是"不影响"，说明操控感设计失败了。

## 一、武器系统架构

### 1.1 双轨武器结构

```
┌─────────────────────────────────────────────────────┐
│  手持武器（1把）                                       │
│  · 玩家控制镜头方向，对准目标                           │
│  · 开火自动触发（无需手动点击射击键）                     │
│  · 辅助瞄准：镜头靠近目标时自动锁定（降低精准度要求）      │
│  · 体现"我在主动射击"的操控感                           │
└─────────────────────────────────────────────────────┘
              +
┌─────────────────────────────────────────────────────┐
│  悬浮武器（0→6把，发育中逐步解锁）                      │
│  · 围绕玩家漂浮，完全自动索敌、自动开火                  │
│  · 玩家零操作干预                                      │
│  · 体现"我的阵容越来越强大"的发育感                     │
└─────────────────────────────────────────────────────┘
```

### 1.2 武器系统的核心体验分工

| 武器 | 负责的情绪 | 设计核心 |
|------|---------|---------|
| 手持武器 | 射击参与感、击杀归属感 | 辅助瞄准让玩家感觉"是我打的" |
| 悬浮武器 | 碾压感、阵容规模感 | 每新增一把，火力密度立刻可见 |

## 二、发育期设计（前2-3分钟）

### 2.1 发育目标

> 在约2分钟内，玩家从"1把手持武器"发育到"手持+6把悬浮武器"的全阵容状态。

发育感的核心在于**质变速度**，而非积累时长。每把悬浮武器解锁时，玩家必须立刻感知到火力的显著提升。

### 2.2 武器解锁节奏提案（待主策划数值拍板）

以单局5-8分钟、发育期2-3分钟为基准：

| 时间节点 | 武器状态 | 体验感受 |
|---------|---------|---------|
| 0:00 入局 | 手持1把 | 基础射击感，开始割草 |
| 0:20 | 手持+悬浮1把 | 多了一个"伙伴"，火力变化开始出现 |
| 0:45 | 手持+悬浮2把 | 开始有"被保护"的安全感，击杀速度明显提升 |
| 1:15 | 手持+悬浮3把 | 中间里程碑，进入"强势发育"状态 |
| 1:50 | 手持+悬浮4把 | 满屏子弹感开始出现 |
| 2:20 | 手持+悬浮5把 | 接近全阵容，碾压感强烈 |
| 2:40 | 手持+悬浮6把 | **全阵容达成**，进入发育完成状态 |

> ⚠️ **以上时间节点为初版提案，所有数值需原型验证后调整。**

### 2.3 武器获取机制

**全局掉落规则（贯穿整局）：**

```
小怪击杀后必定掉落：金币（小额）
小怪击杀后概率掉落：武器（可拾取替换当前装备的悬浮武器）
```

**发育期（0→6把悬浮武器阶段）：**

| 保底规则 | 提案数值 | 设计意图 |
|---------|---------|---------|
| 每击杀N只小怪，必定掉落1把悬浮武器 | N = 8-12只（待验证） | 确保手气差的玩家也能在2.5分钟内完成发育 |

**发育完成后（已持有6把悬浮武器）：**

小怪继续掉落武器，玩家可以用**更高品质的武器替换当前装备的同槽位武器**。

**武器品质随缩圈线性提升：**

| 游戏阶段 | 怪物等级 | 掉落武器品质 |
|---------|---------|-----------|
| 发育期（圈1前） | 低等级 | 白质为主 |
| 第1圈收缩中 | 中等级 | 蓝质开始出现 |
| 第2圈收缩中 | 高等级 | 蓝质/金质混合 |
| 第3圈（最终圈）| 精英级 | 金质为主 |

**设计意图：**
- 发育完成后刷怪不失去意义——更好的武器始终值得追求
- 缩圈本身成为品质升级的节拍器：圈越小，收益越高，但危险也越大
- 玩家始终面临决策："继续刷怪升级武器，还是去打人猎取金币？"

### 2.4 发育期的地图设计要求

发育期内，玩家需要能**持续遇到小怪**。这对地图和刷怪密度有直接影响：

- 刷怪密度：在2-3分钟内，玩家平均需要击杀约 **50-80只小怪**（以保底N=10估算6次掉落）
- 小怪击杀时间：手持1把武器时，单只小怪TTK应控制在 **0.3-0.8秒**（维持割草节奏感）
- 刷怪位置：以玩家为圆心，近距离持续刷入，避免发育期"找不到怪"的空窗期

## 三、缩圈设计

### 3.1 缩圈的核心设计目标

- **强制接解**：让分布在地图各处的8-12名玩家，在约4-5分钟时开始密集接触
- **信号清晰**：目标用户熟悉吃鸡的缩圈，无需学习成本
- **节奏对齐**：缩圈节奏需和发育期结束时间同步——玩家刚好在发育完成时被圈力推进PVP区域

### 3.2 缩圈节奏提案

| 阶段 | 时间 | 安全圈变化 | 圈外伤害 | 设计意图 |
|------|------|---------|---------|---------|
| 第1圈预警 | 2:00-2:30 | 地图显示安全区范围，开始收缩警告 | 0（仅警告） | 告知玩家PVP即将开始 |
| 第1圈收缩 | 2:30-4:00 | 安全区缩小至地图约60% | 每秒扣1%当前HP | 推动发育完成的玩家向中心移动 |
| 第2圈收缩 | 4:00-5:30 | 安全区缩小至地图约30% | 每秒扣2%当前HP | PVP接触高峰，玩家无法回避对抗 |
| 第3圈收缩 | 5:30-7:00 | 安全区缩小至极小区域 | 每秒扣4%当前HP | 决出最终胜者 |

> ⚠️ **以上时间节点为提案，具体需要根据地图大小和玩家移速校准。**

### 3.3 缩圈与发育期的对齐关键

```
发育完成时间（约2:40）< 第1圈开始收缩（约2:30-3:00）

这个对齐是刻意设计的：
玩家在全阵容达成后"来不及继续割草"，
缩圈自然地把他们推向PVP接触区。
```

## 四、PVP期设计

### 4.1 PVP期的核心体验目标

> 玩家感受到："我的发育成果有用，同时我的战术判断也有机会赢。"

两个缺一不可：
- 发育优势**有初始优势**（发育差的玩家在平等对战中处于劣势）
- 战术判断**有翻盘空间**（发育差的玩家通过走位/偷袭仍可击败发育好的玩家）

### 4.2 长TTK的战术空间设计

**TTK目标：3-5秒**（玩家对玩家）

在3-5秒的TTK内，玩家可以执行的战术行为：

| 战术行为 | 所需时间 | 是否可在3-5秒TTK内完成 |
|---------|---------|---------------------|
| 发现危险后移动到掩体 | 0.5-1秒 | ✅ 有充裕时间 |
| 判断对手位置并换方向 | 0.5-1秒 | ✅ 可执行 |
| 利用建筑物角落偷袭 | 1-2秒 | ✅ 可执行 |
| 被打后撤退脱离接触 | 1-2秒 | ✅ 可执行 |

**对比短TTK（0.3-1秒）**：上述行为均无法完成，胜负只由"谁先打中"决定。这正是目标用户在CF/PUBG中失败的原因。

### 4.3 发育差距对战斗结果的影响设计

```
场景：A（6把悬浮武器）vs B（3把悬浮武器）

期望的结果：
- A 有明显火力优势，正面对抗 A 胜率约65-70%
- B 通过战术（偷袭/背刺/消耗）仍有30-35%胜率
- 不能让发育优势达到"碾压"（90%+胜率），否则战术无意义

数值设计原则：
每把悬浮武器提供的DPS提升应线性但有上限，
6把的总DPS不超过3把的2.0倍（控制优势上限）
```

> ⚠️ **具体倍率需通过原型对战测试调整。**

## 五、结算与金币经济设计

### 5.1 金币三来源机制

```
金币来源               频率        金额级别    设计意图
─────────────────────────────────────────────────────
① 击杀小怪             高频·持续   小额        发育期正反馈，鼓励积极割草
② 成功进入下一安全圈   低频·里程碑  中额        认可"活下来"的价值，缩圈成为期待节点
③ 击杀玩家             低频·高风险  高额        继承被杀者损失金币的50%，猎强者收益更高
```

### 5.2 死亡金币结算规则

```
玩家被击杀时：
  └─ 损失当前携带金币的 50%
       ├─ 50% 归 击杀者
       └─ 50% 玩家保留（带入结算）

设计意图：
  ✅ 降低被杀的挫败感（不是全部损失）
  ✅ 制造"猎富玩家"动机（强者更值钱）
  ✅ 给击杀者高额奖励，鼓励主动进攻
```

### 5.3 金币比例提案（待主策划拍板）

以单局估算金币总量为基准（假设高水平玩家单局可获得100金币），各来源占比提案：

| 来源 | 单次金额 | 预计触发次数 | 预估占比 |
|------|---------|-----------|---------|
| 击杀小怪 | 0.5-1金币/只 | 60-100只 | 约40-50% |
| 进入安全圈 | 8-12金币/次 | 2-3次 | 约20-30% |
| 击杀玩家 | 继承对方50%（约10-30金币） | 1-3次 | 约30-40% |

> ⚠️ **以上为初版比例提案，实际数值需通过游玩测试校准。核心原则：三条路径都有正反馈，没有一条路径能让玩家彻底忽略其他两条。**

### 5.4 胜负与赏金发放规则

**所有玩家的局内金币 = 本局赏金收益**

无需"最后存活才有赏金"——每个玩家在结算时拿走自己的金币余额，累积用于购买皮肤。

```
排名激励（可选设计）：
  第1名：金币×1.5（额外奖励系数）
  前3名：金币×1.2
  其余：金币×1.0（原额）
```

### 5.5 结算界面的仪式感要求

赏金发放是**全局情绪最高峰**，界面必须满足：
- 大字显示本局赚取赏金金额，有数字滚动动效
- 分项显示三来源金币明细（割草赚了多少、进圈赚了多少、击杀赚了多少）
- 显示本局排名（第N名 / 共M人）
- 提供"再来一局"一键入口（减少流失）
