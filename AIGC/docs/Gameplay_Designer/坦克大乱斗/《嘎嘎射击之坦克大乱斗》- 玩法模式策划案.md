# 《嘎嘎射击之坦克大乱斗》- 玩法模式策划案

## 1. 项目概述
- **游戏名称**: 嘎嘎射击之坦克大乱斗 (暂定)
- **游戏类型**: TPS (第三人称射击) / 5v5 多人联机对战
- **目标平台**: 移动端 (手游)
- **核心体验**: 快节奏、高频交战、爽快射击、团队配合争夺核心资源。
- **视觉视角**: 第三人称尾随视角（TPS），适合观察战场局势与走位。

## 2. 核心战斗机制
- **对局模式**: 5v5 团队匹配对抗。
- **单局时长**: 3 分钟。
- **胜利条件**:
  - **首要条件**: 率先将敌方基地血量降至 0 的一方立即获胜。
  - **判定条件**: 若 3 分钟时间结束，双方基地均未被摧毁，则判定基地剩余血量百分比更高的一方获胜。
- **基地设定**:
  - **无防御塔机制**: 基地没有任何外围防御建筑（如防御塔）或无敌护盾保护。
  - **开局即战**: 玩家开局即可直接对敌方基地造成实质性伤害，强调前线压制和直接火力交锋。

## 3. 坦克设计与数值设定
- **坦克种类**: 游戏中所有玩家使用**同一种标准坦克**（直接复用“嘎嘎射击”原有的坦克模型及默认操作方式），确保绝对公平竞技，胜负取决于团队战术和个人微操。
- **基础战斗属性**:
  - **生存与机动**:
    - **血量 (HP)**: 8000
    - **移动速度**: 700 cm/s (即 7 m/s)
  - **核心输出与伤害**:
    - **火力 (单发伤害)**: 2700
    - **DPS (不换弹)**: 2700
    - **射击间隔**: 1000 ms (1秒1发)
    - **爆炸范围**: 500 cm (半径 5m 的范围伤害)
  - **武器与弹道**:
    - **子弹速度**: 150 m/s
    - **射程**: 3000 cm (30 m)
    - **精准度**: 100
    - **标准血量 TTK** (击倒标准 100 血量目标的时间): 约 0.93 秒

## 4. 复活机制
  - **零惩罚复活**: 玩家坦克被摧毁后，没有任何经济、经验或复活时间的递增惩罚。
  - **极速重返战场**: 死亡后固定 **5 秒** 冷却时间，随后在己方出生点满血复活。此机制鼓励玩家大胆冲锋，保持战场的高强度对抗节奏。

## 5. 地图设计与环境机制
借鉴《钢铁战场》的设计，对当前大乱斗模式的地图进行适配与融合。
- **地图尺寸**: 120 x 120 米 (平坦地形)
- **边界限制**: 四周设有不可破坏的高大围墙（混凝土材质），防止玩家脱离战场。
- **地图布局**: 呈严格南北对称，划分为红蓝双方区域、中央争夺区和两侧侧翼拉扯区。

### 5.1 掩体系统
为增加战术纵深，地图中散布两种类型的掩体：
- **可破坏掩体 (如：砖墙、沙袋)**：
  - **定位**: 提供临时掩护。
  - **机制**: 可被坦克的攻击摧毁。被摧毁后固定 **5秒** 原地再生（确保大乱斗后期的掩体存量）。
  - **分布**: 多分布于侧翼或双方基地前方的前哨位置。
- **不可破坏掩体 (如：钢铁墙、钢铁箱)**：
  - **定位**: 提供永久的战略掩体，用于规避火力和极限拉扯。
  - **机制**: 免疫所有攻击。
  - **分布**: 集中分布在地图中央（保护 Buff 刷新点）以及基地侧后方盲区。

## 6. 基地系统与数值平衡
### 6.1 基地基础设定
- **红方基地**: 位于地图北侧边缘，红色军事建筑风格。
- **蓝方基地**: 位于地图南侧边缘，蓝色军事建筑风格。
- **目标判定**: 基地血量降至 0 即宣告该方战败。

### 6.2 基地血量数值推演
根据目前坦克的基础 DPS (2700/秒) 以及单局时长 (3分钟 = 180秒) 进行推演：
- 若完全不防守，单辆坦克 10 秒内可输出 27000 伤害。
- 考虑到 5v5 模式下，基地可能面临多辆坦克的集火，同时要保证对局能够产生拉扯（不被一波瞬间偷塔秒杀），基地需要具有极高的血量厚度。
- **基地血量设定**: **150,000 HP**
  - *推演逻辑*: 单辆坦克（无 Buff 状态）需要连续开火约 55 秒才能单独摧毁基地。
  - 5辆坦克集火（无 Buff）需要约 11 秒。
  - 当一方夺取中央超级 Buff（伤害+50%），配合团队推进，可在 6-8 秒内对基地造成毁灭性打击。这个数值既防止了被轻易“偷鸡”秒杀，又确保了夺取 Buff 后能形成一波强力的终结推进。

## 7. 核心资源 (争夺战)
地图的核心战略点在于中央区域的超级增益资源，这是打破僵局、发起致命一击的关键。
- **刷新位置**: 地图绝对中心点（需确保双方到达距离完全对等）。
- **刷新频率**: 开局后，每隔 **1 分钟** 刷新一次（即 1:00, 2:00 时刻刷新）。
- **增益效果 (Super Buff)**: 玩家触碰拾取后，立即获得持续 **15 秒** 的超级强化状态：
  - **状态恢复**: 瞬间恢复 100% 最大生命值。
  - **机动爆发**: 移动速度提升 +50%。
  - **火力倾泻**: 造成的所有伤害提升 +50%。
- **战略意义**: 围绕每分钟的 Buff 刷新，游戏将自然形成高潮团战期。获得 Buff 的玩家（或团队）将获得压倒性的短程优势，可用于强行突破敌方防线或对敌方基地造成毁灭性打击。

## 8. 预期游戏节奏 (3分钟心流)
- **0:00 - 0:50 (布局与消耗)**: 双方离开出生点，在地图中线交火互换血量，或派人尝试侧翼偷袭敌方基地。
- **0:50 - 1:00 (资源抢夺)**: 双方兵力向地图中央集结，准备争夺第一个超级 Buff。
- **1:00 - 1:15 (第一波高潮)**: Buff 被一方夺取，获得方发起猛烈冲锋，防守方则利用 5 秒快速复活的优势进行拼死抵抗。
- **1:15 - 1:50 (重新拉扯)**: Buff 消失，双方重新进入常态对线和牵扯，为下一次争夺做准备。
- **2:00 - 2:15 (决胜团战)**: 第二个超级 Buff 刷新，往往决定了游戏的最终走向。
- **2:15 - 3:00 (残局/压秒)**: 若比赛未提前结束，将进入最后的极限拆家或防守拖延阶段，基地血量的微小差距将决定胜负。

## 9. 游戏流程设计

```text
┌─────────┐    匹配成功    ┌─────────┐    摧毁敌方基地 /    ┌─────────┐
│  主界面  │ ──────────→ │  5v5对战 │ ──── 3分钟倒计时 ──→ │ 结算界面 │
│         │              │         │       结束           │         │
│ 匹配系统 │              │ 激烈交火 │                      │ 胜利/失败│──→ 返回主界面
│ 坦克展示 │              │ 争夺Buff│                      │ 数据统计 │
└─────────┘              │ 拆毁基地 │                      └─────────┘
                         │         │    坦克被毁(5秒重生)  
                         └─────────┘ <───────────────────┘
```

### 9.1 主界面 (Main Menu)
- **视觉呈现**: 动态背景，展示己方坦克模型。
- **主要功能**: 
  - 醒目的“开始匹配 (5v5)”按钮。
  - 玩家基础信息展示。
  - (待定) 坦克皮肤/涂装切换系统。

### 9.2 战斗中 (In-Game)
- **HUD 界面布局**:
  - **顶部居中**: 3分钟倒计时时钟 / 中场 Buff 刷新倒计时提示。
  - **左上/右上**: 红蓝双方基地当前血量进度条（实时显示）。
  - **底部中央**: 玩家当前血量条 / 操作摇杆与射击按钮。
  - **击杀播报**: 屏幕右侧显示实时击杀信息（如：PlayerA 击毁 PlayerB）。
  - **伤害反馈**: 命中敌人或掩体时，在世界坐标位置生成上浮消失的**伤害飘字**。

### 9.3 结算界面 (End Game)
- **胜负判定展示**: 醒目的“胜利 (Victory)”或“失败 (Defeat)”字样及对应音效。
- **数据统计面板**: 展示双方 10 名玩家的对局数据（击杀数、死亡数、对基地造成的总伤害等）。
- **流程操作**: 提供“返回主界面”和“再来一局 (重新匹配)”按钮。
