## 1. 项目概述

- **游戏名称**：嘎嘎射击之坦克大乱斗（暂定）
- **游戏类型**：TPS（第三人称射击）/ 5v5 多人联机对战
- **目标平台**：移动端（手游）
- **核心体验**：快节奏、高频交战、爽快射击、团队配合争夺核心资源。
- **视觉视角**：第三人称尾随视角（TPS），适合观察战场局势与走位。

---

## 2. 核心战斗机制

- **对局模式**：5v5 团队匹配对抗。
- **单局时长**：3 分钟（180 秒）。
- **友伤**：**0%（无友伤）**，己方炮弹不对队友和己方基地造成任何伤害。
- **胜利条件**：
  - **首要条件**：率先将敌方基地血量降至 0 的一方立即获胜。
  - **超时判定**：若 3 分钟时间结束，双方基地均未被摧毁，则判定基地剩余血量**百分比**更高的一方获胜。
  - **超时平局**：若超时时两队基地剩余 HP 百分比完全相同（≤ 0.1% 差异视为相同），判定**平局**，双方均不计入胜败，给予安慰奖励（参见第 11 章）。
- **基地设定**：
  - **无防御塔机制**：基地没有任何外围防御建筑或无敌护盾保护。
  - **开局即战**：玩家开局即可直接对敌方基地造成实质性伤害，强调前线压制和直接火力交锋。

- **基础战斗属性**：

## 4. 复活机制

- **零惩罚复活**：坦克被摧毁后，没有任何经济、经验或递增惩罚。
- **固定复活冷却**：死亡后固定 **5 秒**冷却，随后在己方出生点**满血**复活。
- **出生/复活保护**：
  - 出生或复活落地后，享有 **2 秒无敌保护**。
  - 无敌期间：**无法移动，无法射击，无法被任何伤害命中**。
  - 2 秒保护结束后立即恢复全部操控权。
  - 若玩家持有 Super Buff 状态（理论上不存在，因死亡时 Buff 被清除），无敌期间攻击力仍保持 Buff 数值（保留该规则供边界兜底）。
- **出生位分配**：
  - 各队共有 **5 个固定出生位**，均匀分布在己方基地后方安全区（基地正后方 10 m 范围内）。
  - 初始出生：按玩家编号 1-5 依次分配出生位 1-5。
  - 复活：从 5 个出生位中**随机分配**一个可用位置（无法与已存活队友重叠）。

## 5. 地图设计与环境机制

借鉴《钢铁战场》的设计，对当前大乱斗模式地图进行适配与融合。

- **地图尺寸**：120 m × 120 m（平坦地形）
- **边界限制**：四周设有不可破坏的高大围墙（混凝土材质）
  - 围墙尺寸：**高 6 m、厚 1 m**（高于坦克炮管，无法越墙射击，炮弹命中围墙立即销毁，无反弹）
- **地图布局**：严格南北对称，划分为红蓝双方区域、中央争夺区和两侧侧翼区。

### 5.1 掩体系统

为增加战术纵深，地图中散布两种类型的掩体：

#### 可破坏掩体

| 掩体类型 | 宽 | 高 | 深 | HP | 备注 |
|---------|----|----|----|----|------|
| 砖墙 | 3 m | 1.5 m | 0.5 m | 5400 | 可承受约 2 发炮弹；初版估算值，可调 |
| 沙袋堆 | 2 m | 0.8 m | 1 m | 2700 | 可承受约 1 发炮弹；初版估算值，可调 |

- **定位**：提供临时掩护。
- **机制**：可被坦克攻击摧毁；摧毁后 **5 秒**原地再生（确保后期掩体存量）。
- **分布**：多分布于侧翼及双方基地前方前哨位置。

#### 不可破坏掩体

| 掩体类型 | 宽 | 高 | 深 | 备注 |
|---------|----|----|-----|------|
| 钢铁墙 | 4 m | 2 m | 0.5 m | 免疫所有攻击 |
| 钢铁箱 | 1.5 m | 1.5 m | 1.5 m | 免疫所有攻击 |

- **定位**：提供永久战略掩体，用于规避火力和极限拉扯。
- **分布**：集中于地图中央（保护 Buff 刷新点）及基地侧后方盲区。

#### 不可破坏斜坡（新增）

> 地图整体定位为**宽阔通行为主**，斜坡数量少，仅作为丰富走位选择的点缀元素。

| 参数 | 数值 | 依据 |
|------|------|------|
| 数量 | **4 个**（南北对称，各侧 2 个） | 坦克体积 3m×3m，斜坡不宜密集 |
| 斜坡宽度 | **≥ 4 m** | 坦克宽 3m + 操作余量 1m |
| 斜坡爬升高度 | **1.5 m** | 坡度约 25°，坦克可顺利通行 |
| 斜坡长度 | **约 3.2 m** | 几何推算（1.5m 高 / tan 25°） |
| 斜坡净空 | **≥ 3 m**（含炮管余量） | 坦克高约 2m，炮管竖起约 2.5m |
| 分布位置 | 两侧侧翼区，对称分布 | 不影响中央通道主通行 |
| 材质风格 | 混凝土斜坡，不可破坏 | 与围墙风格统一 |
| 射击逻辑 | **无限制，复用现有坦克逻辑** | 斜坡不提供额外射击优势 |

- **设计意图**：斜坡仅提供额外走位路径（可绕行至侧翼高台），不影响主战场开阔感。坦克可顺畅驾驶上下斜坡，通道宽度确保不会卡体积。

## 6. 基地系统与数值平衡

### 6.1 基地基础设定

| 属性 | 红方基地 | 蓝方基地 |
|------|---------|---------|
| 位置 | 地图北侧边缘 | 地图南侧边缘 |
| 风格 | 红色军事建筑 | 蓝色军事建筑 |
| 几何尺寸 | 宽 20 m × 高 4 m × 深 10 m | 同左 |
| 正面朝向 | 朝向战场（朝南） | 朝向战场（朝北） |
| 目标判定 | HP 降至 0 即战败 | 同左 |

- **技术实现**：基地作为 **GPO（Global Persistent Object）**，HP 变化**实时同步**到所有客户端。
- **队伍归属**：Mode 初始化时按 TeamID **显式绑定**，红队绑定北侧基地，蓝队绑定南侧基地。

### 6.2 基地血量数值推演

- **基地 HP**：**150,000**
- 推演逻辑：
  - 单辆坦克（无 Buff）需连续开火约 **55 秒**才能单独摧毁基地。
  - 5 辆坦克集火（无 Buff）需约 **11 秒**。
  - 夺取 Super Buff（+50% 伤害），5 辆集火可在约 **6-8 秒**内造成毁灭性打击。
  - 此数值防止"偷鸡秒杀"，同时确保 Buff 优势能形成终结推进。

### 6.3 基地低血量警报

- 触发条件：基地当前 HP ≤ **30%（即 ≤ 45,000 HP）**
- 警报表现：
  - 对应基地的 HUD 血条**变为红色**。
  - 该基地所属队伍所有成员的 HUD **全屏边缘闪烁**（红色频闪，每秒约 2 次）。
  - 闪烁持续至基地 HP 回到 30% 以上（本模式基地 HP 不可回复，故警报一旦触发将持续至对局结束）。

## 7. 核心资源争夺（Super Buff）

### 7.1 基本参数

| 参数 | 数值 |
|------|------|
| 刷新位置 | 地图绝对中心点（60, 0, 60），双方距离完全对等 |
| 刷新时刻 | 1:00、2:00（各刷新一次，共 2 次） |
| 拾取方式 | **单体拾取**，谁碰谁得，立即消失 |
| 拾取触发判定 | 坦克 GPO 碰触触发器（绑定坦克 GPO），触发半径 2.5 m |
| 拾取物形态 | 球形，直径 2 m |
| 未拾取自动消失 | 刷新后 **15 秒**无人拾取则自动消失 |
| Buff 持续时长 | **15 秒**（从拾取时刻起计） |

### 7.2 Super Buff 效果

| 效果 | 数值 |
|------|------|
| 生命恢复 | 瞬间恢复至 100% 最大 HP（即满血 8000） |
| 移动速度 | +50%（7 m/s → 10.5 m/s） |
| 伤害倍率 | +50%（2700 → 4050 /发） |

### 7.3 Buff 行为边界

- 同队其他成员**无法**获得同一个 Buff（拾取后立即消失）。
- 持有 Buff 时死亡：**立即清除 Buff**（含 HUD 计时器）；复活为净体，无任何 Buff 残留。
- Buff 倒计时显示于 HUD **顶部**，以**具体秒数倒计时**形式呈现（如"Super Buff: 12s"）。
- Buff 期间被出生保护覆盖（2 秒无敌）：无敌期间**攻击力仍为 Buff 状态**（4050/发）。

### 7.4 战略意义

围绕每分钟的 Buff 刷新，游戏自然形成高潮团战期。获得 Buff 的玩家（或团队）将获得压倒性的短程优势，可用于强行突破敌方防线或对敌方基地造成毁灭性打击。

## 8. 弹道行为规范

> 所有炮弹**复用现有坦克逻辑**，以下为明确边界定义。

### 8.1 飞行行为

| 参数 | 数值/描述 |
|------|---------|
| 弹道类型 | 直线飞行，**无重力** |
| 子弹速度 | 150 m/s（恒定，不衰减） |
| 最大射程 | 30 m（超出后弹丸销毁，无爆炸） |

### 8.2 命中行为

| 命中目标 | 行为 |
|---------|------|
| 命中敌方坦克 | 立即爆炸销毁，爆炸范围（半径 5 m）伤害对范围内所有**敌方**目标生效 |
| 命中敌方基地 | 立即爆炸销毁，爆炸范围伤害对基地 HP 生效（范围内的坦克也受到伤害） |
| 命中可破坏掩体（砖墙/沙袋） | 立即爆炸，AOE 伤害波及范围内其他目标（含掩体本身） |
| 命中围墙 | 立即销毁，**无爆炸，无反弹** |
| 命中不可破坏掩体（钢铁墙/箱） | 立即销毁，**无爆炸，无反弹** |
| 命中己方坦克 / 己方基地 | **无伤害（友伤 0%）**，弹丸正常销毁 |

### 8.3 爆炸范围

- 范围形状：水平圆形（2D），半径 **5 m**。
- 爆炸伤害：与直接命中相同数值（2700，或 Super Buff 状态下 4050）。
- 范围内所有**敌方**目标均受到全额伤害（无衰减）。
- 友伤：**0%**（范围内的己方坦克/己方基地不受伤害）。

## 9. 游戏流程设计

```text
┌─────────┐    快速匹配    ┌──────────┐   3-2-1倒计时   ┌─────────┐
│  主界面  │ ─────────→  │ 匹配等待  │ ──────────────→ │  战斗中  │
│ (模式ID) │   (新增模式ID) │          │   (不可移动/射击)│         │
└─────────┘              └──────────┘                  │ 激烈交火 │
                                                        │ 争夺Buff │
                                                        │ 拆毁基地 │──→ ┌─────────┐
                                                        │         │    │ 结算界面 │
                                                        │ 坦克被毁 │    │ 胜/败/平 │──→ 主界面
                                                        │  ↓5s复活 │    │ 数据统计 │
                                                        └─────────┘    └─────────┘
```

### 9.1 开局流程（新增）

1. 匹配成功 → 进入场景加载。
2. 所有玩家在己方出生位就位。
3. **3-2-1 倒计时开始**：
   - 倒计时期间所有玩家**不能移动，不能射击**。
   - 倒计时 UI 显示于屏幕正中央（大字体，带动画）。
4. 倒计时归 0 → **战斗正式开始**，所有玩家立即获得完整操控权。
5. 开局时所有玩家享有 **2 秒出生保护**（无敌 + 无法攻击）。

### 9.2 主界面（Main Menu）

- **视觉呈现**：动态背景，展示己方坦克模型。
- **主要功能**：
  - 醒目的「开始匹配（5v5 坦克大乱斗）」按钮。
  - 玩家基础信息展示。
  - 坦克皮肤/涂装切换系统（待后续版本）。
- **技术实现**：复用现有快速匹配 CMD，**新增模式 ID 参数**以区分本模式与其他模式。

### 9.3 战斗中 HUD（In-Game HUD）

| 位置 | 内容 |
|------|------|
| 顶部居中 | 3 分钟倒计时时钟 |
| 顶部居中（次行） | 中场 Buff 刷新倒计时提示（如"下次 Buff: 42s"）；持有 Buff 时显示"Super Buff: Xs"倒计时 |
| 左上 | 红方基地血量进度条（实时）；HP ≤ 30% 时变红 + 全队 HUD 闪烁 |
| 右上 | 蓝方基地血量进度条（实时）；HP ≤ 30% 时变红 + 全队 HUD 闪烁 |
| 底部中央 | 玩家当前血量条 / 操作摇杆 / 射击按钮 |
| 右侧 | 实时击杀播报（如：PlayerA 击毁 PlayerB） |
| 世界坐标 | 命中敌人/掩体时，生成上浮消失的**伤害飘字** |

### 9.4 结算界面（End Game）

- **胜负判定展示**：醒目的「胜利（Victory）」/「失败（Defeat）」/「平局（Draw）」字样及对应音效。
- **数据统计面板**：展示双方 10 名玩家对局数据：

| 字段 | 说明 |
|------|------|
| 击杀数（K） | 本局击毁敌方坦克次数 |
| 死亡数（D） | 本局被击毁次数 |
| 对基地造成的总伤害 | 本局对敌方基地输出总伤害值 |
| **Buff 拾取次数**（新增） | 本局成功拾取 Super Buff 的次数 |

- **流程操作**：「返回主界面」和「再来一局（重新匹配）」按钮。

## 11. 异常边界处理

### 11.1 同时触碰 Buff（多人同帧碰触）

| 场景 | 处理规则 |
|------|---------|
| 同一队两名玩家同帧触碰 Buff | 按服务端到达顺序，**先到先得**；第二名玩家无效，Buff 已消失 |
| 敌对双方玩家同帧触碰 Buff | 按服务端到达顺序，**先到先得**；平局情况下优先处理编号较小的玩家请求 |
| 拾取后 Buff 已过 15 秒消失 | 消失判定优先，拾取请求无效 |

### 11.2 死亡时 Buff 状态

| 场景 | 处理规则 |
|------|---------|
| 持有 Buff 时被击毁 | **立即清除 Buff**，HUD 计时器消失，移动/伤害倍率恢复正常 |
| 复活后 | 复活为净体，无任何 Buff |
| 死亡时 Buff 倒计时归零 | Buff 正常结束（无需额外处理） |

### 11.3 断线重连

| 场景 | 处理规则 |
|------|---------|
| 对局中断线 | 断线期间坦克保留在场景中（不销毁），可被敌方攻击击毁 |
| 重连成功 | 恢复操控，若已死亡则在 5 秒复活 CD 结束后正常复活 |
| 重连成功时持有 Buff | Buff 倒计时在断线期间继续流逝；重连时若 Buff 已过期，清除 HUD 计时器 |
| 超过 60 秒未重连 | 该玩家坐席保留（人机接管，停止移动和射击），对局继续 |
| 对局结束时仍离线 | 结算时记录正常，重连后可查看结算数据 |

### 11.4 超时平局

| 场景 | 处理规则 |
|------|---------|
| 双方基地剩余 HP 百分比差值 ≤ 0.1% | 判定**平局（Draw）** |
| 平局奖励 | 双方均不计入胜败场次，给予固定安慰积分（具体数值由运营配置，策划建议为正常失败奖励的 1.2 倍） |
| 平局结算面板 | 显示「平局」字样，不显示胜利/失败，其余数据照常展示 |

### 11.5 开局倒计时期间的异常

| 场景 | 处理规则 |
|------|---------|
| 倒计时期间玩家断线 | 倒计时正常进行，断线玩家连线后直接进入战斗状态（2 秒出生保护） |
| 倒计时期间有玩家未加载完成 | 服务端等待最多 **10 秒**；超时后强制开始，未加载完成的客户端显示 Loading 状态，加载完成后立即同步战场状态 |

### 11.6 基地 HP 归零的同帧处理

| 场景 | 处理规则 |
|------|---------|
| 双方基地同一帧归零（AOE 同时打爆） | 判定**平局**（参见 11.4） |
| 基地 HP < 0（超额伤害） | 以 0 为下限，超额伤害不计入任何统计 |

### 11.7 可破坏掩体的边界

| 场景 | 处理规则 |
|------|---------|
| 掩体再生时该位置有坦克 | 掩体再生延迟，等待坦克离开后再生成（每 0.5 秒检测一次，最多等待 5 秒；5 秒后强制再生，坦克被推出） |
| 掩体再生倒计时中被 AOE 波及 | AOE 不对已销毁的掩体造成二次销毁，再生倒计时不受影响 |

## 12. 预期游戏节奏（3 分钟心流）

| 时间段 | 阶段名称 | 主要行为 |
|-------|---------|---------|
| 0:00 - 0:03 | **开局保护** | 3-2-1 倒计时结束，2 秒出生保护 |
| 0:03 - 0:50 | **布局与消耗** | 双方在中线交火互换血量，或侧翼偷袭敌方基地 |
| 0:50 - 1:00 | **资源抢夺** | 双方向地图中央集结，准备争夺第一个 Super Buff |
| 1:00 - 1:15 | **第一波高潮** | Buff 被夺取，获得方猛烈冲锋，防守方拼死抵抗 |
| 1:15 - 1:50 | **重新拉扯** | Buff 消失，双方重新常态对线 |
| 1:50 - 2:00 | **二次争夺** | 双方向中央集结，争夺第二个 Super Buff |
| 2:00 - 2:15 | **决胜团战** | 第二个 Buff 往往决定游戏最终走向 |
| 2:15 - 3:00 | **残局/压秒** | 极限拆家或防守拖延，基地 HP 差距决定胜负 |
