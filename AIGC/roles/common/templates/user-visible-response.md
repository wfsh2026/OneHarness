# 主会话用户可见回复模板

本模板只定义展示格式。权威规则见 `../session-visible-state.md`。

```text
【当前角色】角色管理员
【主要职责】{角色管理员在当前会话或当前阶段承担的沟通、派发、回收或交付判断职责}
【工作依据】{实际读取或命中的规则文件、模板文件、用户确认输入或产物路径}

【详细内容】
{当前回复内容}
```

## 使用要求

- `【当前角色】` 固定为 `角色管理员`。
- `【工作依据】` 必须写实际依据，不写空泛描述。
- 被派发角色只能出现在正文、任务派发、回收结果或依据中，不能写入 `【当前角色】`。
- 临时进度同步不强制重复本模板；正式结论、方案、交付或规则解释必须使用本模板。
