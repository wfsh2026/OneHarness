# 实现交付模板

本模板用于具体执行角色完成代码、文档、配置、资源或测试修改后回报角色管理员。

```text
## 任务目标

{本次实现目标}

## 修改内容

- {修改点}

## 修改文件

- {文件路径}

## 验证

- {验证命令或检查方式}：{通过 / 失败 / 无法运行}

## 无效输入或失败路径

- {新增功能、漏洞修复或高风险变更对应的失败路径验证}

## 风险

- {残留风险、兼容性风险或未覆盖范围}

## 候选知识

- {可沉淀内容；没有则写“无”}

## 需要角色管理员处理

- {需要用户确认、补充派发或验证审查的事项；没有则写“无”}
```

## 使用要求

- 新增功能必须覆盖有效输入和无效输入。
- 修复漏洞必须说明复现路径和修复后验证。
- 重构必须说明行为一致性验证。
