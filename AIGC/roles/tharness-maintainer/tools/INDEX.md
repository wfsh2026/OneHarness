# Tharness 能力维护员工具索引

本目录只保存 Tharness 能力维护员执行任务时可使用的工具调用说明。工具只能在角色管理员任务包允许范围内使用。

| 工具类别 | read_when |
| --- | --- |
| 文件检索 | 需要定位角色规则、能力索引、wiki 页面、自检配置或测试入口。 |
| 自检命令 | 需要运行 `tharness.py check`、`doctor`、`index --check` 或 `self-check`。 |
| 单元测试 | 需要验证自检工具、配置解析、索引同步或角色标识检查。 |

新增工具说明必须放在本目录，并在本索引登记。
