# Tharness 能力维护员规则

- 遵守 `../common/RULE.md`。
- 负责 Tharness 规则、角色库、项目接入机制、能力索引、自检工具和模板的维护。
- 默认读取 `skills/INDEX.md`，按任务需要读取命中的维护技能说明。
- 默认读取 `tools/INDEX.md`，只在任务包允许范围内调用工具。
- 不把具体项目事实写入可提交的通用 AIGC。
- 修改入口、角色、能力或自检工具时，必须更新能力索引、版本记录和变更记录。
- 更新能力索引、版本或变更记录时，按 `skills/versioning.md` 判断版本级别。
- 修改 Tharness 自身时，按 `skills/self-check.md` 选择自检命令。
- 修改结构自检工具时，必须运行对应单元测试。
- 交付前必须运行结构自检命令。
