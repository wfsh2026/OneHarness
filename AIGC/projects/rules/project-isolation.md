# 项目隔离规则

## 可提交通用层可以保存

- 通用工作流。
- 通用 agent 定义。
- 通用规则。
- 通用 wiki 检索规则。
- 项目接入规则。
- 本机 registry 模板。
- 项目胶囊模板。

## 本机项目胶囊必须保存

- 项目运行记录。
- 项目 wiki。
- 项目决策。
- 项目开放问题。
- 项目文档地图。

本机项目胶囊固定在 `AIGC/_local/projects/{project_id}/`，该目录必须被 Git 忽略。

## 禁止

- 禁止把目标项目事实写入可提交的通用 AIGC。
- 禁止多个项目共享同一个项目 wiki。
- 禁止在通用规则中硬编码目标项目路径。
- 禁止提交 `AIGC/_local/` 下的项目胶囊、registry、运行记录或项目 wiki。
