# AIGC 变更记录

本文件只记录当前角色调度体系从 `1.0.0` 开始的有效变更。

## 1.0.0

- 确立角色管理员调度为当前基线：所有用户请求先进入 `AIGC/roles/INDEX.md` 和 `AIGC/roles/role-manager/RULE.md`。
- 当前能力入口集中到角色库、项目适配路由、通用 wiki 和工具。
- 会话角色标识、自检触发、问题路由、项目适配路由、项目知识维护路由、能力版本规则和游戏策划方法卡均由 `AIGC/roles/` 下的角色资料承载。
- 目标项目适配包统一写入被 Git 忽略的 `AIGC/project-adapters/{project_id}/`。
- 主会话用户可见 `【当前角色】` 固定为 `角色管理员`；执行角色只能由角色管理员通过 SubAgent 或全新会话派发。
- 自检工具检查入口、wiki 元数据、索引、角色库、会话角色标识和结构边界，并报告角色规则数量。
- 本版本是整体重构后的初始基线版本，后续版本按当前版本规则谨慎推进。
