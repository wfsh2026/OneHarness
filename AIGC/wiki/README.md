# 通用架构 wiki

本目录是 Tharness 的通用架构知识库，只服务通用架构判断和低 token 检索。

它借鉴外部 harness 的轻量信息体系：每个知识页用 YAML 头声明 `id`、`title`、`summary`、`tags`、`relates`、`status` 和 `read_when`，入口索引只负责路由，不复制正文。

## 目标

- 用最少 token 找到角色系统、项目适配、知识治理、能力注册和可验证闭环所需的通用知识。
- 把跨项目、跨角色、低频变化的架构判断拆成可检索卡片。
- 保持通用框架和具体项目资料隔离。

## 非目标

- 不保存项目知识。
- 不保存项目运行记录。
- 不保存项目决策事实。
- 不保存项目代码结构分析。
- 不保存某个引擎、业务、玩法或产品的专用资料。
- 不保存具体角色技能正文。
- 不保存具体角色工具调用说明。
- 不保存角色派发边界表。

## 工作方式

1. 先读 `INDEX.md`。
2. 按 `read_when` 命中一个规则或架构分区。
3. 只读取命中的知识页。
4. 产出或修改后执行最小健康检查。

## 设计取舍

- 保留轻量 YAML 头和关联索引思想。
- 废弃旧 `raw/knowledge/log/html` 混合式知识堆放方式。
- 通用知识只写稳定架构模式；角色技能进入角色目录，项目事实进入本机项目适配包。
