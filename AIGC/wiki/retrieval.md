# 低 Token 检索规则

## 原则

- 先读索引，再读正文。
- 索引只放路由信息，不放完整论证。
- 正文必须通过 `read_when` 命中后再读取。
- 默认不读取历史记录。

## 推荐读取层级

| 层级 | 内容 |
| --- | --- |
| L0 | `AIGC/INDEX.md` |
| L1 | 激活工作流的 `WORKFLOW.md` |
| L2 | 工作流 `rules/INDEX.md` 与 `wiki/INDEX.md` |
| L3 | 命中的具体规则或知识卡片 |

## 禁止

- 禁止为了保险读取整个 wiki。
- 禁止把长篇日志放入默认入口。
- 禁止在索引里复制正文。
