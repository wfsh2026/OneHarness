# 策划能力库来源索引

## 来源处理规则

- 来源只用于追溯、去重和可靠性判断。
- 默认检索策划能力时不读取来源正文。
- 只有用户要求依据、能力卡冲突或需要晋升 accepted 时，才读取来源信息。
- 未导入的书籍只能作为来源占位，不能作为知识依据。
