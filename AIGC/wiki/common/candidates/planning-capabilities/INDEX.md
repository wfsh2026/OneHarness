# 候选策划能力库索引

候选策划能力只能作为讨论参考，不能直接当强规则执行。

## 检索规则

- 先按用户问题命中模块，再读取模块索引。
- 默认最多读取 3 张能力卡。
- 模块索引为空时，回到普通策划讨论，不编造来源。
- 书籍未导入前，只能保留模块路由，不能输出书籍结论。
