# 1 代架构赛季道具制作规范

> **适用范围**：SeasonItem 赛季道具系统 — 11 种赛季特殊道具的生成、配置、网络同步、UI 提示与 AutoWar 集成
> **不适用**：常规拾取道具（枪械/护甲/背包/投掷物）→ 归道具系统；Buff 框架通用逻辑 → 归 Buff 系统
> **公共框架依赖**：BuffSystem（BSAddSeasonItem 触发生成）、CarNet（载具型赛季道具）、PickItem（物品型赛季道具）
> **Feature 文件引用**：[[item-base]]（道具核心框架，含 SeasonItem 三端文件索引）

## 一、架构概述

### 1.1 SeasonItemType 枚举（11 种赛季道具）

```csharp
// Assets/Script/GamePlay/Host/Modules/SeasonItem/SeasonItemBase.cs
public enum SeasonItemType {
    Buff,               // Buff 类虚拟节点
    HolySword,          // 圣剑（拔剑平台）
    Dragon,             // 龙（载具）
    Machine,            // 机甲（载具）
    Ufo,                // UFO（载具）
    DemonMachete,       // 恶魔弯刀（物品）
    TRexKing,           // 霸王龙（载具）
    GutsWing,           // 翅膀（载具）
    ShenLong,           // 神龙（物品）
    DeliveryCannon,     // 快递大炮（传送点）
    BeastCampTransport, // 暴打猛兽营传送点
    CyberTitan,         // 巨剑机甲（载具）

```

### 1.2 三端架构

```
Host 层 — SeasonItemBase（基类，定义枚举+数据结构）
  │
  ├─ Client 端 — SeasonItemClient（显示/隐藏，位置同步到小地图）
  │     └─ ClientSeasonItemFeatureManager（客户端管理器，处理 RPC 回调）
  │
  └─ Server 端 — SeasonItemServer（生命周期管理，位置更新，网络广播）
        └─ ServerSeasonItemFeatureManager（服务端管理器，概率计算+去重）
```

**三端职责划分：**

| 层级 | 类 | 核心职责 |
|------|------|---------|
| **Host** | `SeasonItemBase` | 枚举定义、ItemKey 生成规则（`{ItemType}_{ItemId}`）、基础数据字段 |
| **Client** | `SeasonItemClient` | 显示/隐藏位置、同步到 MapInfo 小地图图标 |
| **Client** | `ClientSeasonItemFeatureManager` | RPC 回调处理、管理所有客户端 SeasonItem 实例 |
| **Server** | `SeasonItemServer` | 位置更新（载具型跟随 CarNet）、显示延迟倒计时、子物品管理、RPC 广播 |
| **Server** | `ServerSeasonItemFeatureManager` | 概率随机计算、Buff 序号去重、管理所有服务端实例 |

### 1.3 道具分类

赛季道具按实现方式分为三大类：

| 类别 | 道具 | 创建方式 | 生成对象 |
|------|------|---------|---------|
| **载具型** | Dragon、Machine、Ufo、TRexKing、GutsWing、CyberTitan | `CreateCar()` | CarNet（载具实体） |
| **物品型** | ShenLong、DemonMachete | `CreateItem()` | PickItem（可拾取物品） |
| **特殊型** | HolySword | `BSAddHolySwordPlatform` | 拔剑平台（独立 Buff 系统） |
| **虚拟型** | Buff | `BSAddSeasonItem` | 虚拟 Buff 节点 |
| **传送型** | DeliveryCannon、BeastCampTransport | 自动生成 | 传送点 |

### 1.4 核心数据流

```
BSAddSeasonItemGroup.Init()                    ← Buff 系统触发入口
    ↓
GetGroupBuffIndex()                            ← 概率随机选择
    ↓
BSAddSeasonItem.CreateSeasonItem()             ← 根据 itemType 分发
    ├─ 载具型 → CreateCar(carSign, ...)        ← CarNet 系统创建
    ├─ 物品型 → CreateItem(itemSign, ...)      ← PickItem 系统创建
    └─ 特殊型 → BSAddHolySwordPlatform         ← 独立 Buff 流程
    ↓
ServerSeasonItemFeatureManager.AddSeasonItem() ← 注册到管理器
    ↓
SeasonItemServer.ShowSeasonItem()              ← RPC 广播显示
    ↓ (网络)
RpcShowSeasonItem(itemKey, itemType, pos)      ← 协议传输
    ↓
SeasonItemClient.ShowSeasonItem(pos)           ← 客户端显示
    ↓
MapInfoController.SetSeasonIconPos()           ← 小地图图标
```

## 三、配置详解

### 3.1 Buff SO 配置层

赛季道具通过 Buff 系统配置和触发，核心配置链为：

```
BSOAddSeasonItemGroup（组配置）
  │
  ├─ seasonBuffData[]       ← 本期赛季物品配置数组
  │   └─ SeasonItemBuffData
  │       ├─ seasonItemBuff  ← 指向 BSOAddSeasonItem 或 BSOAddHolySwordPlatform
  │       └─ RandomValue     ← 概率权重（整数，越大越容易被抽中）
  │
  └─ seasonBuffDataOld[]    ← 往期赛季物品配置数组（同结构）
```

### 3.2 概率计算机制

```csharp
// ServerSeasonItemFeatureManager.cs
// 三步概率计算流程：

// Step 1: 初始化权重数组
InitRandomValue()
// 从 SO 数据 → randomValueList[]

// Step 2: 计算累积概率数组
CalcRandomValue()
// [10, 20, 30] → [10, 30, 60]（累积和）

// Step 3: 随机选择
RandomBuffIndex()
// Random(0, totalWeight) → 二分查找对应 index
```

**去重机制**：`GetGroupBuffIndex()` 会检查已生成的赛季道具，避免重复生成同一种类型。

                break;

                break;
            case SeasonItemType.Ufo:
                CreateCar("UFO", ...);
                break;
            case SeasonItemType.TRexKing:
                CreateCar(ItemData.Trexking, ...);
                break;
            case SeasonItemType.GutsWing:
                CreateCar(ItemData.Gutswing, ...);
                break;
            case SeasonItemType.ShenLong:
                CreateItem(ItemData.ShenLong, ...);
                break;
            case SeasonItemType.CyberTitan:

### 4.5 网络协议

赛季道具使用 6 个 RPC 进行网络同步：

| RPC 名称 | Proto ID | 方向 | 参数 | 用途 |
|---------|----------|------|------|------|
| `RpcShowSeasonItem` | 4093 | 广播 | itemKey, itemType, pos | 全体显示赛季道具 |
| `TargetRpcShowSeasonItem` | 4094 | 单播 | itemKey, itemType, pos | 对指定玩家显示（中途加入） |
| `RpcHideSeasonItem` | 4092 | 广播 | itemKey | 全体隐藏赛季道具 |
| `RpcGetSeasonItem` | 4095 | 广播 | itemType, playerName | 全体通知某玩家获得道具 |
| `RpcShowSeasonItemTip` | 4096 | 广播 | tipType, itemType | 全体显示提示消息 |
| `TargetRpcHideSeasonItem` | — | 单播 | itemKey | 对指定玩家隐藏 |

**tipType 含义**：
- `2` = 掉落（Drop）
- `3` = 出现（Create）
- `4` = 销毁（Clear）
- `-1` = 获得（Get，使用单独 RPC）

| 症状 | 可能原因 | 解决方案 |
|------|---------|---------|
| 场景中无赛季道具出现 | `BSOAddSeasonItemGroup.seasonBuffData` 为空 | 检查 SO 资产中是否配置了本期赛季物品 |
| 只生成部分类型 | `RandomValue` 权重为 0 | 确认所有类型的 RandomValue > 0 |
| 重复生成同一类型 | 去重逻辑异常 | 检查 `GetGroupBuffIndex()` 的去重判断 |

### 5.2 载具型道具位置不同步

| 症状 | 可能原因 | 解决方案 |
|------|---------|---------|
| 小地图图标不动 | `UpdateSeasonItemPos()` 未被调用 | 确认 `SeasonItemServer.Update()` 正常运行 |
| 图标跳动 | `updatePosDis` 阈值过大 | 调整 `ServerPartyChargingManager.SeasonItemUpdateDis` |
| 延迟过高 | `updatePosTime` 周期过长 | 调整 `ServerPartyChargingManager.SeasonItemUpdateTime` |

### 5.3 RPC 提示不显示

| 症状 | 可能原因 | 解决方案 |
|------|---------|---------|
| 提示文本为空 | 缺少 Language Key | 添加 `SeasonItemGet_/Drop_/Create_/Clear_{TypeName}` 文本 |
| 提示不触发 | `TipHolySword` 未处理新类型 | 在 `TipHolySword` 中添加新类型的分支 |
| 中途加入玩家无提示 | 未使用 `TargetRpc` 单播 | 确认 `SendSeasonItemData()` 在玩家加入时调用 |

### 5.4 HolySword 拔剑平台特殊处理

**注意**：HolySword 不走 `BSAddSeasonItem` 的标准流程，而是使用独立的 `BSAddHolySwordPlatform` Buff 系统。新增类似的特殊赛季道具时，需要：
1. 创建独立的 `BSAdd{Name}` 类
2. 创建对应的 `BSOAdd{Name}` SO 配置
3. 在 `BSAddSeasonItemGroup` 的概率配置中引用新的 SO

### 5.5 子物品关联

`SeasonItemServer` 支持父子关系（一个赛季道具关联多个子物品/载具）：

```csharp
// 添加子物品
public void AddSeasonItemChild(string childKey) {
    childKeyList.Add(childKey);
}

// 显示其他子物品
public void ShowOtherChild(string childKey) {
    // 当一个子物品被获取时，显示剩余子物品
}
```

**适用场景**：一个赛季道具生成点产出多个关联实体（如一组载具）。
