# 1 代架构镜头系统制作规范

> **适用范围**：第三人称镜头跟随/射击瞄准/载具镜头/技能镜头/震动/自由视角/OB 观战
> **不适用**：UI 镜头/大厅镜头 → 归 UI 系统；后处理效果 → 归渲染管线
> **参考实现**：站立→射击切换（最常见场景）、载具镜头（carCameraMove）、技能镜头（Zeus/关羽）

---

### 1.6 输入管线（Input → Rotation Delta）

**输入来源**：触摸/鼠标/陀螺仪 → Movement 组件 → `cameraMove(xRot, yRot)`

```

  │

  ├── SneakSandMovement.OnDrag()      ← 潜行状态
  ├── RollMovement.OnDrag()           ← 翻滚状态
  └── OBMovement.OnDrag()             ← 观战状态
  │
  ↓
cameraMove(xRot, yRot, isGyro)        ← 统一入口
  │
  ├── [前置屏蔽检查]（20+ 条件，任一满足则 return）
  │   ├── 被举起 IsBeLiftUp
  │   ├── 出生岛移动控制器打开
  │   ├── 拔圣剑/展示圣剑动画中
  │   ├── 弹道测试模式
  │   ├── 死亡且非 OB
  │   └── isCanTurnCamera == false
  │
  ├── [平台分发]
  │   ├── PC → 直接 setCameraMoveValue()
  │   ├── Android/陀螺仪 → 直接 setCameraMoveValue()
  │   └── iOS → DirMoveCount 队列缓冲（丢弃首帧过大幅度）
  │
  ↓
setCameraMoveValue(xRot, yRot, isGyro, isAimRecoil)
  │
  ├── [灵敏度计算]
  │   ├── 基础: RotSpeed × GetSensitivity() × _cannonSencitive
  │   ├── 射击中: speed /= weaponCameraRatioLevel × 0.66（倍镜减速）
  │   └── 射击中非线性: ratioX = 0.3 + Clamp(|xRot|×2, 0, 0.7)
  │
  ├── [旋转叠加]
  │   ├── MyCameraRotationY *= Quaternion.Euler(-_yRot, 0, 0)  ← 垂直（俯仰）
  │   └── MyCameraRotationX *= Quaternion.Euler(0, _xRot, 0)   ← 水平（偏航）
  │
  ├── [角度钳制]
  │   └── MyCameraRotationY = ClampRotationAroundXAxis()
  │
  ├── [辅助瞄准]
  │   └── MyRoleAimAssist.SetRoleDirMove(_xRot, -_yRot)
  │
  └── [射击状态直接应用]
      ├── SetPointLocalRotation(MyCameraRotationX) → WarCameraPoint
      └── SetRotaLocalRotation(MyCameraRotationY) → WarCameraRota
```

### 1.7 旋转计算与角度钳制

**双四元数旋转系统**：

| 变量 | 轴向 | 控制节点 | 含义 |
|------|------|---------|------|
| `MyCameraRotationX` | Y 轴（偏航） | `WarCameraPoint` | 水平旋转 — 同时驱动角色朝向 |
| `MyCameraRotationY` | X 轴（俯仰） | `WarCameraRota` | 垂直旋转 — 独立于角色 |

**Transform 层级与旋转对应**：

```
MyTransform (根节点，跟随目标位置)
  └── WarCameraPoint (水平旋转 Y 轴) ← MyCameraRotationX
        └── WarCameraRota (垂直旋转 X 轴) ← MyCameraRotationY
              └── CameraShake (震动偏移)
                    └── Camera (Unity Camera)
```

**角度钳制规则**（`ClampRotationAroundXAxis`）：

| 状态 | MinX | MaxX | 说明 |
|------|------|------|------|
| 普通站立 | `NoMoClampMinX` | `NoMoClampMaxX` | SO 配置 |
| 游泳/潜水 | 6° | 30° | 固定范围 |
| 跳伞滑翔 | 0° | 70° | 只能向下看 |
| 自由落体 | -30° | 70° | 允许少量仰视 |
| 各技能镜头 | `{Skill}ClampMinX` | `{Skill}ClampMaxX` | 技能专属 SO 字段 |

**旋转应用模式**（`LocalRoleCameraMove`）：

| 模式 | LerpSpeed | 行为 |
|------|-----------|------|
| **射击中** | 直接应用 | `SetPointLocalRotation(MyCameraRotationX)` — 无插值 |
| **队友跟随** | 10 | 锁定跟随角色朝向 |
| **拳套/格挡** | `gaunletCamEnemySpeed`(15) | 锁敌慢速跟随 |
| **特殊状态**（泰迦/雪人/双人舞） | 15 | 慢速跟随 |

**目标锁定**（`SetTarget`）：

```csharp
public void SetTarget(BattleRole role) {
    // 1. 重置前一目标（恢复透明度）
    if (LockRole) LockRole.SetRoleAlpha(1);
    // 2. 将镜头挂到战场 RoleLayer 下
    MyTransform.SetParent(RoleLayer);
    // 3. 继承目标角色的朝向
    MyCameraRotationX = role.MyTransform.localRotation;
    MyCameraRotationY = Quaternion.identity;
    // 4. 设置锁定目标（头部）
    setLookTarget(LockRole.LockTarget);
    // 5. 立即更新一帧
    OnLateUpdate();
    // 6. 广播目标变更消息
    DispatchMessage(ClientMessageConstants.CameraTargetChange);
}
```

**镜头距离计算**（`LerpEndPosition`）：

| 状态 | EndPoint 偏移 | 插值速度 | 说明 |
|------|--------------|---------|------|
| 普通站立 | `NoMoPoint (0,-0.34,-4.37)` | 5/s | 基础距离 |
| 室内 | `EndPoint × InToHouseRatio` | 5/s | 自动拉近 |
| GoldDash | `EndPoint × goldDashRatio` | 5/s | 撤离模式固定比例 |
| 死亡 | `(0, -1, -2)` | 5/s | 俯视 |
| 跳伞跟随 | `flyJumpCameraFallowPos` | 5/s | 远距离 |
| 载具 | `carDistance=10, carHeight=5` | `carHeightDamping=2` | 阻尼模式 |

```csharp
// 载具镜头的特殊逻辑
private void carCameraMove() {
    SetLockTarget(car.CameraTarget);  // 跟随载具节点
    // 阻尼旋转
    currentRotationAngle = Mathf.LerpAngle(currentRotationAngle,
        wantedRotationAngle, carRotationDamping × deltaTime);
    // 位置 = 目标位 - 朝向 × 距离
    position -= currentRotation × Vector3.forward × carDistance;
    // 每帧旋转限制防抖
    if (offsetXAxisAngle > xAxisMaxRotationPerTime)  // 0.4°/帧
        newX = Mathf.Lerp(oldX, newX, maxRotationPerTime / offsetXAxisAngle);
}
```

### 1.9 碰撞检测三层防穿墙

**三层碰撞系统依次执行**（同一帧内顺序处理）：

```
层级 1: CameraHitMove()        ← Raycast 检测（角色→镜头方向）
  │
  └── checkCameraRole() 发射射线
      ├── 起点: lockTarget.position（角色头部）
      ├── 方向: -LookTarget.forward（镜头反向）
      ├── 距离: roleDistance（角色到镜头距离）
      ├── Layer: baseLayerMask & ~serverLayerMask
      ├── 过滤: HitType.CanCamera == false 的跳过
      ├── 过滤: "RoleHitCollider" 自身碰撞跳过
      └── 结果: 取最近碰撞点 → 镜头拉近到该点
          MyCameraTran.localPosition = Lerp(当前, 碰撞点, deltaTime × 10)

层级 2: DefaultCameraRangeMove() ← 碰撞球偏移应用
  │
  └── 比较 MyCameraTranSelf 与 MyCameraRange 位置
      ├── 距离 > 1.0 → 直接 Snap 到碰撞球位置
      ├── 距离 > 0.02 → Lerp(速度 10) 逼近
      └── 距离 ≤ 0.02 → 保持不动

层级 3: MyCameraRange.timeEvent() ← CameraHit 物理碰撞体
  │
  └── CameraHit 组件（挂在碰撞球上）
      ├── OnTriggerStay: 检测墙壁 → visible(true) 启用推离
      ├── 默认偏移: _endPoint = (0, 0, 0.3f) — 30cm 前推
      ├── 距离 > 0.8 → 直接 Snap
      ├── 距离 > 0.3 → Slerp(速度 6) 逼近
      └── 距离 ≤ 0.3 → visible(false) 停止物理
```

**关键约束**：碰撞只会把镜头**拉近**（`distance1 > distance2` 才应用），永远不会把镜头**推远**。

### 1.10 镜头转向的下游影响

镜头旋转不仅改变视角，还**同帧驱动**以下系统：

```
镜头旋转（MyCameraRotationX/Y 变更）
  │
  ├─ [角色朝向] ★ 最核心
  │   └── LockRole.MainRota(WarCameraPoint.eulerAngles.y, WarCameraRota.eulerAngles.x)
  │       → 角色模型 Y 轴旋转跟随镜头水平朝向
  │       → 条件: IsControlRoleRotate == true && 非 ESC 窗口
  │
  ├─ [射击方向]
  │   ├── WeaponCameraTan.rotation = MyCameraTranSelf.rotation
  │   ├── WeaponRenderPassFeature.weaponCameraForward = Camera.forward
  │   └── checkFireRoleForZX() → 射线检测命中点 → 准心 UI 位置
  │
  ├─ [武器模型]
  │   └── userWeapon.MyTransform.localRotation = MyCameraRecoilWeapon.localRotation
  │       → 武器跟随镜头俯仰 + 后坐力偏移
  │
  ├─ [辅助瞄准]
  │   └── MyRoleAimAssist.SetRoleDirMove(_xRot, -_yRot)
  │       → 发送旋转增量给瞄准辅助系统
  │
  ├─ [网络同步] SendCameraStateForLockRoleOrAI()
  │   └── LockRole.SetCameraSendData(
  │         MyCameraRotationX,      // 水平朝向
  │         MyCameraRotationY,      // 垂直瞄准
  │         LookDirX.localRotation, // 自由视角 X
  │         LookDirY.localRotation, // 自由视角 Y
  │         ratioLevel)             // FOV 级别
  │       → 通过 CmdCameraMoveData(12001) 发送到服务器
  │       → 服务器转发 TargetRpcLookCameraMoveData 给其他玩家
  │
  ├─ [FOV 变化] BuffCameraRatio() + LerpCameraRatio()
  │   └── Buff 临时修改 FOV → Lerp 平滑过渡
  │       → cameraRatio = BaseCameraRatio / cameraRatioLevel
  │
  └─ [后坐力] SetRecoil() + FireRecoilEvent()
      ├── 开枪时: 叠加后坐力旋转到 MyCameraRotationX/Y
      │   → yRot × weapnRecoilRatio（抑制系数）
      ├── 射击中: 插值动画播放后坐力
      └── 停火后: Quaternion.RotateTowards 自动回正
          → 速度: _startMyCameraRotationY × (1/userFireRevertTime) × deltaTime
```

```csharp
// SOCameraUserData.BaseCameraRatio
public float BaseCameraRatio {
    get {
        var hFOVrad = 90f * Mathf.Deg2Rad;
        var camH = Mathf.Tan(hFOVrad * 0.5f) / ((float)Screen.width / (float)Screen.height);
        var vFOVrad = Mathf.Atan(camH) * 2f;
        return vFOVrad * Mathf.Rad2Deg;  // 根据屏幕比例计算垂直 FOV
    }
}
```

## 五、常见问题与踩坑记录

### 5.1 镜头穿墙

**现象**：镜头进入墙壁/地面内部，画面全黑或看到模型内部

**根因**：`CameraHitMove()` 和 `DefaultCameraRangeMove()` 碰撞检测未覆盖新增场景物体的 Layer

**解决方案**：
1. 确认场景物体的 Layer 在 `MyCameraRange` 的检测层级内
2. 不要修改 `OnLateUpdate` 中 `CameraHitMove` 和 `DefaultCameraRangeMove` 的调用顺序

### 5.2 镜头抖动

**现象**：镜头在某些状态下持续微抖或来回跳动

**根因**：多个状态方法在同一帧竞争设置镜头点位，或 `cameraLerpSpeed` 过高导致过冲

**解决方案**：
1. 确保同一帧只有一个状态方法生效
2. 载具模式使用 `xAxisMaxRotationPerTime`(0.4°) 限制每帧旋转角
3. `cameraLerpSpeed` 推荐值：正常 60，特殊状态 15，拳套锁定 15

### 5.3 平台差异 FOV 不一致

**现象**：同一场景在手机和 PC 上视野范围差异大

**根因**：`BaseCameraRatio` 基于屏幕宽高比计算垂直 FOV，加上 `NomoCameraFar`(500) vs `PCCameraFar`(600) 差异

**解决方案**：
1. 新增功能时同时测试 16:9 和 18:9 屏幕
2. 如需统一视距，使用固定值而非 `BaseCameraRatio`

### 5.4 镜头 SO 参数不生效

**现象**：修改 SOCameraUserData.asset 中的值后运行时无变化

**根因**：SOCameraUserData 通过 `MyUserData` 属性懒加载，首次访问后缓存。如果在 Init() 之前就被缓存了旧值

**解决方案**：
1. 确保修改的是正确的 .asset 文件（路径 `ToBundle/ScriptableObject/Misc/`）
2. 清除 Library 缓存后重新运行

### 5.5 OB 模式镜头跟丢

**现象**：观战时镜头突然跳转或丢失目标

**根因**：`LockRole` 在目标玩家死亡后被清空，`CheckLookRole()` 切换到下一个目标时产生跳变

**解决方案**：在 `OtherRoleCameraMove()` 中使用 `Quaternion.Lerp` 插值（当前速度 10），不要直接赋值旋转
