# 1 代架构消耗品制作规范

> **适用范围**：`ItemType.Consumables(46)` 下所有治疗类消耗品 — 绷带、急救包、医疗箱、止痛药、能量饮料、变大药剂
> **不适用**：汽油(Oilbucket)、传送胶囊(TransportItem) → 归 B14 战场道具制作；投掷物(Bomb) → 归 B9 投掷物制作
> **参考实现**：绷带 `Bandage` (最简标准消耗品)、变大药剂 `Bigger` (带特殊效果的消耗品)

---

## 一、架构概述

### 1.1 系统分类

消耗品按效果类型分为两大类：

| 分类 | 代表物品 | 核心 Buff SO | 效果模式 |
|------|---------|-------------|---------|
| **即时回血型** | 绷带、急救包、医疗箱 | `BSOAddHPForLimit` | 使用完成后一次性回血/回心情，受血量上限条件限制 |
| **持续回血型** | 止痛药、能量饮料 | `BSOAddHPForTime` | 使用完成后持续周期性回血，有 LifeTime 和 DeployTime |
| **变身型** | 变大药剂 | `BSORoleSize` | 改变体型+额外血量+移速/跳跃力加成，有持续时间 |

## 五、常见问题与踩坑记录

### 踩坑 1：消耗品使用条件 — 血满不能用

- **现象**：配置了 `BSOAddHPForLimit` 但角色满血时无法使用，提示"生命已满"
- **原因**：`BSOAddHPForLimit.checkCanUser()` 检查 `role.Hp >= MinUseHp`，满血时条件不满足
- **解决**：确保 `MinUseHp` 配置为最大血量值（如 200），而非 0。`MinUseHp <= 0` 时表示不限制，但 `MinUseHp > 0` 且 `≥ 当前血量` 才能使用

### 踩坑 2：国内/海外版血量阈值不一致

- **现象**：海外版药品使用条件与国内不同，导致 QA 反馈"海外不能用药"
- **原因**：`BSOAddHPForLimit` 有 `MinUseHp`(国内) 和 `GlobalMinUseHp`(海外) 两套配置，`GetMinUseHp()` 根据 `GlobalDefine.isGlobal` 自动切换
- **解决**：新增消耗品时必须同时配置国内和海外两套阈值

### 踩坑 3：变大药剂在室内无法使用

- **现象**：角色在建筑物内使用变大药剂无效
- **原因**：`CheckBiggerUse_Impl()` 用 CapsuleCast 检测头顶空间，室内天花板阻挡导致检测失败
- **解决**：此为设计意图（防止卡模型）。若需要室内可用，需调整 `castRadius` 和 `roleHeight` 参数，或为特定物品跳过空间检测

### 踩坑 4：useItemSigns 数组索引错位

- **现象**：添加新消耗品后，所有旧药品的快捷键映射错乱
- **原因**：`useItemSigns[]` 索引+1 作为 `useItemState` 通过网络同步，在数组中间插入元素会导致所有后续索引偏移
- **解决**：**只能在数组末尾追加**新条目，不能在中间插入。已有条目的位置不可更改

## 六、验收标准

### 6.1 基础功能验证

- [ ] 消耗品可被拾取并显示在背包 UI 中
- [ ] 通过快速药品按钮 / 快捷键 / 药品列表均可触发使用
- [ ] 使用过程中角色播放正确的使用动画（手持模型显示）
- [ ] 使用计时条正常显示，倒计时结束后生效
- [ ] 使用过程中被攻击/移动可正确取消
- [ ] 使用后数量正确递减
- [ ] 数量为 0 时无法再次使用

### 6.2 效果验证

- [ ] 即时回血型：使用完成后 HP 立即增加到配置值（不超过 MinUseHp 阈值）
- [ ] 持续回血型：使用完成后按 DeployTime 间隔持续回血，总时长 = LifeTime
- [ ] 变身型：体型/移速/跳跃力/镜头 按配置生效，持续时间到后恢复
- [ ] 弱化状态(小肠肠)下使用药品恢复弱化值而非血量（需 `isMinSausage=true`）
- [ ] 心情值(Mood)正确恢复（毒圈模式相关）

### 6.3 多端一致性

- [ ] Host 端 `CanUseItem_Impl()` 和 Server 端 `ServerCheckCanUseItem()` 验证结果一致
- [ ] 网络同步：所有玩家看到使用者的使用动画
- [ ] 延迟补偿：开启 `IsOpenPingCompensate` 时本地预测回血正确

### 6.4 边界情况

- [ ] 游泳状态禁止使用
- [ ] 载具加速状态禁止使用
- [ ] 绷带连续使用（IsReUseItem）正常工作
- [ ] 队友行为树使用药品正常
- [ ] 自定义房间 `HpRate` / `MoodRate` 倍率正确生效
