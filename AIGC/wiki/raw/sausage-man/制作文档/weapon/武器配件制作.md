# 1 代架构武器配件制作规范

> **适用范围**：`ItemType.UpperRail(81)` / `Magazine(82)` / `Stock(83)` / `Muzzle(84)` / `LowerRail(85)` / `Chip(805306369)` / `Ammunition(26)` 相关的配件挂载、属性加成计算和 UI 交互
> **不适用**：角色装备（Equipment/护甲/头盔/背包）→ 归 B12 角色装备制作；GoldDash 模式主逻辑 → 归 mode-golddash
> **参考实现**：瞄准镜（UpperRail）为最完整的配件实现（有独立网络协议 + 皮肤系统）

**占位符说明**：

| 占位符 | 含义 | 示例 |
|--------|------|------|
| `{PartName}` | 配件名称（大驼峰） | `RedDot`、`Compensator`、`ExtendMag` |
| `{PartSign}` | 配件标识符（PickItemData 主键） | `RedDot`、`Suppressor`、`QuickDraw` |
| `{PartItemType}` | 配件物品类型枚举值 | `81`(瞄准镜)、`82`(弹匣)、`84`(枪口) |
| `{SlotName}` | 槽位名称（camelCase） | `upperRailBox`、`muzzleBox`、`chipBox` |
| `{WeaponSign}` | 目标武器标识符 | `AK12`、`AWM`、`M416` |
| `{SkinSign}` | 皮肤标识（SOWepEquipDataConfig 主键） | 由配置表 `SkinSign` 字段指定 |

## 一、架构概述

### 1.1 系统分类

武器配件系统管理 6 种配件类型在武器上的挂载、属性加成计算和 UI 交互。所有配件共享同一套 `WeaponEquipConfig` 属性驱动和 `WepEquip` 运行时组件，区别在于 `SOWepEquipDataConfig` 配置和预制体结构。

**配件类型枚举**（`ItemData.ItemType`）：

| 枚举值 | 类型 | 说明 | 槽位字段 | 典型配件 |
|--------|------|------|----------|---------|
| 81 | UpperRail | 瞄准镜 | `upperRailBox` | 红点/全息/2x/3x/4x/6x/8x/15x 倍镜 |
| 82 | Magazine | 弹匣 | `magazineBox` | 快速装弹弹匣/扩容弹匣/快速扩容弹匣 |
| 83 | Stock | 枪托 | `stockBox` | 战术枪托/腮垫/子弹环 |
| 84 | Muzzle | 枪口 | `muzzleBox` | 消音器/补偿器/制退器/闪光抑制器 |
| 85 | LowerRail | 握把/下导轨 | `lowerRailBox` | 竖握/角握/激光瞄准器 |
| 805306369 | Chip | 芯片 | `chipBox` | 伤害/RPM/精准/容量/充能芯片 |
| 26 | Ammunition | 弹药 | — | 各类弹药类型 |

### 1.2 核心类依赖


### 4.2 通过 WeaponEquipConfig 获取配件属性

```csharp
// 普通模式：直接使用 base 配置

WeaponEquipConfig goldDashConfig = new WeaponEquipConfig("{goldDashId}", "{baseId}");
```

### 4.3 配件预制体挂载 WepEquip 组件

```csharp
// 文件：配件预制体 Inspector
// 说明：在配件预制体根节点挂载 WepEquip 组件
// WepEquip 通过 WeaponEquipConfig 获取属性

// WepEquip 生命周期：
// 1. 武器装配时 → WeaponControl.AddEquip() 实例化配件预制体
```

## 五、常见问题与踩坑记录

### 踩坑 1：倍率配件切换不生效

- **现象**：装备瞄准镜后切换倍率，本地显示正确但其他玩家视角倍率不变
- **原因**：瞄准镜倍率通过 `ProtoStruct_UpperRail.SettingUpperRailRatio` 网络同步，但开发时只更新了客户端本地值，未通过协议同步到 Server 端，导致 Server 端的 `UpperRailMaxRatio` 未更新
- **解决**：倍率切换时必须同时发送 `ProtoStruct_UpperRail` 协议到 Server，确保 `UpperRailMaxRatio` 和 `SettingUpperRailRatio` 双向同步

### 踩坑 2：消音器音效未触发

- **现象**：装备消音器后武器仍然播放正常射击音效，消音效果未生效
- **原因**：消音器效果依赖 `SOWepEquipDataConfig` 中两个字段的**联合配置**：`IsSilencerAudio` 必须为 `true`，且 `ShowFireEffect` 需设为 `2`（Small）。仅配置其中一个字段不会触发完整的消音效果
- **解决**：新增消音器配件时必须同时配置 `IsSilencerAudio = true` + `ShowFireEffect = 2`，两者缺一不可

### 踩坑 3：GoldDash 配件升级属性不叠加

- **现象**：GoldDash 模式下升级配件后，部分属性（如 SpinCd）不随等级变化
- **原因**：`WeaponEquipConfig` 的 `goldDash` 构造函数 `WeaponEquipConfig(goldDashId, baseId)` 是**直接覆盖** base 值而非叠加。但有 5 个字段例外：`SpinCd` / `SpinTime` / `SpinAttackTime` / `SpinDamage` / `FollowWeaponNum` 始终从 baseConfig 读取，不被 GoldDash 配置覆盖
- **解决**：若需要 GoldDash 升级影响这 5 个字段，需修改 `WeaponEquipConfig` 构造函数逻辑（需评审）。一般情况下接受此设计：旋转相关属性由武器 base 配置决定，不随配件升级变化

### 踩坑 4：配件预制体加载后位置偏移

- **现象**：配件模型装备到武器上后位置不正确，出现明显偏移或旋转错误
- **原因**：`AssetsLoad.GetItemSkin()` 加载的模型使用原始 Transform，未重置 localPosition / localRotation。且不同武器的配件挂点（如 `upperRailBox`）坐标空间不同
- **解决**：加载配件皮肤后必须将 `localPosition` 重置为 `Vector3.zero`、`localRotation` 重置为 `Quaternion.identity`，并确保预制体自身锚点正确（美术制作时以槽位原点为基准）

### 踩坑 5：激光瞄准器在回放/观战模式显示异常

- **现象**：观战其他玩家时，激光瞄准器不可见或显示在错误位置
- **原因**：`LaserSight` 的可见性判断依赖 `WarCamera.LockRole`，观战切换锁定角色后未及时刷新激光可见性状态
- **解决**：在 `WarCamera.LockRole` 切换回调中主动调用激光瞄准器的可见性刷新逻辑
