# 1 代架构投掷物制作规范

> **适用范围**：基于 ItemType.Bomb(31) 的手雷类投掷物 和 ItemType.BlastBomb(97) 的爆破炸弹(C4)，通过 RoleSkillBomb → BSClientBomb/BSBlastBomb 链路实现
> **不适用**：2 代 ECS 投掷物（Biubiubiu2/）、空投系统（AirThrow）、轰炸区/空袭系统（BombArea — 属于模式子功能，见 mode-classic.json）、毒圈/缩圈系统（GameQuan — 属于模式子功能）
> **参考实现**：标准手雷 Grenade（路径 → `PickItems/Grenade.prefab` + `Buff/ClientBomb/GrenadecClientBomb.asset`）

---

## 一、架构概述

### 1.1 投掷物分类

| 分类 | ItemType | 代表物品 | 核心 Buff | 拆除机制 |
|------|----------|---------|-----------|---------|
| **普通手雷** | Bomb(31) | Grenade / GrenadeMax / FireGrenade | BSClientBomb | ❌ 投出即炸 |
| **角色手雷** | — (技能触发) | ClownGrenade / SandGrenade / LightningBomb | BSClientBomb 变体 | ❌ |
| **爆破炸弹** | BlastBomb(97) | BlastBomb (C4) | BSBlastBomb | ✅ F 键拆除 |
| **场景炸弹** | — (Buff触发) | DiscoBomb / SlimeBomb / TotemBomb | BSClientBomb 变体 | ❌ |

> **关键区分**：
> - `BombAreaManager` 是**轰炸区/空袭机制**，属于模式子功能（见 mode-classic.json），不在投掷物范围内
> - `GameQuan` 是**毒圈/缩圈机制**，同样属于模式子功能，不在投掷物范围内
> - `AirThrow` 是**空投系统**，不是投掷物
> - 角色手雷由 `RoleSkillBomb` 子类触发，不走背包道具系统

## 三、配置文件详解

### 3.1 BombLineRender.txt — 投掷弧线物理参数

**路径**：`Assets/ToBundle/Config/Txt/BombLineRender.txt`
**格式**：Tab 分隔，每行一个 SkillSign

```
{SkillSign}	{AddSpeed}	{AddHeight}	{Gravity}	{MaxLength}	{PointLength}	{PreviewGoSign}	{IsCheckCollider}	{IsHook}	{IsInkOcclusion}	{IsZetaLine}	{IsCheckMinThrowDistance}	{IsLockPitch}	{IsForceShowEnd}	{MinDistance}	{StartPointX}	{StartPointY}	{StartPointZ}	{IsOnlyCheckPlayer}	{Width}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| SkillSign | string | 技能标识，关联 SORoleSkillConfig |
| AddSpeed | float | 抛物线初始速度加成 |
| AddHeight | float | 抛物线高度加成 |
| Gravity | float | 重力系数 |
| MaxLength | float | 弧线最大渲染长度 |
| PointLength | float | 采样点间隔距离 |
| PreviewGoSign | string | 落点预览预制体标识 |
| IsCheckCollider | bool(0/1) | 是否做弧线碰撞检测 |
| IsHook | bool(0/1) | 是否为钩爪模式（直线弧线） |
| IsInkOcclusion | bool(0/1) | 是否为污污弹弧线 |
| IsZetaLine | bool(0/1) | 是否为 Zeta 特殊弧线 |
| IsCheckMinThrowDistance | bool(0/1) | 是否检查最小投掷距离 |
| IsLockPitch | bool(0/1) | 是否锁定投掷角度 |
| IsForceShowEnd | bool(0/1) | 是否强制显示落点 |
| MinDistance | float | 最小投掷距离（IsCheckMinThrowDistance=1 时生效） |
| StartPoint | Vector3 | 弧线起始点偏移 (x, y, z) |
| IsOnlyCheckPlayer | bool(0/1) | 碰撞是否仅检测玩家 |

## 四、关键代码修改点

### 4.1 RoleSkillBomb 投掷流程

**文件**：`Assets/Script/UI/War/Role/RoleSkill/RoleSkillBomb.cs`

投掷操作核心流程：

```csharp
// 1. 按下技能按钮 → 显示弧线
public override void OnDownSkill() {
    base.OnDownSkill();
    if (CheckCanDownSkill()) {
        SetDownSkillBomb();  // 显示弧线 + HoldOn 动画
    }
}

// 2. 拖动 → 更新弧线方向（由 BombLineRender.Update 驱动）

// 3. 抬起按钮 → 释放投掷
public override void OnUpSkill() {
    base.OnUpSkill();
    if (CheckCanUpSkill()) {
        SetUpSkillBomb();  // 获取落点 → CmdUseSkill
        isDown = false;
    }
}

// 4. 投掷释放核心
public virtual void SetUpSkillBomb() {
    // 检查是否可以投掷
    if (GameData.LocalRole.MyLineRender.CanThrow == false) {
        OnCancelUseSkill("");
        return;
    }
    // 获取弧线轨迹点
    var buffSo = AssetsLoad.GetSOBuffData({SkillBuffSign});
    if (buffSo as BSOLineMove) {
        points = GameData.LocalRole.MyLineRender.GetPoints(false);
    }
    // 发送网络命令
    CmdUseSkill(true);
}
```

### 4.4 击飞物理模型

**文件**：`Assets/Script/GamePlay/Host/Modules/Role/RoleBombMove.cs`（179 行）

```
击飞计算模型 (弹簧 + 阻力):
  - 初始速度 = StartBombSpeed × 方向向量
  - 每帧: velocity += Up方向 × UpRatio
  - 每帧: velocity *= (1 - GroundDragRatio/AirDragRatio)
  - 当 speed < StopSpeed && height < StopHeight → 停止击飞
```

## 五、常见问题与踩坑记录

### 5.1 手雷投掷后不爆炸

**问题现象**：手雷沿弧线飞行落地后无爆炸效果和伤害

**根因分析**：
1. `BSOClientBomb.asset` 未正确创建或 `BombEffect` 字段为空
2. `BSOLineMove.asset` 的 `ROLE_EXPLOSION_BUFF` 未关联到对应 ClientBomb
3. `BombLineRender.txt` 中缺少该 SkillSign 的弧线配置

**解决方案**：
1. 检查 `ToBundle/ScriptableObject/Buff/ClientBomb/{Sign}ClientBomb.asset` 是否存在
2. 确认 LineMove SO 的爆炸 Buff 引用正确
3. 确认 `BombLineRender.txt` 中有对应行

### 5.2 手雷弧线不显示

**问题现象**：按下技能按钮后看不到投掷弧线预览

**根因分析**：
1. `BombLineRender.txt` 中该 SkillSign 缺失
2. `PreviewGoSign` 指向的落点预览预制体不存在
3. `BombLineRender.Init(role)` 未被正确调用

**解决方案**：
1. 在 `BombLineRender.txt` 添加配置行
2. 检查 `PreviewGoSign` 对应的预制体是否在 `ToBundle/Effect/` 中存在
3. 确认角色初始化时 `MyLineRender` 已赋值

### 5.3 爆破炸弹(C4)无法拆除

**问题现象**：靠近 C4 后不显示 F 键拆除提示

**根因分析**：
1. `BSOC4Bomb.asset` 的 `defuseBombDistance` 设置为 0 或过小
2. `BSBlastBombClient` 的 UI 显示条件未满足
3. 拆弹模式 `ServerDefusalModeBombLogic` 的模式限制

**解决方案**：
1. 调大 `defuseBombDistance`（推荐 3-5 米）
2. 检查 `BSOBlastBomb` 的 `removeRange` 和 `removeTime` 配置
3. 确认当前模式是否允许 C4 拆除交互

### 5.4 击飞效果异常（角色飞出地图/飞太高）

**问题现象**：爆炸击飞后角色飞出安全区域或高度异常

**根因分析**：
1. `BSOBombMove.asset` 的 `StartBombSpeed` 或 `UpRatio` 数值过大
2. `StopSpeed` / `StopHeight` 阈值过高导致无法停止
3. `GroundDragRatio` 和 `AirDragRatio` 过小，阻力不够

**解决方案**：
1. 参考标准手雷 `GrenadecBombMove.asset` 的参数作为基准
2. 调整 `StartBombSpeed` 在 5-15 范围内
3. 确保 `StopSpeed` 和 `StopHeight` 有合理阈值（通常 0.1-1.0）
