# 1 代架构近战武器制作规范

> **适用范围**：基于 `SOHitPart` / `HitPart` 的 1 代近战武器系统开发（平底锅/棒球棍/圣剑/火尖枪/拳套/爪子等）
> **不适用**：射击武器（→ `射击武器制作.md`）、弹射/暗器/魔法武器（→ `特殊武器制作.md`）、2 代武器系统（`Biubiubiu2/`）
> **参考实现**：Pan（平底锅），SO: `ToBundle/ScriptableObject/Items/Weapons/Pan.asset`，预制体: `ToBundle/GamePlayItem/WeaponControls/Pan.prefab`

**占位符说明**：

| 占位符 | 含义 | 示例 |
|--------|------|------|
| `{WeaponName}` | 武器名称（大驼峰） | `Pan`、`HolySword`、`FlameSpearRed` |
| `{WeaponSign}` | 武器标识符（PickItemData 主键） | `Pan`、`Bat`、`Fork` |
| `{MeleeEnum}` | 近战类型枚举值 | `Bat`、`Pan`、`HolySword` |

## 一、架构概述

### 1.1 近战武器分类

1 代近战武器系统通过 `SOHitPart` 数据驱动，运行时使用 `HitPart` 组件进行物理碰撞检测（与射击武器的弹道系统完全独立）。

| 分类 | 数量 | 代表武器 | 特殊机制 |
|------|------|---------|---------|
| **通用近战** | ~26 | Pan/Bat/Fork/Plunger/Pole/Cheats/DemonMachete | 标准挥击 + 碰撞伤害 |
| **特殊近战** | ~10 | HolySword/Longspear/FlameSpear(Gold/Purple/Red)/RainbowMagicWand | 专用 SO + MeleeAttackSlot 子类 |
| **拳套类** | ~6 | BoxingGlovesBoss/BoxingGlovesJipiao/BoxingGlovesRenwu/Gaunlet/Kaiju | 拳套挥击 |
| **爪类** | ~3 | ClawBlue/ClawGold/ClawGreen | 抓取攻击 |
| **怪物/特殊模式** | ~6 | MonsterAttack/RatAttack/WolfKingNormal/WolfNormal | 特殊模式 AI 武器 |
| **SpecialA/B 变体** | ~28 | 以上部分武器的模式变体（技能模式下不同数值） | SO 路径切换 |

**近战类型枚举**（`ItemData.ItemType`）：

| 枚举值 | 类型 | 说明 |
|--------|------|------|
| 36 | Melee | 所有近战武器共用此类型 |

> **注意**：近战武器不在 `IsWeapon()` 判定范围内！`ISMelee()` 为独立判定方法。

**MeleeWeaponType 枚举**（`HitPart.cs`，运行时子类判定）：

| 值 | 名称 | 说明 |
|----|------|------|
| None | 通用 | 默认近战（Pan/Bat/Fork 等） |
| Pole | 撑衣杆 | 蓄力机制 + 高度增长 |
| HolySword | 圣剑 | PVE 专用武器 |
| Gaunlet | 拳套 | PVE 能量拳套 |
| Claw | 爪子 | 撤离模式爪子 |
| FlameSpear | 火尖枪 | 能量系统 + 火焰攻击 |
| BoxingGloves | 拳套 | 撤离模式拳套 |

**WeaponEnum 近战武器值**（`WeaponEnum.cs`，动画系统使用）：

| 枚举值 | 武器 | 说明 |
|--------|------|------|
| 89 | Pole | 撑衣杆 |
| 91 | Gaunlet | 能量拳套 |
| 105 | HolySword | 圣剑 |
| 130 | Longspear | 杨戬长枪 |
| 133-135 | ClawBlue/Green/Gold | 利爪系列 |
| 138-140 | FlameSpearRed/Purple/Gold | 火尖枪系列 |
| 142-144 | BoxingGlovesJipiao/Renwu/Boss | 拳套系列 |

### 1.3 预制体与资源加载

**加载链 ①：近战武器 SO 配置**
```
ConfigLoader.GetSOWeaponData(weaponSign)
  → 路径: "Assets/ToBundle/ScriptableObject/Items/" + subPath + weaponSign + ".asset"
  → subPath 由 WeasponAreaConfigHelper.GetAssetSubPath() 计算
  → 缓存: SOWeaponControlDic[weaponSign]
  → 类型: SOHitPart（近战武器专用 SO）
```

**加载链 ②：SpecialA/B 变体 SO**
```
WeasponAreaConfigHelper.GetAssetSubPath()
  → 普通模式: "Weapons/"
  → 技能模式 A: "Weapons/SpecialA/"
  → 技能模式 B: "Weapons/SpecialB/"
  → 文件名必须与根目录完全一致（大小写敏感）
```

**加载链 ③：近战武器预制体**
```
ItemLoader.GetWeaponControl(sign)
  → ItemPool.GetWeaponControl(sign)
    → 路径: "Assets/ToBundle/GamePlayItem/WeaponControls/" + sign + ".prefab"
    → 挂载组件: HitPart（而非 WeaponControl）
```

**加载链 ④：近战武器皮肤**
```
HitPart.InitSkin(pickItem)
  → SubpackageAssets.GetDefaultWarItemSign(itemType, skinSign)
  → AssetsLoad.GetItemSkin(skinSign, callback)
    → 路径: "Assets/ToBundle/Skin/Items/" + skinSign
  → 左手武器: skinSign + "_L" 后缀
  → 等待下载类型: WaitDownloadResType.Melee
```

**加载链 ⑤：特殊近战 SO 配置**
```
AssetsLoad.GetMicPathDataConfig<SOClothesPole>("SOClothesPole")    ← 撑衣杆
AssetsLoad.GetMicPathDataConfig<SOFlameSpear>("SOFlameSpear")      ← 火尖枪
AssetsLoad.GetSOHitPartData("Panch")                               ← 空手拳击回退
```

## 四、关键代码修改点

### 4.1 HitPart 初始化流程

```csharp
// HitPart.Init() 关键步骤
public void Init(BattleRole userRole, AbsPickItemNet item) {
    UserRole = userRole;
    // 1. 判定近战子类型
    UpdateMeleeType(item);  // → 设置 MeleeWeaponType
    // 2. 注册渲染器到角色材质管理
    SetRenderer();
    // 3. 异步加载近战武器皮肤
    InitSkin(item);         // → AssetsLoad.GetItemSkin()
    // 4. 注入武器专用组件（动态 AddComponent）
    InitMeleeWeaponSlot();  // → 根据 MeleeWeaponType 注入对应子类
}

// 武器类型判定逻辑
void UpdateMeleeType(AbsPickItemNet item) {
    switch (item.ItemSign) {
        case "Pole": MeleeType = MeleeWeaponType.Pole; break;
        case "FlameSpearRed": // fall-through
        case "FlameSpearPurple":
        case "FlameSpearGold": MeleeType = MeleeWeaponType.FlameSpear; break;
        case "HolySword": MeleeType = MeleeWeaponType.HolySword; break;
        // ... 其他 case
        default: MeleeType = MeleeWeaponType.None; break;
    }
}
```

### 4.2 近战攻击流程

```
攻击按钮按下
  → HitPart.StartAttack()
    ├── 清空 attackData / monsterAttackData 字典（防重复命中）
    ├── isCanCheckOther = true（启用碰撞检测）
    ├── 添加 Rigidbody（kinematic, 无重力）
    └── MeleeAttackSlot.StartAttack()（武器专属逻辑）

物理碰撞触发
  → HitPart.OnTriggerEnter(Collider)
    ├── 验证 isUseRigidbody && isCanCheckOther
    ├── 从 CollisionObjectManager 获取 HitType
    ├── 视线检测: HitHelper.CheckP2PBlock()（防穿墙攻击）
    └── 路由到具体命中处理器:
        ├── BodyPart → HitBodyPart()     ← 角色命中
        ├── RoleAIHit → HitRoleAI()      ← AI 命中
        ├── BuffHit → HitBuff()          ← Buff 物体命中
        ├── CarHit → HitCar()            ← 载具命中
        ├── WuLinItemHit → HitWuLinItem() ← 武林物品
        ├── Sausage2MonsterHit → HitMonster() ← 怪物命中
        └── BeastTriggerHit → HitBeastTrigger() ← 兽营触发

攻击结束
  → HitPart.EndAttack()
    ├── isCanCheckOther = false（关闭碰撞检测）
    ├── 销毁 Rigidbody
    └── MeleeAttackSlot.EndAttack()
```

### 4.3 近战伤害判定（与射击武器的关键差异）

```
射击武器: 弹道射线 → BulletManager → 服务端验证
近战武器: 物理触发器 → OnTriggerEnter → 视线检测 → 网络命令

关键差异:
├── 近战使用 Collider.OnTriggerEnter（物理碰撞），非射线
├── 通过 attackData Dictionary<int,bool> 防止同一挥击重复命中
├── HitHelper.CheckP2PBlock() 进行穿墙检查
├── Rigidbody 仅在攻击期间存在（StartAttack 添加，EndAttack 销毁）
└── 伤害通过 CmdDownBuffPointHp() 发送到服务端
```

### 4.4 MeleeAttackSlot 蓄力攻击模板

```csharp
// MeleeAttackSlot 抽象接口
public abstract class MeleeAttackSlot : MonoBehaviour {
    public virtual void Init(BattleRole userRole, HitPart hitPart);
    public virtual void Clear();
    public virtual void StartAttack();          // 轻攻击
    public virtual void EndAttack();
    public virtual void StartHeavyCharge();      // 蓄力开始
    public virtual void StartHeavyChargeSuccess(); // 蓄力成功
    public virtual void EndHeavyCharge();        // 蓄力结束
    public virtual void StartHeavyAttack();      // 重攻击
    public virtual void OnChangeFireState(int value); // 射击状态变化
    public virtual void UpdateEquip(bool isEquip);    // 装备/卸下
}

// 动画状态枚举
public enum MeleeAttackType : int {
    ChargeStart = 98,
    ChargeLoop = 99,
    ChargeAttack = 100,
}
```

|----|------|
| **现象** | 特殊模式下近战武器伤害/属性没有使用变体配置 |
| **原因** | `SpecialA/` 和 `SpecialB/` 目录下的 SOHitPart 文件名必须与根目录的完全一致。`WeasponAreaConfigHelper.GetAssetSubPath()` 根据当前模式选择子路径，如果文件名不匹配则回退到默认配置 |
| **修复** | 确保 `SpecialA/{WeaponName}.asset` 与 `Weapons/{WeaponName}.asset` 文件名完全一致（大小写敏感） |

### 踩坑 2：MeleeAttackSlot 组件未注入

| 项 | 内容 |
|----|------|
| **现象** | 特殊近战武器（撑衣杆/火尖枪）没有触发特殊攻击机制 |
| **原因** | `MeleeAttackSlot` 是**动态 AddComponent** 注入的，不是预挂载。`InitMeleeWeaponSlot()` 仅在 `AutoId != -1` 时执行。如果 `UpdateMeleeType()` 未正确识别武器类型，则 MeleeWeaponType 为 None，不会注入任何子类组件 |
| **修复** | 确认新武器在 `UpdateMeleeType()` 的 switch-case 中有对应分支；检查 `PickItemData.txt` 中的 ItemSign 与 case 值一致 |

### 踩坑 3：近战攻击穿墙命中

| 项 | 内容 |
|----|------|
| **现象** | 近战武器可以穿墙打到背后的敌人 |
| **原因** | `OnTriggerEnter` 检测到碰撞后会调用 `HitHelper.CheckP2PBlock()` 进行穿墙检查，但如果碰撞体的 Layer 设置不正确，射线检测可能跳过墙壁层 |
| **修复** | 确认近战武器碰撞体和目标碰撞体的 Layer 设置正确；检查 `CheckP2PBlock` 的 LayerMask 配置 |

### 踩坑 4：近战武器耐久系统不生效

| 项 | 内容 |
|----|------|
| **现象** | SOHitPart.EquipHp 设置了耐久值但武器不会自动消失 |
| **原因** | `EquipHp` 在 SOHitPart 中定义但**基类 HitPart 不会自动扣减耐久**——需要武器专用子类（MeleeAttackSlot）自行实现耐久扣减逻辑 |
| **修复** | 如需耐久系统，在对应 MeleeAttackSlot 子类的攻击逻辑中手动扣减 EquipHp |

### 踩坑 5：Rigidbody 生命周期异常

| 项 | 内容 |
|----|------|
| **现象** | 近战武器攻击后出现物理抖动或碰撞异常 |
| **原因** | Rigidbody 在 `StartAttack()` 中添加（kinematic, 无重力），在 `EndAttack()` 中销毁。如果攻击被中断（角色死亡/切换武器）而未调用 `EndAttack()`，Rigidbody 可能残留导致物理异常。WolfParty 模式特殊处理：使用对象池而非销毁 |
| **修复** | 确保所有中断路径都调用了 `EndAttack(true)`；检查 `Clear()` 方法中是否包含 Rigidbody 清理 |
