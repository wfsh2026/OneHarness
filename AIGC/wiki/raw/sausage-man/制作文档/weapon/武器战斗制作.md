# 1 代架构武器/战斗制作规范

> **适用范围**：基于 `SOWeaponControl` / `WeaponControl` 的 1 代武器系统开发（射击武器 + 近战武器 + 弹射武器）
> **不适用**：2 代武器系统（`Biubiubiu2/GamePlay/Weapon/` 下的枪械组件）
> **参考实现**：AK12（步枪），路径 → SO: `ToBundle/ScriptableObject/Items/Weapons/AK12.asset`，预制体: `ToBundle/GamePlayItem/WeaponControls/AK12.prefab`

**占位符说明**：

| 占位符 | 含义 | 示例 |
|--------|------|------|
| `{WeaponName}` | 武器名称（大驼峰） | `AK12`、`Barrett`、`FlyKnife` |
| `{WeaponSign}` | 武器标识符（PickItemData 主键） | `AK12`、`Pan`、`Bow` |
| `{ItemType}` | 物品类型枚举值 | `17`(手枪)、`19`(突击步枪)、`20`(霰弹枪) |

---

## 一、架构概述

### 1.1 武器体系分类

1 代武器系统通过 SO 数据驱动，所有武器共享同一套 `WeaponControl` 运行时组件，区别仅在于 SO 配置和预制体结构。

| 维度 | 射击武器 | 近战武器 | 弹射武器 | 特殊武器 |
|------|---------|---------|---------|---------|
| **SO 类型** | `SOWeaponControl` | `SOHitPart` | `SOElasticWeaponControl` | `SOWeaponControl` + 专用控制器 |
| **预制体组件** | `WeaponControl` | `HitPart` | `ElasticWeapon` | `WeaponControl` + `HiddenWeaponControl` 等 |
| **SO 数量** | 175 个 | 62 个（含 SpecialA/B 变体） | ~5 个 | ~10 个 |
| **预制体路径** | `GamePlayItem/WeaponControls/` | `GamePlayItem/WeaponControls/` | `Items/{Type}/` | `GamePlayItem/WeaponControls/` |
| **典型武器** | AK12/M416/AWM/S686 | Pan/Bat/Fork/HolySword | Bow/FlyKnife | Gourd/ZiZiBeng/FireBallLauncher |
| **火力类型** | Auto/Single/Dartle | 无（动画驱动） | 蓄力投掷 | 各有专属状态机 |

**武器类型枚举**（`ItemData.ItemType` / `WeaponType`）：

| 枚举值 | 类型 | 说明 |
|--------|------|------|
| 17 | Pistol | 手枪（P92/P18C/P1911/R1895） |
| 18 | SubmachineGun | 冲锋枪（MicroUZI/PP19/MP5/EnergySmg） |
| 19 | Assault | 突击步枪（AK12/M416/QBZ/Groza） |
| 20 | ShotGun | 霰弹枪（S686/S12K/KSG/EnergySG） |
| 21 | Sniper | 狙击枪（AWM/Kar98/Barrett/M24） |
| 22 | ElasticWeapon | 弹射武器（Bow/FlyKnife） |
| 23 | DesignatedMarksmanRifle | 射手步枪（Mini14/MK14/QBU191） |
| 24 | LightMachineGun | 机枪（DP28/M249/HK13/Minigun） |
| 99 | SpecialWeapons | 特殊武器（RPG/RailGun/ParticleCannon） |

### 1.3 预制体与资源加载

**加载链 ①：武器 SO 配置**
```
ConfigLoader.GetSOWeaponData(weaponSign)
  → 路径: "Assets/ToBundle/ScriptableObject/Items/" + subPath + weaponSign + ".asset"
  → subPath 由 WeasponAreaConfigHelper.GetAssetSubPath() 计算
  → 缓存: SOWeaponControlDic[weaponSign]
  → 类型: SOWeaponControl / SOHitPart / SOElasticWeaponControl
```

**加载链 ②：武器预制体**
```
ItemLoader.GetWeaponControl(sign)
  → ItemPool.GetWeaponControl(sign)
    → 路径: "Assets/ToBundle/GamePlayItem/WeaponControls/" + sign + ".prefab"
    → 对象池缓存，复用实例
  → 返回 WeaponControl 组件
```

**加载链 ③：武器皮肤**
```
WeaponControl.InitSkin(pickItem)
  → AssetsLoad.GetSkinItemAsync(skinSign)
    → 路径: "Assets/ToBundle/Skin/Items/" + skinSign（4,691 文件）
    → 异步加载，完成后挂载到 WeaponSkinBox
```

**加载链 ④：地图投放配置**
```
ConfigLoader.GetLevelItemCreate(levelName)
  → 路径: "Assets/ToBundle/ScriptableObject/LevelData/{levelName}/CreateItem.asset"
  → 类型: SOWarCreateItem
  → 返回: WarCreateItem[] (按等级分组的 M_ItemBox 数组)

ConfigLoader.GetLevelDesignItemPoint(levelName)
  → 路径: "Assets/ToBundle/ScriptableObject/LevelData/{levelName}/ItemPoint.asset"
  → 类型: SOItemPoint
  → 返回: WeaponObj[] (坐标数组, pos + isHigh)
```

**加载链 ⑤：配置表（txt → Config 类）**
```
ConfigManager.GetConfigRawDatas("PickItemData")
  → 路径: "Assets/ToBundle/Config/Txt/PickItemData.txt"
  → 解析: TSV 格式（跳过前 3 行表头）
  → 存储: Dictionary<string, PickItemDataConfig>
  → 访问: PickItemDataConfig.Get(itemSign)
```

### 1.4 禁止修改的文件

| 文件 | 原因 |
|------|------|
| `WeaponControl.cs` | 所有武器共享的核心控制器，改动影响全部 96 个武器预制体 |
| `BattleRoleFireComponent.cs` | 开火状态机，改动影响所有角色射击行为 |
| `BattleRoleWeaponComponent.cs` | 武器装备逻辑，改动影响切换/装卸全流程 |
| `BulletManager.cs` | 子弹物理系统，改动影响所有弹道和伤害计算 |
| `ItemPool.cs` | 对象池核心，改动可能导致内存泄漏或实例复用错误 |
| `NetworkServer_RoleWeapon.cs` | 网络同步层，改动需与所有客户端版本兼容 |
| `ConfigLoader.cs` | 全局配置加载中枢，影响所有系统 |

### 3.3 SOWarCreateItem（地图投放配置）

> 路径：`Assets/ToBundle/ScriptableObject/LevelData/{MapName}/CreateItem.asset`
> 创建菜单：`War/CreateObj/LevelCreateItem`
> 每张地图一个

```
SOWarCreateItem
└── levelCreateItem : WarCreateItem[]       ← 按等级分组
    └── WarCreateItem
        ├── info : string                   ← 说明文字
        ├── level : int                     ← 物品等级
```

### 4.5 伤害计算链路

```csharp
// 伤害 = 基础伤害 × 距离衰减 × 爆头加成 × 护甲加成
float damage = SOWeaponControl.BulletPower;

// 距离衰减
foreach (var dp in SOWeaponControl.DistancePower) {
    if (distance >= dp.MinDistance && distance < dp.MaxDistance) {
        damage *= dp.DistancePower;
        break;
    }
}

// 爆头加成
if (isHeadshot) damage *= SOWeaponControl.HeadDiffRatio;

// 护甲减伤
if (hasArmor) damage *= SOWeaponControl.ArmoredVestsHurtDiffRatio;

// 载具加成
if (isVehicle) damage *= SOWeaponControl.BulletAttackVehiclePower;
```

## 五、常见问题与踩坑记录

### 踩坑 1：武器预制体拾取后无模型

| 项 | 内容 |
|----|------|
| **现象** | 拾取武器后角色手中无模型，但可以正常射击 |
| **原因** | `WeaponControlSkin.WeaponBox` 引用为空，或皮肤异步加载路径错误。`InitSkin()` 通过 `AssetsLoad.GetSkinItemAsync()` 异步加载，如果 `Skin/Items/` 下没有对应皮肤目录则静默失败 |
| **修复** | 确认 `ToBundle/Skin/Items/{WeaponSign}/` 目录存在且包含默认皮肤预制体；检查 `PickItemData.txt` 中的 `ItemSign` 与皮肤目录名称一致 |

### 踩坑 2：投放概率不生效，武器不在地图出现

| 项 | 内容 |
|----|------|
| **现象** | 在 `CreateItem.asset` 中配置了新武器但战斗中从未出现 |
| **原因** | 概率系统使用 `Random.Range(0, 10000)`，`Ratio` 字段需要是 0-1 范围的浮点数（内部乘 10000）。如果 `Ratio` 设为 0 或 `M_ItemBox.ItemList` 为空数组则不会产出。另外需检查 `IsGameFuncOpen` 功能开关是否关闭了该武器 |
| **修复** | 确保 `M_Item.Ratio > 0`，确保 `M_ItemBox.Ratio > 0`，确保 `M_Item.CreateMainItem` 对应有效的 `PickItemData.ItemSign` |

### 踩坑 3：配件装上但无效果

| 项 | 内容 |
|----|------|
| **现象** | 装上瞄具/握把后射击手感无变化 |
| **原因** | `SOWeaponControl` 的配件兼容数组（`upperRails[]` 等）必须包含该配件的 `SOWepEquipData` ID。如果数组中不包含，`WeaponControl.AddEquip()` 会静默忽略。此外 `SOWepEquipDataConfig` 的修正倍率默认为 1.0（无效果），需要设为非 1.0 才有实际效果 |
| **修复** | 在 SO 的配件兼容数组中添加配件 ID；检查 `SOWepEquipData.txt` 中对应条目的 `RecoilRatio`/`ShootRangeRatio` 等字段是否非 1.0 |

### 踩坑 4：近战武器 SpecialA/B 变体未加载

| 项 | 内容 |
|----|------|
| **现象** | 特殊模式下近战武器伤害/属性没有使用变体配置 |
| **原因** | `SpecialA/` 和 `SpecialB/` 目录下的 SOHitPart 文件名必须与根目录的完全一致。`WeasponAreaConfigHelper.GetAssetSubPath()` 根据当前模式选择子路径，如果文件名不匹配则回退到默认配置 |
| **修复** | 确保 `SpecialA/{WeaponName}.asset` 与 `Weapons/{WeaponName}.asset` 文件名完全一致（大小写敏感） |

### 踩坑 5：双持武器（WeaponControlMulti）开火特效只显示一侧

| 项 | 内容 |
|----|------|
| **现象** | 双持武器射击时只有右手显示开火特效 |
| **原因** | `WeaponControlMulti` 继承 `WeaponControl` 并重写 `ShowFireEffect()`，需要同时设置 `leftSlots` 和 `rightSlots` 的 Transform 引用。如果左手皮肤 `WeaponSkinMulti` 的 FireBox 未配置则跳过 |
| **修复** | 在双持武器预制体中确保 left/right 两个 Skin 子物体都有 `FireBox` Transform，并在 `WeaponControlMulti` 中正确引用 |
