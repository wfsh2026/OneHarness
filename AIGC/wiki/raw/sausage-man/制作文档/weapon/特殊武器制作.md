# 1 代架构特殊武器制作规范

> **适用范围**：基于 1 代架构的弹射武器（弓箭/飞刀）、暗器（葫芦/水晶球/雷符）、魔法武器（滋滋崩/火球发射器/加特林旋转炮管）等非标准射击/近战武器
> **不适用**：射击武器（→ `射击武器制作.md`）、近战武器（→ `近战武器制作.md`）、2 代武器系统（`Biubiubiu2/`）
> **参考实现**：弹射弓箭 `Bow.asset`，暗器葫芦 `Gourd.asset`，滋滋崩 `ZiZiBeng` 系列

**占位符说明**：

| 占位符 | 含义 | 示例 |
|--------|------|------|
| `{WeaponName}` | 武器名称（大驼峰） | `Bow`、`Gourd`、`ZiZiBeng` |
| `{WeaponSign}` | 武器标识符（PickItemData 主键） | `Bow`、`Gourd`、`FlyKnife` |
| `{BulletName}` | 弹体名称 | `12Gauge`、`HiddenBullet` |

## 一、架构概述

### 1.1 特殊武器分类

特殊武器是介于射击武器和近战武器之间的武器类型，它们**复用 SOWeaponControl** 作为基础配置，但拥有独立的攻击控制器和独特的战斗机制。

| 子类型 | ItemType | 代表武器 | 核心特征 | 控制器 |
|--------|----------|---------|---------|--------|
| **弹射武器** | 22 (Elastic) | Bow(弓箭), FlyKnife(飞刀) | 蓄力→弹射抛物线弹道 | ElasticWeapon + ElasticBulletControl |
| **暗器** | — (SOWeaponControl) | Gourd(葫芦), Crystalball(水晶球), Thundetalisman(雷符) | 蓄力/直射 + Buff 伤害 | HiddenWeaponControl |
| **射线武器** | — (SOWeaponControl) | ZiZiBeng(滋滋崩系列) | 持续射线 + 碎片系统 | ZiZiBengControl |
| **榴弹发射器** | — (SOWeaponControl) | FireBallLauncher(火球发射器) | 单发大伤害 + CD | FireBallLauncherControl |
| **魔法/传说武器** | — (SOWeaponControl) | 各种特殊武器 | BulletPower:0 + Buff 伤害 | 标准 WeaponControl |

> **重要**：除弹射武器（ItemType=22）外，其他特殊武器使用标准 SOWeaponControl，通过 WeaponEnum 和挂载的控制器脚本区分行为。

### 1.2 核心类依赖

```
[弹射武器系统]
SOElasticWeaponControl : ScriptableObject  ← 弹射武器专用 SO
ElasticWeapon : MonoBehaviour              ← 弹射武器控制器
├── Init() / Clear()                       ← 生命周期
├── 蓄力系统: DrawShootRange (Max→Min 递减)
├── 速度插值: BulletMinSpeed → BulletMaxSpeed
└── onDraw / onShoot / canceDraw / putBack ← 动画回调
ElasticWeaponAnim : MonoBehaviour          ← 弹射动画控制
ElasticBulletControl : MonoBehaviour       ← 弹射弹体控制
├── 抛物线弹道计算
├── PenetrationNum 穿透机制
└── AirDamp 空气阻力

[暗器系统]
HiddenWeaponControl : MonoBehaviour        ← 暗器控制器（24.7KB 核心）
├── 状态机: None → Charging → Throw
├── OperateMode: ChargeShoot / DirectShoot
├── hw* 前缀配置字段（12+ 个）
├── InitSlotWeapon() / LoadSlotWeaponModel()  ← 武器模型管理
├── StartThrowProcess() / DoThrowAction()    ← 投掷流程
└── ClientGourdAdsorbFeatureManager         ← 葫芦吸附特殊功能
HiddenWeaponDecalConfig : ScriptableObject  ← 暗器贴花配置

[射线武器]
ZiZiBengControl : MonoBehaviour            ← 射线武器控制器
├── 两阶段射击: FirstFire → SecondFire
├── bulletDamageList (碎片伤害列表)
├── chipBullet / chipFront / chipParts     ← 碎片系统
├── Physics.RaycastNonAlloc (最多 10 目标)
└── coolDownTime 冷却系统
ZiZiBengWeapon : MonoBehaviour             ← 射线 VFX 控制
├── Shader _ChargingTime 动画
└── 射线视觉效果

[榴弹发射器]
FireBallLauncherControl : MonoBehaviour    ← 榴弹控制器
├── AttackCD (5 秒冷却)
├── 单发弹药检测
└── 标准射击流程

[辅助控制器]
WeaponBarrelRotationControl : MonoBehaviour ← 加特林旋转炮管 VFX
├── MoveTime / startMoveTime / endColor
└── 炮管旋转视觉效果

[配置层]
SOElasticWeaponControl : ScriptableObject  ← 弹射 SO（专用）
SOWeaponControl : ScriptableObject         ← 暗器/射线/榴弹共用（hw* 字段）
HiddenWeaponDecalConfig : ScriptableObject ← 暗器贴花
```

### 1.3 预制体与资源加载

**加载链 ①：弹射武器 SO 配置**
```
ConfigLoader.GetSOWeaponData(weaponSign)
  → SOElasticWeaponControl 类型（非 SOWeaponControl）
  → 路径: "Assets/ToBundle/ScriptableObject/Items/Weapons/" + weaponSign + ".asset"
  → 包含弹射专用字段: MaxShootRange, DrawShootDamp, BulletMaxSpeed 等
```

**加载链 ②：暗器 SO 配置**
```
ConfigLoader.GetSOWeaponData(weaponSign)
  → SOWeaponControl 类型 + hw* 前缀字段
  → 路径: "Assets/ToBundle/ScriptableObject/Items/Weapons/" + weaponSign + ".asset"
  → hw* 字段在 SOWeaponControl 中定义但仅暗器使用
```

**加载链 ③：弹射弹体对象池**
```
BulletManager 弹体管理
  → AssetsLoad.GetElasticBulletControl(bulletName)
  → 路径: "Assets/ToBundle/GamePlayItem/Bullet/" + bulletName + ".prefab"
  → 组件: ElasticBulletControl
  → 缓存: ElasticBulletPool
```

**加载链 ④：暗器武器槽模型**
```
HiddenWeaponControl.LoadSlotWeaponModel()
  → ItemPool.GetWeaponControl(slotWeaponSign)
  → 挂载到角色武器挂点
  → 投掷后根据 hwIsThrowHideModel 决定是否隐藏
```

**加载链 ⑤：暗器贴花配置**
```
HiddenWeaponDecalConfig（仅存在一份 SO）
  → 通过 AssetsLoad 加载
  → 控制暗器命中表面的贴花效果
```

**加载链 ⑥：特效对象池**
```
EffectPool.Get(effectSign)
  → 路径: "Assets/ToBundle/Effect/" + effectSign + ".prefab"
  → 用于: 枪口特效(hwMuzzleEffectSign)、命中特效、射线特效
```

| 资源类型 | 路径 | 典型文件 | 加载器 |
|---------|------|---------|--------|
| 弹射 SO | `ToBundle/ScriptableObject/Items/Weapons/` | `Bow.asset`, `FlyKnife.asset` | ConfigLoader |
| 暗器 SO | `ToBundle/ScriptableObject/Items/Weapons/` | `Gourd.asset`, `Crystalball.asset` | ConfigLoader |
| 弹射弹体 | `ToBundle/GamePlayItem/Bullet/` | `12Gauge.prefab` (弹射复用) | BulletManager |
| 暗器弹体 | `ToBundle/GamePlayItem/Bullet/` | `HiddenBullet.prefab` | BulletManager |
| 武器预制体 | `ToBundle/GamePlayItem/WeaponControls/` | `{WeaponName}.prefab` | ItemPool |
| 特效资源 | `ToBundle/Effect/` | 枪口/命中/射线特效 | EffectPool |

### 1.4 禁止修改的文件

| 文件 | 原因 |
|------|------|
| `SOWeaponControl.cs` | 所有武器类型共用的 SO 基类，hw* 字段影响所有暗器 |
| `BulletManager.cs` | 弹体池管理核心，改动影响所有射击/弹射武器 |
| `WeaponControl.cs` | 射击武器核心控制器，特殊武器可能间接引用 |
| `ConfigLoader.cs` | 全局配置加载中枢 |
| `ItemPool.cs` | 对象池核心 |
| `BattleRoleWeaponComponent.cs` | 武器装备逻辑 |

## 三、配置文件详解

### 3.1 SOElasticWeaponControl（弹射武器专用 SO）

> 路径：`Assets/ToBundle/ScriptableObject/Items/Weapons/{WeaponName}.asset`
> 类型：SOElasticWeaponControl（**非** SOWeaponControl）

#### 弹射核心字段

| 字段 | 类型 | 说明 | 默认值/示例 |
|------|------|------|------------|
| `PI_Weapon` | string | 武器预制体标识 | `"Bow"` |
| `PI_Bullet` | string | 弹体预制体标识 | `"12Gauge"` |
| `FireDeployTime` | float | 开火准备时间 | — |
| `BulletPower` | float | 弹体基础伤害 | — |
| `MaxShootRange` | float | 最大射程（蓄力开始） | — |
| `MinShootRange` | float | 最小射程（蓄力结束） | — |
| `DrawShootDeployTime` | float | 蓄力部署时间 | `0.4s` |
| `DownShootRange` | float | 下蹲射程修正 | — |
| `DrawShootDamp` | float | 蓄力阻尼系数（数值越大蓄力越慢） | `30` |
| `BulletMaxSpeed` | float | 弹体最大速度（满蓄力） | `100` |
| `BulletMinSpeed` | float | 弹体最小速度（零蓄力） | `50` |
| `PenetrationNum` | int | 弹体穿透数量 | `1` |
| `AirDamp` | float | 弹体空气阻力系数 | `1.0` |
| `WeaponLength` | float | 武器长度（用于计算偏移） | `0.5` |
| `HeadDiffRatio` | float | 爆头伤害倍率差异 | — |
| `ArmoredVestsHurtDiffRatio` | float | 护甲减伤比例差异 | — |

#### 蓄力公式

```
当前射程 = MaxShootRange - (蓄力时间 × DrawShootDamp)
当前射程 = Max(当前射程, MinShootRange)

蓄力比例 = (MaxShootRange - 当前射程) / (MaxShootRange - MinShootRange)
弹速 = Lerp(BulletMinSpeed, BulletMaxSpeed, 蓄力比例)
```

### 3.2 暗器 hw* 字段（SOWeaponControl 中定义）

> 暗器使用标准 SOWeaponControl，但通过 `hw*` 前缀字段扩展暗器专用配置。

| 字段 | 类型 | 说明 |
|------|------|------|
| `hwFirePoint` | Transform/string | 投掷原点（角色身上的挂点） |
| `hwShootDelayTime` | float | 射击延迟时间（>0 为蓄力模式，=0 为直射模式） |
| `hwShowModelTime` | float | 投掷后模型显示时机 |
| `hwThrowCd` | float | 投掷冷却时间 |
| `hwAutoThrowInterval` | float | 自动投掷间隔 |
| `hwIsThrowHideModel` | bool | 投掷时是否隐藏武器模型 |
| `hwFullAttackTime` | float | 满蓄力时间 |
| `hwRandomAttackAnimCount` | int | 随机攻击动画数量 |
| `hwIsHaveWeaponModel` | bool | 是否有武器模型 |
| `hwMuzzleEffectSign` | string | 枪口/投掷特效标识 |
| `hwEnterChargeTime` | float | 进入蓄力状态时间 |
| `hwChargeAnimTime` | float | 蓄力动画时间 |

#### 暗器操作模式

```
HiddenWeaponControl.OperateMode:
  ChargeShoot  → hwShootDelayTime > 0
    → 按住蓄力 → 释放投掷
    → 状态机: None → Charging → Throw → None

  DirectShoot  → hwShootDelayTime == 0
    → 点击直接投掷
    → 状态机: None → Throw → None
```

### 3.3 ZiZiBeng 射线武器配置

> ZiZiBeng 使用标准 SOWeaponControl，额外行为由 ZiZiBengControl 脚本参数控制。

|------|------|------|--------|
| `coolDownTime` | ZiZiBengControl | 冷却时间 | `1.0s` |
| `bulletDamageList` | ZiZiBengControl | 碎片伤害列表 | — |
| `chipBullet` | ZiZiBengControl | 碎片弹体预制体 | — |
| `chipFront` | ZiZiBengControl | 碎片前端 Transform | — |
| `chipParts` | ZiZiBengControl | 碎片 Transform 数组 | — |
| `_ChargingTime` | Shader 属性 | 蓄力时间（VFX 动画） | 通过 ZiZiBengWeapon 控制 |

### 3.4 FireBallLauncher 榴弹发射器配置

| 字段 | 位置 | 说明 | 默认值 |
|------|------|------|--------|
| `AttackCD` | FireBallLauncherControl | 攻击冷却 | `5.0s` |
| 弹药 | SOWeaponControl | 使用标准弹药系统 | 单发 |
| BulletPower | SOWeaponControl | 弹体伤害 | 高伤害 |

### 3.5 特殊武器 Asset 文件示例

| 武器 | Asset 类型 | 弹体 | BulletPower | 伤害方式 |
|------|-----------|------|-------------|---------|
| `Bow.asset` | SOWeaponControl | `12Gauge` | >0 | 弹体直接伤害 |
| `FlyKnife.asset` | SOWeaponControl | — | >0 | 弹体直接伤害 |

> **关键规律**：暗器 `BulletPower` 通常为 0，伤害通过 `IsUseBulletHitBuff=true` + `attackBuff` 实现。

## 四、关键代码修改点

### 4.1 弹射武器攻击流程

```
玩家按住攻击键
  → ElasticWeapon.onDraw()        ← 开始蓄力
    ├── 播放蓄力动画
    └── 开始计算射程衰减

蓄力中每帧更新
  → 当前射程 = Max(MaxShootRange - 蓄力时间 × DrawShootDamp, MinShootRange)
  → 蓄力比例 = (Max - 当前) / (Max - Min)
  → UI 显示蓄力进度

玩家释放攻击键
  → ElasticWeapon.onShoot()       ← 发射弹体
    ├── 计算弹速: Lerp(BulletMinSpeed, BulletMaxSpeed, 蓄力比例)
    ├── 生成 ElasticBulletControl 弹体
    ├── 设置抛物线初速度和角度
    └── 弹体飞行中受 AirDamp 空气阻力

弹体命中目标
  → ElasticBulletControl.OnCollision()
    ├── 计算伤害 (BulletPower)
    ├── 穿透检测: PenetrationNum--
    ├── if PenetrationNum > 0 → 继续飞行
    └── else → 弹体销毁

取消蓄力
  → ElasticWeapon.canceDraw()     ← 未发射直接取消
```

### 4.2 暗器攻击流程

```
蓄力模式 (ChargeShoot):
  玩家按住攻击键
    → HiddenWeaponControl.StartCharging()
      ├── 状态: None → Charging
      ├── 播放蓄力动画 (hwChargeAnimTime)
      └── 计时: hwEnterChargeTime → 进入蓄力状态

  蓄力完成 / 玩家释放
    → HiddenWeaponControl.StartThrowProcess()
      ├── 状态: Charging → Throw
      ├── hwMuzzleEffectSign → 特效播放
      └── DoThrowAction()
        ├── 生成弹体 (HiddenBullet 或自定义)
        ├── 设置弹体方向和速度
        └── 冷却: hwThrowCd

直射模式 (DirectShoot):
  玩家点击攻击键
    → HiddenWeaponControl.DoThrowAction()
      ├── 状态: None → Throw → None
      ├── 随机攻击动画 (hwRandomAttackAnimCount)
      └── 弹体生成 + 冷却

葫芦 (Gourd) 特殊处理:
  → ClientGourdAdsorbFeatureManager
    ├── 吸附攻击模式
    ├── 将目标吸向自身
    └── 伤害通过 Buff 系统执行
```

### 4.3 ZiZiBeng 射线攻击流程

```
两阶段射击:

第一阶段 (FirstFire):
  → ZiZiBengControl.StartFire()
    ├── 发射射线 (Physics.RaycastNonAlloc)
    ├── 最多检测 10 个目标
    ├── 对第一个目标施加伤害
    └── 激活 ZiZiBengWeapon VFX
      ├── Shader _ChargingTime 动画
      └── 射线特效显示

第二阶段 (SecondFire):
  → 持续射击 (按住攻击键)
    ├── 碎片系统: chipBullet / chipParts
    ├── bulletDamageList 伤害递增
    ├── 对射线路径上所有目标持续伤害
    └── 弹药持续消耗

停止射击:
  → ZiZiBengControl.StopFire()
    ├── coolDownTime 冷却 (1.0s)
    ├── 关闭射线特效
    └── 重置碎片计数
```

### 4.4 各类特殊武器攻击机制对比

| 维度 | 弹射武器 | 暗器 | 射线武器 | 榴弹发射器 |
|------|---------|------|---------|-----------|
| **输入** | 按住蓄力→释放 | 按住/点击 | 按住持续 | 点击单发 |
| **弹道** | 抛物线 | 直线/弧线 | 射线(Raycast) | 弹道(弹体) |
| **伤害源** | 弹体碰撞 | Buff 系统 | 射线检测 | 弹体爆炸 |
| **穿透** | PenetrationNum | 无 | 最多 10 目标 | 无(AOE) |
| **CD** | 蓄力时间 | hwThrowCd | coolDownTime | AttackCD(5s) |
| **弹药** | 标准弹药 | 通常无限 | 标准弹药 | 单发弹药 |
| **专用 SO** | SOElasticWeaponControl | SOWeaponControl(hw*) | SOWeaponControl | SOWeaponControl |

## 五、常见问题与踩坑记录

### 踩坑 1：弹射武器蓄力手感不自然

| 项 | 内容 |
|----|------|
| **现象** | 弹射武器蓄力时射程变化不够线性，松手后弹速不匹配 |
| **原因** | `DrawShootDamp` 参数控制射程衰减速度。当 `DrawShootDamp=30`（默认值）时，从 `MaxShootRange` 到 `MinShootRange` 的衰减可能非常快。弹速通过 `Lerp(BulletMinSpeed, BulletMaxSpeed, 蓄力比例)` 计算，如果 Min/Max 差距过大会导致手感突变 |
| **修复** | 1) 适当降低 `DrawShootDamp`（如 10-20）使蓄力更平滑；2) 缩小 `BulletMinSpeed/BulletMaxSpeed` 差距；3) 确保 `MaxShootRange - MinShootRange` 的差值合理 |

### 踩坑 2：暗器 BulletPower:0 但不造成伤害

| 项 | 内容 |
|----|------|
| **现象** | 暗器命中目标但无伤害效果 |
| **原因** | 暗器通常 `BulletPower=0`，伤害通过 `IsUseBulletHitBuff=true` + `attackBuff` 实现。如果 `IsUseBulletHitBuff` 未设为 true 或 `attackBuff` SO 引用为空，则不会造成任何伤害 |
| **修复** | 确认 SOWeaponControl 中 `IsUseBulletHitBuff=true` 且 `attackBuff` 引用有效的 BuffSOBase 资产 |

### 踩坑 3：ZiZiBeng 射线最多 10 目标限制

| 项 | 内容 |
|----|------|
| **现象** | 射线武器在密集目标场景中遗漏部分目标 |
| **原因** | `ZiZiBengControl` 使用 `Physics.RaycastNonAlloc(ray, hits, maxDistance)` 进行射线检测，`hits` 数组长度硬编码为 10。当射线路径上超过 10 个碰撞体时，多余目标被忽略 |
| **修复** | 这是设计限制而非 Bug。如确需突破限制，需修改 `ZiZiBengControl` 中 `hits` 数组大小并增加服务端验证（需审批） |

### 踩坑 4：葫芦吸附攻击内存泄漏

| 项 | 内容 |
|----|------|
| **现象** | 葫芦武器长时间使用后帧率下降 |
| **原因** | `ClientGourdAdsorbFeatureManager` 管理吸附目标列表，如果目标被销毁但引用未清理，可能产生空引用残留。多次切换武器可能导致 Manager 实例叠加 |
| **修复** | 确保在武器切换/角色死亡时调用 `Clear()`；检查 `OnDestroy` 是否清理了所有订阅的事件 |

### 踩坑 5：弹射弹体穿透后伤害异常

| 项 | 内容 |
|----|------|
| **现象** | 弹射弹体穿透第一个目标后对后续目标伤害不正确 |
| **原因** | `ElasticBulletControl` 的 `PenetrationNum` 每次碰撞递减，但弹体速度受 `AirDamp` 影响会持续衰减。穿透后弹体可能因速度过低导致弹道偏移，或因 `AirDamp=1.0`（默认值）导致减速过快 |
| **修复** | 1) 降低 `AirDamp` 使弹体保持更高速度；2) 如果穿透需保持恒定伤害，需在 `ElasticBulletControl` 中跳过穿透后的速度衰减 |
