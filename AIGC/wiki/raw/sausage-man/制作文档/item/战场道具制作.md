# 1 代架构战场活动道具制作规范

> **适用范围**：`ItemType.ActivityItems(738197504)` 下所有战场活动道具 — 粽子/红包/鞭炮/灯笼/KFC/仙女棒等节日/活动限定道具
> **不适用**：消耗品(Consumables) → 归消耗品制作；投掷物(Bomb) → 归投掷物制作；恶作具(JokerItem) → 归 [[buff-joker-statue]]
> **参考实现**：ActivityZongZi（最简活动道具）、ActivityFairyStick（带独立 Buff 的活动道具）

---

## 一、架构概述

### 1.1 核心类依赖

```
PickItemNet (MonoBehaviour)  ← 所有拾取物的基类
  │  路径: Assets/Script/GamePlay/Host/Item/
  │  继承链: AbsPickItemNet → PickItemNet (C/S 一体)
  │  职责: 道具生成、拾取判定、网络同步、回收
  │
  ├── itemServer : AbsPickItemNetServer  ← 服务端逻辑
  │     拾取判定、背包检查、广播
  │
  ├── itemClient : AbsPickItemNetClient  ← 客户端逻辑
  │     模型显示、UI 提示、拾取动画
  │
  ├── ItemData.cs (常量定义)
  │     int 类型常量 (17-99):
  │       Consumables=17, SpecialWeapon=18, Equipment=19, Vehicle=20,
  │       Bomb=21, JokerItem=99, ...
  │     long 类型常量 (特殊道具):
  │       IdCard, HiddenWeapon, GoldItem, SteelHelmet, ...
  │     ItemType 枚举 (分组):
  │       ActivityItems = 738197504 ← 活动道具类型标识
  │
  ├── PickItemDataConfig.cs (战场道具主配置)
  │     路径: Assets/ToBundle/Config/Txt/PickItemData.txt
  │     49 个字段 (Tab 分隔)
  │
  ├── SOItemDataConfig.cs (ScriptableObject 辅助配置)
  │     路径: Assets/ToBundle/ScriptableObject/Item/{ItemSign}/
  │     16 个字段
  │
  ├── ActivityItemSkinConfig.cs (活动道具皮肤映射)
  │     路径: Assets/ToBundle/Config/Txt/ActivityItemSkin.txt
  │     3 个字段: Sign → WarSign → PrefabName
  │
  └── ItemPool.cs (对象池)
        15+ 池字典，按道具类型分类管理
        资源路径: Assets/ToBundle/GamePlayItem/PickItems/
```

### 1.2 道具类型总览（ItemData.cs 常量）

| 类型值 | 名称 | 说明 | 独立控制器 |
|--------|------|------|-----------|
| 17 | Consumables | 消耗品（药品/饮料） | ✅ MedicineInfo |
| 18 | SpecialWeapon | 特殊武器 | ✅ |
| 19 | Equipment | 装备（护甲/头盔） | ✅ |
| 20 | Vehicle | 载具道具 | ✅ |
| 21 | Bomb | 投掷物（手雷/闪光） | ✅ |
| 22-30 | 武器弹药 | 各口径弹药 | ❌ |
| 31-50 | 武器类 | 各类型枪械 | ✅ WeaponController |
| 99 | JokerItem | 恶作具 | ✅ |
| **738197504** | **ActivityItems** | **活动道具** ← 本文范围 | **❌ 无独立控制器** |

### 1.3 活动道具核心机制

活动道具是最轻量的道具类型：**无独立控制器代码**，所有道具共用 PickItemNet 框架。差异仅在三个层面：

1. **Prefab 模型** — `Activity*.prefab` 放在 `PickItems/` 目录
2. **配置映射** — `ActivityItemSkin.txt` 建立 Sign→WarSign→PrefabName 映射
3. **Buff 效果** — 通过已有 Buff SO 赋予拾取效果（可选）

### 1.4 拾取流程（Client + Server）

```
玩家靠近道具 → BattleRolePickItemComponent 检测
  │
  ├── [Client] 显示拾取 UI 提示
  │     → MyCheckPickItem.CheckPickItem() 检测范围内拾取物
  │     → 显示 "按E拾取" / 自动拾取
  │
  ├── [Client] 发送拾取请求
  │     → gameWorld.Send(CmdPickItem { itemId, ... })
  │
  ├── [Server] 拾取判定
  │     → itemServer.HasPick(role) 检查:
  │       ├── 背包空间检查 (BackpackManager)
  │       ├── 道具类型检查 (是否可拾取)
  │       ├── 距离检查 (是否在拾取范围内)
  │       └── 活动道具分支: ActivityItems → 直接拾取
  │
  ├── [Server] 广播结果
  │     → SendRpc/TargetRpc 通知拾取结果
  │
  └── [Client] 更新显示
        → 道具模型隐藏/销毁
        → 背包 UI 更新
        → 拾取音效播放 (PickAudio 字段)
```

### 1.6 禁止修改的文件

- **PickItemNet.cs 核心拾取流程** — 影响所有道具类型
- **ItemData.cs 已有常量值** — 修改会破坏存档兼容性
- **BattleRolePickItemComponent.cs 拾取优先级逻辑** — 共用逻辑，勿为单个活动道具特殊化

public void ProcessPickItem(PickItemNet item, BattleRole role) {
    switch (item.itemData.itemType) {
        // ... 其他类型
        case ItemData.ActivityItems:
            // 活动道具：直接拾取，无使用流程
            item.ItemClient.HasPick(role);

## 五、常见问题与踩坑记录

### 5.1 活动道具不生成

**现象**：进入战场后地图上看不到新增的活动道具

**根因**：
- `ActivityItemSkin.txt` 中 PrefabName 与实际 Prefab 文件名不匹配（大小写敏感）
- `PickItemData.txt` 中 ItemType 值不是 738197504
- 掉落配置 `LootItemConfig.txt` 未添加该道具

**解决方案**：
1. 确认 PrefabName 拼写完全一致（区分大小写）
2. 确认 ItemType = 738197504 (ActivityItems)
3. 在 LootItemConfig 中添加掉落权重

### 5.2 拾取无反应

**现象**：靠近道具有 UI 提示，但按拾取键无反应

**根因**：
- Prefab 的 Collider 未勾选 IsTrigger
- Layer 不是 PickItem
- PickItemNet 组件未正确初始化

**解决方案**：
1. 检查 Prefab 根节点 Layer = PickItem, Tag = PickItem
2. 确认 Collider 勾选了 Is Trigger
3. 确认 PickItemNet 组件的 ItemSign 与配置一致

### 5.3 拾取后 Buff 不触发

**现象**：道具成功拾取，但关联的 Buff 效果未生效

**根因**：
- `PickItemData.txt` 的 SOBuff 字段为空或拼写错误
- Buff SO 资源文件不存在或路径错误

**解决方案**：
1. 确认 SOBuff 字段值与 SO 资源文件名完全一致
2. 确认 SO 文件在 `ScriptableObject/Buff/` 目录下

### 5.4 活动道具在打金模式重复出现

**现象**：活动道具在不应出现的模式中生成

**根因**：`LootItemConfig.txt` 的 FilterType 未设置活动过滤

**解决方案**：设置 `FilterType=3`（活动限定），或在模式代码中过滤 `IsActivityItem=true` 的道具

### 5.5 道具图标不显示

**现象**：背包 UI 中道具格子为空白

**根因**：图标资源未放在正确路径 `UI/Atlas/ItemIcon/`，或 SOItemDataConfig 的 Icon 字段未赋值

**解决方案**：
1. 确认图标在 `Assets/ToBundle/UI/Atlas/ItemIcon/` 目录
2. 如使用 SOItemDataConfig，确认 Icon 字段已赋值
