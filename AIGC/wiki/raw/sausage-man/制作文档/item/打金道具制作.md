# 1 代架构打金道具制作规范

> **适用范围**：GoldDash（淘金热/撤离模式）专属道具体系 — GoldItem/GoldItem2/GoldXccItem/AltarItem/IdTag/TempItem/TreasureRoomKey 等
> **不适用**：通用战场道具 → 归 [[战场道具制作]]；通用消耗品 → 归 [[消耗品制作]]；GoldDash 模式逻辑 → 归 [[mode-golddash]]
> **参考实现**：GoldDashPickItemNet（标准打金道具）、VariationSystem（变异品质系统）

---

## 一、架构概述

### 1.1 核心类依赖

```
GoldDashItemManagerData (道具注册表)
  │  路径: Assets/Script/GamePlay/Host/GoldDash/Item/
  │  职责: 维护所有打金道具的创建/销毁/查询
  │
  ├── GoldDashPickItemNet (道具网络实体, MonoBehaviour)
  │     ★ 不继承 PickItemNet，完全独立体系
  │     ├── GoldDashPickItemNetClient (Client 端)
  │     │     拾取UI显示、模型加载、收藏品变异视觉
  │     └── GoldDashPickItemNetServer (Server 端)
  │           拾取判定、物品归属、死亡掉落、同步
  │
  ├── GoldDashPickItem (道具视觉表现)
  │     ├── LoadSkin(war_item_lod) → 加载模型 Prefab
  │     ├── SetMark(war_item_mark) → 设置标记特效
  │     └── GoldDashCollectionMono → 收藏品变异视觉控制
  │
  ├── ClientGoldDashItemManager (Client 端管理器)
  │     接口: IGoldDashItemManager
  │     职责: 道具实例化/销毁/UI 显示/拾取动画
  │
  ├── ServerGoldDashItemManager (Server 端管理器)
  │     接口: IGoldDashItemManager
  │     职责: 道具生成决策/拾取判定/死亡掉落逻辑
  │     └── 与 ServerGoldDashDeadLogic 交互（死亡掉落）
  │
  └── VariationSystem (品质变异系统, 类 Diablo)
        ├── BaseVariationStrategy     ← 默认策略
        ├── PurityVariationStrategy   ← 纯度/花纹变异
        ├── EffectVariationStrategy   ← 特效变异(粒子/光效)
        └── VolumeVariationStrategy   ← 体积变异(缩放)
```

### 1.2 系统特点

打金道具系统是独立于通用道具（PickItemNet）的**完整平行体系**：
- 独立的道具网络类 `GoldDashPickItemNet`（不继承 PickItemNet）
- 独立的道具管理器 `IGoldDashItemManager` + Client/Server 实现
- 独立的配置体系（33 个 `GoldDash*.txt` 配置表）
- 类 Diablo 的**道具品质变异系统** `VariationStrategy`

### 1.4 拾取流程（GoldDash 专属）

```
玩家靠近打金道具 → GoldDashPickItemNetClient 检测
  │
  ├── [Client] 显示专属拾取 UI（不走通用 PickItem UI）
  │     → 显示道具名称、品质、价值
  │     → 收藏品显示变异花纹/特效/体积
  │
  ├── [Client] 发送拾取 Cmd
  │     → gameWorld.Send(Proto_GoldDash.CmdPickGoldDashItem { ... })
  │
  ├── [Server] GoldDashPickItemNetServer 拾取判定
  │     ├── 背包容量检查 (GoldDash专属背包, 非通用BackpackManager)
  │     ├── 距离/权限检查
  │     ├── 保险箱/钥匙包等级检查 (SafeBoxLevel/KeyBagLevel)
  │     └── 道具归属判定（死亡掉落物的归属）
  │
  ├── [Server] 广播拾取结果 + 更新道具状态
  │
  └── [Client] 更新显示
        → 道具模型隐藏/销毁
        → 背包 UI 更新 (专属背包面板)
        → 拾取音效/特效
        → 收藏品入库 (CollectionManager)
```

### 1.5 预制体与资源加载（★）

| 资源 | 路径 | 加载方式 | 时机 |
|------|------|---------|------|
| **GoldDash 配置表 ×33** | `Assets/ToBundle/Config/Txt/GoldDash*.txt` | `ConfigManager.Get<GoldDash{Type}Config>()` | 模式初始化 |
| **道具模型** | `Assets/ToBundle/Items/GoldDash/{war_item_lod}` | `GoldDashPickItem.LoadSkin()` → AssetManager | 道具生成时 |
| **标记特效** | `Assets/ToBundle/Items/GoldDash/Effect/{war_item_mark}` | `GoldDashPickItem.SetMark()` | 道具生成时 |
| **变异材质** | `Assets/ToBundle/Items/GoldDash/Variation/` | VariationSystem 按策略加载 | 品质确定时 |
| **身份牌 TMP** | IdTag 使用 TextMeshPro 渲染击杀者名字 | TextMeshPro 组件 | 击杀时 |

**初始化时序**：
```
GoldDash 模式加载
  → ServerGoldDashItemManager.Init()
    → 加载 33 个 GoldDash*.txt 配置
    → VariationSystem.Init() 注册 4 种策略
    → 注册道具生成点 (从地图数据)
  → ClientGoldDashItemManager.Init()
    → 初始化道具池
    → 注册拾取 UI 回调
  → 道具开始生成 (按区域/阶段/权重)
```

### 1.6 禁止修改的文件

- **GoldDashPickItemNet.cs 核心生命周期** — 影响所有打金道具
- **VariationSystem 策略注册顺序** — 影响变异计算结果
- **已有道具类型 long 常量** — 修改会破坏存档/收藏品数据
- **GoldDashItemUtil.cs 序列化格式** — JsonUtility 格式变更会导致旧数据不兼容

public GoldDashPickItemNet CreateItem(int sign, Vector3 position) {
    var config = GoldDashItemConfig.Instance.GetBySign(sign);
    var itemGo = GoldDashItemPool.Get(config.war_item_lod);
    var itemNet = itemGo.GetComponent<GoldDashPickItemNet>();
    
    itemNet.Init(config);

    }
    
    RegisterItem(itemNet);
    return itemNet;
}

## 五、常见问题与踩坑记录

### 5.1 打金道具不生成

**现象**：进入 GoldDash 模式后地图上无打金道具

**根因**：
- `GoldDashItem.txt` 中 `war_item_lod` 字段为空或路径错误
- 道具生成点配置未包含新道具（地图数据/刷新配置）
- GoldDash 模式初始化失败（33 个配置表缺少任一都会报错）

**解决方案**：
1. 确认 `war_item_lod` 路径指向有效 Prefab
2. 检查地图生成点配置是否包含新 Sign
3. 查看 Console 是否有 ConfigManager 加载失败日志

### 5.2 变异品质计算结果全部相同

**现象**：所有收藏品都是相同品质/花纹

**根因**：
- `GoldDashCollectionVariation*Rand.txt` 权重配置全部为 0 或相同值
- 变异 Class 只配了一个等级
- 变异 Part 未配置足够部件

**解决方案**：
1. 确保 Rand 表有差异化权重值
2. 确保 Class 表配了多个稀有度等级
3. 确保 Part 表配了足够的部件变体
4. 13 个变异配置表缺一不可，逐一检查

### 5.3 道具转换后数据丢失

**现象**：打金道具转为通用道具后，部分属性丢失

**根因**：`GoldDashItemConvertSausageItem.txt` 映射不完整，或目标通用道具配置缺失

**解决方案**：
1. 确认转换表中每个 GoldDashSign 都有对应的 SausageItemSign
2. 确认目标 SausageItemSign 在 `PickItemData.txt` 中存在
3. 注意变异属性不随转换保留

### 5.4 身份牌 TextMeshPro 不显示

**现象**：击杀后掉落的 IdTag 上没有玩家名字

**根因**：
- TextMeshPro 字体资源未打包到 AssetBundle
- IdTagEffectControl 组件未正确引用 TMP 节点
- DogTagInfo 序列化/反序列化格式不匹配

**解决方案**：
1. 确认 TMP 字体在 ToBundle 目录内
2. 检查 IdTag Prefab 上 TextMeshPro 组件引用
3. 不要修改 DogTagInfo 的 JsonUtility 序列化格式

### 5.5 保险箱等级不生效

**现象**：升级保险箱后安全容量不变

**根因**：`GoldDashSafeBoxLevel.txt` 等级数值配置不连续（缺少某一级）

**解决方案**：确保等级配置连续无跳跃（Level 1, 2, 3...），每级有明确的容量值
