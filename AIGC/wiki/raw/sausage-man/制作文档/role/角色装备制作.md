# 1 代架构角色装备制作规范

> **适用范围**：防弹衣(`ArmoredVests=66`)、头盔(`Headgear=71`)、背包(`Back=61`)、功能性服装/吉利服(`FunctionalGarment=72`)、小背心(`SmallVest=95`)、狗牌(`DogTag`) 相关的装备穿戴、属性计算和 UI 交互
> **不适用**：武器配件（B11 武器配件制作）、角色皮肤、时装系统
> **参考实现**：SOEquipPartConfig + BattleRoleEquipComponent + EquipPart

**占位符说明**：

| 占位符 | 含义 | 示例 |
|--------|------|------|
| `{EquipName}` | 装备名称（大驼峰） | `LV3Vest`、`GhillieSuit`、`TacticalHelmet` |
| `{EquipId}` | 装备 ID（SOEquipPart 主键） | 配置表 `id` 字段指定 |
| `{EquipType}` | 装备物品类型枚举值 | `61`(背包)、`66`(防弹衣)、`71`(头盔) |
| `{SkinSign}` | 皮肤标识 | 由配置表 `skinInfos` 字段指定 |
| `{PI_Data}` | 拾取物数据 ID | 关联 PickItemData 的主键 |
| `{BuffSign}` | Buff 标识 | `SOBuffList` 数组中的 Buff ID |
| `{Level}` | 装备等级 | `1` / `2` / `3` |

## 一、架构概述

### 1.1 系统分类

角色装备系统管理 6 种角色身上的防具/功能性装备的穿戴、属性加成和 UI 显示。所有装备共享同一套 `SOEquipPartConfig` 配置驱动和 `EquipPart` 运行时组件，区别在于各自的 Renderer 数组和属性逻辑。

**与 B11 武器配件的区别**：

| 维度 | B11 武器配件 | B12 角色装备 |
|------|-------------|-------------|
| 挂载位置 | 武器上 | 角色身上 |
| 管理组件 | WepEquip | EquipPart |
| 配置表 | SOWepEquipData.txt | SOEquipPart.txt |
| 所在目录 | `Items/Attachments/` | `Items/Equipment/` |
| 控制组件 | BattleRoleWeaponComponent | BattleRoleEquipComponent |

**装备类型枚举**（`ItemData.ItemType`）：

| 枚举值 | 类型 | 说明 | 属性 | 典型装备 |
|--------|------|------|------|---------|
| 61 | Back | 背包 | 扩展容量 | 1/2/3 级背包 |
| 66 | ArmoredVests | 防弹衣 | 减伤 + 耐久 | 1/2/3 级防弹衣 |
| 71 | Headgear | 头盔 | 减伤 + 耐久 | 1/2/3 级头盔 |
| 72 | FunctionalGarment | 功能性服装/吉利服 | Buff 效果 | 吉利服、特殊功能衣 |
| 95 | SmallVest | 小背心 | 减伤（轻量） | 小背心 |
| 1805890064002060288 (long) | DogTag | 狗牌 | 特殊能力 | 狗牌（含自动开火 Buff） |

> ⚠️ 狗牌的 ItemID 是 **long 型** (`1805890064002060288`)，不是 int，处理时需注意类型。

### 1.2 核心类依赖

```
[配置层 — 数据驱动]
SOEquipPartConfig                       ← 装备属性配置（来自 SOEquipPart.txt）
├── id                                  ← 装备 ID
├── PI_Data                             ← 拾取物数据 ID
├── EquipHp / Level / ProtectRatio      ← 耐久 / 等级 / 防护比例
├── AddPackValue                        ← 背包增容值
├── SOBuffList[]                        ← 穿戴触发 Buff 列表
├── effSign / HPOverSound               ← 特效 / 耐久归零音效
├── skinInfos[]                         ← 皮肤信息列表
├── userNum                             ← 使用次数
└── headBuffEffect                      ← 头盔 Buff 特效

[GoldDash 模式 — 独立配置体系]
GoldDashVestBaseValue                   ← 防弹衣基础值（df_ratio / depreciation）
GoldDashHelmetBaseValue                 ← 头盔基础值
GoldDashArmorLevel                      ← 防装等级配置
GoldDashBackpackLevel                   ← 背包等级（容量/重量）
GoldDashBackpackBaseValue               ← 背包基础值
GoldDashModelEquip                      ← 模型装备映射
BattleUiArmorOptions                    ← 战斗 UI 防装选项

[战场 3D 层 — 渲染]
EquipPart : MonoBehaviour               ← 装备实例控制器（挂载在角色预制体上）
├── VestsRenderers : MeshRenderer[]     ← 防弹衣网格渲染器
├── HeadRenderers : MeshRenderer[]      ← 头盔网格渲染器
├── BackRenderers : MeshRenderer[]      ← 背包网格渲染器
├── GhillieShrubsRenderers : MeshRenderer[] ← 吉利服网格渲染器
├── AddPackValue : float                ← 背包增容值
├── SetActive()                         ← 控制装备显示/隐藏
└── SignHide()                          ← 标记隐藏

BagControl : MonoBehaviour              ← 背包动画和挂点管理
├── weaponSlots[]                       ← 武器在背包上的槽位
├── BagAniType                          ← 背包动画类型
└── 管理武器挂在背包上的显示位置

[角色组件层 — 装备状态管理] (C/S/H)
BattleRoleEquipComponent : BattleRoleComponent  ← 装备状态管理组件
├── showHeadgear : bool                 ← 头盔显示开关
├── showArmoredVests : bool             ← 防弹衣显示开关
├── showBack : bool                     ← 背包显示开关
├── showFunctionalGarment : bool        ← 功能性服装显示开关
├── isInitGoldDashEquip : bool          ← GoldDash 装备初始化标记
├── goldDashEquipDefaultData            ← GoldDash 默认装备数据
├── 事件注册：
│   ├── BattleRoleEvents.ShowEquipState          ← 装备显示状态变更
│   ├── BattleRoleEvents.CheckArmoredVestsEquip  ← 检查防弹衣装备
│   └── BattleRoleEvents.GetArmoredVestsFashionData ← 获取防弹衣时装数据
└── 用户设置控制：
    ├── GameSettingData.EquipState       ← 头盔显示用户设置
    ├── GameSettingData.ArmorEquipState  ← 防弹衣显示用户设置
    └── GameSettingData.PackEquipState   ← 背包显示用户设置

[狗牌系统] (UI/War/Role/Dogtag/)
Role_DogTag                             ← 狗牌显示组件（ItemID: 1805890064002060288）
DogTagHpPanel                           ← 狗牌血量面板
DogTagHpItem                            ← 血量条项
BSAutoFireDogTag                        ← 狗牌自动开火 Buff（C/S/H 三端）
```

#### 装备创建时序

```
角色初始化
    │
    ├── BattleRoleEquipComponent.Init()
    │   ├── 注册 ShowEquipState 事件
    │   ├── 注册 CheckArmoredVestsEquip 事件
    │   ├── 注册 GetArmoredVestsFashionData 事件
    │   └── 读取用户设置（EquipState / ArmorEquipState / PackEquipState）
    │
    ├── 拾取装备 / 初始装备分配
    │   ├── 查询 SOEquipPartConfig（id → 配置数据）
    │   ├── 加载装备模型（AssetsLoad.GetItemSkin）
    │   └── 挂载到角色 EquipPart 对应 Renderer 数组
    │
    ├── EquipPart.SetActive(true)
    │   ├── 检查用户设置开关
    │   ├── 检查模式特殊逻辑（GoldDash）
    │   └── 启用对应 MeshRenderer 组
    │
    └── GoldDash 模式特殊流程
        ├── isInitGoldDashEquip = true
        ├── 读取 GoldDashVestBaseValue / GoldDashHelmetBaseValue / ...
        ├── 使用 goldDashEquipDefaultData 初始化默认装备
        └── 独立的装备等级/升级体系
```

## 三、配置文件详解

### 3.1 SOEquipPart.txt — 装备属性核心配置

**路径**：`Assets/ToBundle/Config/Txt/SOEquipPart.txt`

**字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 装备 ID（主键） |
| `PI_Data` | string | 拾取物数据 ID，关联 PickItemData |
| `EquipHp` | float | 装备生命值（防弹衣/头盔的耐久度，归零后装备失效） |
| `Level` | int | 装备等级（1-3 级），影响防护能力和 UI 显示 |
| `ProtectRatio` | float | 防护比例（降伤百分比，0.0-1.0） |
| `AddPackValue` | float | 增加背包容量的值（仅背包类型使用） |
| `SOBuffList` | string[] | 穿戴时触发的 Buff 列表（如吉利服隐身、狗牌自动开火） |
| `HPOverSound` | string | 装备耐久归零时播放的音效标识 |
| `effSign` | string | 装备特效标识 |
| `skinInfos` | string[] | 皮肤信息列表，对应 Skin 目录下的预制体名 |
| `userNum` | int | 使用次数（限次使用装备） |
| `headBuffEffect` | string | 头盔 Buff 特效标识（仅头盔使用） |

**注意事项**：
- `ProtectRatio` 是 0-1 的比例值，不是百分比（0.3 = 30% 降伤）
- `SOBuffList` 为数组，多个 Buff 用配置表分隔符分割
- `skinInfos` 为数组，支持一件装备多套皮肤

## 五、常见问题与踩坑记录

### 5.1 EquipPart 与 WepEquip 混淆

**问题现象**：在 `UI/War/Weapon/` 目录下同时存在 `EquipPart.cs`（角色装备）和 `WepEquip.cs`（武器配件），容易混淆修改错文件。

**根因分析**：两者虽然都在 `UI/War/Weapon/` 目录下，但职责完全不同：
- `EquipPart.cs` — B12 角色装备：防弹衣、头盔、背包等穿戴在角色身上的防具
- `WepEquip.cs` — B11 武器配件：瞄准镜、弹匣、枪口等安装在武器上的配件

**解决方案**：
1. 修改角色防具 → 找 `EquipPart.cs`（管理 `VestsRenderers` / `HeadRenderers` / `BackRenderers` / `GhillieShrubsRenderers`）
2. 修改武器配件 → 找 `WepEquip.cs`（管理配件在武器上的挂载）
3. 配置表也不同：角色装备用 `SOEquipPart.txt`，武器配件用 `SOWepEquipData.txt`

---

### 5.2 GoldDash 模式等级体系独立

**问题现象**：修改了 `SOEquipPart.txt` 的 `Level` 和 `ProtectRatio`，但 GoldDash 模式下防装数值不变。

**根因分析**：GoldDash 模式有独立的等级体系，由 6 个专属配置表控制：
- `GoldDashVestBaseValue.txt` — 防弹衣基础值
- `GoldDashHelmetBaseValue.txt` — 头盔基础值
- `GoldDashArmorLevel.txt` — 防装等级
- `GoldDashBackpackLevel.txt` — 背包等级
- `GoldDashBackpackBaseValue.txt` — 背包基础值
- `GoldDashModelEquip.txt` — 模型装备映射

`BattleRoleEquipComponent` 在 GoldDash 模式下会走 `isInitGoldDashEquip` 分支，使用 `goldDashEquipDefaultData` 而非标准 SOEquipPart 配置。

**解决方案**：
1. 修改标准模式防装 → 改 `SOEquipPart.txt`
2. 修改 GoldDash 模式防装 → 改上述 6 个 GoldDash 专属配置表
3. 如果新增的装备需要同时支持两种模式，**两套配置都需要添加**

---

### 5.3 狗牌 ItemID 类型问题

**问题现象**：狗牌 ItemID 使用 int 解析时溢出，导致无法正确识别狗牌道具。

**根因分析**：狗牌的 ItemID 是 `1805890064002060288`，远超 int 的最大值 `2147483647`，必须使用 long 类型存储和比较。

**解决方案**：
1. 所有涉及狗牌 ItemID 的代码，变量类型必须用 `long`
2. 配置表读取时使用 long 解析方法
3. 比较判断时不要与 int 类型变量混用

---

### 5.4 showArmoredVests 控制链路复杂

**问题现象**：设置了防弹衣数据但角色身上不显示，或显示异常。

**根因分析**：`showArmoredVests` 的控制链路涉及多个环节：
1. `GameSettingData.ArmorEquipState` — 用户设置开关
2. 模式检查 — 某些模式可能禁用装备显示
3. GoldDash 特殊逻辑 — GoldDash 模式有独立的显示控制
4. `EquipPart.SetActive()` — 最终渲染层开关

**解决方案**：
1. 按顺序排查：用户设置 → 模式检查 → GoldDash 逻辑 → EquipPart
2. 在 `BattleRoleEquipComponent` 中打断点，确认 `showArmoredVests` 值
3. 检查 `EquipPart.VestsRenderers` 数组是否正确引用了 MeshRenderer
4. 确认 `EquipPart.SetActive()` 是否被正确调用

---

### 5.5 BagControl weaponSlots 影响武器挂载

**问题现象**：修改背包模型后，角色背上的武器位置偏移或消失。

**根因分析**：`BagControl` 的 `weaponSlots[]` 数组管理武器在背包上的显示位置。修改背包模型时如果改变了骨骼结构或挂点位置，会导致 `weaponSlots` 引用丢失。

**解决方案**：
1. 修改背包模型后，必须检查 `BagControl.weaponSlots[]` 的 Transform 引用
2. 确保武器挂点的命名和层级与原模型一致
3. 测试时验证步枪、冲锋枪等不同尺寸武器在背包上的显示位置
