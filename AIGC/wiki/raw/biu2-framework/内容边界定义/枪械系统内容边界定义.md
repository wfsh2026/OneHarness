## 1. 总则

### 1.1 AI 可以做什么

UGC 玩家通过 AI 聊天，可以创建或修改枪械：

| 操作类型 | 说明 | 示例 | 需修改的文件 |
|---------|------|------|------------|
| **调参** | 修改现有枪械的属性数值 | "把乌兹的伤害改成 200" | 仅 `WeaponData.cs` 配置行 |
| **创建通用枪械** | 基于现有参数创建新枪，不需要新 System | "创建一把蓄力狙击枪" | WeaponData 配置 + Item/WeaponSkin 注册 |
| **创建特化枪械** | 需要特殊开火逻辑的新枪（追踪/爆炸等） | "创建一把激光追踪枪" | 新建 ServerXxxSystem + ClientXxxSystem + 注册 |
| **参数微调** | 玩家觉得某把枪"太弱"或"太强"时的调整 | "把加特林的射速调快一倍" | 仅 `WeaponData.cs` 对应字段 |

**唯一限制**：不修改框架层/底层代码（Base 类、Manager 类、框架 Component）。此规则已在`core-rules.md`明确，本文档不重复约束。

**工程上已支持的特殊能力（可在新枪中直接使用）**：

| 能力 | 工程机制 | 相关字段 |
|------|---------|---------|
| **蓄力射击** | `StartFireWaitTime > 0` | GunData.StartFireWaitTime |
| **过热/冷却** | `FireOverHotTime > 0` | GunData.FireOverHotTime + FireOverHotCDTime |
| **霰弹多发** | `FireBulletNum > 1` + `FireRange` | GunData.FireBulletNum |
| **伤害衰减** | `BulletAttnMaps` 曲线 | GunData.BulletAttnMaps |
| **AI 自动开火** | `ServerAttackAutoFire` 组件 | GunData.IsCanAutoFire |
| **开火镜头震动** | `CM_Camera.ShakeCamera` | 客户端 System 内调用 |
| **爆炸子弹** | Ability 系统 `AB_Explosive` | AbilityM_Bullet.M_Explosive |

### 1.2 枪械系统职责

枪械系统负责管理游戏中所有射击类武器的服务器逻辑、客户端表现和数据配置。它与以下系统协作：

- **Ability 系统**：子弹实体由 Ability 系统管理（`SM_Ability.PlayAbility`），枪械系统只负责发射触发
- **镜头系统**：开火目标点必须通过 `CM_Camera.GetCameraCenterObjPoint` 获取
- **GPO 系统**：枪械作为 GPO 的组件挂载（`ServerGPOWeapon` / `ClientGPOWeapon`）

### 1.3 数据层结构

```
数据层
├── WeaponData.GunData        ← 枪械核心属性（ATK / IntervalTime / FireDistance 等）
├── BulletData                ← 子弹类型（Bullet_Gun / Bullet_Gatling 等）
├── Item.cs（ItemSet 常量）   ← 武器 ItemId（Id_FireGun = 49 等）
├── WeaponSkin.cs             ← 皮肤绑定（skinId → weaponItemId）
└── AbilityM_Bullet.cs        ← 子弹 Ability 模板（AbilityBulletID 引用）
```

> ⚠️ **命名注意**：部分旧文档写"WeaponSet.cs"，实际类名为 `ItemSet`，位于 `Item.cs` 文件中。

## 3. 属性参数规范

> ⚠️ **AI 必须将玩家描述的数值裁剪到以下范围内**，超出范围不报错，但自动调整并告知玩家。  
> 例如："一把 ATK 一万的枪" → ATK 自动设为 2800（最大值），并提示"已调整至上限 2800"。

### 3.1 GunData 数据结构

```csharp
public class GunData : Data {
    public float StartFireWaitTime; // 开火蓄力等待时间（加特林蓄力）
    public float FireRange;         // 扩散半径（度）
    public float IntervalTime;      // 射击间隔（毫秒）
    public float ReloadTime;        // 换弹时间（毫秒）
    public float FireDistance;      // 有效射程（厘米，÷100得米）
    public int   MagazineNum;       // 弹夹容量（0=无限）
    public int   FireBulletNum;     // 每次开火子弹数（霰弹枪>1）
    public bool  IsCanAutoLock;     // 是否自动瞄准
    public bool  IsCanAutoFire;     // 是否可 AI 自动开火
    public float FireOverHotTime;   // 过热触发时间（0=不过热）
    public float FireOverHotCDTime; // 过热冷却时间
    public float BulletSpeed;       // 子弹飞行速度（m/s）
    public float MoveSpeed;         // 持枪移动速度系数
    public int   SightStyle;        // 瞄准准星类型（1=圆形，2=横排）
    public CanUseBulletData[] CanUseBullet;    // 可用子弹列表
    public List<BulletAttnMap> BulletAttnMaps; // 射程衰减曲线
}
```

### 3.2 基础战斗属性完整规范

| 字段名 | 最小值 | 推荐范围 | 最大值 | 默认值 | 单位 | 说明 |
|--------|-------|---------|--------|--------|------|------|
| ATK | 50 | 100~500 | 2800 | 200 | 伤害值 | 单发基础伤害 |
| IntervalTime | 30 | 80~300 | 1500 | 100 | ms | 连射间隔（越小越快）|
| MagazineNum | 0 | 20~50 | 100 | 30 | 发 | 弹夹容量（0=无限）|
| ReloadTime | 500 | 1000~2000 | 5000 | 1500 | ms | 换弹耗时 |
| StartFireWaitTime | 0 | 0~2000 | 5000 | 0 | ms | 首发蓄力延迟（加特林/蓄力枪用）|

### 3.3 射程与精度属性

| 字段名 | 最小值 | 推荐范围 | 最大值 | 默认值 | 单位 | 说明 |
|--------|-------|---------|--------|--------|------|------|
| FireDistance | 1600 | 4000~8000 | 10000 | 5000 | cm | 有效射程（5000cm=50m）|
| FireRange | 0 | 3~15 | 180 | 5 | 度 | 水平扩散角（越大越散）|
| FireAngleVertical | 0 | 3~15 | 180 | 5 | 度 | 垂直扩散角 |
| BulletSpeed | 20 | 100~400 | 750 | 200 | m/s | 子弹飞行速度（750=即时命中）|

### 3.4 特殊机制属性

| 字段名 | 最小值 | 推荐范围 | 最大值 | 默认值 | 单位 | 说明 |
|--------|-------|---------|--------|--------|------|------|
| FireBulletNum | 1 | 1~8 | 16 | 1 | 发 | 单次开火子弹数（霰弹枪：6-12）|
| FireOverHotTime | 0 | 3000~8000 | 12000 | 0 | ms | 过热触发时间（0=不过热）|
| FireOverHotCDTime | 0 | 1500~4000 | 10000 | 2000 | ms | 过热后冷却时间 |
| MoveSpeed | 0.5 | 0.8~1.2 | 1.5 | 1.0 | 倍率 | 持枪移速系数（<1=变慢）|
| AddBuffTime | 0 | 0~3000 | 10000 | 0 | ms | 特殊 Buff 持续时间 |

### 3.5 伤害衰减曲线（BulletAttnMaps）

BulletAttnMaps 是 `List<BulletAttnMap>`，定义距离与伤害比例的关系：

| 距离段 | 推荐伤害比例 | 极限范围 | 适用武器 |
|--------|------------|---------|---------|
| 0~10m | 1.0（满伤）| 0.8~1.0 | 所有 |
| 10~30m | 0.8~1.0 | 0.5~1.0 | 步枪/冲锋枪 |
| 30~50m | 0.5~0.8 | 0.3~1.0 | 步枪/狙击 |
| 50m+ | 0.3~0.5 | 0.1~0.8 | 仅狙击 |

> **霰弹枪衰减参考**：10m 内满伤（1.0），10~20m 降至 0.5，20m+ 降至 0.2。

## 5. AI 意图识别增强规则

### 5.1 程度词乘数系统（统一规范）

> **规则**：程度词作用于字段的**默认值**（第 3 章 default 列），得到最终值。  
> **注意**：IntervalTime 越小越快，因此正向程度词对其**除法**（而非乘法）。

| 程度词 | 乘数 | ATK/MagazineNum/FireDistance | IntervalTime 处理 | BulletSpeed 处理 |
|--------|------|------------------------------|-------------------|-----------------|
| 一点点 | ×1.3 | ×1.3 | ÷1.3（更快）| ×1.3 |
| 比较 | ×2.0 | ×2.0 | ÷1.5 | ×2.0 |
| 很 | ×3.0 | ×3.0 | ÷2.0 | ×3.0 |
| 非常/超级 | ×5.0 | ×5.0 | ÷3.0 | ×5.0 |
| 最/无敌 | ×10.0 | 取最大值 | 取最小值（30ms）| 取最大值（750）|
| 有点弱 | ×0.7 | ×0.7 | ×1.3（更慢）| ×0.7 |
| 比较弱 | ×0.5 | ×0.5 | ×1.5 | ×0.5 |
| 很弱 | ×0.3 | ×0.3 | ×2.0 | ×0.3 |

**示例**：
- 输入："一把很强的冲锋枪"
  - ATK: 200（默认）× 3.0 = 600
  - MagazineNum: 30（默认）× 3.0 = 90
  - IntervalTime: 100ms（默认）÷ 2.0 = 50ms

### 5.4 复合描述拆解示例

#### 示例 1：简单组合（多属性修饰）

**输入**："一把射速很快、弹夹很大、伤害比较低的冲锋枪"

**拆解步骤**：
1. **识别类型**："冲锋枪" → A 类通用枪械
2. **拆解程度词**：
   - "射速很快" → IntervalTime = 100ms ÷ 2.0 = **50ms**
   - "弹夹很大" → MagazineNum = 30 × 3.0 = **90 发**
   - "伤害比较低" → ATK = 200 × 0.5 = **100**
3. **预设匹配**：高射速 → W01，弹夹大 → W01（无需额外预设）
4. **输出摘要**：
   ```
   ✅ 已创建：低伤快射大弹夹冲锋枪
   - 类型：通用枪械（ServerGunSystem）
   - ATK：100，射速：50ms，弹夹：90发
   - 预设：W01（标准连发）
   ```

---

#### 示例 2：特殊机制组合

**输入**："一把蓄力狙击枪，蓄力满了一枪秒人，但蓄力时会过热，过热后需要冷却5秒才能再次射击"

**拆解步骤**：
1. **识别类型**："狙击枪" → A 类通用，参考 Sniper 参数
2. **识别特殊机制**：
   - "蓄力" → W03，`StartFireWaitTime > 0`
   - "过热" → W04，`FireOverHotTime > 0`
   - "一枪秒人" → ATK 极高
3. **参数设计**：
   - `StartFireWaitTime = 2000ms`（蓄力2秒）
   - `ATK = 2500`（秒人）
   - `FireOverHotTime = 2000ms`（蓄力满即触发过热）
   - `FireOverHotCDTime = 5000ms`（冷却5秒）
   - `MagazineNum = 3`，`IntervalTime = 1500ms`
4. **输出摘要**：
   ```
   ✅ 已创建：蓄力狙击枪
   - 蓄力时间：2秒 | 伤害：2500（秒人）
   - 过热：蓄力满触发，冷却5秒
   - 弹夹：3发 | 预设：W03 + W04
   ```

#### 示例 3：需要特化 System 的复杂枪械

**输入**："一把散射激光枪，每次射击发射5条激光，激光会追踪最近的敌人，持续3秒"

**拆解步骤**：
1. **识别类型**："散射激光" + "追踪" → **需要特化**
2. **判断是否可用通用模板**：❌ 不可（追踪机制需要特殊弹道逻辑）
3. **技术方案**：
   - Server：继承 `ServerGunSystem`，替换子弹组件为追踪型
   - Client：定制激光特效（持续光束）
   - Ability：新增 `AB_TrackingLaser`（参考 `AB_TrackingMissle`）
4. **输出确认**：
   ```
   ⚠️ 此武器需要新建特化 System：
   - 服务器：ServerLaserGunSystem（基于 Ability 追踪导弹改造）
   - 客户端：ClientGunLaserGunSystem（激光束特效）
   - 预估工作量：2~3天
   - 是否继续？
   ```

## 7. AI 处理流程

### Step 1：意图识别与分类

判断请求类型：
- **调参**：修改现有武器的数值（ATK、射速等）
- **新建通用枪械**：仅需调参 + 注册，不需要新 System
- **新建特化枪械**：需要新建 System 类（追踪、爆炸等特殊逻辑）

### Step 2：枪械类型判定

应用第 5.2 节"外观/类型词→枪械映射"表，确定：
- A 类（通用）→ 走 ServerGunSystem default
- B 类（特化）→ 需要独立 System
- C 类（客户端特效）→ 需要独立 ClientXxxSystem

### Step 3：程度词解析与参数计算

提取程度词（一点点、很、超级等），应用第 5.1 节乘数系统，验证数值是否在第 3.2~3.4 节合法范围内。

### Step 4：行为预设包选择

应用第 5.3 节"行为描述词→预设包映射"，组合多个预设（如 W01+W07），检查第 4.4 节互斥规则。

### Step 5：歧义检测与追问

检查是否触发第 6.2.1 节歧义场景。如有歧义，生成追问，等待玩家明确后再继续。

### Step 6：生成完整配置

- 输出 WeaponData 数据行（或修改指令）
- 输出需要修改的文件列表（见第 10.2 节最小变更集）
- 如需特化 System，输出新建 System 的代码框架

### Step 7：输出摘要与确认

生成人类可读摘要，示例：
```
✅ 已创建：爆发型霰弹枪
- 类型：通用枪械（ServerGunSystem）
- 伤害：400/发 × 8发 = 3200 总伤
- 射速：750ms（单发间隔）
- 弹夹：5发
- 预设：W02（爆发射击）+ W07（霰弹扩散）
- ⚠️ 注意：近距离威力极大，远距命中率低
```

## 10. 开发规范

### 10.1 命名规范

```
服务器武器系统:  Server{武器名}System        (例: ServerExampleGunSystem)
客户端武器系统:  Client{武器名}System        (例: ClientExampleGunSystem)
服务器开火组件:  ServerAttack{武器名}Fire    (例: ServerAttackExampleGunFire)
客户端动画组件:  Client{武器名}Anim          (例: ClientExampleGunAnim)
本地武器处理器:  CharacterLocalWeapon_{名}   (例: CharacterLocalWeapon_ExampleGun)
```

### 10.2 新枪最小变更集

| 优先级 | 文件 | 内容 | 缺失后果 |
|--------|------|------|---------|
| 必须 | `Item.cs` ItemSet 常量区 | `Id_XXX` 和 `Id_XXXDefault` | 编译报错 |
| 必须 | `Item.cs` data 数组 | 武器行 type=0 + 皮肤行 type=8 | 运行时崩溃 |
| 必须 | `WeaponSkin.cs` data 数组 | 默认皮肤行（isDefault=true）| `ArgumentOutOfRangeException` |
| 必须 | `Weapon.cs` data 数组 | 武器数值行（FireRate、Damage 等）| 运行时无武器数据 |
| 必须 | `AnimConfig_HTR.cs` | Group_XXX 常量 + GroupPlayData | 角色无握枪/开火动画 |
| 必须 | `ServerWeaponManager.cs` | `case Id_XXX → ServerXXXSystem` | 服务端无法创建武器 |
| 必须 | `ClientWeaponManager.cs` | `case Id_XXX → ClientXXXSystem` | 客户端无法创建武器 |

> **通用枪**（不需要特殊开火逻辑）：ServerWeaponManager 和 ClientWeaponManager 可以走 default 分支，无需新增 case。

### 10.3 事件总线规范

```
武器系统内部:  mySystem.Dispatcher(SE_Weapon.XXX) / iWeapon.Dispatcher(...)
GPO层通信:     mySystem.Dispatcher(SE_GPO.XXX)
跨系统全局:    MsgRegister.Dispatcher(SM_XXX / CM_XXX)
网络通信:      Client→Server: Cmd(...)  |  Server→Client: Rpc(...) / TargetRpc(...)
```

### 10.4 OnClear 必须做的事

```csharp
protected override void OnClear() {
    // 1. 注销所有 mySystem.Register
    // 2. 注销所有 MsgRegister.Unregister
    // 3. 注销所有 AddProtoCallBack / RemoveProtoCallBack
    // 4. RemoveUpdate（如有 AddUpdate）
    // 5. 清空所有 Action 回调引用（防止内存泄漏）
}
```
