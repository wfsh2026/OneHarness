## 1. 总则

### 1.1 AI 可以做什么

| 操作类型 | 说明 | 示例 | 需修改的文件 |
|---------|------|------|------------|
| **调参** | 修改现有英雄的移动/跳跃数值 | "把所有英雄的移动速度改快一点" | `HeroLevel.cs` 数据行 |
| **按英雄调参** | 修改特定英雄的数值 | "把英雄1的跳跃高度改成 2 米" | `HeroLevel.cs` 对应 HeroId 的所有数据行 |
| **行为参数微调** | 修改滑铲/闪避等行为参数 | "把滑铲速度调快，持续时间改短" | `CharacterInputToSlideState.cs` 对应字段 |
| **物理手感调整** | 修改全局跳跃弧度/重力/下落速度 | "让跳跃更飘一点" | `CharacterMoveToInput.cs` 物理常量 |
| **自动瞄准参数调整** | 修改锁定范围/吸附速度 | "把自动瞄准的锁定距离改成 80 米" | `CharacterLocalAutoLockTarget.cs` 对应字段 |

**唯一限制**：不修改框架层/底层代码（`S_Character_Base`、`C_Character_Base` 等基类与管理器核心类）。此规则已在`core-rules.md`明确，本文档不重复约束。

**工程上已支持的通用能力（可在 3C 相关需求中直接复用）**：

| 能力 | 工程机制 | 相关字段/组件 |
|------|---------|-------------|
| **移动速度实时调整** | `AE_MoveSpeedRate` / `AE_MoveSpeedRateByTime` | `CE_GPO.Event_SpeedChange` → `CharacterMoveToInput.speed` |
| **跳跃高度实时调整** | `ServerHeroAttribute` 通过 TargetRpc 同步 | `CE_GPO.Event_JumpHeightChange` → `CharacterMoveToInput.jumpHeight` |
| **二段跳高度实时调整** | 同上 | `CE_GPO.Event_AirJumpHeightChange` → `CharacterMoveToInput.airJumpHeight` |
| **滑铲（技能触发）** | `CE_Ability.SkillSlide` | `slideSpeed`、`slideHeight`、`slideDuration` 可由技能覆盖 |
| **冲锋位移** | `AB_Charge` | `CharacterLocalDisplacement` 接管移动 |
| **击退** | `KnockbackGPO`（Server）/`CharacterKnockback`（Client）| `TargetRpc_Knockback`：Dir/Speed/Duration |
| **击飞** | `StrikeFlyGPO`（Server）/`CharacterStrikeFly`（Client）| `TargetRpc_StrikeFly`：Dir/Force/Duration |
| **降落伞/飞行** | `CharacterInputToJumpState` + `ServerCharacterAerocraft` | `FlyType.OpenParachute → Fly` |
| **翔虫（钩锁位移）** | `CharacterLocalWirebug`（Client）/`ServerCharacterWirebug`（Server）| `CE_Character.Event_WirebugMove` |

| **服务器位置校正** | `TargetRpc_MovePoint` | 服务端检测位置偏差后强制校正客户端 |

### 1.2 3C 系统职责

3C 系统负责管理玩家角色的操控体验（Character/Camera/Control）：移动物理、跳跃/二段跳/降落伞、滑铲/闪避、视角同步、瞄准辅助等。它与以下系统协作：

- **Ability 系统（AB/AE）**：`AE_MoveSpeedRate` 改变移速；`AB_Charge`/`AB_Slide` 触发位移；`AB_Displacement` 触发瞬移
- **枪械系统**：持枪时 `MoveSpeed` 系数（`GunData.MoveSpeed`）对角色速度施加倍率；开火目标点由镜头系统提供
- **镜头系统**：`CharacterLocalCamera` 接收 `CM_Camera.CameraHVRota` 后更新角色朝向，并将垂直旋转角经 `Cmd_CameraVRota` 发给服务器
- **模式系统**：模式中可通过 `AE_MoveSpeedRate` 对全体玩家施加速度 Buff（如无限火力模式）

### 1.3 数据层结构

```
数据层
├── Template/data/HeroLevel.cs          ← 英雄等级数值表（MoveSpeed/JumpHeight/DoubleJumpHeight/Hp/Attack）
├── Template/data/HeroLevelSkill.cs     ← 英雄等级技能解锁表
├── GPOData.HeroAttributeData           ← 运行时英雄属性（Speed/JumpHeight/AirJumpHeight，运行时从HeroLevel换算）
└── CharacterData                       ← 角色状态枚举（StandType/JumpType/FlyType/WirebugType）
```

> ⚠️ **重要**：`HeroLevel.cs` 是自动生成文件（`// Generated automatically by csv-gen`）。根据`core-rules.md`，缺少模版数据时 AI 可自行根据需求生成模版数据，包括直接修改 `HeroLevel.cs` 中的数据行，后续再反录入模板表。

## 2. 3C 系统架构概览

### 2.1 数据流路径

```
[玩家输入（摇杆/按键）]
       ↓
[CM_InputPlayer.*]（Move / Jump / Dodge / Fire）
       ↓
[客户端本地组件]
  ├── CharacterMoveToInput     → CharacterController.Move()（本地预测移动）
  │                            → Cmd_MoveDir（Unreliable，高频）→ 服务端
  ├── CharacterInputToJumpState → CE_Character.JumpTypeChange
  │                            → Cmd_JumpType（Reliable）→ 服务端
  ├── CharacterInputToSlideState → CE_Character.Event_SlideMove
  │                             → Cmd_Slide（Reliable）→ 服务端
  ├── CharacterInputToStandState → CE_Character.StandTypeChange
  │                              → Cmd_StandType（Reliable）→ 服务端
  ├── CharacterLocalCamera      → CE_Character.CameraRotaV
  │                            → Cmd_CameraVRota（Unreliable，0.1s限流）→ 服务端
  └── CharacterLocalAutoLockTarget → CE_Character.AutoFire / CE_Character.Event_GetFinalPointBeforeFire
       ↓
[服务端]
  ├── ServerCharacterMove     ← Cmd_MoveDir → 广播 Rpc_MoveDir 给所有客户端
  ├── ServerHeroAttribute     → 从 HeroLevelSet 读取数值（Speed/JumpHeight/AirJumpHeight/Hp/Attack）
  │                           → 通过 TargetRpc_Speed/JumpHeight/AirJumpHeight 推送给客户端
  └── 如位置偏差过大 → TargetRpc_MovePoint 强制校正客户端位置
```

### 2.2 状态枚举一览（`CharacterData`）

| 枚举类型 | 枚举值 | 含义 |
|---------|-------|------|
| `StandType` | `Stand = 0` | 站立 |
| | `Crouch = 1` | 蹲伏 |
| | `Prone = 2` | 趴下 |
| `JumpType` | `None = 0` | 无跳跃 |
| | `Jump = 1` | 一段跳 |
| | `AirJump = 2` | 二段跳 |
| | `Fall = 3` | 下落中 |
| `FlyType` | `None = 0` | 无 |
| | `OpenParachute = 1` | 开伞过渡（持续 0.5s）|
| | `Fly = 2` | 飞行（降落伞展开）|
| `WirebugType` | `None = 0` | 无 |
| | `Start = 1` | 翔虫发射 |
| | `Drop = 2` | 翔虫下降 |
| | `Glide = 3` | 翔虫滑翔 |

## 3. 参数规范

> ⚠️ **AI 必须将玩家描述的数值裁剪到以下范围内**，超出范围不报错，但自动调整并告知玩家。
> 例如："把跳跃高度改成 10 米" → 裁剪至最大值 5.0m，提示"已调整至上限 5.0m，过高会影响游戏体验"。

### 3.1 `HeroLevel` 配置表字段（通过 CSV 修改，AI 不直接改 .cs）

| 字段名 | 最小值 | 推荐范围 | 最大值 | 当前值 | 单位 | 说明 |
|--------|-------|---------|--------|--------|------|------|
| `MoveSpeed` | 200 | 500~800 | 1200 | **600** | cm/s | 运行时 ×0.01 转为 m/s（600→6.0 m/s）|
| `JumpHeight` | 50 | 100~250 | 500 | **150** | cm | 运行时 ×0.01 转为 m（150→1.5m）|
| `DoubleJumpHeight` | 30 | 80~200 | 400 | **100** | cm | 二段跳额外提升高度（100→1.0m）|
| `Hp` | 500 | 2000~5000 | 10000 | 2000~5000 | 点 | 各英雄各等级不同 |
| `Attack` | 500 | 1500~4000 | 8000 | 1500~4000 | 点 | 各英雄各等级不同 |

> **各英雄 Lv1 HP / Attack 当前值参考**：
>
> | HeroId | Lv1 HP | Lv11 HP | Lv1 Attack | Lv11 Attack |
> |--------|--------|---------|-----------|------------|
> | 1 | 2500 | 5000 | 1500 | 3000 |
> | 2 | 2000 | 4000 | 2000 | 4000 |
> | 3 | 2500 | 5000 | 1500 | 3000 |
> | 4 | 2200 | 4400 | 1800 | 3600 |
> | 5 | 2000 | 4000 | 2000 | 4000 |
> | 6 | 2500 | 5000 | 1500 | 3000 |

### 3.2 `CharacterMoveToInput` 物理常量（可修改，影响全局手感）

| 字段名 | 当前值 | 类型 | 说明 | 推荐范围 |
|--------|--------|------|------|---------|
| `gravitey` | 1f | `const float` | 重力系数（影响下落速度和跳跃曲线）| 0.5~2.0 |
| `jumpTime` | 1.2f | `const float` | 跳跃到目标高度的时间（秒）| 0.6~2.5 |
| `weight` | 30f | `const float` | 角色重量（影响下落加速度）| 10~60 |
| `jumpPower` | 15f | `const float` | 跳跃力量系数 | 8~30 |

> ⚠️ 以上参数写在 `CharacterMoveToInput.cs` 中，修改后影响**所有角色**的物理手感曲线（跳跃弧度、下落速度等）。调整前建议先理解各参数联动关系：
> - `gravitey` 越大 → 下落越快，跳跃弧度越陡
> - `jumpTime` 越大 → 跳跃更"飘"（缓慢到达顶点）
> - `weight` 越大 → 下落加速度越大，着地更"沉"
> - `jumpPower` 越大 → 初始跳跃速度越快

### 3.3 滑铲行为参数（`CharacterInputToSlideState`，可由 Ability 系统覆盖）

| 字段名 | 最小值 | 推荐范围 | 最大值 | 默认值 | 单位 | 说明 |
|--------|-------|---------|--------|--------|------|------|
| `slideSpeed` | 3 | 10~20 | 30 | **15** | m/s | 滑铲初始速度（逐渐衰减至 0）|
| `slideDuration` | 0.3 | 0.8~2.0 | 4.0 | **1.2** | 秒 | 滑铲持续时间 |
| `slideHeight` | 0.3 | 0.4~0.7 | 1.0 | **0.5** | m | 滑铲时角色碰撞体高度 |

> 注意：`slideHeight` 影响角色在滑铲时能否穿过低矮障碍物，建议不超过站立高度的 60%。

### 3.4 闪避行为参数（`CharacterInputToDodgeState`，可修改）

| 字段名 | 当前值 | 单位 | 推荐范围 | 说明 |
|--------|--------|------|---------|------|
| `dodgaLimitTime`（CD） | 0.5 | 秒 | 0.1~3.0 | 连续闪避的冷却时间，在 `OnDodgaCallBack` 中赋值 |
| `dodgaTime`（持续时间）| 0.4 | 秒 | 0.1~1.5 | 单次闪避动作的持续时间，在 `OnDodgaCallBack` 中赋值 |

### 3.5 跳跃行为参数（`CharacterInputToJumpState`，可修改）

| 字段名 | 当前值 | 单位 | 推荐范围 | 说明 |
|--------|--------|------|---------|------|
| `jumpCount` 上限 | 2 | 次 | 1~4 | 最多允许跳跃次数（1=仅一段跳，2=二段跳，以此类推），在 `OnJump()` 中判断 `jumpCount >= N` |
| `OpenParachuteDistance` | 3 | m | 1.0~10.0 | 离地超过此距离才允许展开降落伞 |
| `CloseParachuteDistance` | 1.5 | m | 0.5~5.0 | 离地不足此距离时自动收起降落伞 |
| `openParachute`（过渡时长）| 0.5 | 秒 | 0.1~2.0 | `OpenParachute` → `Fly` 的过渡动画时间 |

### 3.6 自动瞄准辅助参数（`CharacterLocalAutoLockTarget`，可通过配置消息动态调整）

| 字段名 | 最小值 | 推荐范围 | 最大值 | 默认值 | 单位 | 说明 |
|--------|-------|---------|--------|--------|------|------|
| `LockMaxScreenDistance` | 10 | 50~120 | 200 | **80** | 屏幕像素 | 屏幕空间最大锁定半径 |
| `LockMinScreenDistance` | 5 | 5~20 | 50 | **10** | 屏幕像素 | 屏幕空间最小锁定半径 |
| `LockMaxDistance` | 10 | 50~150 | 300 | **100** | m | 世界空间最大锁定距离 |
| `LockSpeed` | 1 | 10~25 | 50 | **15** | — | 视角吸附速度（由 `CM_InputPlayer.AutoLockSpeed` 动态设置）|

> `LockSpeed` 通过 `CM_InputPlayer.AutoLockSpeed` 消息在运行时动态设置，不在配置表中，需通过代码传入。

### 3.7 视角同步参数（`CharacterLocalCamera`）

| 字段名 | 值 | 单位 | 说明 |
|--------|-----|------|------|
| `vRotaSendLimitTime` | 0.1 | 秒 | 相机垂直旋转上报服务器的限流间隔 |
| 编码精度 | ×10（short）| — | `vRota = Mathf.FloorToInt(角度 * 10)` 精度为 0.1° |

## 5. AI 意图识别增强规则

### 5.1 程度词→参数映射

| 程度词 | 乘数 | `MoveSpeed` | `JumpHeight` / `DoubleJumpHeight` | `slideSpeed` |
|--------|------|------------|----------------------------------|-------------|
| 一点点 / 稍微 | ×1.15 | ×1.15 | ×1.15 | ×1.15 |
| 比较 / 有点 | ×1.3 | ×1.3 | ×1.3 | ×1.3 |
| 很 / 挺 | ×1.6 | ×1.6 | ×1.6 | ×1.6 |
| 非常 / 超级 | ×2.0 | ×2.0 | ×2.0 | ×2.0 |
| 最 / 极限 | — | 取最大值 | 取最大值 | 取最大值 |
| 有点慢 / 偏慢 | ×0.85 | ×0.85 | — | ×0.85 |
| 比较慢 | ×0.7 | ×0.7 | — | ×0.7 |
| 很慢 | ×0.5 | ×0.5 | — | ×0.5 |

**示例**：
- 输入："把移速改得很快"
  - `MoveSpeed`: 600（当前值）× 1.6 = **960 cm/s**（裁剪至最大值 1200 内，合法）

### 5.2 手感描述词→参数映射

| 玩家描述 | 映射参数 | 推荐方向 | 关键参数 |
|---------|---------|---------|---------|
| 移速快/跑得快/灵活 | `MoveSpeed` 提升 | C01 | MoveSpeed 700~900 |
| 移速慢/厚重感/稳重 | `MoveSpeed` 降低 | C03 | MoveSpeed 350~500 |
| 跳跃高/蹦得高 | `JumpHeight` 提升 | C02 | JumpHeight 200~350cm |
| 二段跳好用/空中追加 | `DoubleJumpHeight` 提升 | C02 | DoubleJumpHeight 150~300cm |
| 血厚/耐打 | `Hp` 提升 | C03 | 各等级 Hp ×1.2~1.5 |
| 血少/脆 | `Hp` 降低 | C04 | 各等级 Hp ×0.7~0.8 |
| 滑铲快/流畅 | `slideSpeed` 提升 | C05 | slideSpeed 18~25 |
| 滑铲距离远/持续久 | `slideDuration` 提升 | C06 | slideDuration 2.0~3.5s |
| 自动瞄准强/锁定好用 | `LockMaxScreenDistance`/`LockSpeed` 提升 | C07 | Distance 100+, Speed 20+ |
| 自动瞄准弱/手动感 | `LockMaxScreenDistance`/`LockSpeed` 降低 | C08 | Distance 40~60, Speed 8~12 |

### 5.3 行为描述词→组件/参数映射

| 玩家描述 | 映射能力 | 工程实现 | 是否已支持 |

#### 6.2.1 必须追问的歧义场景

| 歧义场景 | AI 必须问 | ❌ 禁止行为 |
|---------|---------|-----------|
| **"跑得更快"歧义** | "是提升基础移速（所有英雄），还是某个特定英雄？还是通过技能临时加速？" | 默认修改所有英雄 |
| **"跳跃更好"歧义** | "是一段跳跳得更高，还是二段跳额外高度更大？还是两个都提升？" | 同时改两个不告知 |
| **"手感更灵活"歧义** | "是移速快、跳跃高、还是滑铲更流畅？还是三者都调整？" | 随机选一种改 |
| **"自动瞄准更强"歧义** | "是扩大锁定范围，还是提升吸附速度，还是两者都调？" | 把所有参数调最大 |
| **"三段跳/多段跳"** | "你想要几段跳？最多推荐 4 段。" | 直接修改 `jumpCount` 上限 |
| **"针对哪个英雄"不明确** | "是只调整某个特定英雄，还是调整所有英雄的这个参数？" | 默认调全部 |

#### 6.2.2 特殊描述标准应答

| 玩家描述 | AI 应答方式 | 处理方式 |
|---------|-----------|---------|
| "无限跳" | ⚠️ 当前上限推荐 4 段跳，过高会破坏游戏体验。可以改为更高的跳跃次数或更大的跳跃高度吗？ | 引导替代 |
| "飞起来" | ✅ 可以！降落伞系统已支持，需角色装备飞行器后二段跳触发 | 直接说明 |
| "不能滑铲" | ⚠️ 滑铲是基础能力，不能从系统层关闭。可以把滑铲速度调到最低（3 m/s）模拟无效果 | 引导替代 |
| "立刻移动（无加速过渡）" | ✅ 已是即时响应，`CharacterController.Move()` 无加速曲线 | 直接说明 |
| "移速无限快" | MoveSpeed 裁剪至 1200 cm/s，提示"已设置为上限 12 m/s，过快会影响游戏体验" | 裁剪并提示 |
| "所有英雄都改" | 将 `HeroLevel` 表中所有英雄的对应字段同步修改 | 直接执行 |

#### 6.2.3 ⚠️ 禁止规则（AI 绝对不能做的）

| 场景 | ❌ 禁止行为 | ✅ 正确做法 |
|------|-----------|----------|
| 描述不清 | 直接选"最常见的"方案修改 | 必须追问明确 |
| 技术不支持 | 承诺"无限跳"可以实现 | 引导替代（如"改为 4 段跳+更大跳跃高度"）|
| 参数越界 | 创建 MoveSpeed=5000 的角色 | 裁剪至上限并告知玩家 |
| 跨系统操作不告知 | 静默修改 Ability 系统参数来影响 3C 手感 | 明确说明"此修改涉及 Ability 系统" |

## 7. AI 处理流程

### Step 1：意图识别与分类

判断请求类型：
- **调参**：修改 `HeroLevel` 配置表（移速/跳跃高度/HP/Attack）
- **物理手感调整**：修改 `CharacterMoveToInput` 中的物理常量（`gravitey`/`weight`/`jumpPower`/`jumpTime`），影响全局跳跃曲线和下落手感
- **行为参数调整**：修改 `CharacterInputToSlideState`、`CharacterLocalAutoLockTarget` 等组件字段
- **Ability 层调整**：通过 `AE_MoveSpeedRate` 等实现运行时速度变化（跨系统）
- **特化需求**：需要程序修改的能力（如超过 4 段跳等极端情况）

### Step 2：作用域判断

- **全局**（所有英雄所有等级）→ 修改 `HeroLevel` 表所有行对应字段
- **按英雄**（特定英雄）→ 修改 `HeroLevel` 表对应 HeroId 的所有行
- **按英雄+等级**（特定英雄特定等级）→ 修改 `HeroLevel` 表对应 Id 的单行
- **行为层**（滑铲/瞄准等）→ 修改对应组件字段

### Step 3：参数边界验证

提取所有数值参数，应用第 3 章边界表验证：
- `MoveSpeed` 超过 1200 → 裁剪至 1200
- `JumpHeight` 超过 500 → 裁剪至 500
- `slideSpeed` 超过 30 → 裁剪至 30

### Step 4：预设包选择

应用第 5.2 节"手感描述词→参数映射"，确认是否需要组合预设（如 C01+C02）。

### Step 5：歧义检测与追问

检查是否触发第 6.2.1 节歧义场景。如有歧义，生成追问，等待玩家明确后再继续。

### Step 6：生成修改方案

- 直接输出 `HeroLevel.cs` 数据行的修改内容（AI 可直接修改数据行，后续再反录入 CSV 模板表）
- 输出需修改的组件字段（如 `CharacterInputToSlideState.slideSpeed = 20f`）
- 输出需修改的物理常量（如 `CharacterMoveToInput.cs` 中 `gravitey = 1.5f`），并说明影响范围（全局手感变更）
- 如涉及 Ability 系统，输出跨系统调用方案（见 Ability 系统边界定义文档）
- 如需特化，说明所需程序工作量

### Step 7：输出摘要与确认

```
✅ 已设计：快速敏捷型调整方案
- 移动速度：600 → 800 cm/s（6.0 → 8.0 m/s）
- 跳跃高度：150 → 200 cm（1.5 → 2.0 m）
- 二段跳高度：100 → 150 cm（1.0 → 1.5 m）
- 作用范围：所有英雄 / 英雄 1 所有等级
- 需修改文件：HeroLevel.cs（直接修改数据行，后续反录入 CSV）
```

## 8. 代码模板

### 8.1 通过 Ability 系统实现运行时移速调整（推荐方式）

当需要在游戏运行中临时修改角色移速（而非永久改配置表），应使用 Ability 系统的 `AE_MoveSpeedRate`：

```csharp
// 给目标角色施加加速效果（移速 ×1.3，持续 5 秒）
MsgRegister.Dispatcher(new SM_Ability.PlayAbilityEffect {
    FireGPO   = attackerGpo,   // 施放者
    TargetGPO = targetGpo,     // 目标角色
    MData     = AbilityM_MoveSpeedRate.CreateForSign("Speed_130_5s"),
    // M_SpeedRate = 1.3f, M_LifeTime = 5f
});
```

> 参考：[[Ability 系统内容边界定义]] 第 4.2 节 `AE_MoveSpeedRate`。

### 8.2 通过 Ability 系统实现技能触发滑铲

当需要通过释放技能触发滑铲（而非按闪避键），可通过 Ability 的 `CE_Ability.SkillSlide` 事件：

```csharp
// 在技能 System 中触发滑铲
mySystem.Dispatcher(new CE_Ability.SkillSlide {
    SlideSpeed    = 20f,   // 覆盖默认 slideSpeed=15f
    SlideHeight   = 0.5f,  // 覆盖默认 slideHeight=0.5f
    SlideDuration = 1.5f,  // 覆盖默认 slideDuration=1.2f
});
```

> `CharacterInputToSlideState` 监听 `CE_Ability.SkillSlide` 并会使用技能传入的参数，覆盖默认值。

### 8.3 击退/击飞效果（服务端发起）

当需要通过技能/机关对角色施加强制位移：

```csharp
// 击退（服务端 GPO Component 内）
Dispatcher(new SE_GPO.Event_Knockback {
    Dir      = knockbackDir,   // 击退方向（归一化 Vector3）
    Speed    = 20f,            // 击退速度（m/s）
    Duration = 0.5f,           // 击退持续时间（秒），推荐 0.2~1.0
});

// 击飞（服务端 GPO Component 内）
Dispatcher(new SE_GPO.Event_StrikeFly {
    Dir      = flyDir,   // 击飞方向（归一化 Vector3）
    Force    = 30f,      // 击飞力度
    Duration = 0.8f,     // 持续时间（秒）
});
```

> 服务端 `KnockbackGPO` / `StrikeFlyGPO` 组件会接收上述事件，并通过 `TargetRpc_Knockback` / `TargetRpc_StrikeFly` 发给对应客户端执行。

### 8.4 修改角色速度的正确流程（配置表 → 运行时同步）

```
1. 策划修改 HeroLevel.csv 中 MoveSpeed 字段
2. 重新生成 HeroLevel.cs（csv-gen 工具）
3. 服务端 ServerHeroAttribute.CreateAttribute() 读取新值：
     data.Speed = levelInfo.MoveSpeed * 0.01f; // 600 → 6.0 m/s
4. 服务端通过 ServerCharacterAttribute 将 Speed 同步给客户端：
     TargetRpc_Speed → ClientHeroAttribute.OnTargetRpcSpeedCallBack()
5. 客户端触发 CE_GPO.Event_SpeedChange：
     CharacterMoveToInput.speed = entData.NowSpeed;
```

> ⚠️ 不要跳过步骤 2 直接改 `.cs`——该文件标注了 `// Generated automatically by csv-gen: do not edit manually`。

## 9. 通用组件 vs 定制组件

### ⚠️ 9.0 AI 移动组件路由表（必读）

**调整 AI 角色的 3C 手感时，必须先查此表确认目标组件，不得靠文件名猜测。**

服务端 AI 移动组件有多个，按 AI 类型路由：

| AI 类型 | 服务端移动组件 | 文件路径 | 说明 |
|---------|-------------|---------|------|
| **人形角色 AI**（普通大兵/BOSS/英雄型 NPC）| `ServerCharacterAIMove` | `Server/AI/Components/Move/ServerCharacterAIMove.cs` | **最常用**，含完整跳跃/下落/滑铲/冲锋/NavMesh 寻路 |
| **非人形怪物 AI**（机器人/兽型等简单移动单位）| `ServerAIMoveForCharacter` | `Server/AI/Components/Move/ServerAIMoveForCharacter.cs` | 简化版，无滑铲/位移扩展 |
| 所有 AI 移动基类 | `ServerAIMove` | `Server/AI/Components/Move/ServerAIMove.cs` | ❌ 禁止修改（Base 类）|

**物理常量说明**：
- `ServerAIMove`（基类）声明了 `protected const float gravitey = 1f`
- 子类如需覆盖，必须用 `private new float gravitey = xxx` 在子类中声明，**不得修改基类**
- `ServerCharacterAIMove` 和 `ServerAIMoveForCharacter` 的 `FallMove` 逻辑略有差异（见下表），调参时需注意

| 组件 | FallMove 最大下落速度公式 |
|------|------------------------|
| `CharacterMoveToInput`（玩家）| `-weight * gravitey * 0.6f` |
| `ServerCharacterAIMove`（人形 AI）| `-weight * gravitey`（无 0.6 系数）|
| `ServerAIMoveForCharacter`（非人形 AI）| `-weight * gravitey`（无 0.6 系数）|

> 因此，**要让人形 AI 下落速度与玩家一致，AI 的 weight 应设为玩家 weight × 0.6**。

### 10.3 OnClear 必须做的事

```csharp
protected override void OnClear() {
    // 1. 注销所有 mySystem.Register（CE_Character.XXX / CE_GPO.XXX）
    // 2. 注销所有 MsgRegister.Unregister（CM_Character.XXX 等）
    // 3. 注销所有 AddProtoCallBack → RemoveProtoCallBack
    // 4. RemoveUpdate（如有 AddUpdate）
    // 5. 清空所有对象引用（controller = null, bodyTran = null 等）
}
```

### 10.4 关键注意事项

1. **`HeroLevel.cs` 是自动生成文件**：不得手动修改，通过 CSV 工具生成
2. **`gravitey`/`weight`/`jumpPower`/`jumpTime` 是 `const`**：不能运行时覆盖，改动影响所有角色的物理手感，必须程序审核
3. **移速同步链路**：CSV → `HeroLevel.MoveSpeed` → `ServerHeroAttribute.Speed` → `TargetRpc_Speed` → `ClientHeroAttribute` → `CE_GPO.Event_SpeedChange` → `CharacterMoveToInput.speed`；任何环节中断都会导致客户端速度不正确
4. **`Cmd_MoveDir` 是 Unreliable 通道**：移动指令可能丢失，客户端本地预测是主移动来源，服务端通过 `TargetRpc_MovePoint` 纠偏
5. **相机 VRota 有 0.1s 限流**：`Cmd_CameraVRota` 每 0.1s 最多发送一次，用于动画系统计算上半身朝向
