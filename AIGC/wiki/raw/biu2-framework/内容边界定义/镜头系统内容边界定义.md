## 1. 总则

### 1.1 AI 可以做什么

| 操作类型 | 说明 | 示例 | 需修改的文件 |
|---------|------|------|------------|
| **调参** | 修改现有镜头组件参数（旋转、远近、防穿墙、震动） | “把镜头再拉远一点，转向慢一些” | `CameraFar.cs` / `CameraRota.cs` |
| **行为组合** | 复用现有组件组合出新镜头体验，不新建框架 | “驾驶时镜头更贴近，步行时更远” | `CameraFar.cs` + `CameraRota.cs` + 消息调用 |
| **事件接入** | 在现有消息体系中增加调用点 | “开火时加入轻微抖动” | 调用 `CM_Camera.ShakeCamera` 的业务代码 |
| **能力开关** | 切换输入旋转、插值模式、自动锁定 | “剧情期间禁用玩家转镜头” | 派发 `CM_Camera.EnablePlayerInputToRotateCamera` |
| **查询能力接入** | 接入准心命中点/可见目标查询 | “技能读取准心命中位置” | 调用 `CM_Camera.GetCameraCenterObjPoint` |

**唯一限制**：不修改框架层/底层基类（`SystemBase`、`EntityBase`、消息总线核心）。仅在镜头系统已有组件与消息协议内扩展。

**工程上已支持的通用能力（可直接复用）**：

| 能力 | 工程机制 | 关键类/消息 |
|------|---------|-----------|
| 角色跟随 | 根节点跟随 `CameraLook` 骨骼 | `CameraMove` + `CM_GPO.AddLookGPO` |
| 水平/垂直旋转 | 输入驱动 `HRota` / `VRota` | `CameraRota` + `CM_Camera.SetDelta` |
| 垂直角度限制 | 普通/驾驶双区间夹角 | `CameraRota.DefaultAxis()` |
| 自动锁定 | 前方角度、屏幕范围、遮挡过滤 | `CameraAutoLockTarget` |
| 辅助瞄准 | 吸附/减速系数动态计算 | `CameraAimAssist` + `AimAssistSet` |
| 防穿墙 | SphereCast 回推 + nearClip 调整 | `CameraCollisionHandler` |
| 镜头震动 | Perlin 噪声位移/旋转震动 | `CameraShake` + `CM_Camera.ShakeCamera` |
| 准心查询 | 中心射线命中点/GPO/障碍查询 | `GetCameraCenterGPO` |
| 可见性查询 | 视锥 + 遮挡筛选 | `GetCameraVisibleGPO` |

### 1.2 镜头系统职责

镜头系统是**纯客户端系统**，负责相机的输入响应、目标跟随、旋转限制、自动锁定、碰撞规避与可见性查询。它与以下系统协作：

- **3C 系统**：`CharacterLocalCamera` 接收 `CM_Camera.CameraHVRota` 同步角色朝向，并以 `Cmd_CameraVRota` 上报垂直角度。
- **枪械系统**：射击目标点通过 `CM_Camera.GetCameraCenterObjPoint` 获取。
- **GPO 系统**：通过 `CM_GPO.AddLookGPO` 绑定跟随对象（角色/载具/观战目标）。

### 1.3 数据与消息结构

```
镜头层
├── CameraSystem / CameraEntity         ← 组件容器与 Transform 层级
├── CameraMove / CameraFar / CameraRota ← 跟随、远近、旋转
├── CameraAimAssist / CameraAutoLockTarget
├── CameraCollisionHandler / CameraShake
├── GetCameraCenterGPO / GetCameraVisibleGPO
└── CM_Camera / CE_Camera               ← 世界消息与系统内消息
```

> ⚠️ 镜头系统无服务端 Proto 专属协议层；网络同步仅通过 3C 侧角色网络命令完成（如 `Proto_Character.Cmd_CameraVRota`）。

## 2. 镜头能力模板库

### 2.1 模板分类体系

#### 🔵 A 类：通用调参（无需新建组件）

| 模板 | 能力 | 关键参数 | 目标 |
|------|------|---------|------|
| C01 | 旋转手感 | `baseRotaSpeed`、插值开关 | 提升/降低转向灵敏度 |
| C02 | 俯仰范围 | 普通 `[-65°, 75°]`、驾驶 `[-45°, 60°]` | 控制视野上抬/下压 |
| C03 | 跟随距离 | `CameraFar` 的 `point(x,y,z)` 与 `LerpRate` | 第三人称距离风格 |
| C04 | 防穿墙强度 | `SPHERE_RADIUS`、`nearClip` 参数 | 近墙可视稳定性 |
| C05 | 镜头震动 | `Duration/Magnitude/DampingSharpness` | 打击反馈强度 |
| C06 | 自动锁定 | `maxDistance/maxAngle` 与筛选策略 | 手柄/移动端辅助瞄准 |

#### 🟡 B 类：消息组合（无需新建架构）

| 模板 | 组合方式 | 场景 |
|------|---------|------|
| C07 | `EnablePlayerInputToRotateCamera` + `SetLockTargetDelta` | 剧情/过场临时控镜 |
| C08 | `SetCameraOffset` + `AddLookGPO(IsDrive)` | 驾驶态镜头切换 |
| C09 | `ShakeCamera` + `GetCameraCenterObjPoint` | 武器命中反馈一体化 |
| C10 | `FindCenterGPOInFrontForLockRadius` + `LockTarget` | 自动吸附瞄准 |

#### 🔴 C 类：特化开发（需要新组件）

| 需求 | 原因 |
|------|------|
| 分屏/双相机同步 | 现有系统仅单 CameraEntity |
| 电影轨道镜头（路径关键帧） | 当前无 Timeline/轨道组件 |
| 高级摄影机状态机（多镜头混合） | 当前组件为并列执行，不含状态机容器 |

## 3. 参数规范

> ⚠️ AI 必须将用户描述值裁剪到可用边界。超限时需提示“已按上/下限调整”。

### 3.1 旋转与输入参数（`CameraRota`）

| 字段/能力 | 当前值 | 推荐范围 | 极限值 | 说明 |
|----------|-------|---------|-------|------|
| `baseRotaSpeed` | 0.5 | 0.3~0.9 | 0.1~2.0 | 基础旋转倍率 |
| 普通俯仰角 | -65°~75° | 保持 | 不建议突破 | `ClampVRotaAroundXAxis` 固定夹角 |
| 驾驶俯仰角 | -45°~60° | 保持 | 不建议突破 | 驾驶时减小俯仰 |
| 插值加速度 `baseAcceleration` | 60 | 30~90 | 10~200 | 开启 `EnabledCameraLeap` 时生效 |
| 插值倍率 `maxAccelerationMultiplier` | 3 | 2~4 | 1~8 | 过大会突变 |
| 输入禁用开关 | `DisablePlayerInput` | bool | bool | 剧情/锁定镜头期使用 |

### 3.2 跟随与远近参数（`CameraMove` / `CameraFar`）

| 字段/能力 | 当前值 | 推荐范围 | 极限值 | 说明 |
|----------|-------|---------|-------|------|
| `CameraMove.speed` | 20 | 10~30 | 1~60 | 根节点追随速度 |
| `DEFAULT_LERP_RATE` | 3 | 2~6 | 1~20 | 距离变化平滑率 |
| 步行默认偏移 | `(0.7,0.6,-5.25)` | z:-4.5~-6.0 | z:-1~-10 | 普通第三人称 |
| 驾驶默认偏移 | z 约 `-3~-5` | -3~-6 | -1~-10 | 根据移动状态切换 |
| `SetCameraOffset.LerpRate` | 默认 3 | 2~8 | 0.5~20 | 0 时回退默认值 |

### 3.3 自动锁定与辅助瞄准（`CameraAutoLockTarget` / `CameraAimAssist`）

| 字段/能力 | 当前值 | 推荐范围 | 极限值 | 说明 |
|----------|-------|---------|-------|------|
| `maxDistance` | 100m | 50~120 | 10~300 | 自动找目标距离 |
| `maxAngle` | 60° | 30~75 | 10~120 | 前方角度阈值 |
| 解锁阈值 | `|dx|+|dy| > 6` | 4~10 | 1~30 | 玩家大幅拖拽时取消锁定 |
| `cameraLockCircleRadiusScale` | 1 | 0.8~1.5 | 0.2~3 | 吸附半径缩放 |
| `cameraSlowDownCircleRadiusScale` | 1 | 0.8~1.5 | 0.2~3 | 减速半径缩放 |

### 3.4 防穿墙参数（`CameraCollisionHandler`）

| 字段 | 当前值 | 推荐范围 | 极限值 | 说明 |
|------|-------|---------|-------|------|
| `SPHERE_RADIUS` | 0.3 | 0.2~0.5 | 0.05~1.0 | 防穿墙球体半径 |
| `defaultNearClip` | 0.3 | 0.2~0.4 | 0.05~1.0 | 正常近裁剪面 |
| `minNearClip` | 0.05 | 0.03~0.1 | 0.01~0.3 | 贴墙时近裁剪面 |
| `GetLookOffset()` | `(0.3,0.3,-0.2)` | 小幅微调 | 谨慎修改 | 射线起点偏移 |

### 3.5 震动参数（`CameraShake`）

| 字段 | 默认值 | 推荐范围 | 极限值 | 说明 |
|------|-------|---------|-------|------|
| `Duration` | 0.5s | 0.05~0.35 | 0.01~2.0 | 震动时长 |
| `Magnitude` | 0.1 | 0.03~0.2 | 0.01~0.8 | 位移幅度 |
| `DampingSharpness` | 2 | 1~5 | 0.1~10 | 衰减速度 |
| `MaxRotationAngle` | 10° | 1~6 | 0~20 | 旋转震动上限 |
| `NoiseFrequency` | (2,2,0) | 1~5 | 0~20 | Perlin 噪声频率 |
| `AffectRotation` | false | bool | bool | 是否叠加旋转震动 |

### 3.6 查询能力固定参数（只读）

| 常量 | 值 | 说明 |
|------|----|------|
| `AI_PREDICTED_RATE` | 6.0 | AI 网络点预测倍率 |
| `PLAYER_PREDICTED_RATE` | 2.4 | 玩家网络点预测倍率 |
| `GetCameraVisibleGPO.CLOSET_DISTANCE` | 60.0 | 可见性检测距离阈值 |
| `GetCameraVisibleGPO.CLOSET_ANGLE` | 180 | 可见角度阈值（配合前向点积） |
| `CharacterLocalCamera` 上报限流 | 0.1s | 垂直角度网络上报节流 |

## 4. 镜头行为预设包

### 4.1 预设包一览

| 预设码 | 名称 | 核心机制 | 关键参数 |
|--------|------|---------|---------|
| **CAM01** | 稳定跟随 | 拉高平滑，降低抖动 | `LerpRate=4~6`，`Magnitude<=0.08` |
| **CAM02** | 灵敏转向 | 提升旋转响应 | `baseRotaSpeed=0.6~0.9` |
| **CAM03** | 重量镜头 | 降低旋转速度 + 略增距离 | `baseRotaSpeed=0.3~0.45`，`z=-5.5~-6` |
| **CAM04** | 驾驶宽视角感 | 驾驶偏移后拉 + 限制俯仰 | `IsDrive=true` + `z=-4.5~-5.5` |
| **CAM05** | 强辅助瞄准 | 吸附圈与减速圈扩大 | `LockScale/SlowDownScale=1.2~1.5` |
| **CAM06** | 弱辅助瞄准 | 缩小辅助圈 | `LockScale/SlowDownScale=0.7~0.9` |
| **CAM07** | 轻武器后坐反馈 | 短时低幅震动 | `Duration=0.08~0.15`，`Magnitude=0.04~0.1` |
| **CAM08** | 爆炸冲击反馈 | 中时高幅震动 | `Duration=0.2~0.35`，`Magnitude=0.12~0.25` |

### 4.2 互斥与组合规则

| 预设 A | 预设 B | 关系 | 说明 |
|--------|--------|------|------|
| CAM02（灵敏） | CAM03（重量） | ❌ 互斥 | 手感目标相反 |
| CAM05（强辅助） | CAM06（弱辅助） | ❌ 互斥 | 仅保留一套辅助强度 |
| CAM01（稳定） | CAM07/CAM08（震动） | ✅ 可组合 | 平时稳定，事件触发震动 |
| CAM04（驾驶） | CAM01（稳定） | ✅ 可组合 | 驾驶镜头建议加平滑 |

### 4.3 复合预设示例

| 需求描述 | 预设组合 | 建议 |
|---------|---------|------|
| “手柄玩家希望更好锁目标” | CAM02 + CAM05 | 提升旋转速度并增强吸附圈 |
| “PVE 想要电影感一点” | CAM01 + CAM03 | 转向更稳、镜头更后 |
| “爆炸武器打击感要明显” | CAM01 + CAM08 | 平时稳定，命中事件触发强震动 |

## 5. AI 意图识别增强规则

### 5.1 程度词→参数映射

| 程度词 | 旋转速度 | 跟随/平滑 | 震动幅度 |
|--------|---------|---------|---------|
| 稍微 | ×1.15 | ×1.15 | ×1.15 |
| 比较 | ×1.3 | ×1.3 | ×1.3 |
| 很/明显 | ×1.6 | ×1.5 | ×1.6 |
| 非常/强烈 | ×2.0 | ×1.8 | ×2.0 |
| 极限 | 裁剪至上限 | 裁剪至上限 | 裁剪至上限 |

### 5.2 关键词→能力映射

| 用户关键词 | 映射能力 | 默认处理 |
|-----------|---------|---------|
| 镜头太晃 | 震动减弱 / 平滑增强 | 降低 `Magnitude`，提高 `LerpRate` |
| 转镜头太慢 | 旋转速度调整 | 提升 `baseRotaSpeed` |
| 视角太近/太远 | 远近偏移调整 | 调整 `CameraFar` 的 z |
| 自动瞄准不明显 | 辅助瞄准增强 | 提升锁定/减速圈缩放 |
| 贴墙穿模 | 防穿墙增强 | 调整 `SPHERE_RADIUS` 与 nearClip 逻辑 |
| 开火反馈弱 | 事件震动 | 接入 `ShakeCamera` |

### 5.3 行为意图 → 预设包匹配

| 玩家描述 | 匹配预设 | 优先级 |
|---------|---------|--------|
| 跟随要稳、不晃、电影感 | CAM01 稳定跟随 | 高 |
| 转向更快、拉枪更灵敏 | CAM02 灵敏转向 | 高 |
| 镜头更沉、更重 | CAM03 重量镜头 | 中 |
| 开车/开飞机镜头要区分 | CAM04 驾驶宽视角感 | 高 |
| 自动瞄准更明显 | CAM05 强辅助瞄准 | 中 |
| 自动瞄准弱一点 | CAM06 弱辅助瞄准 | 中 |
| 枪后坐反馈 | CAM07 轻武器后坐反馈 | 中 |
| 爆炸冲击感 | CAM08 爆炸冲击反馈 | 中 |

### 5.4 复合描述拆解方式

```
Step 1：先判定场景（步行/驾驶/观战/剧情）
Step 2：提取手感词（稳、快、重）→ 映射 CAM01/02/03
Step 3：提取辅助词（自动瞄准强弱）→ 映射 CAM05/06
Step 4：提取事件词（开火/爆炸/受击）→ 映射 CAM07/08
Step 5：检查互斥（CAM02 vs CAM03、CAM05 vs CAM06）
Step 6：输出组合方案 + 参数裁剪说明
```

**拆解示例：**

```
玩家："驾驶坦克时镜头更远，平时转向要更灵敏，爆炸要更震"
1) 驾驶镜头更远 → CAM04（按载具分型，坦克 z 后拉）
2) 平时转向更灵敏 → CAM02（baseRotaSpeed 上调）
3) 爆炸更震 → CAM08（仅爆炸事件触发）
4) 无互斥冲突，组合生效
```

### 5.5 技术安全底线（唯一不可绕过的规则）

| 规则 | 原因 |
|------|------|
| 组件事件必须在 `OnAwake` 注册、`OnClear` 注销 | 防止事件泄漏 |
| 禁止在高频 `Update/LateUpdate` 中新增分配热点（`new`/LINQ） | 保证客户端帧稳定 |
| 不修改镜头框架基类与消息总线核心 | 保持架构边界 |
| 驾驶分型必须按 `GpoMTypeID` 路由 | 防止资源名/字符串耦合 |
| 自动瞄准与震动开关必须可配置可回退 | 保障竞技/可访问性需求 |

## 6. 意图理解规范

### 6.1 必须追问的歧义场景

| 歧义场景 | AI 必须问 | ❌ 禁止行为 |
|---------|---------|-----------|
| “镜头更舒服” | “你更关注旋转速度、远近距离，还是震动强度？” | 不经确认同时改全部 |
| “自动瞄准更强” | “是希望更容易锁定，还是锁定后转向更快？” | 直接把所有辅助参数拉满 |
| “驾驶镜头要改” | “仅驾驶态改，还是步行与驾驶都改？” | 默认全局修改 |
| “镜头震动更强” | “只对爆炸生效，还是所有开火都生效？” | 全事件统一增强 |

### 6.2 特殊描述标准应答

| 玩家描述 | AI 应答方式 | 处理 |
|---------|-----------|------|
| “不要自动瞄准” | 可将锁定圈缩放降到接近 0 | 保留机制但弱化到最小 |
| “镜头完全不受墙影响” | 当前不支持忽略碰撞；可改为更激进回推 | 调整防穿墙参数 |
| “无限旋转看上下” | 不建议破坏俯仰夹角 | 保持 clamp，给出安全范围 |
| “震动越大越好” | 需提醒眩晕风险并裁剪 | 按上限裁剪并提示 |

### 6.3 模糊意图处理规范（禁止猜测）

| 歧义场景 | AI 必须问的问题 | ❌ 禁止行为 |
|---------|---------------|-----------|
| “镜头更爽” | “你希望优先提升：转向速度、距离、还是震动反馈？” | 默认全改 |
| “驾驶镜头要改” | “只改坦克，还是直升机/机枪位也一起改？” | 默认所有载具同参 |

## 9. 通用组件 vs 定制组件

### 9.1 通用组件（默认在 `CameraSystem` 注册）

| 组件 | 职责 |
|------|------|
| `CameraMove` | 跟随目标骨骼 |
| `CameraFar` | 距离/偏移控制 |
| `CameraRota` | 输入旋转与角度限制 |
| `CameraAimAssist` | 吸附/减速系数计算 |
| `CameraAutoLockTarget` | 目标选择与锁定旋转 |
| `CameraCollisionHandler` | 防穿墙与近裁剪调整 |
| `CameraShake` | 震动表现 |
| `GetCameraCenterGPO` | 准心命中查询 |
| `GetCameraVisibleGPO` | 可见性查询 |

### 9.2 需要新建定制组件的场景

| 场景 | 需新建 |
|------|------|
| 轨道电影镜头 | `CameraCinematicTrack`（示例命名） |
| 多目标构图（Boss+玩家同屏） | `CameraMultiTargetComposer` |
| 回放自由镜头 | `CameraReplayFreeLook` |

## 10. 开发规范

1. **优先消息驱动**：优先新增 `CM_Camera`/`CE_Camera` 调用，不要硬耦合跨系统引用。  
2. **保持节点职责单一**：`HRota/VRota/Far/Shake` 分层不混用。  
3. **先复用后新增**：已有组件能覆盖需求时，不新建镜头系统架构。  
4. **防眩晕优先**：震动、旋转速度、近裁剪参数必须经过边界裁剪。  
5. **纯客户端边界**：镜头系统内不直接引入服务端玩法逻辑。

## 11. 已决策项归档

### 11.1 已确认规则（2026-03-20）

1. **平台参数策略**：不按平台拆分，手柄/触屏/PC 统一使用同一套镜头参数。  
2. **竞技模式自动瞄准**：允许进入竞技模式。  
3. **震动作用对象**：不按 `localRole` 区分；只对当前 `lookRole` 生效。  
4. **驾驶镜头策略**：需要按载具类型拆分配置（至少区分坦克/直升机/机枪位）。  

### 11.2 驾驶镜头分型落地约束

1. 优先复用 `CameraFar.GetCameraFarPoint()` 现有分支，不改框架层。  
2. 新增载具差异参数时，按 `GpoMTypeID` 分型，不使用硬编码字符串。  
3. 至少覆盖：坦克、直升机、机枪位；其余类型默认回退通用配置。  
4. 所有分型配置需保持 `CM_GPO.AddLookGPO(IsDrive=true)` 链路兼容。
