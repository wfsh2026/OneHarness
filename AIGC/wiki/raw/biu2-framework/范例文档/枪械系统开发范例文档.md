### 1.2 Server / Client 逻辑划分

| 职责 | Server | Client |
|------|--------|--------|
| 游戏逻辑判断 | ✅ 射击间隔、弹夹管理、伤害计算 | ❌ |
| 子弹生成 | ✅ SM_Ability.PlayAbility | ❌ |
| 武器属性 | ✅ ServerGunAttribute | 同步副本 ClientGunAttribute |
| 弹夹弹药 | ✅ ServerGunMagazine | 同步副本 ClientGunMagazine |
| 输入接收 | ❌ | ✅ CM_InputPlayer.Fire |
| 网络 Cmd | ❌ | ✅ Cmd_GunFire, Cmd_Reload |
| 网络 Rpc | ✅ Rpc_GunFire, Rpc_Reload | ❌ |
| 动画驱动 | ❌ | ✅ ClientGunAnim |
| 特效 | ❌ | ✅ ClientGunVfx |
| UI 弹药显示 | ❌ | ✅ CM_Weapon.BulletChange |

### 1.3 GPO 与 CharacterWeapon 的关系

```
GPO（Game Play Object）= 游戏中所有可以持有武器的实体（角色、AI、宠物等）

CharacterWeapon    = GPO武器系统 针对「本地玩家角色」的专化子类
                     处理玩家输入、网络Cmd 发送、换弹动画驱动

GPO武器继承体系：
  ServerGPOWeapon         ─ 通用服务器GPO武器控制器
    └── ServerCharacterWeapon   ─ 玩家角色专化（重写 GetWeaponComponent）

  ServerGPOWeaponPack     ─ 通用服务器武器背包
    └── ServerCharacterWeaponPack  ─ 玩家角色专化（监听 Cmd_UseWeapon）

  ClientGPOWeapon         ─ 通用客户端GPO武器控制器
    └── CharacterOtherWeapon    ─ 其他玩家角色

  ClientGPOWeaponPack     ─ 通用客户端武器背包
    └── CharacterLocalWeaponPack   ─ 本地玩家（监听 CM_InputPlayer.UseWeapon）
```

## 三、数据结构设计

### 3.1 WeaponData

**路径**: `Assets/Scripts/Data/WeaponData.cs`

```csharp
namespace Sofunny.BiuBiuBiu2.Data {
    public partial class WeaponData {

        // 武器大类枚举
        public enum WeaponType { Gun, Melee }

        // 通用武器数据
        public class Data {
            public int ItemId;
            public WeaponType WeaponType;
            public int ATK, DEF, Hp;
            public float AttackRange;
        }

        // 枪械专用数据（继承 Data）
        public class GunData : Data {
            public float StartFireWaitTime; // 开火蓄力等待时间（如加特林）
            public float FireRange;         // 扩散半径
            public float IntervalTime;      // 射击间隔（毫秒）
            public float ReloadTime;        // 换弹时间（毫秒）
            public float FireDistance;      // 有效射程（厘米，除以100得米）
            public int   MagazineNum;       // 弹夹容量
            public int   FireBulletNum;     // 每次开火子弹数量（霰弹枪>1）
            public bool  IsCanAutoLock;     // 是否自动瞄准
            public bool  IsCanAutoFire;     // 是否可自动开火（AI）
            public float FireOverHotTime;   // 过热时间
            public float FireOverHotCDTime; // 过热 CD 冷却时间
            public float BulletSpeed;       // 子弹速度
            public float MoveSpeed;         // 持枪移动速度
            public int   SightStyle;        // 瞄准准星类型（1=圆形，2=横排）
            public CanUseBulletData[] CanUseBullet;     // 可用子弹列表
            public List<BulletAttnMap>  BulletAttnMaps; // 射程衰减曲线
        }

        // 距离-伤害衰减映射
        public class BulletAttnMap {
            public float MinDistanceRatio; // 最小距离比（0~1）
            public float MaxDistanceRatio; // 最大距离比（0~1）
            public float MinHurtRatio;     // 最小伤害比（0~1）
            public float MaxHurtRatio;     // 最大伤害比（0~1）
        }
    }
}
```

**数据加载流程**:
1. 调用 `WeaponData.Init()` 从策划配表 `WeaponSet.Data` 读取数据
2. 对特殊武器（Gatling、FireGun 等）在 `UpdateGunData()` 中追加特化配置
3. 运行时通过 `WeaponData.Get(itemId)` 查询数据

**特殊 ItemId 特化配置位置**（`WeaponData.cs`，`UpdateGunData` 方法）:
```csharp
// 例：为 Gatling 配置过热冷却时间和专用子弹类型
case ItemSet.Id_Gatling:
    weaponData.StartFireWaitTime = 0.4f;
    weaponData.FireOverHotCDTime = 2f;
    weaponData.CanUseBullet = new[] { new CanUseBulletData { BulletId = BulletData.Bullet_Gatling, isUnlimited = true } };
    break;
```

## 四、枪械开火完整流程

```
1. 玩家按下开火键
   └─ MsgRegister 发出 CM_InputPlayer.Fire { IsDown = true }

2. CharacterLocalWeapon.OnFireCallBack
   └─ 检查 IsCanFire()（死亡/控制状态/禁射标记）
   └─ 调用 characterWeapon.Fire1(isDown=true)

3. CharacterLocalWeapon_Gun.Fire1
   └─ mySystem.Dispatcher(CE_Weapon.StartFire) → 角色动画层触发持枪动画
   └─ iWeapon.Dispatcher(CE_Weapon.StartFire)  → 武器系统启动开火状态机

4. C_Weapon_Base（客户端武器系统）接收 StartFire
   └─ ClientAttackGunFire 组件: 按照 IntervalTime 循环触发 CE_Weapon.Fire

5. CharacterLocalWeapon_Gun.OnFireCallBack
   └─ 发送网络 Cmd:
      Cmd(new Proto_Weapon.Cmd_GunFire {
          weaponId    = iWeapon.GetWeaponId(),
          startPoint  = 枪口位置,
          targetPoint = 瞄准目标点
      })

   └─ ServerCharacterWeapon_Gun.OnCmdGunFireCallBack

   └─ 通过 SM_Ability.PlayAbility 生成子弹 Ability 实例:

    └─ SetBullet(UseBulletNum - 1) → 弹药-1
    └─ SendNowBulletNum() → SE_Weapon.Event_NowBulletNum
    └─ CheckReload() → 子弹耗尽自动换弹

11. ServerGPOWeapon_Gun.OnPlayFireCallBack
    └─ fireCallBack.Invoke(bulletData) → 外部开火回调
    └─ Rpc(new Proto_Weapon.Rpc_GunFire { isTrue = true })  ← 广播给所有客户端

12. 所有客户端接收 Rpc_GunFire
    └─ ClientGPOWeapon_Gun.OnRpcGunFireCallBack
    └─ GunFire(isTrue=true)
       └─ mySystem.Dispatcher(CE_Weapon.Fire)   → 触发角色开火动画
       └─ iWeapon.Dispatcher(CE_Weapon.Fire)    → 触发武器 ClientGunAnim

13. ClientGunAnim.OnFireCallBack
    └─ playable.PlayAnimSign(GunAnimConfig.Play_Fire, callback)
       // 开火动画播完后若未持续开火则回到 Idle
```

### 5.3 无动画时的占位方案

当新枪械尚未配置动画资源时，有以下占位方案：

**方案A：跳过 ClientGunAnim 组件（推荐）**

> ⚠️ **重要**：`ClientGunAnim` 在 `OnSetEntityObj` 时读取枪模型上的 `Animator` 组件（`entity.WeaponAnim`）。  
> 程序化 Box / Sphere 占位 **没有 Animator**，添加此组件会抛 **`PlayableController Init animator is null`** 并崩溃。  
> **必须注释掉 `ClientGunAnim`，待真实枪模型 Prefab 就绪后再启用。**

```csharp
// 在客户端枪械系统的 OnAwake 中，注释掉 ClientGunAnim
private void AddComponents() {
    AddComponent<ClientGunVfx>();
    // AddComponent<ClientGunAnim>(); ← 暂时跳过：Box 占位无 Animator，否则崩溃
    AddComponent<ClientGunAttribute>();
    AddComponent<ClientAttackGunFire>();
    AddComponent<ClientGunMagazine>();
}
```

**Box 占位模型的 Pivot 对齐规范**

`CharacterLocalWeapon.SetWeaponParent()` 调用 `EntityBase.SetParent()`，会把实体根节点 reset 到 **(0,0,0)**（localPosition = zero，localRotation = identity）。  
因此：**枪械实体根节点的 (0,0,0) = 手骨位置**。

如果握把中心偏离根节点，角色的手会落在枪管或枪身上，而非握把：

```csharp
// ❌ 错误：握把在根节点 Y=-0.07，手骨落在枪管上
barrel.transform.localPosition = new Vector3(0f,  0f,   0.22f);
grip.transform.localPosition   = new Vector3(0f, -0.07f, -0.05f);

// ✅ 正确：以握把中心为原点，让根节点 = 手骨 = 握把中心
barrel.transform.localPosition = new Vector3(0f, 0.07f, 0.22f);   // 枪管在握把上方
grip.transform.localPosition   = new Vector3(0f, 0f,   -0.05f);   // 握把在根节点
```

> **规律：把"手握住的位置"设为子部件 Y=0 的参考点，其余部件以此为基准偏移。**

**方案B：注册空的 AnimConfig 占位**

### 8.4 新增子弹 Ability 的完整步骤

## 九、AI 自动开火（ServerAttackAutoFire）使用详解

### 9.1 功能概述

`ServerAttackAutoFire` 是枪械的 **AI 自动瞄准开火组件**，专用于：
- AI 控制的角色（`GPOType.RoleAI`）
- 怪物 NPC 持枪自动攻击
- 不需要玩家输入驱动的自动枪械（如炮台）

**触发条件**：`ServerGPOWeapon_Gun.EnabledAutoFire()` 调用 `weapon.Dispatcher(SE_Weapon.Event_EnabledAutoFire { IsTrue = true })`

---

### 9.2 自动开火启用/禁用逻辑

```csharp
// ServerGPOWeapon_Gun.EnabledAutoFire
protected void EnabledAutoFire() {
    var isTrue = !mySystem.HasTag(GamePlayTagData.TagEnum.Dead) // 未死亡
              && WarData.TestIsAIFire                           // 调试开关（全局AI开火总开关）
              && canAutoFire;                                   // 该GPO的autoFire标记
    weapon?.Dispatcher(new SE_Weapon.Event_EnabledAutoFire { IsTrue = isTrue });
}

// ServerCharacterWeapon_Gun.OnUpdate 中动态切换
// isCharacterNetwork=true（玩家网络连接）→ 禁用自动开火（玩家自己控制）
// isCharacterNetwork=false（AI/离线状态）→ 启用自动开火
protected void SetCanAutoFire(bool canAutoFire) {
    this.canAutoFire = canAutoFire;
    EnabledAutoFire();
}
```

---

### 9.3 目标选择逻辑

`FindNearestGPOInFront()` 每秒执行一次（`checkLockGPO = 1.0f`），在视野锥内寻找最近可攻击目标：

```
筛选条件：
  1. 非死亡、非无敌（无 Dead/GodMode Tag）
  2. 非同队（TeamID 不同）
  3. 非场景元素（GPOType != SceneElement）
  4. 在有效射程内（distance <= maxDistance，来自 FireDistance）
  5. 水平视角 ≤ maxYawAngle（默认30°）
  6. 垂直视角 ≤ maxPitchAngle（默认70°）
  7. 无障碍物遮挡（Physics.RaycastNonAlloc 检测）

命中点选择（随机）：
  20% 概率瞄准 Head 骨骼
  80% 概率瞄准 Body 骨骼
```

---

### 9.4 最小射击间隔保护

AI 角色的射击间隔有下限保护，防止 AI 射击过快：

```csharp
private const float AI_MIN_ATTACK_INTERVAL = 0.15f;

private float GetFireInterval() {
    if (useGPO.GetGPOType() == GPOData.GPOType.RoleAI) {
        return Mathf.Max(AI_MIN_ATTACK_INTERVAL, intervalTime); // 不低于0.15秒
    }
    return intervalTime;
}
```

---

### 9.5 开发新 AI 武器时的注意事项

| 场景 | 处理方式 |
|------|----------|
| AI 武器希望自动攻击 | 确保 System 中包含 `ServerAttackAutoFire`，并在 `EnabledAutoFire()` 中设置 `canAutoFire = true` |
| AI 武器**不需要**自动攻击 | 在 System 的 `AddComponents()` 中不添加 `ServerAttackAutoFire` |
| 玩家控制的枪需要 AI 代打 | 由 `ServerCharacterWeapon_Gun.OnUpdate` 动态切换（网络断开时自动启用） |
| 自定义 AI 目标选择 | 继承 `ServerAttackAutoFire` 并覆写 `FindNearestGPOInFront()` |
| 调整 AI 攻击范围 | 修改 `maxYawAngle`（水平）和 `maxPitchAngle`（垂直），默认 30°/70° |

## 十、枪械与镜头系统的调用关系

枪械系统（客户端）需要与镜头系统交互的场景有 3 个：目标点获取、镜头震动、辅助瞄准配置。

### 10.1 开火目标点获取（必须通过镜头系统）

**为什么不能用 `fireBox.forward`**：
- 玩家看到的准心方向由镜头（CameraRota）决定，与枪口朝向有偏差
- 必须从镜头中心向前发射射线，才能保证子弹打到玩家准心对准的位置

```
[客户端武器 OnFireRequest]
     │
     ▼
MsgRegister.Dispatcher(CM_Camera.GetCameraCenterObjPoint {
    CheckForwardPoint = fireBox.position,   // 枪口世界坐标（射线起点修正用）
    FarDistance       = gunData.FireDistance,
    IgnoreTeamId      = iGPO.GetTeamID(),
    CallBack          = OnGetTargetPoint
})
     │
     ▼ [GetCameraCenterGPO 组件]
  摄像机中心向前 Raycast
     │
     ▼ CallBack(Vector3 targetPoint, bool isHit)
  mySystem.Dispatcher(CE_GPO.Event_OnDeviceFire {
      Points = new[] { targetPoint }
  })
     │
     ▼ [CharacterLocalWeapon_Gun / ClientAttackGunFire]
  发送 Cmd_GunFire { TargetPoint = targetPoint }
```

**标准实现模板**：
```csharp
// 在 ClientAttackGunFire 或 ClientXxxGunSystem 的开火逻辑中
private void RequestFireTargetPoint() {
    MsgRegister.Dispatcher(new CM_Camera.GetCameraCenterObjPoint {
        CheckForwardPoint = GetFireBoxPosition(),
        FarDistance       = gunData.FireDistance,
        IgnoreTeamId      = iGPO.GetTeamID(),
        CallBack          = OnTargetPointGot,
    });
}

private void OnTargetPointGot(Vector3 targetPoint, bool isHit) {
    mySystem.Dispatcher(new CE_GPO.Event_OnDeviceFire {
        Points = new Vector3[] { targetPoint }
    });
}
```

---

### 10.2 开火镜头震动

**触发条件**：武器的 `iGPO` 是当前 `LookGPO`（而非 `iGPO.IsLocalGPO()`）。  
理由：观战模式下，LookGPO 是被观战角色，该角色开枪时也应触发本地玩家的镜头震动。

```csharp
// 在武器 ClientSystem 中跟踪当前 LookGPO
private IGPO lookGPO;

protected override void OnAwake() {
    // 订阅镜头绑定事件
    MsgRegister.Register<CM_GPO.AddLookGPO>(ent => lookGPO = ent.LookGPO);

    // 订阅开火事件
    Register<CE_Weapon.Fire>((body, ent) => {
        if (lookGPO != null && !lookGPO.IsClear()
            && lookGPO.GetGpoID() == iGPO.GetGpoID()) {
            MsgRegister.Dispatcher(new CM_Camera.ShakeCamera() {
                Duration         = 0.2f,
                Magnitude        = 0.1f,
                DampingSharpness = 1.6f,
                NoiseFrequency   = new Vector3(10, 10, 0),
                AffectRotation   = true,
                MaxRotationAngle = 10,
            });
        }
    });
}

protected override void OnClear() {
    MsgRegister.Unregister<CM_GPO.AddLookGPO>(...); // 注意取消注册
}
```

**震动参数速查**：

| 武器类型 | Duration | Magnitude | DampingSharpness | AffectRotation |
|---------|----------|-----------|-----------------|----------------|
| 手枪/冲锋枪 | 0.15f | 0.05f | 2.0f | false |
| 步枪/标准枪 | 0.2f | 0.1f | 1.6f | true / 10° |
| 狙击/重型 | 0.35f | 0.2f | 1.2f | true / 20° |
| 霰弹枪 | 0.25f | 0.15f | 1.4f | true / 15° |
| 加特林（单次）| 0.1f | 0.06f | 3.0f | false |

**加特林持续射击（计时器循环）**：
```csharp
private float shakeTimer = 0f;
private void OnUpdate(float delta) {
    if (!isFiring) return;
    shakeTimer -= delta;
    if (shakeTimer <= 0 && IsLookGPO()) {
        shakeTimer = 0.1f;  // 略小于 Duration(0.15f)，保证震动无缝衔接
        MsgRegister.Dispatcher(new CM_Camera.ShakeCamera() {
            Duration = 0.15f, Magnitude = 0.06f, DampingSharpness = 3.0f,
            NoiseFrequency = new Vector3(15, 15, 0), AffectRotation = false,
        });
    }
}
private bool IsLookGPO() => lookGPO != null && !lookGPO.IsClear()
                             && lookGPO.GetGpoID() == iGPO.GetGpoID();
```

### 10.3 辅助瞄准与武器的关联

普通武器无需修改辅助瞄准配置（使用全局默认 ID=1 配置）。

特殊武器（如瞄准镜武器、无后坐力武器）可以在进入/退出瞄准状态时切换配置：

```csharp
// 进入瞄准（如狙击镜）
MsgRegister.Dispatcher(new CM_Camera.SetAimAssistConfig {
    Config = AimAssistSet.GetAimAssistById(2) // ID=2 的高吸附配置
});
// 放大辅助圆范围
MsgRegister.Dispatcher(new CM_Camera.SetLockCircleRadiusScale { Scale = 1.5f });

// 退出瞄准时恢复默认
MsgRegister.Dispatcher(new CM_Camera.SetAimAssistConfig {
    Config = AimAssistSet.GetAimAssistById(1)
});
MsgRegister.Dispatcher(new CM_Camera.SetLockCircleRadiusScale { Scale = 1f });
```

### 10.4 武器开发与镜头系统的交互总结

| 开发场景 | 调用方法 | 注意事项 |
|---------|---------|---------|
| 开火目标点 | `CM_Camera.GetCameraCenterObjPoint` | **必须**用此替代 `fireBox.forward` |
| 单次开火震动 | `CM_Camera.ShakeCamera` | 判断 LookGPO，非 IsLocalGPO |
| 持续射击震动 | 计时器 + `ShakeCamera` | 间隔略小于 Duration |
| 切换辅助瞄准 | `CM_Camera.SetAimAssistConfig` | 退出时恢复默认 ID |
| 镜头推近（瞄准镜） | `CE_Camera.SetCameraOffset`（在 iGPO 上发） | 退出时 Offset=zero |
