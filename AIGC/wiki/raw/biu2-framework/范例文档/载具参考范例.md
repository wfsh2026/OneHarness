# 载具与骑乘系统 参考文档

> 适用场景：新增载具类型（坦克、直升机、船等）、扩展骑乘交互逻辑、修改驾驶员位置同步策略

---

## 系统概述

载具系统分为两类角色：
- **载具 GPO**：Tank / Helicopter 等，由 AI System 管理，有独立的行为树
- **驾驶员 GPO**：角色（Role），骑上载具后将控制权委托给载具

核心设计原则：**载具侧持有驾驶关系，角色侧感知驾驶状态。**

## 核心类结构

### 服务端

| 类名 | 归属 | 职责 |
|------|------|------|
| `ServerAITankSystem` | 载具 System | 坦克的组件注册入口，包含 `ServerAIDrive` |
| `ServerAIHelicopterSystem` | 载具 System | 直升机的组件注册入口，包含 `ServerAIDrive` |
| `ServerAIDrive` | 载具 Component | 维护驾驶关系，触发进/出载具事件，控制位置同步开关 |
| `ServerGPODrivingVehicle` | 角色 Component（基类） | 监听载具驾驶事件，广播网络消息，每帧同步角色位置到载具 |
| `ServerCharacterDrivingVehicle` | 角色 Component（子类） | 处理本地玩家的操作指令（动画、炮塔旋转、开火） |

### 客户端

| 类名 | 归属 | 职责 |
|------|------|------|
| `ClientAITankSystem` | 载具 System | 坦克客户端组件注册入口 |
| `ClientAIHelicopterSystem` | 载具 System | 直升机客户端组件注册入口 |
| `ClientAIDrive` | 载具 Component | 接收驾驶关系变化，驱动 `ClientAIMoveForDrive` 启停 |
| `ClientAIMoveForDrive` | 载具 Component | 本地玩家驾驶时的物理移动（CharacterController）|
| `CharacterLocalDrive` | 角色 Component（本地） | 接收载具 ID，绑定载具事件，转发输入指令 |
| `CharacterOtherDrive` | 角色 Component（其他玩家） | 将角色网络位置同步给载具 |
| `CharacterGPODrive` | 角色 Component（基类） | 处理 Rpc_DriveGPOID 广播，绑定载具 GPO |

## 关键流程

### 进入载具（Enter Vehicle）

```
[服务端触发]
ServerAIDrive.SetDriverGPO(true)
  │
  ├─► masterGPO.Dispatcher(SE_GPO.Event_DrivingVehicle { IsDriving=true, DriveGPO=vehicle })
  │       └─► ServerGPODrivingVehicle.OnOnDriveGPOCallBack()
  │               ├─ driveGPO = vehicle
  │               ├─ 角色添加 Tag: DrivingVehicle
  │               └─ Rpc(Proto_Drive.Rpc_DriveGPOID { gpoId })  ──► 广播给所有客户端
  │                       TargetRpc(Proto_Drive.TargetRpc_DriveGPOID { gpoId, drivePos, driveRota }) ──► 仅本地客户端
  │
  ├─► mySystem.Dispatcher(SE_AI.Event_DriveState { IsDrive=true })
  │       └─► ServerAIBehaviour 关闭/开启行为树（取决于是否 Pet 模式）
  │
  └─► mySystem.Dispatcher(SE_Network.Event_EnabledSyncNetworkTransform { IsTrue=false })
          └─► 关闭载具的 NetworkTransform 自动同步（由驾驶员控制位置）

[客户端 - 本地玩家]
CharacterLocalDrive.OnTargetRpcDriveGPOIDCallBack()
  ├─ 缓存初始位置 createPoint/createRota
  ├─ SetDriveGPOID(gpoId)
  │       └─ GetGPO 回调 → GetGPOCallBack(vehicleGPO)
  │               ├─ driveGPO = vehicleGPO
  │               ├─ mySystem.Dispatcher(CE_GPO.Event_PlayerDriveGPO { DriveGPO=vehicle })
  │               ├─ vehicle.Dispatcher(CE_GPO.Event_DriveGPO { PlayerDriveGPO=character })
  │               ├─ 注册载具事件：PlayAnimSign / SyncTankUpperBodyRota / DeviceFire
  │               └─ MsgRegister.Dispatcher(CM_InputPlayer.EnabledDevice { Device=vehicle })
  │                       └─► 将输入设备切换为载具

[客户端 - 其他玩家]
CharacterGPODrive.OnRpcDriveGPOIDCallBack()
  └─ SetDriveGPOID(gpoId) → 绑定载具 GPO，每帧同步角色网络位置到载具
```

### 离开载具（Exit Vehicle）

```
ServerAIDrive.SetDriverGPO(false)
  ├─► masterGPO.Dispatcher(SE_GPO.Event_DrivingVehicle { IsDriving=false })
  │       └─► ServerGPODrivingVehicle: 清除 driveGPO，移除 Tag，Rpc(gpoId=0)
  │
  ├─► mySystem.Dispatcher(SE_AI.Event_DriveState { IsDrive=false })
  │
  └─► mySystem.Dispatcher(SE_Network.Event_EnabledSyncNetworkTransform { IsTrue=true })
          └─► 重新开启载具 NetworkTransform 自动同步

[客户端]
OnRpcDriveGPOIDCallBack(gpoId=0)
  └─ SetDriveGPOID(0)
          ├─ CE_GPO.Event_PlayerDriveGPO { DriveGPO=null }
          ├─ driveGPO.Dispatcher(CE_GPO.Event_DriveGPO { PlayerDriveGPO=null })
          └─ ClearDirveGPO() → 恢复输入设备
```

### 位置同步（Position Sync）

#### 本地玩家驾驶

```
每帧:
CharacterLocalSystem(NetworkTransform) 同步角色位置
  └─► 服务端 ServerCharacterDrivingVehicle.UpdateDrivePoint()
          ├─ 向载具 Dispatcher: SE_AI.Event_DriverPointRota { Point, Rota }
          │       └─► ServerAIDrive.OnDriverPointRotaCallBack() → vehicle.SetPoint/SetRota
          └─ 角色位置跟随 driveTransform（驾驶员座位骨骼）
```

#### 其他玩家驾驶

```
每帧:
CharacterOtherDrive.OnUpdate()
  └─► vehicle.Dispatcher(CE_AI.Event_DriverPointRota { Point, Rota, IsSync=false })
          └─► ClientAIDrive.OnDriverPointRotaCallBack()
                  └─ IsSync=false → CE_GPO.Event_SetTransformPointRota（插值平滑）
```

## 核心事件

### 服务端事件（SE_）

| 事件 | 发送方 | 接收方 | 说明 |
|------|--------|--------|------|
| `SE_GPO.Event_DrivingVehicle` | `ServerAIDrive` | `ServerGPODrivingVehicle` | 通知角色进/出载具 |
| `SE_AI.Event_DriveState` | `ServerAIDrive` | `ServerAIBehaviour` | AI 行为树响应驾驶状态 |
| `SE_AI.Event_DriverPointRota` | `ServerCharacterDrivingVehicle` | `ServerAIDrive` | 驾驶员位置同步给载具 |
| `SE_AI.Event_GetDriveState` | 查询方 | `ServerAIDrive` | 回调获取当前驾驶状态 |
| `SE_AI.Event_TakeBack` | 载具行为树 | `ServerAIDrive` | 强制退出驾驶（被收回） |
| `SE_AI.Event_PlayerDriveSetTankUpperBodyRota` | `ServerCharacterDrivingVehicle` | 坦克上车体旋转组件 | 同步炮塔方向 |
| `SE_AI.Event_PlayerDriveFireForPoints` | `ServerCharacterDrivingVehicle` | 坦克攻击组件 | 触发开火，结果回调 |

### 客户端事件（CE_）

| 事件 | 发送方 | 接收方 | 说明 |
|------|--------|--------|------|
| `CE_GPO.Event_DriveGPO` | `CharacterLocalDrive` / `CharacterGPODrive` | `ClientAIDrive` / `ClientAIMoveForDrive` | 通知载具当前驾驶员 |
| `CE_GPO.Event_PlayerDriveGPO` | `CharacterLocalDrive` | 角色系统内部 | 通知角色系统正在驾驶哪个载具 |
| `CE_GPO.Event_DriverPointRota` | `ClientAIDrive` | 载具内各组件 | 广播驾驶员当前位置/朝向 |
| `CE_AI.Event_DriverPointRota` | `CharacterOtherDrive` / `CharacterLocalDrive` | `ClientAIDrive` | 从角色侧同步到载具侧 |
| `CE_AI.Event_MoveDir` | `CharacterLocalDrive` | `ClientAIMoveForDrive` | 转发玩家移动输入 |
| `CE_AI.Event_MoveUp` / `MoveDown` | `CharacterLocalDrive` | 载具移动组件 | 上坡/下坡输入 |
| `CE_AI.Event_EnabledDriveMove` | `ClientAIDrive` | `ClientAIMoveForDrive` | 开启/关闭本地物理移动 |
| `CE_AI.Event_SyncTankUpperBodyRota` | 坦克上车体旋转组件 | `CharacterLocalDrive` | 触发 Cmd 发送炮塔旋转 |
| `CE_GPO.Event_OnDeviceFire` | 载具攻击组件 | `CharacterLocalDrive` | 触发 Cmd 发送开火 |

## 网络通信协议（Proto_Drive）

| 消息 | 类型 | 方向 | 说明 |
|------|------|------|------|
| `Rpc_DriveGPOID` | RPC（广播） | Server → All Clients | 广播进/出载具（gpoId=0 表示退出） |
| `TargetRpc_DriveGPOID` | TargetRPC | Server → 本地客户端 | 带初始位置的驾驶通知（仅本地玩家收到） |
| `Cmd_DriveAnim` | CMD | 本地 Client → Server | 在载具上播放动画 |
| `Rpc_DriveAnim` | RPC（广播） | Server → All Clients | 广播载具动画 |
| `Cmd_SyncTankUpperBodyRota` | CMD | 本地 Client → Server | 同步坦克炮塔旋转角度 |
| `Cmd_DeviceFire` | CMD | 本地 Client → Server | 发起载具武器开火请求（含弹道点列表） |
| `TargetRpc_DeviceFireState` | TargetRPC | Server → 本地客户端 | 开火结果（成功/失败） |

## 新增载具类型步骤

### 1. 服务端

```csharp
// 新建 ServerAIBoatSystem.cs
public class ServerAIBoatSystem : S_AI_Base {
    private GPOM_Boat useMData;

    protected override void OnAwake() {
        useMData = (GPOM_Boat)MData;
        AddComponents();
    }

    protected override void AddComponents() {
        base.AddComponents();
        // 必须：AI 行为树
        AddComponent<ServerAIBehaviour>(new ServerAIBehaviour.InitData {
            AIBehaviour = MasterGPO != null ? useMData.PetBehavior : useMData.AiBehavior,
        });
        // 必须：属性
        AddComponent<ServerAIAttribute>(new ServerGPOAttribute.InitData {
            ATK = useMData.Atk, AttackRange = useMData.AttackRange,
            MaxHp = useMData.Hp, MoveSpeed = useMData.MoveSpeed,
        });
        // 必须：驾驶关系管理
        AddComponent<ServerAIDrive>();
        // 按需：移动、攻击等组件
        AddComponent<ServerAIBoatMove>();
        AddComponent<ServerAIBoatAttack>();
    }

    protected override void OnStart() {
        base.OnStart();
        CreateEntity(AttributeData.Sign + "Server");
    }
}
```

### 2. 客户端

```csharp
// 新建 ClientAIBoatSystem.cs
public class ClientAIBoatSystem : C_AI_Base {
    protected override void OnAwake() {
        base.OnAwake();
        AddComponents();
    }

    protected override void AddComponents() {
        base.AddComponents();
        AddComponent<ClientAIAttribute>();
        // 必须：驾驶关系监听
        AddComponent<ClientAIDrive>();
        // 按需：移动（若本地玩家可驾驶）
        AddComponent<ClientAIMoveForDrive>(new ClientAIMoveForDrive.InitData {
            MoveSpeed = ..., MoveRotaSpeed = ...,
        });
        // 渲染相关
        AddComponent<ClientGPOOtherTeamMaterial>();
        AddComponent<ClientGPOCameraHideRoleRenderer>();
        AddComponent<ClientGPOSignalRenderer>();
    }

    protected override void OnStart() {
        base.OnStart();
        iEntity.SetPoint(startPoint);
        CreateEntity(AttributeData.SkinSign);
    }
}
```

### 3. 关键注意点

- **驾驶员座位骨骼**：载具 Entity 上必须有 `GPOData.PartEnum.Driver` 骨骼节点，`ServerGPODrivingVehicle` 和 `ClientAIDrive` 用它定位角色位置
- **NetworkTransform 控制权**：进入载具时 `Event_EnabledSyncNetworkTransform { IsTrue=false }` 关闭载具的自动位置同步，由驾驶员的位置驱动，退出后恢复
- **Pet 模式 vs AI 模式**：`ServerAIDrive` 在 `OnSetEntityObj` 时检查 `MasterGPO`，有 Master 则立即 `SetDriverGPO(true)`（宠物/坐骑模式），无 Master 则等行为树调用
- **位置同步优先级**：本地玩家驾驶 → 服务端通过角色网络位置驱动；AI 驾驶 → 行为树移动直接设置载具位置

## 现有实现经验总结

### 载具类型一览

| 载具 | System | 驾驶模式 | 特殊武器 |
|------|--------|----------|----------|
| 坦克 | `ServerAITankSystem` | 玩家/AI 均可驾驶 | `Cmd_SyncTankUpperBodyRota`（炮塔旋转）+ `Cmd_DeviceFire`（开火） |
| 直升机 | `ServerAIHelicopterSystem` | 玩家/AI 均可驾驶 | 玩家驾驶时空投 |
| 召唤载具（超级武器） | `ServerGPOSkillSummonDriver` | 玩家技能召唤，AI 跟随 | `SE_AI.Event_MasterAIFire` 触发开火 |

---

### 驾驶关系的两种触发方式

#### 方式1：Pet / MasterGPO 直接绑定（坐骑/宠物模式）

`ServerAIDrive.OnSetEntityObj()` 在 Entity 创建时检查 `S_AI_Base.MasterGPO`：

```csharp
// ServerAIDrive
protected override void OnSetEntityObj(IEntity iEntity) {
    var monsterSystem = (S_AI_Base)mySystem;
    masterGPO = monsterSystem.MasterGPO;
    if (masterGPO != null) {
        SetDriverGPO(true);  // 有 Master 则立即建立驾驶关系
    }
}
```

适用于：坐骑、随行载具（出生即绑定驾驶员）

#### 方式2：行为树主动呼叫驾驶员（坦克/直升机）

行为树通过事件查询可驾驶的角色，发起驾驶请求，`SetDriverGPO(true)` 在行为树动作中触发。

```
行为树 ActionXXXDrive.OnUpdate()
  └─ iGPO.Dispatcher(new SE_AI_XXX.Event_Drive { })
        └─ 载具能力组件处理：找到最近角色 → SetDriverGPO(true)
```

---

### 行为树 Condition 节点（载具专用）

| 节点 | 含义 | 监听事件 |
|------|------|----------|
| `ConditionIsGPODrive` | 当前载具是否正在被角色（Role）驾驶 | `SE_AI.Event_DriveState` |
| `ConditionIsPlayerDrive` | 角色侧：是否正在驾驶某载具 | `SE_GPO.Event_DrivingVehicle` |
| `ConditionIsDriveCall` | 是否被驾驶呼叫（预留，当前未启用） | - |

典型载具行为树模式：

```
Selector
├─ Sequence [正在被驾驶]
│   ├─ ConditionIsGPODrive  ← 检查是否有 Role 驾驶
│   └─ ActionXXXDriveMove   ← 跟随驾驶员移动
│
└─ Sequence [无人驾驶]
    └─ ActionXXXIdle / ActionXXXPatrol
```

### `ServerGPOSkillSummonDriver`：技能召唤载具完整流程

玩家使用超级武器（`SkillTypeEnum.SummonDriver`）召唤的载具（如直升机）：

```
SE_Skill.Event_UseWeaponSkill（UseSkill）
  │
  ├─ SetIsDriving(true) → SE_GPO.Event_IsUsingDriveSkill { IsUsingDriveSkill=true }
  │
  └─ SE_Character.Event_AddMasterAI { MonsterSign, ATK, HP, StartPoint }
        └─ 召唤完成 → SE_AI.Event_SummonFollowAIEnd
              ├─ summonDriverGPO.Register<SE_AI.Event_MasterAIFire>(OnSummerAIFire)
              ├─ summonDriverGPO.Register<SE_GPO.Event_SetIsDead>(OnSummerMonsterSetIsDead)
              ├─ summonDriverGPO.AddTag(GamePlayTagData.TagEnum.SuperWeapon)
              └─ SE_Skill.Event_UseSkillSummonDriver { UseGPOId, SummerDriverGPOId }

[载具死亡时]
SE_GPO.Event_SetIsDead(IsDead=true)
  └─ 所有召唤载具死完 → SE_Skill.Event_RequestSkillOverBySummonAIDead

[技能结束时 SE_Skill.Event_SkillOver]
  ├─ SkillOver() → ClearSummerDriver() → 清除所有召唤载具
  ├─ SetIsDriving(false)
  └─ SE_Character.Event_RemoveMasterMonster

[特殊：直升机技能结束后传送玩家回出生点]
ResetMasterPoint() → SM_Mode.GetStartPoint → SE_Entity.SyncPointAndRota
```

### 新增载具的完整检查清单

- [ ] Entity 骨骼：`GPOData.PartEnum.Driver` 座位节点（`ServerGPODrivingVehicle` 依赖它）
- [ ] 服务端 System：继承 `S_AI_Base`，`AddComponent<ServerAIDrive>()`
- [ ] 客户端 System：继承 `C_AI_Base`，`AddComponent<ClientAIDrive>()`，若玩家可驾驶还需 `ClientAIMoveForDrive`
- [ ] 行为树 AI 模式：设计 `ConditionIsGPODrive` 节点，区分被驾驶/无人驾驶的行为分支
- [ ] 特殊武器（炮塔/开火）：扩展 `Cmd_SyncTankUpperBodyRota` / `Cmd_DeviceFire` 或新增 Proto 消息
- [ ] `GamePlayTagData.TagEnum.Vehicle` 标签：`ServerAIDrive.OnStart()` 中已自动添加，无需手动处理
- [ ] GPOM 模板数据：配置 `AiBehavior`、`PetBehavior`、`Atk`、`Hp`、`MoveSpeed` 等字段
