# 镜头系统开发范例文档
> **用途**：AI 编程系统参考文档，用于开发新的镜头效果、武器镜头反馈及镜头事件调用。
> **版本**：v2.0（完整版）

## 一、系统总体架构

### 1.1 架构全景

```
┌────────────────────────────────────────────────────────────────┐
│                  输入层（UIPlayerControl）                       │
│  触屏滑动 / GamePad 右摇杆 / 鼠标拖拽                           │

│  CameraRota ────────  HRota / VRota 节点旋转                   │
```

### 1.2 CameraEntity Transform 层级

```
[CameraEntity root]（SystemBase 的 Entity 节点，世界跟随目标 GPO）
  └── HRota (Transform)            ← CameraRota 控制：水平旋转 Y 轴
        └── VRota (Transform)      ← CameraRota 控制：垂直旋转 X 轴
              └── Far (Transform)  ← CameraFar 控制：localPosition Z 轴偏移
                    └── Shake (Transform) ← CameraShake 控制：震动偏移
                          └── UseCamera (Camera) ← 实际摄像机（受 Shake 随动）
```

> **规则**：每层节点只感知自身职责，不访问下层。世界位置由 CameraMove 控制 root 节点。

## 三、角色与镜头的绑定流程

### 3.1 绑定触发时机

绑定条件需同时满足两个异步条件（双检锁机制）：

```
条件 A：角色 Entity 加载完成
  CharacterLocalCamera.OnSetEntityObj() → isLoadEntityEnd = true → SetLookGPO()

条件 B：场景加载阶段到达 SetLookRole
  M_Stage.TaskLoadStart { loadState = SetLookRole } → stageLoadState = SetLookRole → SetLookGPO()
```

两个条件均满足后，`SetLookGPO()` 才真正执行：

```csharp
private void SetLookGPO() {
    if (stageLoadState != StageData.LoadEnum.SetLookRole || isLoadEntityEnd == false) return;
    MsgRegister.Unregister<M_Stage.TaskLoadStart>(OnTaskLoadStartCallBack); // 防重入
    MsgRegister.Dispatcher(new CM_GPO.AddLookGPO {
        LookGPO = iGPO,
        IsDrive = false,
    });
    UpdateRegister.AddInvoke(InvokeTaskLoadEnd, 0.5f); // 0.5s 后通知加载完成
}
```

### 3.2 完整绑定序列

```
[ClientCharacterManager]
  │ CM_Character.AddLocalCharacter
  ▼
[CharacterLocalSystem]
  │ AddComponent<CharacterLocalCamera>()
  │ CreateEntityObj("Character/LocalCharacter_xxx")  ← 异步加载
  ▼
[CharacterLocalCamera.OnSetEntityObj]
  │ isLoadEntityEnd = true
  │ SetLookGPO() ← 等待 stageLoadState 满足
  ▼
[M_Stage.TaskLoadStart(SetLookRole)] ← 场景加载阶段到达
  │ stageLoadState = SetLookRole
  │ SetLookGPO()
  ▼
[MsgRegister.Dispatcher(CM_GPO.AddLookGPO)]
  ├── CameraMove.OnAddLookGPOCallBack()    → lookTarget = GPO.GetBodyTran(CameraLook)
  ├── CameraFar.OnAddLookGPOCallBack()     → 订阅角色状态事件
  ├── CameraRota.OnAddLookGPOCallBack()    → 同步初始 HRota
  ├── CameraAimAssist.OnAddLookGPOCallBack()
  ├── CameraAutoLockTarget.OnAddLookGPOCallBack()
  └── CameraCollisionHandler.OnAddLookGPOCallBack()
  ▼
[CameraSystem 开始每帧跟随角色]
  ▼
[0.5s 后]
  M_Stage.TaskLoadEnd(SetLookRole) → 通知场景管理器镜头绑定完成
```

### 3.3 CameraLook 骨骼位置

`CameraMove` 跟随的是 `GPO.GetBodyTran(GPOData.PartEnum.CameraLook)` 骨骼。
该骨骼通常在角色头部上方位置，用于决定镜头跟随点（而不是角色脚底）。

## 四、输入系统与镜头的交互

### 4.1 输入管道全流程

```
[触屏/手柄/鼠标原始输入]
      │
      ▼
[UIPlayerControl]
  OnInputCameraPerformed(Vector2 value, bool isPhysical)
  ├── 手柄物理输入（isPhysical=true）：isDown=true, sendGamePadTouchDelta=value
  └── 非物理输入：SetCameraPerformed(value) 直接发送
      │
      ▼ SetCameraPerformed(Vector2 value)
  坐标系转换：sendDelta.x = -value.y  (触屏 Y → 垂直方向取反)
              sendDelta.y =  value.x  (触屏 X → 水平方向)
  MsgRegister.Dispatcher(CM_InputPlayer.SetDelta { Delta = sendDelta })
      │
      ▼ [CameraAimAssist 拦截]
  OnSetDelta(CM_InputPlayer.SetDelta)
  ├── 若准心附近有减速目标(slowDownGpo)：乘以减速系数
  └── 发送 CM_Camera.SetDelta { Delta = finalDelta }
      │
      ▼ [CameraRota]
  SetDeltaCallBack(CM_Camera.SetDelta)
  speed = baseRotaSpeed(0.5f) * TouchUtil.TouchSensitivityPercent
  HRota *= Quaternion.Euler(0, delta.y * speed, 0)  ← 水平旋转
  VRota *= Quaternion.Euler(delta.x * speed, 0, 0)  ← 垂直旋转（已夹角）
  UpdateRota() → cameraEntity.HRota / VRota.localRotation = ...
      │
      ▼ 广播
  CM_Camera.CameraHVRota { HRota, VRota }
      │
      ▼ [CharacterLocalCamera]
  OnCameraHVRotaCallBack(CM_Camera.CameraHVRota)
  ├── iEntity.SetRota(HRota)               ← 同步角色身体朝向
  ├── CE_Character.CameraRotaV{vRota}      ← 通知角色垂直旋转（用于动画）
  └── CameraVRotaCallBack(vRota)
        └── 限速 0.1s → network.Cmd(Proto_Character.Cmd_CameraVRota{vRota})
                                           ← 同步垂直旋转到服务器
```

### 4.2 垂直角度限制

| 模式 | 最小角度 | 最大角度 |
|------|----------|----------|
| 普通跟随模式 | -65° | +75° |
| 驾驶模式（IsDrive=true）| -45° | +60° |

限制在 `CameraRota.DefaultAxis()` 中通过 `ClampVRotaAroundXAxis()` 实现。

### 4.3 旋转插值平滑模式

默认关闭。开启后旋转使用加速/减速插值（适用于锁定镜头等场景）：

```csharp
MsgRegister.Dispatcher(new CM_Camera.EnabledCameraLeap { IsEnable = true });
// 参数：baseAcceleration=60f，maxAccelerationMultiplier=3f，减速加速度=加速×2
```

### 4.4 观战/录像（WarReport）模式下的输入行为

```csharp
// UIPlayerControl.ReportState() — 进入观战时隐藏操作 UI
if (WarReportData.IsStartWarReport()) {
    BtnJump.gameObject.SetActive(false);
    BtnMoveUp.gameObject.SetActive(false);
```

## 五、驾驶载具时的镜头切换

当本地玩家进入/离开载具时，`CharacterGPOCamera`（`CharacterLocalCamera` 的基类）负责切换跟随目标：

```csharp
// CharacterGPOCamera.cs
private void OnDriveGPOCallBack(ISystemMsg body, CE_GPO.Event_PlayerDriveGPO ent) {
    isDriveIng = ent.DriveGPO != null;
    driveGPO = ent.DriveGPO;
    UpdateDriveState(prevDriveGpoId);
}

private void UpdateDriveState(int driveGpoId) {
    if (isDriveIng) {
        // 切换到载具 GPO
        MsgRegister.Dispatcher(new CM_GPO.AddLookGPO { LookGPO = driveGPO, IsDrive = true });
    } else {
        // 退出载具，切换回角色 GPO
        MsgRegister.Dispatcher(new CM_GPO.AddLookGPO { LookGPO = iGPO, IsDrive = false });
        // 重置角色 Entity 旋转（去掉 X/Z 偏转）
        var rota = iEntity.GetEulerAngles();
        rota.x = 0f; rota.z = 0f;
        iEntity.SetEulerAngles(rota);
    }
}
```

`IsDrive=true` 会影响 `CameraFar`（调整距离）和 `CameraRota`（调整俯仰角上限）。

## 六、九大组件职责详解

### 6.1 CameraMove — 位置跟随

**文件**：`Assets/Scripts/GamePlay/Client/Camera/Componet/CameraMove.cs`

| 属性 | 值 | 说明 |
|------|-----|------|
| `speed` | 20f | 基础跟随速度（单位/秒） |
| `cameraHDelta` | 实时更新 | 水平输入 delta 绝对值，用于提升响应速度 |

**跟随逻辑（LateUpdate）**：
```csharp
var useSpeed = speed + cameraHDelta;
if (distance <= 10f && cameraHDelta <= 10f) {
    // 平滑跟随：距离越近越慢（speedRatio = max(distance,1)）
    iEntity.SetPoint(Vector3.MoveTowards(current, target, speedRatio * useSpeed * deltaTime));
} else {
    // 距离过远时直接贴合（防止镜头拉远时延迟）
    iEntity.SetPoint(target);
}
```

**关键**：跟随 `GPO.GetBodyTran(GPOData.PartEnum.CameraLook)` 骨骼，非角色位置。

### 6.2 CameraFar — 距离调整

**文件**：`Assets/Scripts/GamePlay/Client/Camera/Componet/CameraFar.cs`

**默认 Far.localPosition 预设**：

| 状态 | x | y | z |
|------|---|---|---|
| 普通站立/默认 | 0.7 | 0.6 | -5.25 |
| 驾驶（默认） | 1.0 | 0 | -4.0 |
| 驾驶·行走 | 1.0 | 0 | -4.5 |

| 骑乘怪物 | 1.0 | 0 | -1.8 |

### 6.4 CameraAimAssist — 辅助瞄准

**文件**：`Assets/Scripts/GamePlay/Client/Camera/Componet/CameraAimAssist.cs`

**工作机制**：
1. 订阅 `CM_InputPlayer.SetDelta`（玩家原始输入）
2. 每 2 帧查找一次准心附近的减速目标（`FindCenterGPOInFrontForLockRadius`，isSlowDown=true）
3. 若找到减速目标，计算目标偏离准心角度比例，乘以减速系数：
   ```csharp
   var pow = Mathf.Pow(Clamp01(angle / maxAngle), aimAssistConfig.CameraSlowDownPowRate);
   var slowDownRate = cameraSlowDownRate * Lerp(CameraMaxSlowDownRate, CameraMinSlowDownRate, pow);
   finalDelta = ent.Delta * (1 - slowDownRate);
   ```
4. 输出 `CM_Camera.SetDelta { Delta = finalDelta }`

**每帧也计算吸附系数** `cameraLockRate`，根据当前转速与阈值：
```csharp
UpdateCameraRate(out cameraLockRate, angleSpeed, CameraLockThresholds, LowLockRate, HighLockRate, MiddleLockRates);
```

**配置来源**：`AimAssist` Template，默认使用 ID=1，可通过消息切换：
```csharp
MsgRegister.Dispatcher(new CM_Camera.SetAimAssistConfig { Config = AimAssistSet.GetAimAssistById(2) });
```

### 6.5 CameraShake — 镜头震动

**文件**：`Assets/Scripts/GamePlay/Client/Camera/Componet/CameraShake.cs`

**实现机制**：
- Perlin Noise 三轴偏移（比 RandomInsideSphere 平滑）
- 指数衰减：`damping = Clamp01(remainingDuration * dampingSharpness)`
- 可选旋转震动（`Shake.localRotation`）

**触发消息**：
```csharp
MsgRegister.Dispatcher(new CM_Camera.ShakeCamera() {
    Duration         = 0.2f,
    Magnitude        = 0.1f,
    DampingSharpness = 1.6f,
    NoiseFrequency   = new Vector3(10, 10, 0),
    AffectRotation   = true,
    MaxRotationAngle = 10,
});
```

**典型参数参考**：

| 效果 | Duration | Magnitude | DampingSharpness | NoiseFrequency |
|------|----------|-----------|-----------------|----------------|
| 轻型枪击 | 0.15f | 0.05f | 2.0f | (8,8,0) |
| 标准枪击 | 0.2f | 0.1f | 1.6f | (10,10,0) |
| 重型武器 | 0.35f | 0.2f | 1.2f | (6,6,0) |
| 爆炸冲击 | 0.5f | 0.3f | 1.0f | (5,5,0) |
| 连续射击 | 0.1f | 0.06f | 3.0f | (15,15,0) |

**强制规则**：只对当前被镜头跟随的 GPO 触发。通过 `CM_GPO.AddLookGPO` 跟踪当前 LookGPO，比对武器的 `iGPO.GetGpoID()`：

```csharp
// 正常游戏：LookGPO = 本地角色 GPO
// 观战模式：LookGPO = 被观战角色 GPO（IsLocalGPO() 此时为 false，但仍需触发震动）
private bool IsLookGPO() => lookGPO != null && !lookGPO.IsClear()
                             && lookGPO.GetGpoID() == iGPO.GetGpoID();
```

### 6.6 CameraCollisionHandler — 防穿墙

**文件**：`Assets/Scripts/GamePlay/Client/Camera/Componet/CameraCollisionHandler.cs`

**参数**：
| 常量 | 值 | 说明 |
|------|-----|------|
| `SPHERE_RADIUS` | 0.3f | 球形射线半径 |
| `smoothSpeed` | 10f | 恢复平滑速度 |
| `defaultNearClip` | 0.3f | 正常近裁面 |
| `minNearClip` | 0.05f | 贴近时的近裁面 |

**检测流程**：
```
1. 从 lookGPO 头部位置出发（加偏移 0.3, 0.3, -0.2）
2. 向 Far 节点方向 SphereCastNonAlloc（排除 Trigger、HitType.Ignore、GPO 自身碰撞体）
3. 若有命中 → 摄像机移至命中点前 SPHERE_RADIUS 处
4. 若无命中 → 摄像机 localPosition 平滑回 Vector3.zero
5. 近裁面根据距离动态调整（贴近时缩小防止画面裁切）
```

**广播**：位置变化超过 0.1 平方距离时，通知 `CE_Camera.EndCameraLocalPoint { LocalPoint }`。

### 6.8 CameraAutoLockTarget — 自动锁定

**文件**：`Assets/Scripts/GamePlay/Client/Camera/Componet/CameraAutoLockTarget.cs`

**主要消息**：

```csharp
// 开始自动锁定最近目标（如技能锁敌）
MsgRegister.Dispatcher(new CM_Camera.StartAutoLookTarget());

// 缓慢对准最近 GPO
MsgRegister.Dispatcher(new CM_Camera.LookNearestGPO { LimitAngle = 15f, Speed = 3f });

// 强制锁定指定目标
MsgRegister.Dispatcher(new CM_Camera.LockTarget { Speed = 5f, TargetGPO = targetGpo });

// 设置持续自动跟随 GPO（死亡/清除时自动解除）
MsgRegister.Dispatcher(new CM_Camera.SetAutoLookGPO { GPO = targetGpo });
```

锁定时通过 `CE_Camera.SetLockTargetDelta { Delta }` 通知 `CameraRota` 进行旋转对准，使用 `Quaternion.Slerp` 插值平滑旋转。

### 6.9 GetCameraVisibleGPO — 可见性查询

**文件**：`Assets/Scripts/GamePlay/Client/Camera/Componet/GetCameraVisibleGPO.cs`

```csharp
// 获取所有可见 GPO
MsgRegister.Dispatcher(new CM_Camera.GetVisibleGPOList { CallBack = (list) => { } });

// 检查 GPO 是否可见
MsgRegister.Dispatcher(new CM_Camera.CheckGPOIsVisible { TargetGPO = gpo, CallBack = (isVisible) => { } });

// 检查空间点是否可见
MsgRegister.Dispatcher(new CM_Camera.CheckPointIsVisible { Point = worldPos, CallBack = (isVisible) => { } });

// GPO 遮挡检查
```

## 八、武器与镜头的标准接口

### 8.1 开火目标点获取（必须通过镜头系统）

所有枪械开火时的目标点，**禁止直接使用枪口朝向的 forward**，必须通过镜头中心射线查询：

```csharp
// 在 ClientWeaponSystem 开火逻辑中
private void RequestFireTarget(Transform fireBox, float maxDistance, int teamId,
                                Action<Vector3> onGot) {
    MsgRegister.Dispatcher(new CM_Camera.GetCameraCenterObjPoint {
        CheckForwardPoint = fireBox.position,
        FarDistance       = maxDistance,
        IgnoreTeamId      = teamId,
        CallBack          = (point, _) => onGot(point),
    });
}
```

### 8.2 开火镜头震动（标准写法）

**正确写法**（跟踪 LookGPO，而非判断 IsLocalGPO）：

```csharp
// 在 ClientWeaponSystem 中，通过 AddLookGPO 跟踪当前被观察的 GPO
private IGPO lookGPO;

protected override void OnAwake() {
    // ... 其他注册
    MsgRegister.Register<CM_GPO.AddLookGPO>(ent => lookGPO = ent.LookGPO);
}

// 判断当前武器是否属于被观察的 GPO（含本地玩家 + 观战目标）
private bool IsLookGPO() => lookGPO != null && !lookGPO.IsClear()
                             && lookGPO.GetGpoID() == iGPO.GetGpoID();
```

```csharp
Register<CE_Weapon.Fire>((body, ent) => {
    if (IsLookGPO()) {
        MsgRegister.Dispatcher(new CM_Camera.ShakeCamera() {
            Duration         = 0.2f,
            Magnitude        = 0.1f,
            DampingSharpness = 1.6f,
            NoiseFrequency   = new Vector3(10, 10, 0),
            AffectRotation   = true,
            MaxRotationAngle = 10,
        });
    }
});
```

### 8.3 持续射击震动（加特林类武器）

```csharp
private float shakeTimer = 0f;

private void OnUpdate(float delta) {
    if (!isFiring) return;
    shakeTimer -= delta;
    if (shakeTimer <= 0 && IsLookGPO()) {
        shakeTimer = 0.1f; // 比震动 Duration(0.15f) 短，保证连续
        MsgRegister.Dispatcher(new CM_Camera.ShakeCamera() {
            Duration = 0.15f, Magnitude = 0.06f, DampingSharpness = 3.0f,
            NoiseFrequency = new Vector3(15, 15, 0), AffectRotation = false,
        });
    }
}
```

### 8.4 技能/瞄准镜推近效果

```csharp
// 进入瞄准
iGPO.Dispatcher(new CE_Camera.SetCameraOffset { Offset = new Vector3(0f, 0f, 3f), LerpRate = 5f });

// 退出瞄准
iGPO.Dispatcher(new CE_Camera.SetCameraOffset { Offset = Vector3.zero, LerpRate = 3f });
```

## 十、开发规范

### 10.1 必须遵守

1. **镜头震动触发条件**：判断武器的 `iGPO` 是否是当前镜头跟随的 `LookGPO`（通过订阅 `CM_GPO.AddLookGPO` 跟踪）。**不要用 `iGPO.IsLocalGPO()`**，因为观战模式下 LookGPO 是被观战角色而非本地角色。
2. **目标点必须走镜头中心射线**：禁止直接使用 `fireBox.forward * distance`
3. **镜头是纯客户端系统**：不要在 Server 端添加任何镜头逻辑
4. **不要直接操作 CameraEntity 节点**：所有交互通过消息总线
5. **不要直接引用 CameraShake/CameraRota 等组件实例**

### 10.2 禁止行为

- ❌ 在非本地玩家 GPO 上触发镜头震动
- ❌ 跳过镜头系统直接写 `Camera.main.transform.position`
- ❌ 每帧发送 ShakeCamera（会重置持续时间，改用计时器控制间隔）
- ❌ 将 `cameraHDelta`、`lookGPO` 等状态字段直接在外部读写
- ❌ 在 Update 里直接修改 `CameraEntity.Shake.localPosition`
