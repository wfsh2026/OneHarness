# 游戏模式系统 参考文档

> 适用场景：新增游戏模式（如坦克大战、飞机大战）、扩展模式内逻辑（积分、回合、胜负判定）、调整模式生命周期

---

## 系统概述

模式系统分为三层：
- **ModeData**：静态全局数据，保存当前模式类型、游戏状态、配置参数
- **ServerModeSystem**：服务端模式管理器，根据 `ModeData.PlayMode` 动态挂载模式专属组件
- **ClientModeSystem**：客户端模式管理器，结构与服务端对称，其子组件 `ClientModeMainLoop` 接收服务端状态广播，驱动 UI 和本地状态机

---

## 核心类结构

### 服务端

| 类名 | 职责 |
|------|------|
| `ServerModeSystem` | 模式顶层 System，监听 `SM_Mode.StartMode`，注册通用组件+模式专属组件 |
| `ServerModeMainLoop` | 回合管理、状态机、网络广播（**底层，不含业务概念**） |
| `ServerModeHero` | 英雄模式扩展组件：AI 英雄配置、英雄数据初始化、武器技能战报（**独立 ComponentBase**） |

| `ServerModeScore` | 积分管理 |
| `ServerModeTimer` | 回合计时 |
| `ServerModeClockSync` | 服务器时间同步 |
| `ServerModeCreateAI` | 模式内 AI 生成管理 |
| `ServerModeDropItem` | 击杀掉落物品 |

### 客户端

| 类名 | 职责 |
|------|------|
| `ClientModeSystem` | 客户端模式顶层 System，结构与 `ServerModeSystem` 对称，注册客户端通用组件+模式专属客户端组件 |

## 游戏状态机

```
None
 └─► Wait（等待玩家加入）
       └─► WaitStartDownTime（达到最小人数，开始倒计时）
             └─► WaitRoundStart（等待回合开始）
                   └─► RoundStart（回合进行中）
                         └─► RoundEnd（回合结束）
                               ├─► WaitNextRound（多回合：等待下一回合）→ WaitRoundStart
                               └─► WaitModeOver（最终回合结束，等待结算）
                                     └─► ModeOver（模式结束，触发结算）
                                           └─► SaveReport（保存战报）
                                                 └─► QuitApp（退出）
```

> **实现注意**：`ServerModeMainLoop.OnUpdate()` 中，`ModeOver` 状态调用的是 `OnWaitSaveReport()`，`SaveReport` 状态调用的是 `OnWaitQuitAPP()`，函数名与状态名存在一级偏移，阅读代码时注意对照。

状态变更由服务端发起，通过以下消息同步到客户端：
- `Proto_Mode.Rpc_GameState` → 广播给所有客户端
- `Proto_Mode.TargetRpc_GameState` → 仅发给本地客户端（加入时补发当前状态）

## 核心流程

### 模式初始化

```
服务端启动
  └─► ServerModeSystem.OnAwake()
          ├─ MsgRegister.Register<SM_Mode.StartMode>(OnPlayMode)
          ├─ AddComponents()  ← 注册通用组件（Score、Time、CreateAI 等）
          └─ InitModeComponent()
                  └─ switch(ModeData.PlayMode):
                          case ModeEnum.XXX:
                              AddComponent<ServerXXXMode>();  ← 模式专属组件
                              AddComponent<...>();             ← 附加功能组件

[若模式类型尚未确定（PlayMode==None）]
  └─► SM_Mode.StartMode 事件到来后再次调用 InitModeComponent()
```

### 回合开始

```
服务端 ServerModeMainLoop:
  状态切换到 RoundStart
    └─► Rpc(Proto_Mode.Rpc_GameState { gameState = RoundStart })
            └─► 所有客户端 ClientModeMainLoop.SetGameState(RoundStart)
                    ├─ ModeData.SetGameState(RoundStart)
                    └─ MsgRegister.Dispatcher(CM_Mode.SetGameState { GameState=RoundStart })
                            └─► 所有监听 CM_Mode.SetGameState 的组件响应
                                （如 ClientAIMoveForDrive 在 RoundEnd 时停止移动音效）
```

### 积分更新

```
服务端 ServerModeScore:
  有人得分 → Rpc(Proto_Mode.Rpc_Score { playerId, score, continueScore })
    └─► 客户端 ClientModeMainLoop.OnRpcScoreCallBack()
            ├─ 更新 characterDataDic[playerId].Score
            ├─ MsgRegister.Dispatcher(CM_Mode.UpdateCharacterScore)  → UI 更新
            └─ OnTeamScoreChange(teamId)
                    └─ MsgRegister.Dispatcher(CM_Mode.TeamScoreUpdate)  → 队伍积分 UI
```

### 模式结算

```
服务端:
  最终回合结束
    └─► TargetRpc(Proto_Mode.TargetRpc_VSModeWarEnd)  → 本地客户端
            └─► 客户端 OnVSModeWarEndCallBack()
                    ├─ 更新最终数据（击杀数、总分、死亡数）
                    └─ MsgRegister.Dispatcher(CM_Mode.ShowWarEndUI)  → 显示结算界面

    └─► TargetRpc(Proto_Mode.TargetRpc_VSModeWarEndWinTeamList)
            └─► 客户端 OnVSModeWarEndWinTeamListCallBack()
                    └─ MsgRegister.Dispatcher(CM_Mode.WinTeamList)  → 显示胜队

状态切换到 ModeOver
  └─► 客户端 ClientModeMainLoop:
          └─ DeltaModeOver() 倒计时 10 秒后 → ModeOver()
                  └─ MsgRegister.Dispatcher(CM_Mode.SaveData)  → 保存战报
```

### 模式专属组件的标准结构

所有模式专属组件的统一写法：

```csharp
public class ServerXXXMode : ComponentBase {
    private List<SE_Mode.PlayModeCharacterData> characters;
    private ModeData.GameStateEnum gameState = ModeData.GameStateEnum.None;

    protected override void OnAwake() {
        // 1. 注册状态变化 - 响应回合开始/结束
        Register<SE_Mode.Event_GameState>(OnSetGameState);
        // 2. 注册玩家加入 - 新角色加入时初始化（装备武器、注册死亡事件等）
        Register<SE_Mode.Event_AddCharacterFinish>(OnAddCharacterFinish);
        // 3. 注册出生点请求
        MsgRegister.Register<SM_Mode.GetStartPoint>(OnGetStartPointCallBack);
        // 4. 注册模式启动 - 拉取出生点数据
        MsgRegister.Register<SM_Mode.StartMode>(OnStartModeCallBack);
    }

    protected override void OnStart() {
        base.OnStart();
        AddUpdate(OnUpdate);
    }

    protected override void OnClear() {
        characters = null;
        RemoveUpdate(OnUpdate);
        Unregister<SE_Mode.Event_GameState>(OnSetGameState);
        Unregister<SE_Mode.Event_AddCharacterFinish>(OnAddCharacterFinish);
        MsgRegister.Unregister<SM_Mode.GetStartPoint>(OnGetStartPointCallBack);
        MsgRegister.Unregister<SM_Mode.StartMode>(OnStartModeCallBack);
    }

    private void OnSetGameState(ISystemMsg body, SE_Mode.Event_GameState ent) {
        gameState = ent.GameState;
        if (ent.GameState == ModeData.GameStateEnum.RoundStart) {
            OnGameStart();
        }
    }

    private void OnStartModeCallBack(SM_Mode.StartMode ent) {
        // 拉取角色列表和出生点数据
        Dispatcher(new SE_Mode.Event_GetCharacterList {
            CallBack = list => { characters = list; }
        });
    }

    private void OnAddCharacterFinish(ISystemMsg body, SE_Mode.Event_AddCharacterFinish ent) {
        var gpo = ent.Data.CharacterGPO;
        // 装备武器（通用写法）
        gpo.Dispatcher(new SE_GPO.Event_ModeEquipWeapon {
            WeaponList = ent.Data.WeaponList,
        });
        // 注册死亡监听
        gpo.Register<SE_GPO.Event_SetIsDead>(OnCharacterDead);
    }
}
```

### 重生机制（通用模板）

**ServerVSReLifeMode / ServerGoldRushMode / ServerMobileControlPointMode** 均使用同一套倒计时重生模板：

```csharp
private struct RelifeData {
    public float relifeTimer;
    public IGPO relifeGpo;
}
private readonly List<RelifeData> relifeList = new List<RelifeData>();

// 死亡时加入重生队列
private void OnCharacterDead(ISystemMsg body, SE_GPO.Event_SetIsDead ent) {
    if (!ent.IsDead) return;
    relifeList.Add(new RelifeData {
        relifeTimer = RELIFE_DURATION,  // 各模式自定义秒数
        relifeGpo = body.GetGPO(),
    });
}

// 每帧倒计时
private void OnUpdate(float dt) {
    for (int i = relifeList.Count - 1; i >= 0; i--) {
        var relife = relifeList[i];
        relife.relifeTimer -= Time.deltaTime;
        if (relife.relifeTimer <= 0) {
            relifeList.RemoveAtSwapBack(i);
            RelifeGpo(relife.relifeGpo);
        } else {
            relifeList[i] = relife;
        }
    }
}

// 重生：重置位置 + 回满血 + 无敌时间
private void RelifeGpo(IGPO gpo) {
    // 重置到出生点
    Dispatcher(new SE_Mode.Event_ResetCharacterSpawnPoint {
        IsGameStart = false,
        CharacterGpo = gpo
    });
    // 回满血
    gpo.Dispatcher(new SE_GPO.Event_ReLife { UpHp = 9999999 });
    // 无敌保护
    MsgRegister.Dispatcher(new SM_Ability.PlayAbilityEffect {
        TargetGPO = gpo,
        MData = AbilityM_ProtectGPO.CreateForID(AbilityM_ProtectGPO.ID_GoldRushProtect)
    });
}
```

### 出生点管理方案

| 模式 | 方案 | 组件 |
|------|------|------|
| 探索、1V1 | 单队出生点列表，随机选取 | 在模式组件内直接管理 |
| 5V5 / 占点 / 夺金（队伍） | 按队伍分组，每人不重复选点，用完重置 | `ServerTeamModeSpawnPoint` |
| 夺金（个人） | 个人出生点，有最小安全距离 | `ServerPersonalModeSpawnPoint` |

**`ServerTeamModeSpawnPoint` 使用方式：**
- 只需在 `ServerModeSystem.InitModeComponent()` 里 `AddComponent<ServerTeamModeSpawnPoint>()`
- 它自动监听 `SE_Mode.Event_GetCharacterSpawnPoint` 和 `SE_Mode.Event_ResetCharacterSpawnPoint`
- 模式组件调用出生点时，Dispatcher 这两个事件即可

### 掉线处理（1V1 / VS 模式）

ServerVSMode 的掉线倒计时模式（掉线 30 秒后强制结束对局）：

```csharp
private const float OFFLINE_DURATION = 30f;
private Dictionary<long, Time> playerIdToOfflineTimer = new Dictionary<long, Time>();

// 监听在线状态变化
gpo.Register<SE_Network.Event_SetIsOnline>(OnSetIsOnlineCallBack);

private void OnSetIsOnlineCallBack(ISystemMsg body, SE_Network.Event_SetIsOnline ent) {
    if (ent.IsOnline) {
        playerIdToOfflineTimer.Remove(playerId);  // 重连，取消倒计时
    } else {
        playerIdToOfflineTimer[playerId] = new Time { value = OFFLINE_DURATION };
        Rpc(new Proto_Mode.Rpc_OnlineChange {
            playerId = playerId, isOnline = false, reconnectDuration = OFFLINE_DURATION
        });
    }
}
```

## 新增模式步骤

### 1. 注册模式枚举

```csharp
// ModeData.cs
public enum ModeEnum {
    ...
    ModeTankBattle = 17,  // 新增：坦克大战
}
```

### 2. 配置模式数据

```csharp
// ModeData.Init() 的 switch 中添加:
case ModeSet.Id_ModeTankBattle:
    modeData.Mode = ModeEnum.ModeTankBattle;
    modeData.RoundWinState = RoundWinStateEnum.TeamScoreTop;
    modeData.ScoreChannelDatas = new[] {
        new ScoreChannelData { Channel = GetScoreChannelEnum.KillAI, Score = 1 },
    };
    break;
```

### 3. 服务端模式组件

```csharp
// 新建 ServerTankBattleMode.cs
public class ServerTankBattleMode : ComponentBase {
    protected override void OnAwake() {
        // 订阅模式相关事件，如 AI 击杀计分
        MsgRegister.Register<SM_Mode.StartMode>(OnStartMode);
    }

    protected override void OnClear() {
        MsgRegister.Unregister<SM_Mode.StartMode>(OnStartMode);
    }

    private void OnStartMode(SM_Mode.StartMode ent) {
        // 模式开始时的初始化逻辑
        // 例如：生成坦克 AI、设置地图等
    }
}
```

### 4. 在 ServerModeSystem 注册

```csharp
// ServerModeSystem.cs → InitModeComponent() → switch:
case ModeData.ModeEnum.ModeTankBattle:
    AddComponent<ServerTankBattleMode>();
    AddComponent<ServerModeDropItem>();    // 按需
    AddComponent<ServerTeamModeSpawnPoint>(); // 按需
    break;
```

> 通用组件（`ServerModeMainLoop`、`ServerModeHero`、`ServerModeCharacter`、Score、Time、CreateAI 等）已在 `AddComponents()` 中统一注册，模式专属组件只需关注差异化逻辑。若该模式无英雄概念，在 `AddComponents()` 中去掉 `ServerModeHero` 注册即可。

### 5. 关键注意点

- **ModeData 是全局静态类**，`PlayMode`、`PlayGameState` 等属性在整个运行时共享，客户端和服务端都依赖它
- **`SM_Mode.StartMode`** 是服务端模式启动信号，如果 `ModeData.PlayMode` 还未设置就调用 `InitModeComponent`，则会等到该消息到来后再初始化
- **通用组件（Score、Time、CreateAI）** 已在 `AddComponents()` 中注册，模式专属组件只需关注差异化逻辑
- **`ServerModeMainLoop` 与 `ServerModeHero` 均需注册**：两者都是独立的 ComponentBase，必须同时在 `AddComponents()` 中注册。`ServerModeMainLoop` 是底层状态机，`ServerModeHero` 是英雄模式专属扩展。
- **不含英雄概念的模式**：只注册 `ServerModeMainLoop`，不注册 `ServerModeHero`，底层不受影响
