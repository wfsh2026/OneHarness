# 会话与交付物知识提取规则

## 用途

本规则用于从会话、开发交付物和工作流运行记录中提取可检索知识。

## 三层模型

```text
原始会话或执行过程 -> 摘要与决策提取 -> Wiki 知识
```

## 提取内容

可以提取：

- 已确认事实。
- 已确认决策。
- 稳定约束。
- 后续会重复查询的模块边界。
- 已验证的开发经验。
- 经验教训。
- 被否决方案。
- 意外发现。
- 风险和限制。

不能提取为稳定知识：

- 未确认想法。
- 临时讨论。
- 一次性调试过程。
- 尚未验证的猜测。
- 大段原始聊天。

## 写入位置判断

| 内容 | 写入位置 |
| --- | --- |
| 可跨项目复用的规则 | `AIGC/wiki/common/candidates/` |
| 目标项目稳定事实 | 目标项目 wiki |
| 本轮执行过程 | 目标项目工作流运行记录 |
| 未确认问题 | 目标项目 `open-questions.md` |
| 原始会话 | 目标项目会话记录或运行记录附件 |

## 来源要求

每条知识必须能追溯到来源：

- 用户请求。
- 工作流运行记录。
- 开发交付物。
- 验证记录。
- 已确认决策。

没有来源的信息不能进入 wiki。

## 知识碎片提取

当交付物中出现以下段落时，可以提取为知识碎片：

| 段落 | 默认类型 |
| --- | --- |
| 关键决策 | `decision` |
| 经验教训 | `lesson` |
| 被否决方案 | `rejected` |
| 已确认事实 | `fact` |
| 背景约束 | `context` |
| 意外发现 | `discovery` |

提取时必须遵守：

- 一条碎片只表达一个结论。
- 保留来源文件和任务信息。
- 未验证内容只能进入候选区或运行记录。
- 与目标项目绑定的内容写入目标项目 wiki，不写入通用 AIGC。
