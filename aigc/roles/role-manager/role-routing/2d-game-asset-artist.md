# 2D 游戏资源绘制师派发检索

## 命中

- 用户目标要求绘制、生成、重绘或补齐非 UI 的 2D 游戏静态资源。
- 主要产出是角色或怪物精灵、装备图标、物品图标、掉落图标、地图对象图标、资源点图标、静态 VFX 帧、攻击预警图、命中反馈图或状态表现图。
- 任务要求根据项目风格、用户确认样张、设计文档或资源清单生成可接入游戏的透明背景图片。
- 批量视觉资源目标按游戏内容类型组织，而不是按 UI 界面或 UI 状态组织。

## 不命中

- 主要产出是按钮底图、面板、徽章、头像框、弹窗装饰、HUD 图形、完整界面效果图或 UI 状态变体时，派发 2D UI 绘图师。
- 主要产出是怪物透明动画序列帧、spritesheet、循环预览、动画 manifest 或帧位规划时，回报角色管理员另行处理。
- 主要目标是把已绘制 UI 正式稿拆分成开发可用透明素材、黑白底预览、九宫格、状态变体、图集 manifest 或接入说明时，派发 UI 素材拆分师。
- 主要目标是 Shader、材质、粒子系统、动画事件或运行时表现接入时，回报角色管理员另行处理。
- 主要目标是批量导入、图集打包、资源处理工具或自动化校验工具时，回报角色管理员另行处理。
- 主要目标是玩法判定、战斗数值、AI 行为、掉落规则或场景接入时，回报角色管理员另行处理。

## 派发时必须给

- 目标资源类型、用途、资源粒度、尺寸或裁切要求、格式、透明背景要求、命名约定和允许分批交付方式。
- 批量任务必须给出资源清单、编号或资源 id、名称、优先级、每项成功标准和是否允许复用既有确认样张。
- 可选的用户确认样张、项目既有资源、风格文档、设计文档、外部资源目录或用户提供参考图；存在多个来源时必须给出读取顺序。
- 允许写入的资源输出目录、临时目录和禁止覆盖范围。
- 是否允许替换既有图片；允许替换时必须说明备份、版本后缀或旧图保留策略。
- 描述匹配度、风格一致性、资源规格、透明背景、主体完整性、重复图、缺失清单和后续接入验收方式。
