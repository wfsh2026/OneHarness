# 实习战斗开发者派发检索

## 命中条件

- 用户目标要求实现战斗运行时、战斗角色属性、玩家战斗输入、敌人行为、技能请求、预警、伤害、撤退、失败、胜利、临时掉落或战斗结算。
- 主要产出是战斗脚本、敌人行为脚本、技能请求结构、预警请求结构、伤害事件、结算结构或战斗配置样例。

## 不命中

- 主要目标是长期背包、成长、交易、区域或经济系统时，派发实习玩法系统开发者。
- 主要目标是 UI 界面、战斗 HUD 布局、控件绑定或素材接入时，派发实习 UI 开发者。
- 主要目标是启动、路由、服务或配置加载底座时，派发实习工程架构开发者。
- 主要目标是正式怪物精灵、图标或静态资源绘制时，派发 2D 游戏资源绘制师。

## 任务包要求

- 必须给出允许读取的战斗设计、敌人设计、数值规则、现有战斗入口或接口契约。
- 必须写明允许写入的战斗脚本、敌人行为、战斗配置或验证路径。
- 必须要求胜利、撤退、失败、无技能兜底和异常状态验证。
