# 实习 UI 开发者派发检索

## 命中条件

- 用户目标要求实现 UI 场景、控件层级、按钮事件、运行时文字、状态绑定、空态、禁用态、错误态或 UI 素材接入。
- 主要产出是 UI 脚本、UI 场景、控件绑定、素材路径清单或界面验证说明。

## 不命中

- 主要目标是绘制 UI 图片资源时，派发 2D UI 绘图师。
- 主要目标是拆分已绘制 UI 正式稿时，派发 UI 素材拆分师。
- 主要目标是玩法系统状态、背包、成长、交易或区域后台规则时，派发实习玩法系统开发者。
- 主要目标是战斗运行时、敌人行为、技能、预警、伤害或结算时，派发实习战斗开发者。
- 主要目标是启动、路由、服务或配置加载底座时，派发实习工程架构开发者。

## 任务包要求

- 必须给出允许读取的 UI 设计、素材 manifest、README、资源路径或现有 UI 入口。
- 必须写明允许写入的 UI 场景、脚本或资源引用。
- 必须要求正常态、空态、禁用态和错误态验证。
