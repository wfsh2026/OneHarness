# 实习玩法系统开发者派发检索

## 命中条件

- 用户目标要求实现非战斗逐帧玩法系统、成长、背包、装备、交易、区域、资源点、传送、推荐、配置 schema、有效样例或无效样例。
- 主要产出是玩法系统脚本、运行时数据结构、配置 schema、样例数据、错误码或系统验证说明。

## 不命中

- 主要目标是战斗逐帧运行、敌人行为、技能、预警、伤害、撤退或结算时，派发实习战斗开发者。
- 主要目标是 UI 界面、控件层级或 UI 素材接入时，派发实习 UI 开发者。
- 主要目标是启动、路由、全局服务或配置加载框架时，派发实习工程架构开发者。
- 主要目标是功能案和任务包拆分时，派发实习功能案设计者。

## 任务包要求

- 必须给出允许读取的设计文档、数值规则、配置规则、现有系统入口或接口契约。
- 必须写明允许写入的玩法脚本、配置 schema、样例数据或契约文档。
- 必须要求有效输入、无效输入、失败路径和配置引用验证。
