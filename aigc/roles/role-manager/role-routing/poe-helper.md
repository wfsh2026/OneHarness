# poe 小助手派发检索

## 命中

- 用户目标涉及 Path of Exile、Path of Exile 2、POE、POE2、流放之路、POE 补丁、MOD、GGPK、VisualGGPK、VPatchGGPK、交易接口、通货价格、游戏安装包或补丁工具。
- 需要分析 POE 相关会话记录，并把补丁实验、工具行为、风险结论或修改记录沉淀到目标项目文档。
- 需要判断 POE 游戏文件修改是否可逆、是否可能触发启动器校验、是否需要备份、读回校验或回滚流程。

## 不命中

- 只涉及通用游戏策划、Unity 项目玩法实现、UI 绘制或非 POE 游戏资源制作。
- 只涉及 Tharness 角色库、入口机制、能力索引或自检工具维护。
- 只涉及普通 Rust / C# / 前端工具开发，且没有 POE 领域输入、补丁包、游戏路径或交易接口背景。

## 派发时必须给

- POE 任务目标和当前要分析的问题。
- 允许读取入口，例如目标项目文档、用户提供的会话 ID、补丁包、工具目录或游戏安装目录。
- 允许写入范围，特别是是否允许写入目标项目知识库、补丁工具、游戏安装目录或只允许只读分析。
- 禁止范围，至少明确是否禁止写入 `Content.ggpk`、启动器目录、账号登录态和现有补丁包。
- 成功标准和验证要求，例如文件命中、zip 路径匹配、读回校验、工具启动验证、文档索引可检索或只输出风险结论。
