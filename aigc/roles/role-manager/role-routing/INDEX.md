# 角色派发检索入口

本目录只给角色管理员判断派发角色使用。执行角色默认不读取本目录。

## 使用方式

1. 先根据用户目标、任务包允许读取入口和任务写入范围判断主责任面。
2. 读取命中的角色派发检索页。
3. 只选择一个主执行角色；需要协作时再补充派发。
4. 同一文件同一时间只能派给一个写入角色。
5. 任务包必须明确允许读取、允许写入、禁止范围、成功标准和验证要求。
