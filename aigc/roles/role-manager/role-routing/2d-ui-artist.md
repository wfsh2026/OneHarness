# 2D UI 绘图师派发检索

## 命中

- 用户目标要求绘制、生成、重绘或补齐 2D UI 图片资源。
- 主要产出是图标、按钮底图、面板、徽章、头像框、弹窗装饰、HUD 图形、九宫格面板或 UI 状态变体图片。
- 主要产出是完整界面效果图、页面级 UI 参考图、整屏流程稿、系统弹窗组或 UI 状态页组。
- 任务要求根据描述或参考图生成可供后续接入的图片资源。
- 用户要求批量补齐一组 UI 视觉参考图，且主要交付物仍是静态图片资源。

## 不命中

- 主要目标是 UI 布局、交互、数据展示、界面状态流或资源接入时，回报角色管理员另行处理。
- 主要目标是把已绘制 UI 正式稿重绘拆分成开发可用透明素材、黑白底预览、九宫格、状态变体、图集或 manifest 时，派发 UI 素材拆分师。
- 主要目标是把已绘制的多帧角色精灵表、动作帧表或 UI 动画帧表拆分为像素级对齐的独立透明帧 PNG 时，派发 UI 素材拆分师。
- 主要目标是 Shader、材质、粒子、动画事件或动态表现接入时，回报角色管理员另行处理。
- 主要目标是批量导入、切图流水线、图集打包或资源处理工具时，回报角色管理员另行处理。

## 派发时必须给

- 目标资源类型、用途、资源粒度、尺寸、格式、透明背景要求、状态变体和命名约定。
- 批量任务必须给出资源清单、编号、名称、优先级、每项成功标准和是否允许分批交付。
- 完整界面或整屏流程稿必须给出界面职责、核心信息层级、必要控件、禁用信息和不可遮挡区域。
- 可选的项目参考图、风格文档、外部资源目录或用户提供参考图；存在多个来源时必须给出读取顺序。
- 允许写入的资源输出目录。
- 禁止覆盖范围和是否允许替换既有图片。
- 是否要求中文命名；要求中文命名时必须给出中文命名约定。
- 描述匹配度、可选风格一致性、资源规格、文件存在性、批量缺失清单和后续 UI 接入验收方式。
