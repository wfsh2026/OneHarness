# UI 素材拆分师派发检索

## 命中

- 用户目标要求把已绘制 UI 正式稿拆成开发可用素材。
- 用户目标要求在不改变界面内容的前提下，按参考图样式重建干净 UI 元素并输出开发素材。
- 用户目标要求把框体、槽位、底板拆成可复用无字通用素材，并把文字、数字、图标或元素字形分离。
- 主要产出是 UI 素材包、透明参考重建 PNG、黑白底预览图、重组校验图、九宫格面板、状态变体、图集、素材 manifest 或接入 README。
- 主要产出是从已绘制的多帧角色精灵表、动作帧表或 UI 动画帧表中拆分开发可用的同尺寸透明帧 PNG。
- 任务要求从整屏 UI 图中识别面板、按钮、页签、图标框、物品槽、标签、进度条、装饰线或角花。
- 任务要求提供素材命名、尺寸、用途、状态、源图坐标、九宫格边距或 Godot 接入建议。
- 用户明确提到“素材拆分”“重绘拆分”“切图”“九宫格”“图集”“manifest”“界面元素拆分”“开发素材包”“黑白底预览”“像素级对准”“帧动画”“精灵表”“动作帧拆分”。

## 不命中

- 主要目标是绘制、生成、重绘或补齐 UI 图片资源时，派发 2D UI 绘图师。
- 主要目标是 UI 布局、交互、数据展示、状态流或资源接入到 Godot 场景时，回报角色管理员另行处理。
- 主要目标是批量导入工具、自动切图工具、图集打包工具或编辑器流水线开发时，回报角色管理员另行处理。
- 主要目标是 Shader、材质、粒子、动画事件或动态表现接入时，回报角色管理员另行处理。

## 派发时必须给

- 源 UI 正式稿路径、界面编号、界面职责、设计基准分辨率和对应 UI 文档入口。
- 允许读取的参考图、风格规则和已有素材目录。
- 允许写入的素材输出目录、命名约定、文件格式和是否允许覆盖。
- 需要拆分或参考重建的素材粒度，例如背景、主面板、子面板、按钮、页签、物品框、标签、进度条、图标、装饰件。
- 必须说明参考图截图片段只能作为中间分析素材，正式交付 PNG 需要去掉无关背景、相邻控件、动态文字和运行时数据，并保持参考图样式一致。
- 必须说明通用框体不得带字：按钮底板、物品槽、五行槽、标签底、头像框、进度条和存档字段行都要优先拆为无字空框，文字和数据字段交给运行时控件。
- 需要标注的状态变体，例如 normal、hover、pressed、disabled、selected、locked、warning、danger。
- 是否需要透明重绘素材、黑底预览、白底预览、重组校验图、manifest、README、九宫格边距、最小尺寸或 Godot 控件接入建议。
- 多帧动画素材任务必须给出或要求执行角色确认源图网格行列、帧序、输出尺寸、统一画布、统一缩放、统一偏移、Pivot 建议、是否删除辅助产物和正式目录只保留哪些文件。
- 派发时必须说明黑底图和白底图是素材元素检查图，不是完整界面效果图；其中不得出现任何字体内容、标题字标、字段名、数值或五行字形。
- 是否需要 `common_frame_purity_checked` 清单；派发时必须要求 `runtime_control`、`needs_manual_art`、`blocked` 项不得绑定 PNG 文件。
- 是否允许删除旧试切素材或覆盖已有素材。
- 必须说明不允许输出占位切片；无法干净参考重建的项只能记录为 `needs_manual_art` 或 `blocked`。
- 验收标准：文件存在性、尺寸、透明通道、黑白底像素级对准、重组校验图、九宫格可拉伸、通用框纯净度、运行时项无 PNG 绑定、命名一致性、manifest 可读性和后续 UI 接入可用性；多帧动画素材还必须验收固定网格/统一缩放/统一偏移、深色底无白底残留、正式目录无未要求保留的预览图/调试图/压缩包。
