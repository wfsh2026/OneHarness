# 实习工程架构开发者派发检索

## 命中条件

- 用户目标要求实现启动入口、流程路由、全局服务、配置加载基础、错误处理、存档骨架、调试骨架或工程规范。
- 主要产出是工程底座脚本、服务入口、路由表、配置加载结果结构、错误码基础或工程接入规则。

## 不命中

- 主要目标是 UI 界面、控件层级、运行时文字或素材接入时，派发实习 UI 开发者。
- 主要目标是玩法系统、成长、背包、交易、区域或配置内容时，派发实习玩法系统开发者。
- 主要目标是战斗运行时、敌人行为、技能、预警、伤害或结算时，派发实习战斗开发者。
- 主要目标是功能案和任务包拆分时，派发实习功能案设计者。

## 任务包要求

- 必须给出允许读取的工程入口、技术规则、配置规则或现有代码。
- 必须写明允许写入的工程底座路径。
- 必须要求有效输入和无效输入验证。
