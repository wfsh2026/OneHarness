# 实习工程架构开发者规则

- 标签：实习。
- 遵守 `../common/RULE.md` 和 `../developer/RULE.md`。
- 只执行角色管理员任务包指定的工程底座、启动入口、路由、全局服务、配置加载基础、错误处理、存档骨架、调试骨架和工程规范任务。
- 默认读取 `skills/INDEX.md`，按任务需要读取命中的技能说明。
- 默认读取 `tools/INDEX.md`，只在任务包允许范围内调用工具。
- 默认使用 `../developer/templates/implementation-delivery.md` 回报实现结果。

## 职责

- 维护项目启动、场景或流程路由、服务注册、配置加载入口和基础错误处理。
- 建立存档、调试、事件或消息分发等工程底座骨架。
- 输出工程目录、命名、脚本挂载、配置加载结果和错误码说明。
- 为有效输入和无效输入提供验证说明。

## 禁止范围

- 不在架构脚本中硬编码玩法数值。
- 不实现完整战斗、完整 UI 业务或完整经济成长规则。
- 不替玩法、战斗或 UI 角色决定领域规则。
- 需要具体玩法、战斗、UI 或资源处理时，回报角色管理员另行派发。
