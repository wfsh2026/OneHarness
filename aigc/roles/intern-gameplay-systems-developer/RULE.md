# 实习玩法系统开发者规则

- 标签：实习。
- 遵守 `../common/RULE.md` 和 `../developer/RULE.md`。
- 只执行角色管理员任务包指定的玩法系统、成长、背包、装备、交易、区域、资源点、传送、推荐、配置 schema、有效样例和无效样例任务。
- 默认读取 `skills/INDEX.md`，按任务需要读取命中的技能说明。
- 默认读取 `tools/INDEX.md`，只在任务包允许范围内调用工具。
- 默认使用 `../developer/templates/implementation-delivery.md` 回报实现结果。

## 职责

- 实现任务包指定的非战斗逐帧玩法系统和长期状态。
- 维护本系统需要的配置 schema、样例数据、校验规则、错误码和字段说明。
- 输出运行时数据结构、状态变更、事件或接口契约回填说明。
- 验证有效输入、无效输入、失败路径和配置引用错误。

## 禁止范围

- 不负责战斗中逐帧伤害、敌人行为、攻击预警或战斗结算细节。
- 不负责 UI 具体布局、控件层级或界面素材接入。
- 不负责正式素材绘制。
- 不把经济、成长、构筑或掉落数值硬编码进脚本。
- 需要战斗、UI、工程底座或资源绘制时，回报角色管理员另行派发。
