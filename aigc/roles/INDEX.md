# 角色库入口

本目录是 Tharness 的默认调度入口。所有任务先进入角色管理员，再由角色管理员根据任务目标、风险和写入范围派发给具体角色。

## 默认读取

1. `common/RULE.md`
2. `role-manager/RULE.md`
3. 读取 `common/autonomy-policy.md`，再按任务命中读取角色规则、派发资料与紧凑 `tools/INDEX.md`；完整执行说明渐进加载。

## 目录结构

| 路径 | 存放内容 |
| --- | --- |
| `common/` | 所有角色必须遵守的最小规则、主会话输出格式和通用交付模板。 |
| `role-manager/` | 角色管理员规则、角色派发检索、角色会话复活、问题路由、派发模板和回收模板。 |
| `developer/` | 执行角色通用规则和实现交付模板。 |
| `{dispatchable-role}/` | 可派发角色根目录只保留 `RULE.md`，技能说明放 `skills/`，工具说明放 `tools/`。 |
| `wiki-manager/` | wiki 管理员规则、wiki 管理技能和工具说明。 |
| `tharness-maintainer/` | Tharness 本体维护、版本、自检规则、维护技能和工具说明。 |

## 调度原则

自治、授权、合理假设、委派、任务包和验证分级统一遵守 `common/autonomy-policy.md`，本文件不复述其判断条件。开发能力统一路由到 `project-developer/` 的独立领域入口。

## 角色资料位置

角色相关规则、调用资料和方法卡都维护在 `AIGC/roles/` 下。需要形成多步骤执行方式时，由角色管理员基于角色库、用户输入、任务包允许读取入口和通用 wiki 组合任务包。

通用输出格式由 `common/session-visible-state.md` 维护；可复用模板放在各角色目录的 `templates/` 下。角色规则引用模板，不复制模板正文，避免多处规则漂移。

具体可派发角色目录的根目录只保留 `RULE.md`。`tools/INDEX.md` 是主会话可读的紧凑摘要契约；完整 skills 和具体工具操作说明只由实际执行者渐进读取。输入由任务与授权范围提供，输出遵守分级规则，边界和交接由路由资料维护。
