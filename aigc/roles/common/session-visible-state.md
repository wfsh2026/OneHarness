# 会话角色标识规则

## 权威规则

本文件是 Tharness 正式审计型输出四字段格式的唯一权威。其他规则或模板只引用本文件，不复制解释性约束。

正式派发回收、正式审查和中高风险验收必须使用 `【当前角色】`、`【主要职责】`、`【工作依据】`、`【详细信息】` 四字段格式。

普通问答、短结论、代码解释、过程消息、工具进度、计划、任务包和用户指定格式不强制使用固定格式。

## 固定格式

```text
【当前角色】{角色名称}
【主要职责】{当前角色在本次输出结果中承担的职责}
【工作依据】{实际读取或命中的规则文件、模板文件、用户确认输入、项目文件、验证依据或产物路径}

【详细信息】
{当前输出结果}
```

## 角色名规则

- 主会话输出结果的 `【当前角色】` 只能是 `角色管理员`。
- 被派发角色交付时，`【当前角色】` 填写被派发角色名。
- 执行角色名称可以出现在任务派发、工作依据、回收结果或内部执行记录中。
- 工具内部 Agent ID 只允许作为工具参数、日志归属或内部路由标识，不能作为用户可见角色名。

## 适用范围

必须使用固定格式：

- 正式角色派发回收与高风险执行角色交付。
- 正式审查、中风险或高风险验收、需要审计追溯的规则修订结果。

不强制使用固定格式：

- 普通问答、短结论、代码解释、过程消息、工具执行进度、临时同步、计划和任务派发包。
- 用户明确指定其他输出格式的结果。

## 禁止

- 禁止使用 `【详细内容】` 替代 `【详细信息】`。
- 禁止只输出字段值而省略 `【当前角色】`、`【主要职责】`、`【工作依据】`、`【详细信息】` 标签。
- 禁止调换四个固定字段的顺序。
- 禁止在主会话输出结果的 `【当前角色】` 之前输出任何内容。
- 禁止在主会话 `【当前角色】` 中写入任何被派发角色。
- 禁止把输出主题、文档类型、评审对象或任务标题写成 `【当前角色】`。
- 禁止用空泛依据，例如“相关文档”；必须列出实际依据。
- 禁止使用旧 AIGC 三段式作为 Tharness 当前输出结果格式。

## 上下文恢复

发生上下文压缩、会话恢复、长任务续接或只剩摘要上下文时，如果当前回复属于输出结果，必须重新读取或遵守本文件。

上下文压缩摘要必须保留：输出结果必须使用固定四字段格式；主会话 `【当前角色】` 只能是 `角色管理员`；被派发角色和工具内部 Agent ID 不等于主会话用户可见角色。
