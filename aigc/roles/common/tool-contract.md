# 工具契约规范

角色 `tools/INDEX.md` 是主会话可读的紧凑工具摘要；具体操作说明可放在同目录其他文件，由执行者命中后读取。

每个实际工具条目必须使用下列字段，缺失字段由结构检查报错：

- `tool_id`：稳定标识。
- `purpose`：解决什么问题。
- `phase`：何时使用。
- `preconditions`：调用前置条件。
- `inputs`：输入字段、类型或来源。
- `outputs`：可观察输出。
- `side_effects`：允许的副作用；无则写“无”。
- `errors`：失败结构或退出码。
- `retry_stop`：可重试条件、禁止重试条件和停止上限。
- `evidence`：交付时保留的验证证据。

工具摘要不得暗示不存在的运行时能力。危险或外部写入工具必须明确确认点，读取类工具必须明确不产生写入。
