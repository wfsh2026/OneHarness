# 实习版本功能分析员技能索引

执行时按最小上下文渐进读取：先读取角色 `RULE.md`，只有命中 Git 版本取证任务时才读取本索引和工具索引。

| 技能 | read_when |
| --- | --- |
| 版本范围取证 | 需要确认 base、target、merge-base、提交数量、merge、rename 和变更文件。 |
| 功能聚类审核 | 需要把分支名、提交标题和文件共现整理为待人工确认的功能目录。 |
| 确认后文档展开 | 已取得“目录已确认”证据，且任务包提供模板或文档约定。 |

## 最小执行顺序

1. 校验仓库与引用，不读取无关历史。
2. 先产出结构化证据和功能目录审核稿。
3. 未获得目录确认时停止，不提前生成详细开发功能文档。
4. 只对低置信度或工具失败项回报待确认，不扩展为代码审核。
