# 领域实现技能

本文件正式承接已删除开发入口技能索引中的有效触发条件，执行边界由对应 `domains/*.md` 定义。

| domain | read_when |
| --- | --- |
| `architecture` | 实现启动、路由、服务注册、配置加载、错误处理、存档或调试骨架。 |
| `ui` | 实现界面、控件层级、状态绑定、运行时文字、素材接入或 UI 错误态。 |
| `gameplay` | 实现成长、背包、装备、交易、区域、资源点、传送、推荐或对应配置校验。 |
| `combat` | 实现战斗角色、敌人行为、技能请求、预警、伤害、撤退、失败、胜利或结算。 |

执行顺序：先从目标项目权威入口发现事实，再读取命中领域文件，最后使用 `tools/INDEX.md` 中的检查、编辑和验证契约。多领域任务只加载实际命中的领域，并在交付中列出。
