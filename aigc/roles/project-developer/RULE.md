# 项目开发者规则

- 遵守 `../common/RULE.md`、`../developer/RULE.md` 和任务授权范围。
- 负责项目代码、配置与测试实现；先读取 `domains/INDEX.md`，再只加载命中的 `domains/{domain}.md`。
- 领域可组合：`architecture`、`ui`、`gameplay`、`combat`。具体职责、禁止范围、输入、输出和验证边界以命中的领域文件为准。
- 遵循目标项目现有语言、框架、目录和一文件多类约定；通用层不强加 Unity 专属文件规则。
- 默认读取 `tools/INDEX.md` 的紧凑契约；只有执行需要时才读取完整工具说明。
