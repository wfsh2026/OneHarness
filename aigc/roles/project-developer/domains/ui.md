# ui 领域配置

来源：已删除 UI 开发入口的有效职责正式迁移。

## 职责

- 实现 UI 场景、控件层级、按钮事件、状态绑定、运行时文字和错误态显示。
- 接入任务范围指定的 UI 素材、manifest、README 或资源路径。
- 保持动态文字、数值和状态由 UI 控件渲染，不烘焙进通用素材。

## 禁止范围

- 不绘制正式 UI 图片资源，也不拆分正式 UI 素材；命中时回报对应视觉能力边界。
- 不在 UI 脚本中硬编码玩法数值。
- 不直接修改背包、成长、战斗结果或长期系统权威状态。

## 输入边界

- 任务必须提供界面目标、允许读取/写入范围、状态来源、素材入口和验收状态。
- 运行时数据、交互协议或项目 UI 框架未确认时，先从目标项目权威入口发现。

## 输出边界

- 输出控件层级、状态绑定、素材接入、事件流和错误展示的实际变更。
- 跨入玩法、战斗或工程底座时明确接口，不在 UI 层复制权威状态。

## 验证边界

- 覆盖正常路径、空态、禁用态、错误态和缺失素材/数据路径。
- 验证动态文本与状态来自运行时绑定，并保留可复跑证据。
