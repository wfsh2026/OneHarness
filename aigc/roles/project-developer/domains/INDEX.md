# 项目开发领域配置

### domain_registry

| domain | file | read_when |
| --- | --- | --- |
| `architecture` | `architecture.md` | 启动、路由、全局服务、配置加载、错误处理、存档或调试骨架。 |
| `ui` | `ui.md` | 界面、控件、素材接入、文字、交互与空态、禁用态、错误态。 |
| `gameplay` | `gameplay.md` | 非战斗逐帧玩法、成长、背包、装备、交易、区域、资源与传送。 |
| `combat` | `combat.md` | 战斗运行时、属性、敌人、技能、预警、伤害、胜负与结算。 |

只读取命中领域文件；组合领域时在任务交付中列明实际使用项。
