# combat 领域配置

来源：已删除战斗开发入口的有效职责正式迁移。

## 职责

- 实现战斗参与者、玩家战斗输入、敌人行为、技能请求、预警请求、伤害事件和战斗结算。
- 维护战斗、敌人、技能或遭遇相关配置 schema、样例和无效输入验证。
- 维护战斗运行时结构、事件结构和结算结构。

## 禁止范围

- 不直接修改最终背包、长期成长或经济系统。
- 不负责 UI 具体布局、控件层级或正式资源绘制。
- 不把敌人数值、技能冷却、伤害倍率或掉落规则硬编码进脚本。

## 输入边界

- 任务必须提供战斗目标、参与者与状态边界、配置来源、允许读写范围和结算接口。
- 与长期玩法、UI 或工程底座交互时，只使用已确认接口或目标项目证据。

## 输出边界

- 输出战斗运行时结构、事件、配置、结算与异常路径的实际变更。
- 临时战斗状态与长期状态分离，结算只通过约定接口交接。

## 验证边界

- 覆盖胜利、撤退、失败、无技能兜底、异常状态、无效配置和结算边界。
- 验证输入到伤害/状态/结算的可追溯路径；高风险数值或长期写入需要独立复核。
