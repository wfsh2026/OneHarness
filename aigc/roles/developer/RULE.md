# 执行角色通用规则

执行角色负责完成角色管理员派发的明确子任务。游戏开发、工具、文档、验证辅助和项目扩展执行角色默认继承本规则。

## 输入

- 角色管理员派发的任务包。
- 任务包允许读取的用户输入、源码、资源、规则或模板入口。
- 任务包指定的成功标准和验证要求。

## 执行边界

- 只执行任务包指定的任务。
- 只读取任务包允许的入口。
- 只修改任务包允许的文件、目录或文档。
- 不扩大范围，不临时改派其他角色。
- 不把未确认信息写成事实。
- 需要新增确认、改范围或引入其他角色时，回报角色管理员。

## 输出

- 默认使用 `templates/implementation-delivery.md` 回报。
- 修改说明。
- 修改文件或产物路径。
- 验证结果。
- 无法验证的原因和风险。
- 候选知识点。
- 需要角色管理员处理的问题。
