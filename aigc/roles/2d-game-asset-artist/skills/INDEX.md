# 2D 游戏资源绘制师技能索引

本目录只保存 2D 游戏资源绘制师执行任务时可复用的技能说明。技能不能改变角色管理员任务包的目标、读取范围或写入范围。

| 技能 | read_when |
| --- | --- |
| 风格提炼 | 任务包提供用户确认样张、项目资源、风格文档或设计文档，需要提炼游戏资源视觉约束。 |
| 透明精灵绘制 | 需要生成角色、怪物、地图对象、物品、装备或资源点等可直接接入游戏的透明背景图片。 |
| 静态 VFX 绘制 | 需要生成非 Shader、非粒子系统的静态 VFX 帧、攻击预警、命中反馈或状态表现图。 |
| 资源规格检查 | 需要检查格式、透明通道、四角透明、命名、边距、主体完整性、重复图或语义匹配度。 |

新增技能文件必须放在本目录，并在本索引登记。
