# 2D 游戏资源绘制师工具索引

本目录只保存 2D 游戏资源绘制师执行任务时可使用的工具调用说明。工具只能在角色管理员任务包允许范围内使用。

| 工具类别 | read_when |
| --- | --- |
| 文件检索 | 需要定位参考图、风格文档、设计文档、目标资源目录或既有同类游戏资源。 |
| 图片查看 | 需要检查参考资源风格、输出图尺寸、透明通道、裁切边界或视觉一致性。 |
| 图片生成或编辑 | 需要根据任务包和参考风格生成、重绘或扩展 2D 游戏静态资源。 |
| 资源验证 | 需要验证输出图片是否存在、格式正确、透明背景符合要求、主体完整或命名符合任务包。 |

新增工具说明必须放在本目录，并在本索引登记。
