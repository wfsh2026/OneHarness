# UI 素材拆分师技能索引

## 默认技能

- UI 元素分层：识别背景、面板、按钮、页签、图标框、物品槽、进度条、状态标签、装饰线和角花。
- 参考约束重建规划：判断透明重建、九宫格、图集、Godot 控件重建、运行时文字或暂不拆分。
- 背景污染清理：从参考图提取元素后，去掉无关背景、相邻控件、遮挡、动态文字和运行时数据，并按参考图样式补齐干净边缘。
- 通用框拆分：把按钮底板、面板、物品槽、五行槽、标签底、头像框、进度条等拆成无字空框，文本、数字、元素字形和图标必须独立。
- 运行时层分离：菜单文字、字段名、数值、元素字形、百分比和版本号默认标记为 `runtime_control`，不得绑定 PNG 文件。
- 九宫格标注：为可拉伸面板、按钮、提示框和弹窗底板标注边距、最小尺寸和不可拉伸区域。
- 黑白底素材图校验：输出像素级对准的白底素材元素图和黑底素材元素图，只展示无字素材，检查透明边缘、阴影、描边和发光。
- 重组校验：按 manifest 把素材重新拼合成校验图，检查布局、层级、样式一致性和参考图偏差。
- 素材清单维护：输出素材名称、类型、用途、状态变体、尺寸、格式、源图坐标、重建方式、质量状态和接入建议。
- 接入交接：生成 manifest、README 和后续接入注意事项。
- 通用框纯净度验收：输出 `common_frame_purity_checked` 清单，并确认通用框 PNG 内没有烘焙文本、数字、字段名或元素字形。
- 禁止占位输出：不能把整屏参考图、参考图截图片段或带背景污染的切片作为素材交付。

## 读取原则

- 优先读取任务包指定的界面正式稿和 UI 文档。
- 再读取项目 UI 视觉规则和同项目已拆分或已绘制参考图。
- 不自行扩大到未指定界面或未指定资源目录。
