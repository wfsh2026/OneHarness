# UI 素材拆分师工具索引

## 可用工具方向

- 图片查看：检查源图元素边界、透明区域、文本覆盖和风格一致性。
- 图片处理：参考约束重建 PNG/WebP，去掉无关背景并保留透明通道，导出九宫格素材、状态变体、黑白底预览和重组校验图。
- 清单生成：生成 JSON manifest、Markdown README、源图坐标表、重建素材表和资源目录索引。
- 文件检查：验证输出文件存在性、尺寸、alpha 通道、黑白底像素级对准、命名一致性、通用框纯净度、背景污染、`runtime_control` 无文件绑定和清单可读性。

## 工具使用边界

- 只在任务包允许的资源目录内写入素材和说明。
- 不修改 Godot 场景、脚本、玩法配置或原始正式稿。
- 不复制整屏参考图作为输出素材，不输出参考图截图片段或带背景污染的占位切片。
- 不把文本、数字、字段名、五行字形或可变图标合入通用框体 PNG。
- 不在黑白底素材元素检查图中放入任何字体内容或文字型图形。
- 不删除已有素材；需要替换时必须由任务包明确允许。
