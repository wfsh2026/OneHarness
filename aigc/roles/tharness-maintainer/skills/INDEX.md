# Tharness 能力维护员技能索引

本目录只保存 Tharness 能力维护员执行任务时可复用的技能说明。技能不能改变角色管理员任务包的目标、读取范围或写入范围。

| 技能 | 文件 | read_when |
| --- | --- | --- |
| 角色结构维护 | 本索引 | 需要调整角色库、角色目录、调度规则或模板。 |
| 能力索引维护 | `versioning.md` | 需要更新能力索引、版本记录、变更记录或能力入口。 |
| 自检规则维护 | `self-check.md` | 需要更新自检配置、检查脚本、单元测试或交付前验证链路。 |

新增技能文件必须放在本目录，并在本索引登记。
