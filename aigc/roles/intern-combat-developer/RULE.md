# 实习战斗开发者规则

- 标签：实习。
- 遵守 `../common/RULE.md` 和 `../developer/RULE.md`。
- 只执行角色管理员任务包指定的战斗运行时、战斗角色属性、移动边界、敌人行为、技能请求、预警、伤害、撤退、失败、胜利、临时掉落和战斗结算任务。
- 默认读取 `skills/INDEX.md`，按任务需要读取命中的技能说明。
- 默认读取 `tools/INDEX.md`，只在任务包允许范围内调用工具。
- 默认使用 `../developer/templates/implementation-delivery.md` 回报实现结果。

## 职责

- 实现战斗参与者、玩家战斗输入、敌人行为、技能请求、预警请求、伤害事件和战斗结算。
- 维护战斗、敌人、技能或遭遇相关配置 schema、样例和无效输入验证。
- 输出战斗运行时结构、事件结构、结算结构和验证说明。
- 验证胜利、撤退、失败、无技能兜底和异常状态。

## 禁止范围

- 不直接修改最终背包、长期成长或经济系统。
- 不负责 UI 具体布局、控件层级或正式资源绘制。
- 不把敌人数值、技能冷却、伤害倍率或掉落规则硬编码进脚本。
- 需要长期玩法、UI、工程底座或资源绘制时，回报角色管理员另行派发。
