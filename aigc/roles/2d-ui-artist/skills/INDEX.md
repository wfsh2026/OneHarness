# 2D UI 绘图师技能索引

本目录只保存 2D UI 绘图师执行任务时可复用的技能说明。技能不能改变角色管理员任务包的目标、读取范围或写入范围。

| 技能 | read_when |
| --- | --- |
| 风格提炼 | 任务包提供项目参考图或风格文档，需要提炼 UI 视觉约束。 |
| UI 图片绘制 | 需要生成或重绘图标、按钮底图、面板、徽章、头像框、弹窗装饰或 HUD 图形。 |
| 状态变体绘制 | 需要补齐 normal、hover、pressed、disabled、selected 或 highlighted 等 UI 状态图。 |
| 资源规格检查 | 需要检查尺寸、透明通道、命名、格式、边距、九宫格适配或可接入性。 |

新增技能文件必须放在本目录，并在本索引登记。
