# poe 小助手技能索引

本目录保存 poe 小助手可复用的 POE 领域处理方法，只记录通用流程、检查项和风险边界，不记录具体项目路径、会话历史、本地实验结论或某次补丁包事实。

## 当前技能

| 技能 | 入口 | 适用场景 |
| --- | --- | --- |
| Modes 落地修改 | `modes-landing.md` | 需要把 POE / POE2 mode、mod、补丁 zip 或替换文件落到游戏内容包内部路径，并判断 VisualGGPK、GGPK、bundle、shader、fxgraph 写入方式时。 |
| 目录与内容包分析 | `content-package-analysis.md` | 需要分析 POE / POE2 安装目录、游戏内容包、GGPK 内部索引、bundle 资源路径、安装包变更对比或后续检索数据库时。 |

## 使用规则

- 先判断任务属于只读分析、可逆修改还是高风险写入。
- 需要形成事实沉淀时，通用方法留在本角色技能；具体路径、版本、文件名、计数、工具位置和验证结果写入目标项目知识库。
- 对无法确认的工具行为、补丁生效状态或内容包结构，必须标记为待确认，不得写成已确认。
